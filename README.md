# ontology-editor

건물 온톨로지(Turtle, `.ttl`)를 브라우저에서 열어 보고 고치는 화면입니다.

지금은 뼈대만 있습니다. 파일을 열어서 접두사 선언을 표로 보여 주는 데까지 됩니다.
삼중항을 읽거나 고쳐서 저장하는 기능은 아직 없습니다.

온톨로지 정본은 이 저장소가 아니라 `ieum-pipeline/data/ontology/` 에 있습니다.

## 돌리는 법

```bash
npm install
npm run dev        # http://localhost:5174
```

백엔드가 없어서 파일을 브라우저 안에서만 읽습니다. 서버를 따로 띄우지 않아도 됩니다.

## 확인하는 법

```bash
npm test           # vitest: src 의 순수 로직
npm run e2e        # playwright: 화면이 파일을 받아 무엇을 보여 주는지
npm run build      # vue-tsc 타입 검사 + vite 빌드
```

`npm run e2e` 는 처음 한 번 브라우저를 받아야 합니다: `npx playwright install chromium`.

## 구조

| 자리 | 내용 |
|---|---|
| `src/lib/ttl.ts` | Turtle 에서 접두사 선언을 읽고, IRI 를 짧은 이름으로 줄입니다 |
| `src/App.vue` | 파일을 받아서 접두사 표를 그립니다 |
| `e2e/` | Playwright 테스트입니다. 픽스처 파일 없이 문자열을 그대로 넣습니다 |
