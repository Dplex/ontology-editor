# ADR-0042 층 이름은 에디터에서 넣는다

## 맥락

등급 0(공간 골격)은 "외곽선 있는 물리존 ≥ 85% · 층 이름 100%" 다(PRD 1.8, ADR-0040 의 제안안). 이름 없는 층이 하나라도 있으면 게이트 미달이라
[구축하기] 가 막히고, 재제출 항목은 "R0~R4·R6·R7 — 물리존 외곽선과 층 이름" 이다. 그런데 에디터에는 층 이름을 고칠 곳이 없어 BIM 을 다시 받는 것
말고는 길이 없었다. 합성 성수(성수에서 본 버릇을 심은 BIM)는 기초 층 하나가 이름이 없어 비율은 97.1% 인데도 구축하지 못했다. 기초 층처럼 사람이
이름만 넣으면 끝나는 경우에 재제출을 기다리는 것은 과하다.

## 결정

- **층별 요약 표에서 층 이름을 넣고 고친다**(편집 모드). 이름 없는 층은 [이름 넣기], 이름 있는 층은 [고치기], 고친 층은 출처 `편집` 과 [BIM 이름으로].
- **BIM 이름은 남긴다**(`Storey.bimName`, 빈 값일 수 있다). 고친 층은 편집 파일(`storeyNames`)·리포트("층 이름 (없음) → 1F")·출처 표시가 이것을 본다.
  BIM 이름을 다시 넣으면 고친 것이 아니다.
- **빈 이름과 같은 건물의 같은 이름은 받지 않는다.** 같은 이름의 층은 탐색기 트리·층 파일에서 가를 수 없다.
- **게이트는 넣은 이름으로 판정한다**(ADR-0040 "판정은 지금 모델로"). 넣으면 [구축하기] 가 풀린다. 막는 글이 이유를 비율이 아니라 "층 이름 20/21(이름 없는 층 1개)"
  로 말하고 "층별 요약에서 넣을 수 있습니다" 를 붙인다.
- 되돌리기 한 번에 돌아온다. 그 층의 임시 저장본에 든다. TTL `rdfs:label` 과 GeoJSON 층 파일 이름이 넣은 이름이 된다.

## 고려한 다른 길

- **재제출만.** PRD 의 재제출 항목대로지만, 이름 하나 때문에 BIM 을 다시 받는 사이 구축이 멈춘다. 재제출 항목 표시는 그대로 둔다(BIM 을 고치는 것이 맞는 일이라).
- **이름 없는 층을 층 id 로 채워 내보내기.** 사람이 읽을 수 없는 이름이 탐색기에 뜬다.
- **등급 0 의 층 이름 조건을 빼기.** D1 결정 범위라 이 repo 가 정하지 않는다.

## 결과

- PRD 1.8 의 "층 이름" 은 BIM 요구로 남고, 에디터에서 보정할 수 있다는 점은 PM 확인 거리다(`needs-pm`).
- 되돌리려면 `src/lib/storey-name.ts`, `App.vue` 의 "층 이름" 묶음, edit-file 의 `storeyNames` 를 걷어낸다.
