# ADR-0054 용량 검증 Z-03 의 입력값과 판정

## 맥락

공조존 검증 여섯 규칙 중 Z-03(용량 초과)만 비어 있었다. 판정에는 두 값이 든다. 공간 쪽의 설계 급기 풍량과 설비 쪽의 정격 풍량이다.
PRD 는 이 값을 사이트가 설계한 것만 쓰라고 한다(OE-ZON-06). 에디터가 환기 횟수나 실 높이로 필요 풍량을 계산하면 그럴듯한 숫자로
잘못된 경고가 뜨기 때문이다.

가진 BIM 을 재 보면 표준 자리(`Pset_SpaceThermalDesign`)에 설계 풍량을 적은 파일은 하나도 없다. Revit MEP 공간은
`PSet_Revit_Mechanical - Airflow` 의 `Specified Supply Airflow` 로 낸다. Duplex MEP-2 는 방 24개 중 15개에 값이 있고, 병원 MEP 는 방
260개가 모두 0 이다. 이 값은 단위 없는 `IfcReal` 이다. 병원 MEP 의 `Actual Supply Airflow` 8.298946679549818 이 235 L/s 를 ft³/s 로
적은 값(235 ÷ 28.3168)이라서, Revit 이 내부 단위 그대로 적는다는 것을 알 수 있다.

설비의 정격 풍량은 용량(R21)으로 이미 읽고 있었지만 단위를 바꾸지 않은 날값이었다. TTL 은 그 값을 그대로 낸다.

## 결정

**입력값**

- 단위는 읽을 때 CMH 로 바꾼다. `IfcVolumetricFlowRateMeasure` 는 파일이 선언한 풍량 단위를 따르고, 선언이 없으면 m³/s 로 본다.
  풍량 단위는 대개 유도 단위(부피 ÷ 시간)라서 원소마다 배수를 지수만큼 곱한다(`units.ts` 의 `flowScale`).
- 단위 없는 `IfcReal` 은 `PSet_Revit_*` 세트에 있을 때만 ft³/s 로 읽는다. 다른 세트의 단위 없는 값은 단위를 모르니 읽지 않는다.
- 0 이하는 값이 없는 것으로 본다. Revit 은 넣지 않은 값을 0 으로 낸다.
- 설비의 정격 풍량은 `ratedAirflow` 에 따로 둔다. TTL 이 쓰는 `capacity` 는 바꾸지 않는다.
- 사람 값은 BIM 이 비운 곳만 채운다. 순서는 PRD 와 같다. 설계 풍량은 BIM 물리존 다음에 사람(공조존 또는 물리존)이고, 정격 풍량은
  BIM 다음에 사람이다. BIM 값이 있으면 입력 칸을 보이지 않는다.
- 합칠 때 설비 파일의 방이 건축 방에 흡수되면 설비 쪽 방의 설계 풍량을 남는 방으로 옮긴다. Revit 은 이 값을 설비 파일의 MEP 공간에
  적기 때문이다.

**공조존의 설계 풍량**

1. 담당 물리존이 모두 BIM 값을 갖고, 다른 공조존과 함께 담당하는 방이 없으면 그 합을 쓴다.
2. 아니면 사람이 공조존에 넣은 값을 쓴다.
3. 아니면 물리존 값(BIM 과 사람이 섞인 것)을 더한다.
4. 그래도 없으면 판정 불가다.

함께 담당하는 방이 있으면 방 값을 나눌 근거가 없어서 공조존 값만 받는다. 합은 냉방끼리, 난방끼리 더한 뒤 큰 쪽을 고른다. 방마다 큰
값을 골라 더하면 서로 다른 때의 정점이 섞이기 때문이다. 냉방·난방이 둘 다 없으면 Revit 값(냉방·난방을 가르지 않는 값)을 쓴다.

**판정**

- 판정 대상은 담당 공조존이 있는 VAV·FCU·실내기·공조기다. 여러 공조존에 급기하는 공조기는 뺀다(Q16). 말단은 담당 설비로 골라도
  판정하지 않는다.
- 설비마다 따로 잰다. 정격 풍량이 그 설비가 담당하는 공조존들의 설계 풍량 합보다 작으면 경고다. 한 공조존을 FCU 두 대가 나눠 맡아도
  묶지 않는다(2026-10-13 결정, PRD 문장 그대로).
- 값이 없으면 경고가 아니라 판정 불가로 따로 센다. 무엇이 없는지(정격 풍량, 어느 공조존의 어느 방)를 한 줄에 적는다. 공조존 도구와
  반영 결과 리포트에 같은 줄이 나간다.

**R26**

정본 4.2 의 권장 요구로 옮겼다. 공조 대상인 방만 세고, 계단실·승강로는 해당 없음이다. 종류를 모르는 방은 비공조인지 몰라 빼지
않는다. IDS 는 비공조 방을 가르지 못해 "일부만 옮겼다" 에 둔다.

## 결과

- 가진 BIM 은 대부분 판정 불가로 나온다. 표준 Pset 이 없어서다. 값이 없다는 것과 무엇이 없는지는 보인다.
- Revit 매개변수를 냉방·난방 중 어디로 매핑할지는 확인하지 않았다(U7). 그래서 고객사 요청 문구에는 표준 자리만 적고, Revit 매개변수
  이름은 정해 주지 않는다.
- 공조존을 FCU 여럿이 나눠 맡으면 각각 경고가 뜬다. 현장에서 흔하면 묶어 재는 쪽으로 바꾼다.
- 생성 전 검증 화면(OE-GEN-03)은 아직 없다. 생기면 같은 `zoneChecks` 를 싣는다.
- 단위를 바꾼 정격 풍량은 TTL 에 내지 않는다. 받는 쪽이 `ex:nominalAirFlowRate` 의 단위를 정하면 그때 맞춘다.
