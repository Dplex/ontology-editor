# ADR-0039 층별 임시 저장본·편집 잠금은 서버 파일

## 맥락

임시 저장본은 층마다 하나이고(OE-WF-03), 층에 들어가면 묻지 않고 열리며(OE-WF-02), 폐기하면 반영된 레이아웃으로 돌아간다(OE-WF-04). 사람의 것이 아니라
층의 것이라 다른 편집 권한자가 이어 편집한다(OE-COM-03). 편집 잠금은 층 단위이고 [편집 종료]·[반영하기]·[임시 저장] 뒤 떠나면 바로 풀린다(OE-COM-05·06).
지금까지는 저장 위치(D-INT)가 정해지기 전이라 브라우저(localStorage)가 임시 저장본이었다(OE-HIST-05). 2026-10-09 인터뷰에서 "서버 파일로, 층마다 하나",
"로그와 층 잠금 둘 다" 로 정했다(ADR-0037·0038 과 같은 서버 파일 방식).

## 결정

- **임시 저장본은 `data/.drafts/<열쇠>/<층>.json`**(층 조각 편집 파일 + 저장한 사람·시각). 조각은 지금처럼 층 id 와 층이 없는 편집의 건물 조각(`*`)으로
  가른다(storey-drafts.ts, ADR-0014). [임시 저장] 은 브라우저와 서버 둘 다에 쓰고, 열 때는 서버 것이 브라우저 것보다 앞선다. 브라우저 사본은 서버에 닿지
  못할 때의 복구용이다. 반영하면(ADR-0037) 그 건물의 임시 저장본을 지운다.
- **[임시 저장본 폐기]** 는 지금 층에 임시 저장본이 있을 때만 보이고 한 번 더 묻는다. 서버·브라우저의 그 층 조각을 지우고, 그 층을 반영된 버전의
  조각으로(반영 전이면 BIM 그대로) 갈아 끼운다.
- **잠금은 `data/.locks/<열쇠>/<층>.json`**(사람·만료). 편집 모드에서 보고 있는 층(한 층이면 그 층, "모든 층" 이면 전부)을 잡는다. 2분짜리를 1분마다
  다시 잡아 늘이고, [편집 종료]·층 바꾸기·창 닫기(`pagehide`, keepalive)에 푼다. 브라우저가 죽어 못 풀면 2분 뒤 저절로 풀린다. 남이 잡은 층이면 서버가
  409 와 그 사람을 주고, 화면은 보기로 돌려 "OOO님이 1F를 편집 중입니다" 를 보인다. 보기는 막지 않고 다른 층은 막지 않는다. 남의 잠금은 풀지 못한다.
- 사람 목록이 없는 곳(서버 없이 손으로 연 파일)은 예전처럼 브라우저에만 남기고 잠그지 않는다.

## 고려한 다른 길

- **잠금을 화면이 열려 있는 동안 계속(만료 없이).** 브라우저가 죽거나 네트워크가 끊기면 영영 잠긴다. 2분이면 관리자가 파일을 지우지 않아도 풀린다.
- **사람마다 임시 저장본.** OE-COM-03 이 층의 것이라고 한다.
- **8084 저장본([편집 저장])을 임시 저장본으로 합친다.** 저장본은 건물 전체의 편집 파일이라 층마다 하나·층 잠금과 맞지 않는다. 지금은 둘 다 두고, 반영된
  버전보다 나중이면 저장본을 얹는다(ADR-0037).

## 결과

- 잠금은 사람 이름으로 잡아, 같은 사람이 두 창에서 같은 층을 고치는 것은 막지 않는다.
- 되돌리려면 `src/server/floor-state.ts` 와 `data-catalog.ts` 의 연결, `App.vue` 의 `syncDraftsToServer`·폐기·"층 잠금" 묶음을 걷어낸다.
