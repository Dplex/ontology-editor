# ADR-0027 공조존 경계 고치기

## 맥락

OE-ZON-04 는 공조존의 경계 다각형을 고칠 수 있어야 한다고 한다. 길은 둘이었다.

- 물리존처럼 3D 에 꼭짓점 손잡이를 달고 끌기·넣기·지우기
- 경계를 처음부터 다시 그리기

처음(2026-10-09)에는 다시 그리기만 넣었다. 공조존은 물리존 몇 개를 묶는 단위라 꼭짓점이 많지 않다고 봤다.
2026-10-12 검토에서 "모서리 하나를 1m 넓히려고 꼭짓점 8개를 다시 찍는 것" 은 받아들이기 어렵다고 해서(#154) 손잡이도 넣었다.

다시 그리거나 꼭짓점을 옮긴 뒤 담당 물리존을 어떻게 정할지도 정해야 했다. 물리존을 골라 만든 공조존(ADR-0026)은 담당을 사람이 고른 것인데,
경계를 고쳤는데도 그 목록을 두면 바닥과 담당이 어긋난다. 예를 들어 사무실 하나를 고른 공조존을 창고까지 걸치게 고치면,
창고가 공백(Z-01)으로 남고 중복(Z-02)도 바닥 기준이라 틀린 답을 낸다.

## 결정

- 공조존 한 줄의 [경계 다시 그리기] 로 새 경계를 찍는다(Enter 마침, Esc 취소). 그리기 규칙은 [경계를 그려 만들기] 와 같다
  (셋 이상, 변 엇갈림 막음).
- 공조존 한 줄의 [꼭짓점 고치기] 를 누르면 3D 에 그 경계의 손잡이가 달린다. 물리존 꼭짓점과 같은 손으로 고친다.
  - 손잡이를 끌어 옮긴다. 변이 엇갈리는 자리에는 놓지 않고 손잡이를 원래 자리로 돌린다
  - `[ ]` 로 꼭짓점을 짚고 방향키로 옮긴다. Insert 는 다음 꼭짓점과의 가운데에 넣고, Delete 는 지운다(셋은 남긴다)
  - Esc·[마치기], 또는 물리존·설비를 고르거나 그리기를 시작하면 끝난다
  - 바닥이 떨어진 조각 여럿인 공조존(떨어진 물리존을 골라 만든 것)은 어느 조각을 고치는지 모호해서 손잡이를 달지 않는다. 다시 그리기를 쓴다
- 어느 쪽으로 고쳐도 그 공조존은 그린 공조존(`drawn`)이 되고, 새 경계와 0.05㎡ 넘게 겹치는 물리존이 담당이다(ADR-0026 의 그린 공조존 규칙).
  몫(`spaceShares`)도 새로 잰다. 손잡이 편집은 바뀐 점들로 다시 그리기(`reshapeHvacZone`)를 부르는 것이라 규칙이 하나다.
- 새 경계와 겹치는 물리존이 없으면 막는다. 담당이 없는 공조존은 검증(Z-01·Z-05)에서 뜻이 없다.
- 담당 설비와 이름은 그대로 둔다.

## 결과

- 골라 만든 공조존을 고치면 "담당 물리존을 골라 만든 것" 이 아니게 된다. 되돌리기(Ctrl+Z)로 돌아온다.
- 공조존 손잡이는 물리존 손잡이와 같은 3D 손잡이(`setSpaceHandles`)를 쓰고, `src/App.vue` 의 `dropVertex`·`[ ]`·방향키·Insert·Delete 가
  공조존을 고치는 중이면 공조존 쪽(`moveZoneVertex`·`insertZoneVertex`·`deleteZoneVertex`, `src/lib/hvac-zone.ts`)으로 보낸다.
- 평면도에는 공조존 손잡이가 없다. 평면도가 물리존만 그리기 때문이다. 평면도에 공조존을 그리게 되면 같은 함수로 잇는다.
