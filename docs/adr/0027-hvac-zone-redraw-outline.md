# ADR-0027 공조존 경계 고치기

## 맥락

OE-ZON-04 는 공조존의 경계 다각형을 고칠 수 있어야 한다고 한다. 길은 둘이었다.

- 물리존처럼 3D·평면도에 꼭짓점 손잡이를 달고 끌기·넣기·지우기
- 경계를 처음부터 다시 그리기

물리존의 꼭짓점 편집은 3D 손잡이, 평면도 손잡이, `[ ]` 키보드, 꼭짓점 넣기·지우기가 모두 `space:` 표시와 물리존 id 에 묶여 있다.
공조존에 같은 것을 달려면 이 다섯 길을 공조존에도 열어야 한다. 커스텀존도 같은 이유로 손잡이 없이 나누기·합치기만 있다.

다시 그린 뒤 담당 물리존을 어떻게 정할지도 정해야 했다. 물리존을 골라 만든 공조존(ADR-0026)은 담당을 사람이 고른 것인데,
경계를 다시 그렸는데도 그 목록을 두면 바닥과 담당이 어긋난다. 예를 들어 사무실 하나를 고른 공조존을 창고까지 걸치게 그리면,
창고가 공백(Z-01)으로 남고 중복(Z-02)도 바닥 기준이라 틀린 답을 낸다.

## 결정

- 공조존 한 줄의 [경계 다시 그리기] 로 새 경계를 찍는다(Enter 마침, Esc 취소). 그리기 규칙은 [경계를 그려 만들기] 와 같다
  (셋 이상, 변 엇갈림 막음).
- 다시 그리면 그 공조존은 그린 공조존(`drawn`)이 되고, 새 경계와 0.05㎡ 넘게 겹치는 물리존이 담당이다(ADR-0026 의 그린 공조존 규칙).
  몫(`spaceShares`)도 새로 잰다.
- 새 경계와 겹치는 물리존이 없으면 막는다. 담당이 없는 공조존은 검증(Z-01·Z-05)에서 뜻이 없다.
- 담당 설비와 이름은 그대로 둔다.

## 결과

- 꼭짓점 하나만 옮기려 해도 경계 전체를 다시 찍는다. 공조존은 물리존 몇 개를 묶는 단위라 꼭짓점이 많지 않다고 보고 이 비용을
  받아들였다. 손잡이가 필요하다는 요청이 오면 아래처럼 바꾼다.
- 골라 만든 공조존을 다시 그리면 "담당 물리존을 골라 만든 것" 이 아니게 된다. 되돌리기(Ctrl+Z)로 돌아온다.
- 손잡이를 달기로 바꾸면 `src/App.vue` 의 `startHvacZoneOutline` 과 `hvacZoneOutline` 그리기 목적을 걷어내고, 물리존 꼭짓점 편집
  (`moveVertex`·`dropVertex`·`insertSpaceVertex`)을 공조존 id 로도 받게 고친다. `reshapeHvacZone`(`src/lib/hvac-zone.ts`)은
  손잡이 편집의 마지막 단계로 그대로 쓸 수 있다.
