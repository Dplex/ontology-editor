# ADR-0018 사람이 지정한 설비 소속은 기계 판정과 따로 둔다

## 맥락

OE-MAP-01 "사람의 소속 지정"(K17)은 기계가 확신하지 못하는 설비(소속 허용 거리로 붙었거나 소속이 없는 설비, 샤프트·승강로 안)만
사람이 소속 물리존을 정하게 한다. 사람 지정은 기계 판정과 따로 저장하고, 재판정 때 기계가 확신하는 단계(미배치, BIM 명시 소속,
외곽선 안)로 정해지면 그 값을 쓰고 사람 지정은 풀린다. 풀리면 "사람 지정 해제" 로 보이고, 편집 파일에 남아 불러올 때도 같은 순서로
판정한다(OE-HIST-03).

"풀린다" 를 지정을 지우는 것으로 만들면, 경계를 고쳐 지정이 풀린 뒤 Ctrl+Z 로 경계를 되돌려도 지정이 돌아오지 않는다. 경계 되돌리기
기록마다 설비의 지정을 따로 담아야 한다.

## 결정

**지정은 `Equipment.spaceSet` 에 두고, 설비를 옮기거나 사람이 지울 때만 없앤다.** 판정(`assignEquipment`)은 BIM 명시 소속 → 외곽선
안 → 사람 지정 → 소속 허용 거리 순이다. 기계가 확신하는 단계에서 정해지면 지정을 지우지 않고 쓰지 않기만 한다. 그 상태가 "사람 지정
해제" 이고 까닭(BIM 이 적은 소속 · 외곽선 안 · 지정한 물리존이 없어짐)과 함께 바뀐 내용에 보인다(`spaceSetState`).

- 경계·물리존 되돌리기가 지정을 따로 담지 않아도 된다. 판정이 다시 돌면 지정이 다시 쓰인다.
- 설비를 옮기면 지정이 지워진다(OE-EQP-12). 설비 되돌리기 기록에 지정을 담는다.
- 지정을 받을지는 `spaceAssignable` 이 가른다. 미배치·BIM 명시 소속·외곽선 안이면 까닭을 돌려주고 칸이 막힌다.

**편집 파일에는 `assignedSpaces: { id, spaceId }[]` 로 남는다.** 설비 줄(`equipment`)에 넣지 않은 것은 사람이 지정만 하고 설비를
옮기지 않은 경우가 대부분이라서다. 불러올 때 물리존·좌표를 다 얹은 뒤 지정을 두고 같은 판정을 거친다. 그 사이 기계가 확신하게 된
설비는 `ApplyResult.assignReleased` 로 화면에 알린다.

**GeoJSON 의 `spaceSource` 는 사람 지정이면 `edit` 이다.** ADR-0008 의 `bim`·`calc` 에 벽 `externalSource` 가 이미 쓰는 `edit` 을
더했다. TTL 의 `brick:hasLocation` 은 출처 없이 같은 방을 가리킨다.

## 고려한 다른 길

- **해제 때 지정을 지우고 까닭만 남기기**: 되돌리기에서 지정이 돌아오게 하려면 물리존·층 되돌리기 기록마다 설비 지정을 담아야 한다.
- **설비 줄(`equipment`)에 `space` 를 더하기**: 설비 줄은 "연 때와 달라진 설비" 라 지정만 한 설비도 거기 들게 되고, 다른 PR 들이
  같은 줄의 타입을 고치고 있다.

## 결과

- 지정한 방이 나중에 외곽선 안이 아니게 되면(그린 방을 지우면) 지정이 다시 쓰인다. 사람이 정한 값이 기계가 확신하지 못할 때 쓰인다는
  원칙과 같다.
- 5단계의 [소속 허용 거리] 설정(U6)과 6단계 동점(향), 샤프트·승강로 안 설비(Q12)는 이 결정 밖이다. 지금 판정은 허용 거리 5cm 고정이다.
