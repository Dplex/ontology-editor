# ADR-0017 새 벽 두께는 BIM 내벽 최빈값, 사이트 기본값과 스냅 거리는 브라우저 설정

## 맥락

OE-SPC-12 는 새로 긋는 벽의 두께를 1) 같은 층 BIM 내벽 두께의 최빈값 → 2) 사이트 기본값 → 3) 0.2m 순으로 정하라고 한다.
OE-SPC-13 은 문·창 스냅 거리(0.6m)를 사람이 고칠 수 있게 하라고 한다. 그 전에는 새 벽이 늘 0.2m 였고 스냅 거리는 코드의 상수였다.

가진 BIM 에서 "외벽이 아닌 벽" 의 두께를 세어 보니, Revit 의 마감벽(`Basic Wall:Interior - Furring (38 mm Stud)`, 0.05m)이
칸막이(`Interior - Partition (92mm Stud)`, 0.12m)만큼 많았다. 병원 건축 1층은 마감벽 292개, 칸막이 288개이고 Duplex 2층은
8개씩 같았다. 그대로 세면 새 칸막이가 0.05m 로 그어진다.

## 결정

**8cm 보다 얇은 벽은 내벽 최빈값에서 세지 않는다**(`LINING_MAX`). 마감벽(0.05m)과 화장실 칸막이(0.03m)가 여기에 든다.
에디터가 더한 벽, 외벽(`external` 이 true), 두께를 모르는 벽도 세지 않는다. 두께는 cm 로 반올림해 세고, 같은 수면 두꺼운 쪽이다.

| BIM | 층별 새 벽 두께 |
|---|---|
| AC20 | 0.24 · 0.3 |
| Duplex 건축 | 기본값 0.2(벽 없음) · 0.12 · 0.12 · 기본값 0.2 |
| 병원 건축 | 0.12 · 0.12 · 0.12 |
| Institute | 0.3 · 0.3 · 0.2 · 0.2 · 0.3 |
| 성수 건축 | 지하 0.3 · 지상 0.2 |

**사이트 기본값과 스냅 거리는 브라우저 설정이다**(`localStorage` 의 `oe-element-settings`). [벽·문·창] 을 켜면 개요 패널에
두 칸이 뜬다. 편집 파일에는 남기지 않는다. 그은 벽의 두께는 벽마다 편집 파일에 남으므로, 설정이 다른 PC 에서 열어도 결과는 같다.
스냅 거리는 0.1~3m 로 받는다.

## 고려한 다른 길

- **마감벽을 이름(`Furring`)으로 거르기**: Revit 템플릿 이름에 기대게 된다. 두께 기준은 이름과 무관하다.
- **벽 길이로 가중한 최빈값**: 마감벽은 다른 벽을 따라 길게 덧대서 길이로도 칸막이와 비슷했다.
- **사이트 기본값을 편집 파일에 담기**: 파일마다 값이 갈리고, 이 값을 쓰는 것은 벽을 긋는 순간뿐이다.

## 결과

- 8cm 보다 얇은 칸막이만 있는 층(드물다)은 BIM 최빈값을 쓰지 않고 사이트 기본값이나 0.2m 가 된다. 그은 뒤 패널에서 고친다.
- 되돌리려면 `newWallThickness` 의 `LINING_MAX` 조건을 빼고, `addWall` 을 부르는 곳에 0.2 를 넘긴다.
