# ADR-0022 연결 누락의 후보는 거르고 보이며, 사람이 골라 잇는다

## 맥락

OE-PIP-08 은 완전성 검사의 연결 누락에 [연결 후보 확인 후 잇기] 를 준다. 후보에는 대상 이름·거리·계통·매체를 보이고, 가깝다는 것만으로
다른 매체·맞지 않는 흐름·흐름 없는 기기를 잇지 않는다. 사용자가 해제한 BIM 연결은 자동으로 되살리지 않는다. 맞는 후보가 없으면 사유와
수동 검토 길을 보인다.

이 PR 전에는 같은 계통이 아닌 것만 빼고 가장 가까운 하나를 골라, 버튼 한 번에 바로 이었다. 매체·흐름 없는 기기·해제한 연결을 보지 않았다.

## 결정

**후보는 connect-candidates.ts 가 1m 안에서 고르고, 가까운 순으로 셋까지 보인다.** 빼는 것과 그 기준:

- 해제 보정한 BIM 연결의 상대(`releasedBetween`).
- **흐름 없는 기기**: 종류를 알고 사전의 `flow` 가 비어 있는 것. 다만 냉매 설비(실외기)는 빼지 않는다 — `flow: {}` 는 지금 규칙이 공기·물만
  다룬다는 뜻일 뿐이다(OE-PIP-18). 종류를 모르는 설비도 빼지 않는다.
- 다른 계통(둘 다 계통이 있고 다를 때. 예전 기준 그대로).
- **다른 매체**: 둘 다 매체를 알고 겹치지 않을 때. 매체는 종류의 흐름 → 계통 종류 → 덕트·배관 유형 이름 → IFC 클래스(Duct·Pipe) 순으로
  모은다. 한쪽이라도 모르면 거르지 않고 후보에 "매체 모름" 으로 보인다.
- **말단끼리**: 둘 다 말단 기기(디퓨저·그릴 등)일 때. "맞지 않는 흐름" 중 지금 사전으로 확실히 가를 수 있는 경우다.

뺀 수는 위반 이유에 "가까워도 후보에서 뺀 것: …" 으로 붙는다. 남은 후보가 없으면 고치기 버튼 없이 "직접 확인한 뒤 설비 패널의 [연결하기]로
잇습니다" 를 붙인다. 해제 보정한 연결이 있는 설비는 이유 앞에 의도한 해제임을 말한다.

**고치기 버튼은 바로 잇지 않고 후보 목록을 연다.** 각 후보에 [잇기] 가 있고, 누르면 패널의 [연결하기] 와 같은 길(`connectTo`)로 출처
`manual`·방향 없는 연결이 생긴다. 되돌리기는 한 번이다.

## 고려한 다른 길

- **매체를 모르면 후보를 권하지 않기**: 포트 없는 파일의 덕트·배관 조각은 계통도 IFC 클래스도 비는 일이 많아 쓸 수 있는 후보가 사라진다.
  후보 목록에서 "매체 모름" 을 보고 사람이 고르게 했다.
- **흐름 없는 기기를 `flow: {}` 하나로 가르기**: 실외기 같은 냉매 설비가 흐름 없는 기기로 빠진다(OE-PIP-18 이 금한다).

## 결과

- 위반 이유가 길어졌다. 다른 계통이 많은 기계실 설비는 "다른 계통 94" 처럼 큰 수가 붙는다(Duplex HVAC 보일러). 예전에도 같은 기준으로
  빠지던 것을 보이게 한 것이다.
- 되돌리려면 diagnoseFailure 의 `connectCandidates` 호출을 예전 가장 가까운 하나 고르기로 바꾸고, App 의 `applyFix` 가 다시 바로 잇게 하면 된다.
