# ADR-0058 말로 편집 시키기

## 맥락

"1F A룸에 공조기 설치해줘", "공조기랑 VAV3 이랑 연결해줘" 처럼 말로 편집하고 싶다는 요청이 있었다. 길은 둘이었다. gemini 가 화면을
보고 마우스를 누르는 것(브라우저 사용)과, gemini 가 편집 명령을 내고 화면이 그 명령을 이미 있는 편집 함수로 실행하는 것이다.
3D 캔버스의 자리를 눌러 대는 것은 느리고 깨지기 쉽다. 편집 함수(`addEquipment`·`addConnection`)는 이미 되돌리기·겹침 검사·소속 판정까지
갖고 있다.

gemini 는 55 서버에 있고 모델은 사람의 브라우저에 있다. gemini 가 "A룸" 이 무엇인지 알려면 반영 전 지금 화면을 봐야 한다 — ADR-0050 의
"지금 화면 (반영 전)" 이 그 길이다.

## 결정

- **gemini 는 고치지 않고 계획을 붙인다.** [온톨로지] 칸의 답 끝에 ```` ```oe-edit ```` 블록(JSON 배열)을 붙이게 한다(`scripts/onto-chat.md`).
  명령은 둘이다.
  - `add_equipment {space, kind, name?}` — 방 안의 점(`interiorPoint`)에서 시작해 다른 설비와 겹치면 0.5m 씩 비켜 놓는다. 천장에만 놓는
    종류(디퓨저 등)는 천장고를 알면 천장에 놓는다.
  - `connect {from, to}` — 방향 없는 연결. "파이프로 연결" 도 이것이다. 배관 형상은 그리지 않는다.
  - 같은 계획의 `connect` 는 앞에서 더한 설비를 `name` 으로 가리킬 수 있다.
- **대상은 id 로 받고 지금 모델에서 다시 찾는다**(`src/lib/edit-commands.ts`). gemini 는 도구(onto_find)가 준 `ex:…` 를 쓴다. TTL 의 id 는
  모델 id 를 `escapeLocalName` 으로 바꾼 것이라 거꾸로 맞춘다. 이름도 받지만 하나뿐일 때만이다.
- **사람이 [적용] 을 눌러야 실행한다.** 창은 계획을 글로 보이지 않고, 편집 화면(`window.__oe.plan`)이 만든 한 줄씩의 미리보기와 [적용] 을
  보인다. 못 찾은 대상이 하나라도 있으면 [적용] 이 막힌다. 편집 모드가 아니면 적용하지 않는다.
- **실행은 여느 편집과 같다**(`window.__oe.apply`). 명령마다 되돌리기 이력에 쌓이고("…더하기(말로)"), 겹침·소속·규칙 방향 재계산이 같다.
  출처는 편집이다.
- **서버는 아무것도 실행하지 않는다.** gemini 의 도구·정책(`onto-chat.policy.toml`)은 그대로 읽기만이다. 계획은 답 글일 뿐이다.
- 명령은 한 번에 10개까지다. 말 한마디로 수십 개가 바뀌면 사람이 미리보기로 볼 수 없다.

## 고려한 다른 길

- **gemini 가 화면을 보고 누른다(브라우저 사용)** — 3D 자리를 픽셀로 짚어야 하고 한 번 누를 때마다 화면을 다시 봐야 한다. 같은 일을 편집 함수가
  이미 한다.
- **gemini 에게 편집 도구(MCP)를 준다** — 도구는 55 서버에서 돈다. 모델이 브라우저에 있어서 서버가 브라우저로 되돌려 보내는 길을 따로 만들어야
  하고, 사내망 누구나 쓰는 8084 의 정책을 "쓰기" 로 넓히게 된다.
- **창이 계획을 곧바로 실행한다** — 다른 층에 놓는 것 같은 실수를 사람이 볼 틈이 없다.

## 결과

- 2026-10-13 55 의 gemini 로 성수 화면 기준 편집 요청 7개를 물었다.
  - 되물은 것 5: 1F 에 없는 "Lobby"(EV Lobby 둘을 후보로), AHU2 8대, Stair 8곳, 다른 펌프 12대, 1F 라 했는데 B1F 에만 있는 Lobby.
  - 계획을 붙인 것 1: "B5F Machine Room 에 펌프 하나 추가해줘"(11.2초, 도구 2번). 그 계획을 성수 편집 화면에 적용하니 0.57초에 B5F Machine Room
    에 "펌프-1" 이 들어갔다.
  - 처음에는 "1F Lobby 에 디퓨저" 를 B1F Lobby 로 계획했다. 안내문에 "사람이 말한 층과 찾은 것의 층이 다르면 묻는다" 를 더한 뒤 되물었다.
  - 답마다 11~42초다.
- 할 수 있는 것은 더하기·잇기 둘이다. 옮기기·지우기·이름·계통은 gemini 가 "편집 화면에서 이렇게 하면 된다" 까지만 말한다.
- 되돌리려면 `onto-chat.md` 의 편집 요청 절과 창의 계획 상자(`showPlan`), App.vue 의 `planOf`·`applyPlan` 을 지운다.
