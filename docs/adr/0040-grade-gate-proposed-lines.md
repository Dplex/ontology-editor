# ADR-0040 등급 판정·수용 기준선은 제안안으로

## 맥락

OE-REQ-04 는 등급 0~5 를 PRD 1.8 의 지표와 통과선으로 내라고 하고, OE-BIM-21 은 게이트(등급 2) 통과/미달 배너와 재제출 항목을, OE-GEN-02 는 게이트
미달이면 생성을 막으라고 한다. 통과선(D1, 그룹장)과 분모·사전 채움 포함(D12, 민주님·희록)은 열린 결정이고 수용 기준도 "확정 뒤 적는다" 이다.
2026-10-09 인터뷰에서 사용자가 "제안안대로 구현해 두기 — 기준값은 설정 한 곳에, 결정이 다르면 숫자만 바꾼다" 로 정했다. 등급 칩(profile.ts)은 이미
칸마다 채움을 보이고, 방향 칩은 D12 안대로 두 수치를 병기한다.

## 결정

- **D1 C안**: 게이트 = 등급 2(0~2 모두 통과해야 생성), 목표선 = 등급 3(경고만). 통과선은 1.8 정량 기준(안) — 0 ≥ 85%·층 이름 100%, 1 ≥ 90%, 2 ≥ 85%,
  3 ≥ 70%, 4 ≥ 50%(`src/lib/grade.ts` 의 `DEFAULT_LINES`).
- **D12 안**: 게이트(0~2)는 BIM+계산 수치로만 판정한다. 목표선(3·4)은 BIM 과 사전 포함(이름 사전·규칙 방향이 고른 계통·방향) 두 수치를 같이 보이고,
  판정은 BIM 수치로 한다.
- **지표는 칩과 같은 셈이다**: 1 설비(배치점 있는 기기/기기), 2 소속(외벽 부착 제외), 4 방향(방향 아는 기기/연결망 기기). 분모가 0 이면 해당 없음이라
  통과로 본다(건축만 있는 파일은 1·2 가 막지 않는다 — 1.6 의 "건축만" 경로).
- **기준값은 한 곳**: 기본값은 `DEFAULT_LINES` 하나다. 화면의 [등급 판정 보기] 에서 통과선을 고칠 수 있고 이 브라우저(`oe.gradeLines`)에 남는다.
  [기본값으로] 가 1.8 의 안으로 되돌린다. 결정이 다르게 나면 `DEFAULT_LINES` 만 바꾼다.
- **게이트 미달이면 [구축하기] 만 막는다**(OE-GEN-02). 운영 편집의 [반영하기] 는 이미 만든 온톨로지라 막지 않는다. 판정은 지금 모델(사람이 고친 것까지)로
  하므로, 보정으로 기준을 넘기면 구축할 수 있다.
- **배너는 오른쪽 "이 파일" 패널의 등급 칩 아래**다. 위 막대에 두면 3D 가 밀려 화면 좌표가 바뀐다.
- **이름 없는 층은 에디터의 층별 요약 표에서 이름을 넣는다**(편집 모드, 2026-10-10 더함). 등급 0 은 "층 이름 100%" 라 이름 없는 층 하나로 게이트 미달인데,
  BIM 을 다시 받는 것 말고는 길이 없었다(합성 성수: 기초 층 하나가 이름이 없어 97.1% 인데 구축 불가). 이름 없는 층은 [이름 넣기], 있는 층은 [고치기],
  고친 층은 출처 `편집` 과 [BIM 이름으로]. BIM 이름은 `Storey.bimName` 에 남기고 편집 파일(`storeyNames`)·리포트("층 이름 (없음) → 1F")가 이것을 본다.
  빈 이름과 같은 건물의 같은 이름은 받지 않는다(탐색기 트리·층 파일에서 가를 수 없다). 게이트는 넣은 이름으로 판정하고, 막는 글은 "층 이름 20/21(이름
  없는 층 1개) — 층별 요약에서 넣을 수 있습니다" 로 말한다. TTL `rdfs:label` 과 GeoJSON 층 파일 이름이 넣은 이름이 된다.

## 고려한 다른 길

- **결정 뒤에 한다.** 결정 전에도 화면·막기를 만들어 두면 숫자만 바꾸면 된다(인터뷰 결정).
- **판정을 연 때(BIM 그대로) 값으로 고정.** 1.6 은 "보정 → 생성" 흐름이고, 보정으로 넘긴 파일을 막을 까닭이 없다. 리포트에는 지금 값이 남는다.
- **이름 없는 층은 재제출만.** PRD 재제출 항목대로지만 이름 하나 때문에 구축이 멈춘다. 재제출 항목 표시는 그대로 둔다(BIM 을 고치는 것이 맞는 일이라).
  이름 없는 층을 층 id 로 채우면 사람이 읽을 수 없는 이름이 탐색기에 뜬다.
- **통과선을 서버 설정으로.** 사이트마다 다를 수 있으나 지금은 결정 전이라 브라우저 설정으로 둔다(ADR-0017 의 사이트 기본값과 같은 자리).

## 결과

- 고객사 결과 리포트(OE-GEN-08)는 이 판정과 재제출 항목을 그대로 쓰면 된다.
- 등급 0+(방 종류·방-문-방)·4+(담당 공간)·5(운영)는 판정에 넣지 않았다. 게이트·목표선에 들지 않는다.
- PRD 1.8 의 "층 이름" 은 BIM 요구로 남고, 에디터에서 보정할 수 있다는 점은 PM 확인 거리다(`needs-pm`).
- 되돌리려면 `src/lib/grade.ts` 와 `App.vue` 의 "등급 판정·수용 기준선" 묶음을 걷어낸다. 층 이름 넣기는 `src/lib/storey-name.ts`, `App.vue` 의 "층 이름"
  묶음, edit-file 의 `storeyNames` 를 걷어낸다.
