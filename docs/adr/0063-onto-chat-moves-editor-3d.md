# ADR-0063 온톨로지 챗 답을 편집 화면 3D 에서 보기

## 맥락
ADR-0050 의 온톨로지 챗은 답의 `ex:…` id 옆에 [3D] 를 붙여, 누르면 내보낸 파일 뷰어(viewer.html)를 새 창으로 열어 그 반영본에서
그 요소를 고른다. 편집 화면(8084)에서 BIM 을 열어 둔 채 물으면 답의 대상이 바로 옆 3D 에 있는데도 새 창으로 가야 했다.
에테리온 데모(2026-07-24, 이화빌딩 "Ontology-Grounded AI Chat")는 답과 함께 3D 에서 대상을 격리·강조하고, 대화에 "뷰어 동작: 객체 1개 격리"
같은 줄을 남긴다(2026-10-13 희록님 요청: 에테리온에서 편집·뷰어·리플레이에 참조할 것을 최대한 반영).

ADR-0050 은 "앱 상태(열어 둔 BIM, 편집 중인 것)는 서버로 보내지 않는다", "앱이 서버를 아는 길을 만들지 않는다" 로 정했다.

## 결정
- 편집 화면(App.vue)은 `window.__editor3d.show(ids)` 하나만 연다. 받은 id 중 열어 둔 BIM 에 있는 것을 설비 → 물리존 → 층 순으로
  고르고 그 자리로 시점을 옮긴 뒤 `{ equipment, spaces, storeys, missing, label }` 을 돌려준다. 설비가 여럿이면 첫 대를 고르고 모두가 들어오게 본다.
  격리는 하지 않는다(필터·격리는 따로 다룬다).
- 챗 창(scripts/docs-chat.js)은 [온톨로지] 답이 끝나면 답에 나온 `ex:` id 를 그 함수로 넘기고, 돌려받은 `label` 을 "🎯 3D 동작" 칩으로
  답 아래에 남긴다(대상이 없으면 회색 칩). id 마다 [여기] 를 붙여 하나씩 가고, 칩의 [다시 보기] 로 같은 대상에 다시 간다.
  `window.__editor3d` 가 없는 페이지(viewer.html, 다른 앱)에서는 아무것도 하지 않고 [3D] 만 남는다.
- 서버(/__ask)의 요청·응답은 바꾸지 않는다. 창이 보내는 것은 여전히 질문·앞선 대화·고른 건물뿐이고(e2e 가 요청 키를 본다),
  열어 둔 BIM 과 고른 것은 브라우저 안의 함수 호출로만 오간다. 답의 id 와 열어 둔 BIM 이 맞는지는 GlobalId 가 같은지로만 본다 —
  반영본과 편집 중인 BIM 이 달라도(다른 건물이거나 지운 설비) "이 화면의 BIM 에 없는 id n" 으로 센다.
- 같은 PR 에서 3D 위 설비 라벨(에테리온의 MAPPED·SENSOR 배지)을 더했다. 층 하나를 볼 때 [라벨] 을 켜면 기기마다 이름과
  소속 출처(BIM·계산·편집·없음, TTL 의 brick:hasLocation)·종류 출처(BIM·사전·편집·모름, TTL 의 `a brick:…`) 배지를 띄운다.
  고른 것·화면 가운데에 가까운 것부터 겹치지 않는 만큼만, 많아야 40개다.

## 고려한 다른 길
- 서버 응답에 대상 id 목록을 따로 실어 보낸다 — 답 글의 `ex:` 를 읽는 것과 결과가 같고, /__ask 를 바꾸면 55 배포·질문 시험대(onto:bench)까지 고쳐야 한다.
- 창이 앱 상태(열어 둔 BIM 의 id 목록)를 서버에 보내 답을 거기에 맞춘다 — ADR-0050 이 막은 길이다.
- 답마다 묻지 않고 바로 격리한다 — 에테리온처럼 다른 것을 다 숨기면 편집 중인 화면이 사라진다. 고르기·시점 이동만 한다.
- 라벨을 설비 전부에 띄운다 — 성수 3F 처럼 기기가 많은 층은 글자가 겹쳐 읽을 수 없다.

## 결과
- 답이 끝날 때마다 편집 화면의 고른 것과 시점이 바뀐다. 편집하는 중에 물으면 고른 설비가 답의 대상으로 바뀌니, 칩이 무엇을 했는지 남긴다.
- 라벨은 시점이 바뀔 때마다 자리를 다시 잰다. 처음 그린 라벨만 실제 폭을 잰다 — 프레임마다 재면 레이아웃을 강제해 성수 3F(라벨 19개)에서
  끌어 돌릴 때 p95 프레임 간격이 16.7 → 33.3ms 가 됐고, 한 번만 재게 한 뒤 16.7ms(끈 것과 같음)다.
- 되돌리려면 App.vue 의 `showFromChat`·`window.__editor3d` 와 docs-chat.js 의 `act`·[여기] 를 빼면 된다. 라벨은 App.vue 의 `--- 3D 위 설비 라벨` 절,
  `lib/equipment-labels.ts`, viewer.ts 의 `screenOf`·`viewVersion` 이다.
