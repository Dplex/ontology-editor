# ADR-0037 반영·버전은 서버 파일

## 맥락

[반영하기](OE-WF-10)는 편집 내용을 DT 3D 맵과 온톨로지에 한 번에 반영하고, 둘 중 하나만 반영된 상태를 만들지 않는다(OE-SYNC-02). 반영하면 새 버전이
생기고(OE-WF-13, 초기 구축은 v1 — OE-GEN-05) 히스토리에서 7일 안의 버전을 보고 되돌린다(OE-WF-18~20). 저장 위치는 D-INT(DT↔에디터 교환 방식)인데
"결정 전 ①(파일)로 진행" 이다. 이 PoC 에는 DT·DB 가 없다. 2026-10-09 인터뷰에서 사용자가 "서버도 PoC 범위, 실제 DB 대신 파일로 관리" 로 정했다.
이 repo 의 서버(dev 서버와 55 의 `scripts/serve.mjs`)는 이미 `data/.edits/` 에 [편집 저장] 을 파일로 둔다(`src/server/saved-edits.ts`).

## 결정

- **버전은 서버 파일의 폴더다.** `data/.layouts/<열쇠 해시>/vN/` 에 `meta.json`(버전·일시·반영자·대상 층·변경 요약·종류)과 반영한 것 —
  `ontology.ttl`(온톨로지), `geojson/*.geojson`(층마다, 3D Map 기하), `model.glb`(3D 형상), `edits.json`(다시 열 때 BIM 에 얹는 편집 파일),
  `tree.json`(사이트 > 건물 > 층 > 물리존, 탐색기 트리 대신), `report.json`(생성 리포트, OE-GEN-09). 열쇠는 [편집 저장] 과 같은 "연 파일의 data/ 경로".
- **`current.json` 이 가리키는 버전이 "DT 3D 맵과 온톨로지에 반영된 것" 이다.** 다른 모듈(DT·뷰어마스터)에는 붙이지 않는다. 확인은 그 버전의 파일과
  이 repo 의 뷰어로 한다.
- **반만 반영되지 않게 올린 뒤 한 번에 바꾼다.** 화면은 파일을 하나씩 `.stage-<id>/` 에 올리고 [반영] 을 보낸다. 서버는 꼭 있어야 하는 파일
  (TTL·편집 파일·공간 계층·GeoJSON 하나 이상)을 확인하고, 빠졌으면 반영하지 않는다. 다 있으면 `meta.json` 을 쓰고 폴더를 `vN` 으로 rename 한 뒤
  `current.json` 을 임시 파일에 써서 rename 한다. 동시에 둘이 반영해 번호가 겹치면 다음 번호로 다시 한다. 하루 넘게 남은 올리던 판은 치운다.
- **첫 반영이 v1 이고 버튼은 [구축하기] 다**(OE-GEN-01·05). 그다음은 [반영하기]. 둘 다 확인 창에서 대상 층(바뀐 것이 있는 층)·편집 수를 보이고
  반영자를 받는다(OE-WF-11·12). 반영자는 브라우저가 기억한다(사람 목록은 다음 PR 의 `users.json`). 반영은 PoC 의 저장이라 임시 저장본을 지운다.
  손으로 연 파일은 열쇠가 없어 예전처럼 두 파일을 내려받는다.
- **되돌리기는 옛 버전 폴더를 베껴 새 버전으로 반영한다**(OE-WF-19, KPI_2 이력 보존). 지금 버전으로는 되돌리지 않는다. 지금 화면의 편집은 그대로다.
- **1주가 지난 버전은 히스토리에서 감추고 되돌릴 수 없게 하되 파일은 지우지 않는다**(OE-WF-20). 지금 버전은 오래돼도 보인다.

## 고려한 다른 길

- **git 저장소로 버전을 둔다.** diff 는 공짜지만 서버에 git 의존이 생기고, GLB 같은 큰 바이너리가 저장소를 키운다.
- **JSON 하나에 버전 배열.** 파일을 그 버전에서 바로 내려받거나 3D Map 이 폴더를 그대로 읽는 쪽이 단순하다.
- **1주 지난 버전 파일을 지운다.** 로그(OE-COM-04)는 기간과 무관하게 남기라고 해서, 파일도 지우지 않고 목록에서만 뺀다. 디스크가 문제면 그때 지운다.

## 결과

- 반영자·알림·잠금·로그·모드 자동 분기·서버 임시 저장본은 같은 저장소 위에 얹는다(NEXT.md "6. 서버·플랫폼"). 반영 결과 리포트(OE-SYNC-04)는 아직 변경 요약뿐이다.
- 55 의 `serve.mjs` 도 `/__data/__layouts` 의 PUT·POST 를 받는다. 사내망 누구나 쓸 수 있어(정문 없음) 열쇠는 data/ 의 IFC 로만 받고 파일 이름을 거른다.
- 되돌리려면 `src/server/layouts.ts`·`src/lib/layout-files.ts`·`PublishDialog.vue`·`App.vue` 의 "반영하기·버전" 묶음을 걷어내고 [구축하기] 를 내려받기로 돌린다.
