# ADR-0059 사람이 더한 설비는 복제한 원본이나 종류가 같은 BIM 설비의 3D 형상을 제 자리로 옮겨 빌리고, 복제 원본만 편집 파일에 적는다

## 맥락
[설비 더하기] 로 놓은 설비는 IFC 형상이 없어 0.4m 상자로 그렸다. 같은 라디에이터를 하나 더 놓아도 3D·GLB 에서는 상자라, 화면이
BIM 과 달라 보이고 내보낸 3D 형상에도 상자가 나갔다(2026-10-13 희록님 요청: "기존에 있는 설비면 object 모양 그대로").

- 3D 형상(`MeshMap`)은 IFC 에서 읽은 설비마다 세계 좌표로 들고 있고, 설비를 옮기면 `shiftMesh` 가 그 형상을 평행이동한다.
  복제는 원본 형상을 복사해 새 자리로 옮기는 것과 같다.
- 형상은 3D 화면과 GLB·OBJ·FBX(`export/mesh3d.ts` 가 `meshes.get(id)`)에만 쓰인다. TTL·GeoJSON 에는 설비 모양이 없다.
- Duplex 1층 라디에이터 536919 를 복제하면 형상 상자 0.111 × 1.932 × 0.279 m 가 그대로 선다(상자일 때 0.4 × 0.4 × 0.4 m).

## 결정
- 고른 설비 패널의 [같은 모양으로 더하기](Ctrl+D)는 바닥을 눌러 원본과 종류·모양이 같은 설비를 놓는다. 높이는 원본이 제 층 바닥에서
  떠 있던 만큼이다. 연결·계통·소속은 복사하지 않는다 — 원본에 붙은 배관을 새 설비가 가져가면 엉뚱한 곳이 이어진다. 덕트·배관은 복제하지 않는다.
- 사람이 더한 설비(`added`)의 모양은 이 순서로 빌린다. ① 복제한 원본(`shapeOf`, 종류가 원본과 같을 때) ② 종류가 같은 BIM 설비 중
  형상이 있고 ObjectType(Revit "패밀리:유형")이 가장 많은 묶음의 첫 설비 ③ 없으면 상자. 사람이 정한 종류도 같은 종류로 친다.
  종류를 바꾸거나 되돌리면 다시 고른다(App.vue 의 `syncBorrowedShapes`, 모델이 바뀔 때마다).
- 편집 파일에는 복제 원본만 `equipmentAdded[].shapeOf` 로 적는다. 종류로 빌린 것은 같은 규칙으로 다시 고르니 적지 않는다.
- BIM 에서 온 설비 중 형상이 없는 것은 그대로 상자다. 빌려 오면 "BIM 에 형상이 없다" 가 화면에서 가려진다.
- 패널에 "3D 모양: ○○의 형상 — 복제한 원본 / 같은 종류의 BIM 설비" 와 어느 출력에 나가는지를 적는다.

## 고려한 다른 길
- [설비 더하기] 에서 종류별 대표 모양 목록을 고르게 한다 — 무엇을 대표로 둘지 사람이 또 골라야 하고, 종류를 정하면 저절로 따르는 것으로
  같은 결과가 난다.
- 형상을 편집 파일에 통째로 적는다 — 파일이 형상 크기만큼 커지고, 원본 BIM 을 같이 열어야 하는 지금 편집 파일 구조로는 id 하나면 된다.
- 연결까지 복제한다 — 원본 배관의 끝이 둘이 되어 흐름 방향·계통 판정이 틀어진다.

## 결과
- 겹침 판정은 새 설비를 형상 상자가 아닌 기본 크기로 본다(`overlapForNew`). 큰 형상을 빌린 설비는 옆 설비와 겹쳐도 놓일 수 있다.
- 회전은 원본 그대로다. 돌려 놓는 기능은 없다.
- 원본 BIM 설비를 지운 편집 파일을 다시 열면 `shapeOf` 가 가리킬 형상이 없어 종류로 빌리거나 상자가 된다.
- 되돌리려면 App.vue 의 `syncBorrowedShapes`·`startDuplicate`·[같은 모양으로 더하기] 단추와 `shortcuts.ts` 의 `duplicate`, model·edit·edit-file 의 `shapeOf` 를 뺀다.
