# ADR-0019 BIM 포트 연결의 해제 보정은 연결을 별도 목록으로 옮겨 둔다

## 맥락

OE-PIP-06(K13 개정)은 BIM 포트가 말한 연결을 지우지 않고 **해제 보정**하게 한다. 원본 연결과 방향은 보존하고, 해제한 연결은 유효
계통·규칙 방향·일치율·TTL `brick:feeds` 에서 빠진다. 취소하면 원본이 돌아오고, 보정·취소의 시각·사유가 이력에 남는다. 저장·불러오기와
BIM 재임포트에서도 해제는 유지되고, 원본을 못 찾거나 방향이 바뀌면 재검토로 표시한다. 재검토 중인 연결은 사람이 확인하기 전에 내보내지
않는다.

`model.connections` 를 읽는 곳이 많다. 규칙 방향(flow-rules), 계통 추적(topology), 공급 관계(served), TTL, 검사(checks), 커버리지,
종류 추천, 프로필, 요구사항 보고, 층 완료 지문, 3D 화살표, 패널 표가 모두 이 목록을 읽는다.

## 결정

**해제한 연결은 `model.connections` 에서 빼 `model.releasedConnections` 로 옮긴다**(connection-release.ts). 연결 객체를 고치지 않고 해제할
때의 자리(`index`)·시각·사유와 함께 들고 있다. 연결을 읽는 곳은 하나도 고치지 않았고, 해제한 연결을 보지 않는다. 취소하면 같은 객체가
같은 자리로 돌아가 방향·확정 상태가 해제 전과 같다.

- 이력은 `model.connectionLog` 에 해제·취소·재검토 확인을 한 줄씩 남긴다. 되돌리기로 무른 해제는 이력에서도 빠진다. 스냅숏이 이력
  전체를 들고 있다.
- 해제한 두 설비를 손으로 다시 잇지 않는다(`addConnection` 이 거절한다). 같은 두 설비에 원본과 수동 연결이 겹치지 않게, [해제 취소]로
  되살리게 한다.
- 연 때와 견준 차이(`diffBaseline`)에서 해제한 연결은 "끊은 연결" 로 세지 않는다. 바뀐 내용에는 해제 보정으로 따로 적는다.

**편집 파일에는 `connectionsReleased: { from, to, directed, at, reason, review? }[]` 와 `connectionLog` 로 남는다.** 끊은 연결
(`connections.remove`)과 섞지 않는다. 불러올 때는 같은 두 설비 사이의 포트 연결을 찾는다.

- 방향까지 같으면 다시 해제한다.
- 포트 연결은 있으나 방향이 다르면, 새 판본의 그 연결을 해제한 채 `review: 'direction'` 으로 둔다. 사람이 [해제 유지] 나 [해제 취소] 를
  고를 때까지 TTL 에 나가지 않는다.
- 못 찾으면 파일에 적힌 두 끝으로 연결을 만들어 `review: 'missing'` 으로 둔다. 되살릴 원본이 없어 취소는 막고 [보정 지우기] 만 준다.
  지워도 이력은 남는다.
- 재검토가 남은 채 저장하면 `review` 를 같이 적는다. 다시 불러와도 재검토다.

## 고려한 다른 길

- **연결에 `released` 표시를 붙이고 읽는 곳마다 거르기**: 열두 곳 넘게 고쳐야 하고, 한 곳이라도 빠지면 해제한 연결이 TTL 이나 규칙
  방향에 다시 들어간다. 새로 연결을 읽는 코드도 매번 기억해야 한다.
- **해제를 연결 끊기로 처리하고 원본만 따로 보관**: 끊기는 포트가 아닌 연결의 삭제라 편집 파일에서 둘을 구별할 수 없고, 재임포트 때
  "같은 연결이 다시 생김" 과 "해제를 유지함" 을 가를 수 없다.

## 결과

- 연결 대상이 바뀐 경우(A–B 가 A–C 로)는 A–B 를 못 찾은 재검토로만 잡는다. 새 A–C 는 유효 연결로 들어간다. 두 판본 사이에 어느
  연결이 어느 연결로 바뀌었는지 짝지을 근거가 편집 파일에 없어서다.
- 수행자는 남기지 않는다. 로그인(OE-COM-01)이 없어 누구인지 알 수 없다. 이력 줄에 `by` 를 더하면 된다.
- 되돌리려면 connection-release.ts 와 edit.ts 의 `releasedBetween` 두 곳(잇기 거절·차이 계산), edit-file.ts 의 `connectionsReleased`
  읽고 쓰기를 걷어 내면 된다.
