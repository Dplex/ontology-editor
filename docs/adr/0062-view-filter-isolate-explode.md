# ADR-0062 3D 보기 필터·숨기기·격리·클래스별 분해도는 화면 상태로만 두고, 층 보기 위에 얹으며, 끌지 않은 우클릭을 메뉴로 쓴다

## 맥락
3D 에서 걸러 보는 길이 층 하나·연속 구간(다중층 뷰)뿐이었다. 성수(설비 20,541개 중 덕트·배관 15,864개)에서 기기만 보거나 고칠 대상만
남겨 놓고 작업할 수 없었고, 우클릭은 끌지 않으면 왼쪽 누르기처럼 골랐다. 에테리온 데모(02·07 Filtering·Selection Box·Clustering)를
참조해 2026-10-13 희록님이 반영을 요청했다.

## 결정
- **화면 상태다.** 필터·숨김·격리·분해도는 모델을 바꾸지 않는다 — 편집 파일·TTL·GeoJSON·GLB 가 그대로이고(view-filter.test 가 TTL·편집 파일
  문자열을 견준다), 파일을 새로 열면 푼다. 3D 위에 늘 "화면에서만" 을 적는다(패널·우클릭 메뉴·칩).
- **층 보기 위에 얹는다.** 층 보기(`applyStoreyFilter`)가 정한 보일 층·숨길 설비에 필터가 숨길 설비를 더해 `viewer.setStoreyFilter` 에
  준다. 뷰어에는 새 숨김 장치를 두지 않는다 — 숨긴 설비는 고르기·상자 선택·맞추기에서 이미 빠지므로, 필터를 켜고 Ctrl+끌기 하면 보이는 것만 고른다.
- **층 여러 개 고르기는 "모든 층" 일 때만.** 층 하나만 보거나 다중층 뷰면 그쪽이 층을 정한다 — 편집할 층이 하나여야 하는 도구(설비 더하기 등)가
  층을 헷갈리지 않게.
- **클래스는 내보내기와 같은 규칙**(`export/ttl.ts` 의 `classOf`)으로 센다. 필터에서 고른 `brick:Air_Diffuser` 가 TTL 의 그 클래스다. 덕트·배관(FSO)은 목록 뒤에 따로.
- **우클릭은 끌지 않았을 때만 메뉴다.** 오른쪽 드래그는 그대로 회전이다. 설비 위: 숨기기·이것만 보기·시점 맞추기·같은 클래스만·같은 계통만·
  GlobalId 복사(여러 개 고른 묶음 안이면 묶음 전체). 빈 곳: 모두 보이기·전체 맞추기(지금 방향)·카메라 초기화(처음 방향)·분해도.
- **분해도**는 보이는 기기를 Brick 클래스별로 묶어 형상을 평행이동한다(꼭짓점을 고쳐 쓰는 미끄러짐과 같은 장치). 넓은 건물은 건물 위로 한 켜씩,
  높은 건물(높이 > 평면 긴 변 × 0.8)은 건물 옆 바둑판 칸에 — 성수 19층을 위로 쌓으니 기둥처럼 길어져 라벨이 읽히지 않았다. 덕트·배관은 제자리.
  펼친 동안은 3D 끌기를 막고, 다시 그리기·설비 옮기기가 오면 먼저 접는다(띄운 자리에서 옮기면 접을 때 옛 자리로 돌아간다). 400대를 넘으면 미끄러지지 않고 바로 옮긴다.

## 고려한 다른 길
- 리플레이의 층 펼치기(`setSpread`, 셰이더로 층을 띄움)를 쓴다 — 층 단위라 클래스로 가를 수 없다.
- 숨김·격리를 편집 파일에 적는다 — 보기 설정이 편집 이력·내보내기에 섞여, 다른 사람이 연 파일에서 설비가 "없는" 것처럼 보인다.
- 필터를 뷰어 안에 둔다 — 층 보기가 이미 App 에서 숨길 설비를 정하고 있어 두 곳이 서로를 덮는다.

## 결과
- 성수 건축+기계(2026-10-13, 윈도 d3d11): 패널 열기 140ms · 덕트·배관 빼기 176ms(최장 프레임 80ms) · 분해도 펼치기 550ms(483ms, 기기 4,677대 · 21칸) ·
  접기 180ms · 모두 보이기 151ms.
- 숨긴 설비는 표(설비 위치와 소속)에서는 그대로 보인다 — 표에서 고르면 패널에 뜨지만 3D 에는 없다. 걸러 보는 중이면 오른쪽 위 칩이 알린다.
- 되돌리려면 App.vue 의 `--- 보기 필터 · 숨기기 · 격리 · 분해도` 절과 우클릭 메뉴·패널 템플릿, viewer.ts 의 `onContext`·`setExplode`·`frameVisible`, `src/lib/view-filter.ts` 를 뺀다.
