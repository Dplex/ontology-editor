# 수용 기준 ↔ 시험

2026-10-10 · `npm run ac:coverage` 가 쓴 파일이다. 손으로 고치지 않는다. 태그 다는 법은 [testing.md](testing.md) "수용 기준 태그".

칸은 기준(위임 제외) 수와, 그중 다 재는 시험이 있는 것·일부만 재는 시험뿐인 것이다. 태그는 사람이 "이 시험이 이 기준을 잰다" 고 단
것이라, 태그가 없다는 것은 시험이 없다는 뜻이 아니라 **짝을 아직 적지 않았다**는 뜻일 수 있다.

- ✗ **#5** Z-03 — 설계 풍량이나 설비 용량이 없는 설비는 경고가 아니라 "판정 불가"로 보이고, 없는 값의 이름이 함께 보인다.
- ✗ **#6** Z-03 — 다른 공조존과 함께 담당하는 물리존이 있고 공조존 단위 설계 풍량이 없으면 "판정 불가"다.
