## 보인 것
- 토큰만 바꿔서는 1단계 "고칠 것" 5개가 하나도 안 풀린다. 모바일 넘침·작은 글자·작은 클릭 영역·툴바 무게·패널 길이는 CSS/레이아웃 수정이 따로 필요하다. 토큰은 색·둥글기·밀도의 "느낌"만 바꾼다.
- 3D 장면(벽 회색·분홍 바닥)은 Three.js 가 직접 칠해서 토큰이 안 닿는다. 어떤 후보를 골라도 패널 색과 3D 색이 따로 논다.
- 다크: Vercel(순흑)은 3D 와 패널이 가장 분리돼 보이고, Stripe(네이비)는 패널이 3D 보다 파랗게 떠 보인다. Linear 가 중간.
- 눈으로 본 건 라이트 1440 두 장(Linear·Stripe)과 다크 요약 시트뿐. 모바일·시작 화면 스샷은 찍었지만 상세는 안 봤다.

## 추천
A. Linear 계열. 편집 도구라 화려함보다 차분·촘촘이 맞고, 그림자 없이 선으로 구분해 패널이 많은 화면에서 덜 시끄럽다. 줄 간격 1.5 로 열람 화면 세로 길이도 조금 줄 것으로 기대된다(수치는 3단계에서 잰다).

## 편집 모드·큰 파일 점검 (`edit-large.spec.ts`, 2026-10-15)
성수 파일은 이 PC 에 없어 같은 Revit IFC2x3 인 NIBS Medical Clinic(건축 + HVAC, 272 물리존·668 기기·3695 연결)으로 대신 봤다 — 성수 자체는 못 봤다.
스샷: `.local/design-audit/edit-large/ee-*.png`. 재현: `npx playwright test -c docs/prd/prototype/design-audit/playwright.audit.config.ts edit-large`.

처음 layout.css 는 편집 모드에서 **깨졌다**(모바일 문서 너비 1280px 로 넘침). 편집 막대 단추 9개가 줄바꿈 없이 늘어서는 게 원인이었고 원본에서도 같다(1287px). 편집용 규칙을 layout.css 에 더해 고쳤다.

데스크톱 1440 은 전후 모두 넘침·겹침 없음(Duplex·Clinic). Clinic 은 파일 이름이 길어 앱바가 두 줄(161px)로 접히는 것도 원본과 같다.

남은 것: 모바일 편집 막대는 한 줄 가로 스크롤이라 `편집 저장`·`임시 저장`·`편집 종료`는 밀어야 보인다(구축하기·모드 칩은 앞으로 당김). 모바일에서 조작 안내 글을 숨겼다 — 안내는 상단 `?` 로만 남는다. 도구 팔레트는 3D 왼쪽 아래를 계속 가린다. 가로 넘침·겹침 외 UX(탭 영역, 실제 편집 동작)는 안 쟀다.
