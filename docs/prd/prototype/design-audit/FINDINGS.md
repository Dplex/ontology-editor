## 고칠 것 후보
1. 모바일(390) 가로 넘침 — 우측 패널·툴바가 접히지 않고 뷰어를 덮음(범례 글자가 한 글자씩 세로로 꺾임).
2. 11.5px 이하 글자 약 70곳 — 최소 12px 로 올릴 기준 필요. 글자 크기가 17종이라 4~5단 스케일로 정리.
3. 링크형 버튼 클릭 영역 24px 미만 — 편집 도구에서 자주 쓰는 `고치기` 포함.
4. 상단 툴바 — 열기·읽을 것·덧붙이기·경고·보기/편집·내보내기 5종·도움말·테마가 한 줄에 같은 무게로 늘어섬. 주·보조 구분 필요.
5. 열람 화면 세로 2705px — 우측 패널 길이.

## 아직 안 본 것
편집 모드, 성수·병원 같은 큰 파일, 다크 모드 스샷, 키보드 포커스 표시, 모션(현재 reduced-motion 으로 찍음). 스샷은 눈으로 본 건 데스크톱·모바일 열람 화면 2장뿐.

## 추가 발견 (2026-10-15, 시스템 시험 중)
- 편집 모드에서 3D 아래 조작 안내 글(`설비 클릭: …`)이 오른쪽 범례(`미배치·소속 없음·위반`)와 겹친다(성수 1440px, 원본에서도 발생). 3D 위 요소끼리의 자리 규칙이 없다는 근거(`COMPONENTS.md` 시스템 시험 4번).
- 경고 영역(`#warnings`)은 스크롤되는데 키보드로 포커스할 수 없다(axe `scrollable-region-focusable`) — 소스에 `tabindex="0"` 필요.
- 다크 테마에서 accent 켠 칸(편집 대상 공간·설비)의 글자가 흰색 하드코딩이라 대비가 2.9:1 이다(accent 가 밝음).
