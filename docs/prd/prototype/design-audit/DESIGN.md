# DESIGN.md — ontology-editor 디자인 시스템 초안 (Linear 계열)

2026-10-15 작성, **제안·검토 전**. 근거: `FINDINGS.md`(진단) · `COMPARE.md`(후보 비교) · `COMPONENTS.md`(인벤토리·상태·다크·시험 결과) · `MOTION.md`(모션) · `TOKEN-MAP.md`(현재 값 → 토큰 매핑). 시험 구현은 `themes.ts`(색 토큰) + `fixes.css` + `system.css`(아래 규칙)이고, 앱 코드는 고치지 않았다.

성격: 차분하고 촘촘한 편집 도구. 색은 거의 중립, 강조색은 인디고 하나, 구분은 그림자가 아니라 선. 범위는 1024px 이상 화면(모바일·태블릿은 범위 밖, OE-UI-23).

## 4. 상태

| 상태 | 규칙 | 현재 |
|---|---|---|
| 호버 | 모든 누르는 컴포넌트에 있다. 배경을 한 단 진하게(`--surface-soft`). 링크 단추만 밑줄 | 모드 스위치·접기 머리·진단 칩·분절은 호버 없음 → 추가 |
| 눌림 | `transform: scale(0.97)` 100ms, ease-out. 표 안 링크 단추 제외 | **앱 전체에 `:active` 규칙 0개** |
| 키보드 포커스 | 전 컴포넌트 공통 `:focus-visible`: 2px `--focus` 고리 + 2px 오프셋. 라이트 `--accent`, 다크 `#a5a8ff` | 브라우저 기본(1px 거의 검정). 다크에서 약함 |
| 비활성 | `opacity: 0.45` + `cursor: not-allowed`, 네이티브 단추도 | 0.45 와 0.42 혼재, 네이티브 단추는 미적용 |
| 켬 | `aria-pressed`·`aria-expanded` 를 한 규칙으로 | 분절만 `aria-pressed`, 접기 머리는 없음 |
| 다크 | 컴포넌트 규칙은 토큰만 쓴다. 출처 배지·모드 칩·kbd 의 하드코딩 색은 토큰으로 | |

## 5. 모션 (`MOTION.md`)
- 호버 색 전환 120ms, 눌림 100ms, 패널 진입 180ms. 모두 ease-out(`cubic-bezier(0.22, 1, 0.36, 1)`). `transition: all` 금지.
- 자주 하는 동작(편집·선택·단축키)은 기다리게 하지 않는다. 숫자 굴림은 처음 한 번만 300ms 이하. 번쩍임 0.8초 이하.
- 움직임 끄기: 이동·확대만 끄고 배경색 변화는 남긴다.
- 리플레이(`ReplayHud`·`ReplayGeo`, 2287줄·어두운 극장식 연출)는 이 시스템의 대상이 아니라 별도 "보여주기 모드".

## 6. 하지 않는 것·열려 있는 것
- 3D 장면 색(벽 회색·위반 분홍, Three.js 재질)은 이 문서 밖.
- 웹폰트 도입, 그라데이션 장식, 카드마다 그림자.
- 모바일·태블릿(1024px 미만).
- 한 가지 확인 필요: 8084 에 배포된 판이 이 repo `main` 과 같은지(이 PC 에서는 접속 불가).

## 7. 시험 결과 요약 (`system.css` + `themes.ts`, 1440px)

상세는 `COMPONENTS.md` 마지막 장. 대상은 Clinic(건축+HVAC)과 성수(건축+기계).

| 측정 | 원본 | 시험 시스템 |
|---|---|---|
| 단추 서명(모양) 수 — 보기 / 편집 | 31 / 39 | 27 / 31 |
| 단추 높이 종류 — 보기 / 편집 | 16 / 19 | 9 / 9 |
| 12px 미만 글자(보기·편집) | 73 · 75 | 3 · 7 |
| 눌림 반응(`:active`) | 0 | 눌러지는 컴포넌트 전부 |
| 호버가 없던 컴포넌트 | 모드 스위치·접기 머리·진단 칩·편집 대상 | 0 |
| 포커스 고리 | 브라우저 기본 | 2px accent(다크 밝은 accent) |
| axe 색 대비 위반 (Clinic: 라이트·다크 × 보기·편집) | 1 · 1 · 1 · 3 | 0 · 0 · 0 · 0 |
| axe 색 대비 위반 (성수) | 2 · 1 · 2 · 3 | 1 · 0 · 1 · 0 |
| 남은 axe | 경고 영역 키보드 스크롤 불가, 미배치 링크 24px 미만 | 경고 영역(소스 `tabindex` 필요), `target-size` 해석 불확실, 성수 `.aux` 1곳 |

오버라이드로는 모양 수가 크게 줄지 않았다(31→27) — 같은 컴포넌트가 여러 클래스로 따로 구현돼 있어 소스 클래스 정리가 필요하다. 시험이 알려 준 규칙(표 안 단추 24px, 숫자 입력 폭 4.5rem, 팔레트 토글 예외, accent 면 위 글자는 `--on-accent`)은 3장에 반영했다.
