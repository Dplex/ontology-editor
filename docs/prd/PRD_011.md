## 1. 개요

### 1.1 배경 및 목적

- **[운영]** 운영 중 리모델링·벽체 변경·설비 재배치가 발생하면 3D 모델·공간 계층·설비 소속·관제 화면·AI 응답이 서로 다른 상태가 되기 쉽다. 변경 반영이 구축 조직이나 개별 시스템에 의존하면 느리고 무엇이 최신인지 알 수 없다.
- **[구축]** 온톨로지가 없는 사이트(예: SR 캠퍼스)는 물리존·공조존·설비·배관 정보를 처음부터 만들어야 한다. BIM이 있으면 가져와 골격을 자동 생성하고, 없으면 수동으로 구축할 수 있는 도구가 필요하다.
- 레이아웃 에디터는 두 목적을 한 도구에 담는다: **온톨로지 생성 툴**이면서, 권한 있는 운영자가 공간·오브젝트·공조존·배관을 **하나의 버전 단위로 편집하고 검증·영향 확인을 거쳐 게시**함으로써 모든 소비 시스템(관제 화면·이상 알림·계통도·AI Agent)의 기준 버전을 일치시킨다.
- 공간 변경 전 영향을 미리 검토할 수 있는 **미리보기**를 제공한다.

**사용자 플로우**
- 초기 구축: 에디터 실행 → 사이트·층 선택 → [BIM 가져오기](IDF 는 R2) 또는 [빈 층에서 시작] → 검토 화면(등급·요구사항·완전성) → 물리존·커스텀존·공조존·설비·배관 구축·보정 → 검증 → [온톨로지 생성·내보내기] → DT 등록
- 운영 편집: 에디터 진입 → 층 선택(잠금) → 편집 → ① [임시 저장] / ② [미리보기] → [반영하기] → DT·온톨로지 반영 + 새 버전 → 결과 리포트 → (필요 시) 되돌리기 / ③ [편집 종료]

### 1.2 대상 사용자

| User                      | Job to be done                                                |
| ------------------------- | ------------------------------------------------------------- |
| 구축 담당자 (삼성·협력사)           | IDF·BIM 또는 수동 입력으로 사이트의 초기 온톨로지(물리존·공조존·설비·배관)를 구축하고 DT에 등록한다 |

| 로봇 관제                     | 문·창문·벽·천장 설비의 통과 가능/불가 정보를 이동 경로 판단에 쓴다                       |

| 없음 | BIM 건축만 (MEP 없음, 등급 0) | 미지원 | 공간 골격만 자동. 설비 전량 수동(#13), R9 재제출 요청 병행 |
| 없음 | BIM 無 | 미지원 | 3D 스캔·평면도 배경에서 수동(#7) |
| 없음 | BIM 無 + IDF 有 | 미지원 | IDF 층 윤곽·존 외곽을 **참조선으로만** 제공, 물리존은 사용자가 작성. 벽 두께는 사이트 기본값(내벽 150 / 외벽 300mm). 공조존·설비 자동 |
| 있음 | 기존 온톨로지 + 3D 모델 | 운영 편집 (공간 편집 모드 / 설비 편집 모드, 층을 넘는 것은 다중층 뷰) | 층 잠금 · 임시 저장 · 미리보기 · 반영 · 버전 히스토리 |

※ BIM(물리 공간)과 공조존(에너지 시뮬레이션 IDF)은 별개 체계. 물리존은 BIM/스캔에서, 공조존은 IDF에서 오며 둘의 매핑을 에디터가 만든다.
※ **IFC2x3도 등급 0~2를 만족할 수 있다**(개발 실측: Revit 샘플·성수 전부 IFC2x3). IFC4는 권장(R10)이며 분기 조건이 아니다. gbXML·IDF는 공조존 출처(등급 5)이므로 분기 조건에서 제외.

| 항목 | 내용 |

### 1.8 BIM 수용 기준선과 등급

등급은 누적이다. 원본 BIM+계산의 **등급 0~3을 모두 통과**해야 자동 생성 게이트 통과이며, 등급 4는 목표선이다(D1·D12). 게이트 0~3 은 그룹장 결정을 기다리는 안이다(D1).

| 등급 | 지표 | 기준 | 적용 |
|---|---|---|---|
| 0 공간 골격 | 외곽선 있는 대상 IfcSpace 비율·층 이름 매핑 | 85% 이상·100% | 게이트 |
| 1 설비 위치 | 유효 형상 배치점 있는 대상 기기 비율 | 90% 이상 | 게이트 |
| 2 설비 소속 | 대상 기기의 물리존 소속 비율 | 85% 이상 | 게이트 |
| 3 계통 | 대상 기기의 계통 소속 비율 | 60% 이상 | 게이트 |
| 4 방향 | 대상 연결망 기기의 확정 흐름 방향 비율 | 50% 이상 | 목표·경고. 미확정 규칙 미리보기 제외 |
| 0+·4+·5 | 공간 의미·담당 공간·공조존/관제점 | 개발 정본의 추가 활용 단계 | 게이트 대체 조건 아님 |

**기준선 결정안 (D1, @그룹장)**

| 안 | 기준선 | 장점 | 위험 | 권고 |
|---|---|---|---|---|
| A | 등급 2 게이트 | 첫날 화면 셋 보장, 대부분 Revit 파일 도달 | 계통도 전부 수동 | |
| B | 등급 3 게이트 | 계통도 뼈대 자동 | 일반 Revit 내보내기 IfcSystem 0 → 재제출 급증, 첫날 화면이 계통 때문에 막힘 | |
| **C** | **게이트 = 등급 2, 목표선 = 등급 3** | A의 안전성 + 자동화 범위를 리포트로 소통 | 두 선 설명 필요 → 리포트 문구로 해결 | **권고** |

원본 게이트에는 BIM+계산만 포함하고 사전 후보·사용자 보정은 별도 성과로 표시한다. 지표별 대상·분자·분모·제외 사유·출처·산식 버전을 제공한다. 외벽 부착 등 해당 없음 제외는 명시하며, 피처를 읽지 않았다는 이유로 분모를 줄이지 않는다. 분모 0·미측정 필수 항목은 평가 불가로 두고 통과로 표시하지 않는다(OE-REQ-04·OE-BIM-16).

원본 미달이면 누락 R 항목·대상 ID·현재값/필요값·고객사 조치를 담은 재제출 가이드를 제공한다. 내보내기 설정의 검증 근거가 없으면 확인 필요로 표시한다. 기존 R1 도구로 보정한 최종 모델이 필수 생성 검증을 통과하면 생성 가능하되 원본 미달 등급·보정 출처·미해결 사항은 보존한다(OE-BIM-21·OE-GEN-02/03).

성수 기존 실측 89% 외곽선·100% 배치점·87.9% 소속·60% 계통(BIM 만, 사전 포함 97%)은 참고 자료이며 동일 대상·판본·산식으로 재검증해야 한다. 사전 포함 계통 수치와 미확정 규칙 포함 방향 수치를 원본·확정 목표 달성률로 사용하지 않는다.

누락 분류는 X(외부 입력: BAS·IDF), A(설정·속성 누락), B(부재 없음), C(관계 보정)이며 자동 추정 후보의 확정과 재제출 절차를 구분한다.

## 부록 A. 고객사 BIM 요구사항 R0~R26

고객사에 요구하는 BIM 항목 전체다(필수 13 · 권장 14). 요구·등급·빠졌을 때의 대응·실측은 개발 문서 [`../bim-to-dt-ontology.md`](../bim-to-dt-ontology.md) 4장(4.1 필수 · 4.2 권장)에서 옮겼고, 검사 파일은 [`../requirements.ids`](../requirements.ids) 다.

**필수는 세 조건을 모두 만족하는 것이다** — ① 생성 게이트 등급(1.8)에 필요하다 ② 빠지면 계산으로 되살릴 수 없다 ③ 코드가 실제로 쓴다. R13(GUID 유지)은 등급과 관계없지만 다시 내보낸 뒤에도 DT 쪽 id 가 유지되어야 해서 필수에 둔다. 권장은 없어도 게이트까지는 되고, 빠진 부분은 계산·사전·사람이 채운다(출처 표시).

**2026-10-08 R15·R16 을 권장에서 필수로 올렸다** — 생성 게이트를 등급 3(계통 소속 60%)까지로 올리는 안(D1, 그룹장 결정 대기)에 따른 것이다. 개발 문서 4장과 `requirements.ids` 는 아직 권장이라 반영이 필요하다. R25·R26 은 PRD 가 제안한 항목이라 개발 문서에 아직 없다.
