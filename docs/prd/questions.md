# 열린 것 — 결정(D) · 오픈 이슈(Q) · 확인(U) · 협의 실무(P)

PRD_011 4장(4.1 결정 사항, 4.2 오픈 이슈)과 부록 G(협의 실무)를 한 표로 옮긴 것이다. 결정이 나면 **행을 지우지 않고**
상태를 "결정됨(날짜)" 으로 바꾸고 결론을 "권고안 / 현재 상태" 칸에 한 줄 적는다. 티켓 파일은 본문에 번호만 적고
(`blocked_by: ["D1"]`), 사안은 여기에서만 설명한다. `prd.test.ts` 가 티켓이 가리키는 번호가 이 표에 있는지,
"영향 티켓" 열의 ID 가 실제 파일인지 확인한다.

시한의 W40·W41 은 2026년 ISO 주 번호다(W40 = 9/28~10/4, W41 = 10/5~10/11).

## 적는 법

- **새 사안**은 종류에 맞는 머리글자와 다음 번호를 쓴다. 번호는 재사용하지 않는다(원문 D·Q 번호가 띄엄띄엄인 것도 그래서다).
- **티켓 쪽**에는 `blocked_by`(이 결정이 나야 진행)나 `depends`(참고)에 번호만 적는다.
- **결정되면** 상태를 "결정됨(YYYY-MM-DD)" 으로, 권고안 칸을 결론으로 바꾼다. 영향 티켓의 `blocked_by` 에서 번호를 빼고 `status` 를 고치는 것은 그 티켓을 고치는 PR 에서 한다.
- 결정의 **이유**가 길면 PR 설명에 적고 여기에는 결론만 둔다. 이력은 git 이 든다.
