# OE-HIST-05 임시 저장과의 관계

## 관련 티켓

- [OE-HIST-03](./OE-HIST-03.md): 편집 파일, 완료 작업 규칙
- [OE-HIST-04](./OE-HIST-04.md): 복구용 자동 저장
- [OE-WF-01](../E14-WF/OE-WF-01.md): 임시 저장
- [OE-WF-03](../E14-WF/OE-WF-03.md): 층마다 하나인 임시 저장본
- [OE-WF-13](../E14-WF/OE-WF-13.md): 반영 때 만들어지는 버전
- [OE-GEN-05](../E08-GEN/OE-GEN-05.md): 구축 때 만들어지는 v1

## 요구사항
> User story : 구축 담당자와 고객사 관리자는 작업이 어떤 저장에 남는지 헷갈리지 않는다. 서비스가 복구용으로 보관하는 자동 저장, 사용자가 층마다 눌러 보관하는 [임시 저장], [반영하기]·[구축하기]로 남는 완료 작업·버전은 역할이 서로 다르다. 임시 저장본과 작업본, 자동 저장을 서버·로컬·브라우저 어디에 둘지는 개발 구현 방식에 따르며, 사용자는 어디에 있든 그것을 기반으로 이어서 편집할 수 있으면 된다. [임시 저장]을 누르는 동작과 같은 층에 들어가면 이어서 편집된다는 결과는 저장 위치와 무관하게 같아야 하며, 사용자는 저장 방식이 바뀌어도 기존 편집 파일을 그대로 불러올 수 있고 작업 습관을 바꾸지 않아도 된다는 것을 기대할 수 있어야 한다.

저장은 역할이 다른 넷이다.
- 자동 저장(OE-HIST-04) — 서비스가 수시로 보관하는 복구용. 사용자가 누르지 않고, 임시 저장본·버전·완료 작업을 만들지 않는다. 비정상 종료 뒤 다시 접속하면 반영할지 묻는다.
- [임시 저장](OE-WF-01) — 사용자가 누르는 층별 보관본. 층마다 1개이고 다시 저장하면 덮어쓴다(OE-WF-03). DT 와 온톨로지에 반영되지 않는다.
- 완료 작업·버전 — 운영 편집은 [반영하기]로(OE-WF-13), 초기 구축은 [구축하기]로(OE-GEN-05) 남고, 다중층 세션은 종료 때 한 작업으로 기록된다(OE-HIST-03).
- 편집 파일(OE-HIST-03) — 사용자가 직접 내려받고 불러오는 편집 기록. 형식은 저장 위치가 바뀌어도 유지한다.
임시 저장본·작업본·자동 저장의 저장 위치는 개발 구현 방식에 따르며 데이터 교환 방식 결정(D-INT)을 기다리지 않는다.

## 수용 기준

- **AC1** [임시 저장] 뒤 같은 층에 다시 들어가면 이어서 편집된다. 저장 위치가 무엇이든 같다.
- **AC2** 자동 저장은 임시 저장본·버전·완료 작업을 만들지 않는다.
- **AC3** 저장 위치가 바뀌어도 이전에 저장한 편집 파일을 그대로 불러올 수 있다.
