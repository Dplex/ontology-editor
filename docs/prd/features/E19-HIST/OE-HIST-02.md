# OE-HIST-02 다시 하기

## 관련 티켓

- [OE-UI-05](../E03-UI/OE-UI-05.md): 다시 하기 동작·수용 기준

## 요구사항

### User story

고객사 관리자가 Ctrl+Z로 되돌렸다가 '아까 게 맞았네' 싶을 때 Ctrl+Shift+Z나 버튼으로 되돌린 편집을 다시 실행한다. 동작은 OE-UI-05와 같다. 되돌리기와 다시 하기가 짝으로 제공되어 사용자가 두 상태를 비교하며 결정할 수 있고, 되돌린 뒤 새 편집을 하면 다시 하기 이력이 끊기는 일반적인 편집기 규칙을 따른다. 분할·병합처럼 여러 오브젝트에 영향을 주는 편집도 하나의 단위로 다시 실행되어 중간 상태가 생기지 않고, 되돌리기와 다시 하기 모두 저장·불러오기 뒤에는 세션 이력이 초기화된다.

OE-UI-05 를 따른다. (다시 하기)
