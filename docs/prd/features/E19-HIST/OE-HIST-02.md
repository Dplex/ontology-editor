# OE-HIST-02 다시 하기

## 관련 티켓

- [OE-UI-05](../E03-UI/OE-UI-05.md): 다시 하기 동작·수용 기준

## 요구사항
> User story : 고객사 관리자는 되돌렸던 편집을 다시 실행할 수 있다. 동작은 되돌리기/다시 실행 기능과 같다. 되돌리기와 다시 하기가 짝으로 제공되어 사용자가 두 상태를 비교하며 어느 쪽이 맞는지 결정할 수 있다. 분할·병합처럼 여러 오브젝트에 영향을 주는 편집도 하나의 단위로 다시 실행되어 중간 상태가 생기지 않는다. 사용자는 되돌린 뒤 새 편집을 하면 다시 하기 이력이 끊기는 일반적인 편집기 규칙을 기대할 수 있어야 하며, 다시 하기 역시 탭 안 이력으로 버전 히스토리와는 별개다.

OE-UI-05 를 따른다. (다시 하기)
