# OE-HIST-01 탭 내 되돌리기

## 관련 티켓

- [OE-UI-05](../E03-UI/OE-UI-05.md): 탭 안 되돌리기 동작·수용 기준

## 요구사항
> User story : 고객사 관리자가 편집 세션(탭) 안에서 직전 편집을 Ctrl+Z로 한 단계씩 되돌린다. 동작 규칙은 OE-UI-05와 같으며, 편집 이력 Epic 관점에서는 이 탭 내 이력이 서버에 기록되는 버전 히스토리와 분리되어 관리된다는 점이 핵심이다. 반영 전 시행착오를 자유롭게 되돌릴 수 있어 반영된 버전 히스토리가 시행착오로 지저분해지지 않는다. 모드를 바꿔도 이력이 이어지므로 공간 편집에서 벽을 그린 뒤 설비 편집으로 넘어가 Ctrl+Z를 눌러도 벽 편집이 되돌아가며, 사용자가 모드별로 이력이 따로 있는지 신경 쓰지 않아도 된다.

OE-UI-05 를 따른다. (탭 안 되돌리기)

## 수용 기준

OE-UI-05 의 수용 기준을 따른다.

## 검증 (이 repo)

- 어느 편집이든 Ctrl+Z 한 번으로 그 편집 전과 같아진다. 끝까지 되돌리면 연 때와 같다 — `edit.test.ts` "되돌리기"·"다시 하기", `e2e/edit-3d.spec.ts` "Ctrl+Z 세 번이면 한 단계씩", 성수 I-1·I-2
