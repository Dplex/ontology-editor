# OE-HIST-01 탭 내 되돌리기

## 관련 티켓

- [OE-UI-05](../E03-UI/OE-UI-05.md): 탭 안 되돌리기 동작·수용 기준

## 요구사항

> User story : 고객사 관리자는 편집 세션(탭) 안에서 직전 편집을 한 단계씩 되돌릴 수 있다. 동작 규칙은 되돌리기/다시 실행 기능과 같다. 편집 이력 관점에서 중요한 점은 이 탭 안의 이력이 서버에 기록되는 버전 히스토리와 분리되어 관리된다는 것이다. 사용자는 반영 전 시행착오를 자유롭게 되돌릴 수 있어 반영된 버전 히스토리가 시행착오로 지저분해지지 않으며, 모드를 바꿔도 이력이 이어져 공간 편집에서 벽을 그린 뒤 설비 편집으로 넘어가 되돌리기를 눌러도 벽 편집이 되돌아가는 것을 기대할 수 있어야 한다.

OE-UI-05 를 따른다. (탭 안 되돌리기)
