# OE-HIST-06 덧붙이기 후 재적용

## 요구사항
> User story : 구축 담당자가 건축 BIM을 먼저 열어 외곽선을 채우고 종류를 지정하다가 뒤늦게 MEP 파일을 받아 [덧붙이기]한다. 에디터가 처음 연 모델(pristine)에 MEP를 합친 뒤 편집 파일을 다시 적용하므로 이미 해 둔 보정이 그대로 남아 리포트의 편집 항목이 유지된다. 되돌리기 이력만 끊기므로 담당자는 덧붙이기 전 상태로 Ctrl+Z할 수는 없다는 것을 알고 작업한다. 덧붙이기 뒤에는 MEP 설비가 건축 공간 안에 들어와 소속 판정과 완전성 검사가 다시 돌아가므로, 담당자는 리포트에서 새로 들어온 설비의 소속 결과와 기존 보정이 공존하는지 확인한다.

편집한 뒤 파일을 덧붙이면(건축에 MEP 를 더하는 등) 처음 연 모델(`pristine`)을 합친 다음 편집 파일을 다시 적용한다. 편집은 남고 되돌리기 이력만 끊긴다.

## 수용 기준

편집 뒤 [덧붙이기] 해도 리포트의 편집 항목이 그대로 있다.

## 검증 (이 repo)

- 편집한 뒤 [덧붙이기] 하면 연 때의 모델을 합치고 편집 파일을 다시 얹는다. 소속을 안 바꾸는 편집이 리포트에서 사라지지 않는다 — `e2e/merge.spec.ts` "편집한 뒤에 덧붙여도 편집이 합친 모델에 그대로 남는다", `e2e/edit-safety.spec.ts` "방 이름만 고쳐도 덧붙이기는"
