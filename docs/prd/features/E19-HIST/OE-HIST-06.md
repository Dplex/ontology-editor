# OE-HIST-06 추가 파일 불러오기 후 재적용

## 관련 티켓

- [OE-HIST-03](./OE-HIST-03.md): 편집 파일 다시 적용
- [OE-UI-15](../E03-UI/OE-UI-15.md): 올린 파일마다 인식하는 분야·건물

## 요구사항
> User story : 구축 담당자가 건축 IFC 로 프로젝트를 시작해 보정하다가 뒤늦게 설비 IFC 를 받으면, 에디터의 [추가 파일 불러오기]로 설비 파일을 더할 수 있다. 에디터는 처음 연 원본 모델에 새 파일을 합친 뒤 그동안의 편집을 다시 적용하므로 해 둔 보정이 그대로 남는다. 같은 건물에서 이미 불러온 분야의 파일은 받지 않아, 건축 IFC 로 작업 중인 건물에 그 건물의 건축 IFC 를 다시 넣어 작업이 꼬이는 일이 없다. 다른 건물의 파일이나 그 건물에 아직 없는 분야의 파일은 받아서, 건물이 여럿인 사이트에서 B동 건축 IFC 를 뒤늦게 받아도 더할 수 있다. 같은 건물을 같은 분야의 파일로 처음부터 다시 하려면 새 프로젝트를 만든다. 되돌리기 이력은 끊기므로 사용자는 불러오기 전 상태로 되돌릴 수 없다는 것을 알고 작업한다.

에디터의 [추가 파일 불러오기]로 프로젝트에 아직 없는 건물이나 분야의 IFC 를 더한다.
- 분야는 IFC 파일이 사이트 모델에 더하는 내용의 구분이며 건축·설비 둘이다. 건축은 층·방(물리존)·벽·문·창 같은 공간 골격을 담은 파일, 설비는 공조·배관·덕트 같은 설비(MEP)와 계통을 담은 파일이다. 한 건물은 보통 건축 파일과 설비 파일로 나뉘어 나온다. 올린 파일의 분야와 건물은 처음 올릴 때와 같은 방식으로 인식한다(OE-UI-15 ①).
- 중복은 건물과 분야의 짝으로 가린다. 같은 건물에 이미 불러온 분야의 파일은 받지 않고, 같은 건물을 다시 시작하려면 [새 프로젝트]를 쓰라고 안내한다. 새 건물의 파일이나 그 건물에 아직 없는 분야의 파일은 받는다. IFC 외 형식은 받지 않는다.
- 불러오면 처음 연 모델에 새 파일을 합친 다음 편집 파일을 다시 적용한다(OE-HIST-03). 편집은 남고 되돌리기 이력만 끊긴다.
- 불러오기에 실패하면 기존 모델·편집·이력은 그대로 둔다.

## 수용 기준

- **AC1** 건축 IFC 로 시작한 프로젝트에서 설비 IFC 를 불러오면 설비가 더해지고 리포트의 편집 항목이 그대로 있다.
- **AC2** 건축 IFC 로 시작한 프로젝트에서 같은 건물의 건축 IFC 를 불러오려 하면 받지 않고 [새 프로젝트] 안내가 보인다.
- **AC3** A동 건축 IFC 로 시작한 프로젝트에 B동 건축 IFC 를 불러오면 받아서 B동이 더해지고, 기존 편집이 그대로 남는다.
- **AC4** IFC 가 아닌 파일은 받지 않고 이유가 보인다.

## 메모

한 파일이 건축과 설비를 함께 담은 경우의 분야 판정은 정하지 않았다. 설비 파일에도 방이 들어 있을 수 있고(Duplex MEP), 건축 파일에 설비성 부재가 들어 있을 수도 있다(성수).
