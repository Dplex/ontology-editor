# OE-HIST-06 추가 파일 불러오기 후 재적용

## 관련 티켓

- [OE-HIST-03](./OE-HIST-03.md): 편집 파일 다시 적용

## 요구사항
> User story : 구축 담당자가 건축 IFC 로 프로젝트를 시작해 보정하다가 뒤늦게 설비 IFC 를 받으면, 에디터의 [추가 파일 불러오기]로 설비 파일을 더할 수 있다. 에디터는 처음 연 원본 모델에 새 파일을 합친 뒤 그동안의 편집을 다시 적용하므로 해 둔 보정이 그대로 남는다. 이미 불러온 분야의 파일은 받지 않아, 건축 IFC 로 작업 중인 프로젝트에 건축 IFC 를 다시 넣어 작업이 꼬이는 일이 없다. 같은 분야의 파일로 처음부터 다시 하려면 새 프로젝트를 만든다. 되돌리기 이력은 끊기므로 사용자는 불러오기 전 상태로 되돌릴 수 없다는 것을 알고 작업한다.

에디터의 [추가 파일 불러오기]로 프로젝트에 아직 불러오지 않은 분야의 IFC 를 더한다.
- 분야는 건축·설비로 구분한다. 프로젝트에 이미 불러온 분야의 파일은 받지 않고, 같은 분야로 다시 시작하려면 [새 프로젝트]를 쓰라고 안내한다. IFC 외 형식은 받지 않는다.
- 불러오면 처음 연 모델에 새 파일을 합친 다음 편집 파일을 다시 적용한다(OE-HIST-03). 편집은 남고 되돌리기 이력만 끊긴다.
- 불러오기에 실패하면 기존 모델·편집·이력은 그대로 둔다.

## 수용 기준

- **AC1** 건축 IFC 로 시작한 프로젝트에서 설비 IFC 를 불러오면 설비가 더해지고 리포트의 편집 항목이 그대로 있다.
- **AC2** 건축 IFC 로 시작한 프로젝트에서 건축 IFC 를 불러오려 하면 받지 않고 [새 프로젝트] 안내가 보인다.
- **AC3** IFC 가 아닌 파일은 받지 않고 이유가 보인다.

## 메모

한 사이트에 건물이 여럿일 때 다른 건물의 건축 IFC 를 나중에 더하는 경우는 정하지 않았다.
