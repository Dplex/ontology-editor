# OE-HIST-04 자동 저장

## 관련 티켓

- [OE-WF-02](../E14-WF/OE-WF-02.md): 임시 저장본을 묻지 않고 엶
- [OE-WF-06](../E14-WF/OE-WF-06.md): 프로젝트 작업본(초기 구축의 시작 상태)
- [OE-HIST-03](./OE-HIST-03.md): 완료 작업 저장과 구분

## 요구사항
> User story : 구축 담당자와 고객사 관리자는 편집 중 서비스가 알 수 없는 이유로 종료되어도 작업을 되살릴 수 있다. 자동 저장은 사용자가 누르지 않아도 서비스가 편집 내용을 수시로 보관해 두는 복구용 저장이다. 다시 접속하면 "자동 저장된 내용을 반영하시겠습니까?"라고 묻고, 예를 고르면 자동 저장된 상태 그대로 열리고 아니오를 고르면 자동 저장은 지워지고 가장 최근의 임시 저장본이나 반영 기록 기준으로 열린다. 자동 저장은 임시 저장본이나 버전을 만들지 않으므로 [임시 저장]과 반영 이력이 지저분해지지 않는다. 편집이 남아 있는 채로 탭을 닫으려 하면 확인을 받아, 실수로 작업을 날리지 않는다.

편집 내용을 자동 저장한다. 복구용이며 임시 저장본·버전·완료 작업을 만들지 않는다(OE-HIST-03). 자동 저장을 서버·로컬·브라우저 어디에 둘지는 개발 구현 방식에 따른다. 사용자에게는 보관 위치가 드러나지 않고, 자동 저장이 되고 다시 접속하면 복구된다는 결과만 같으면 된다.
서비스가 비정상으로 종료된 뒤 같은 작업을 다시 열면 "자동 저장된 내용을 반영하시겠습니까?"를 묻는다.
- 예 — 자동 저장된 상태 그대로 불러온다.
- 아니오 — 그 자동 저장을 지우고, 그 층의 임시 저장본이 있으면 그것으로 연다(OE-WF-02). 없으면 가장 최근 반영한 레이아웃으로(운영 편집), 초기 구축은 임포트 결과로 연다(OE-WF-06).
정상적으로 [임시 저장]·[반영하기]·[구축하기]를 했거나 변경을 버리고 종료한 뒤에는 그 시점까지의 자동 저장을 묻지 않는다. 연 직후 편집이 0 인 상태로는 기록을 지우지 않는다. 편집이 남아 있으면 탭을 닫기 전에 묻는다.

## 수용 기준

- **AC1** 편집 중 서비스가 비정상으로 종료된 뒤 같은 작업을 다시 열면 "자동 저장된 내용을 반영하시겠습니까?"가 뜬다.
- **AC2** [예]를 고르면 자동 저장된 상태 그대로 열린다.
- **AC3** [아니오]를 고르면 그 자동 저장이 지워지고, 그 층의 임시 저장본으로, 임시 저장본이 없으면 가장 최근 반영한 레이아웃(초기 구축은 임포트 결과)으로 열린다. 다시 열어도 같은 질문이 또 뜨지 않는다.
- **AC4** 자동 저장은 임시 저장본이나 버전을 만들지 않는다.
- **AC5** 편집이 남아 있는 채로 탭을 닫으려 하면 확인을 묻는다.
