# OE-HIST-04 브라우저 자동 저장

## 관련 티켓

- [OE-WF-02](../E14-WF/OE-WF-02.md): 임시 저장본을 묻지 않고 엶
- [OE-WF-06](../E14-WF/OE-WF-06.md): 프로젝트 작업본

## 요구사항
> User story : 구축 담당자는 편집 내용이 브라우저에 자동으로 저장되는 것을 믿고 작업할 수 있다. 작업본 저장 위치가 정해지기 전까지 브라우저 자동 저장이 작업본 역할을 하며, 프로젝트를 다시 열면 묻지 않고 이어서 열리고 화면에 이어서 편집 중임이 표시된다. 편집이 남아 있는 채로 탭을 닫으려 하면 확인을 받아, 실수로 작업을 날리지 않는다.

편집 내용을 브라우저에 자동 저장한다. 프로젝트를 다시 열면 묻지 않고 이어서 열고(OE-WF-02·06), 이어서 편집 중임을 화면에 보인다. 연 직후 편집이 0 인 상태로는 기록을 지우지 않는다. 편집이 남아 있으면 탭을 닫기 전에 묻는다.

## 수용 기준

- 편집 뒤 탭을 닫고 같은 프로젝트를 다시 열면 묻지 않고 편집이 돌아오고, 이어서 편집 중임이 표시된다.
- 편집이 남아 있는 채로 탭을 닫으려 하면 확인을 묻는다.

## 검증 (이 repo)

- 편집이 브라우저에 자동 저장되고, 같은 IFC(합친 조합까지 같을 때)를 다시 열면 이어서 할지 묻는다. 연 직후 편집 0 인 상태로는 기록을 지우지 않는다 — `e2e/autosave.spec.ts`, 성수 K-3~K-6
- 편집이 남아 있으면 다른 파일을 열거나 탭을 닫기 전에 묻는다 — `e2e/edit-safety.spec.ts`
