# OE-HIST-04 브라우저 자동 저장

## 요구사항
> User story : 구축 담당자가 편집하는 동안 내용이 브라우저에 자동 저장된다. 브라우저가 멈춰 탭이 닫혀도 같은 BIM(합친 조합까지 같은 경우)을 다시 열면 이어서 할지 묻고, 예를 고르면 편집이 돌아온다. 연 직후 편집이 하나도 없는 상태로는 기록을 지우지 않아 실수로 열었다 닫아도 이전 작업이 사라지지 않는다. 편집이 남아 있는 채 다른 파일을 열거나 탭을 닫으려 하면 확인을 묻는다. 사용자는 몇 시간 보정하다 예기치 않게 종료되어도 작업을 잃지 않는다는 것을 신뢰할 수 있어야 한다.

편집 내용을 브라우저에 자동 저장한다. 같은 IFC(합친 조합까지 같을 때)를 다시 열면 이어서 할지 묻는다. 연 직후 편집이 0 인 상태로는 기록을 지우지 않는다. 편집이 남아 있으면 다른 파일을 열거나 탭을 닫기 전에 묻는다.

## 수용 기준

편집 뒤 탭을 닫고 같은 IFC 를 다시 열면 이어서 할지 묻고, 예를 고르면 편집이 돌아온다.

## 검증 (이 repo)

- 편집이 브라우저에 자동 저장되고, 같은 IFC(합친 조합까지 같을 때)를 다시 열면 이어서 할지 묻는다. 연 직후 편집 0 인 상태로는 기록을 지우지 않는다 — `e2e/autosave.spec.ts`, 성수 K-3~K-6
- 편집이 남아 있으면 다른 파일을 열거나 탭을 닫기 전에 묻는다 — `e2e/edit-safety.spec.ts`
