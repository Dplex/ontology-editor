# OE-HIST-03 편집 파일 저장·불러오기

## 관련 티켓

- [OE-MAP-01](../E11-MAP/OE-MAP-01.md): 사람이 지정한 설비 소속
- [OE-UI-15](../E03-UI/OE-UI-15.md): 시작 화면은 IFC 업로드만
- [OE-HIST-04](./OE-HIST-04.md): 완료 작업과 구분하는 복구용 자동 저장

## 요구사항
> User story : 사용자는 편집 내용을 편집 파일로 저장하고 다시 불러올 수 있다. 저장한 편집 파일을 다시 불러올 때, 사용자가 마지막으로 수정한 내용이 반영된 최신 파일을 불러올 수 있어야 한다. 

원본 파일/판본 식별 정보와 편집 파일 형식 버전을 보관한다. 
동일 ID 또는 유일하게 매칭되는 보조 식별자만 재적용하고 미매칭·복수·충돌·삭제 대상을 보고한다. 
사람 소속 재판정 K17과 연결 해제·유체·방향·형상 보정 보존을 구분한다. 
단일 층 편집에서 다중층 모드에 진입하기 전 현재 층의 편집을 별도 층 작업으로 저장한다. 저장 성공을 확인한 상태를 다중층 세션의 기준으로 삼고 저장 실패 시 화면·편집을 유지하여 진입을 완료하지 않는다. 
다중층 모드 진입부터 종료까지의 모든 모델 변경은 층과 관계없이 하나의 세션 작업 ID에 묶어 저장하며, 보는 층이나 공간/설비 모드를 바꾸어도 작업을 나누지 않는다.이전 층 작업은 기준 이력으로 보존하고 다중층 세션에서 발생한 차이만 새로운 작업으로 기록한다. 다중층 종료 시 전체 영향 층의 저장이 성공한 후에만 층 편집으로 돌아가고 실패 시 복구 가능한 세션을 유지한다. 나중에 다시 다중층 모드를 열면 별도 세션이 시작된다.
완료 작업 저장과 복구용 자동 저장(OE-HIST-04)을 구분하며 자동 저장마다 완료 작업·버전을 생성하지 않는다.
편집 파일에 담기는 변경 목록(편집 기록)과 탭 안에서 되돌리는 되돌리기 이력은 다르다. 불러오면 편집 기록이 복원된다.

편집 파일 저장·불러오기는 에디터 안에서 한다. 초기 구축 시작 화면은 IFC 업로드만 두므로(OE-UI-15) 그곳에 두지 않는다.


## 수용 기준

- **AC1** 사람이 지정한 소속이 저장·불러오기 뒤에도 유지되고, 다시 연 판본에서 그 설비가 외곽선 안에 들면 지정이 풀리고 알림이 보인다
- **AC2** 동일 기준 모델에서는 산출물·확정·검토·해제 상태가 복원된다. 새 판본에서 미매칭은 조용히 버리지 않고 보고하며 충돌은 확인 전 활성화되지 않는다.
- **AC3** 추가 파일 불러오기 실패 시 기존 모델·편집·되돌리기 이력은 유지되고 성공 후 되돌리기 이력 초기화를 안내한다. 다중층 진입 전 층 작업과 다중층 종료 시 작업이 서로 다른 ID로 기록되고, 다중층에서 서로 다른 층·모드로 작업해도 종료까지 완료 저장 기록이 하나의 작업으로 묶인다.
- **AC4** 복구용 자동 저장은 추가 완료 버전을 만들지 않고 개별 undo가 동작한다. - 시작 전 층 저장·종료 저장 실패 시 기존 편집이 남고 화면 전환이 완료되지 않는다. 층별 형상·개구부·면적·배관·연결·소속과 편집 기록을 함께 복원한다.
