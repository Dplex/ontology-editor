# OE-WF-05 임시 저장 후 잠금 해제

## 관련 티켓

- [OE-COM-06](../E01-COM/OE-COM-06.md): 종료 시 편집 잠금 해제
- [OE-COM-03](../E01-COM/OE-COM-03.md): 다른 권한자의 이어 편집

## 요구사항
> User story : R2에서 고객사 관리자가 [임시 저장] 뒤 에디터를 종료하면 그 층의 편집 잠금이 즉시 풀린다. 임시 저장본은 층의 것으로 남아 있어 다른 편집 권한자가 바로 그 층에 들어가 이어서 편집할 수 있다. 작업이 특정 사용자 계정에 묶여 멈추지 않고, 잠금이 남아 다른 사람이 못 들어가는 일도 없다. 사용자는 교대 근무나 담당자 변경 환경에서 레이아웃 변경을 팀 단위로 이어 갈 수 있어야 하며, 이어받은 사람이 반영하면 임시 저장본에 담긴 이전 사용자의 편집도 함께 반영된다.

[임시 저장] 뒤 에디터를 종료하면 편집 잠금을 푼다(OE-COM-06). 임시 저장본은 남아 있어 다른 편집 권한자가 이어서 편집할 수 있다(OE-COM-03).

## 수용 기준

임시 저장 후 종료한 층에 다른 사용자가 바로 들어갈 수 있다.
