# OE-WF-05 임시 저장 후 잠금 해제

## 요구사항

[임시 저장] 뒤 에디터를 종료하면 편집 잠금을 푼다(OE-COM-06). 임시 저장본은 남아 있어 다른 편집 권한자가 이어서 편집할 수 있다(OE-COM-03).

## 수용 기준

임시 저장 후 종료한 층에 다른 사용자가 바로 들어갈 수 있다.
