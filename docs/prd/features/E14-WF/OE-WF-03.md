# OE-WF-03 단일 임시 저장본

## 요구사항

### User story

고객사 관리자가 같은 층을 여러 번 [임시 저장]해도 저장본은 하나뿐이고 새 저장이 이전 것을 덮어쓴다. 목록·복사·이름 붙이기가 없어 '어느 저장본을 열어야 하지' 고민하거나 오래된 저장본을 잘못 열어 반영하는 실수가 없다. 임시 저장은 작업 중단 지점을 보관하는 용도일 뿐 버전 관리는 반영 후 버전 히스토리가 맡는다는 역할 구분이 명확해진다. 다시 저장할 때 이전 저장본을 덮어쓴다는 사실이 명확하므로 '이전 저장본으로 돌아가고 싶으면 폐기 후 반영 레이아웃에서 다시 시작한다'는 단순한 규칙으로 사용자가 상태를 관리한다.

임시 저장본은 층마다 1개만 둔다. 목록·복사·이름 붙이기는 없다. 다시 [임시 저장] 하면 덮어쓴다(PRD 변경 이력 v1.1).

## 수용 기준

[임시 저장] 을 두 번 해도 임시 저장본이 하나다.
