# OE-WF-03 단일 임시 저장본

## 요구사항
> User story : 고객사 관리자가 같은 층을 여러 번 [임시 저장]해도 임시 저장본은 하나뿐이며 새 저장이 이전 것을 덮어쓴다. 저장본 목록·복사·이름 붙이기는 없다. 사용자는 어느 저장본을 열어야 할지 고민하거나 오래된 저장본을 잘못 열어 반영하는 실수 없이, 임시 저장은 작업 중단 지점을 보관하는 용도이고 버전 관리는 반영 후 버전 히스토리가 맡는다는 단순한 역할 구분으로 상태를 관리할 수 있어야 한다. 이전 저장본으로 돌아가고 싶으면 폐기 후 반영된 레이아웃에서 다시 시작한다.

임시 저장본은 층마다 1개만 둔다. 목록·복사·이름 붙이기는 없다. 다시 [임시 저장] 하면 덮어쓴다(PRD 변경 이력 v1.1).

## 수용 기준

[임시 저장] 을 두 번 해도 임시 저장본이 하나다.
