# OE-WF-06 임포트 결과 = 임시 저장본

## 요구사항
> User story : 구축 담당자가 대형 BIM을 임포트하고 검토·보정하다가 퇴근할 때, 임포트 결과와 보정 내용이 임시 저장본으로 보관되어 다음 날 에디터를 열면 그대로 이어서 작업한다. 수백 MB 파일을 다시 파싱하거나 어제 손본 외곽선·종류 지정을 반복하지 않아도 된다. 보정이 끝나면 임시 저장본에서 온톨로지를 생성하므로, 임포트→보정→생성이 끊기지 않는 하나의 흐름으로 이어지고 R2에서는 IDF 임포트 결과도 같은 방식으로 보관된다.

초기 구축 모드의 BIM 임포트 결과도(R2 부터 IDF 임포트 결과도) 임시 저장본으로 보관하고(#5·#6), 수동 보정한 뒤 온톨로지를 생성한다(#8).

## 수용 기준

임포트 뒤 에디터를 닫았다 다시 열면 임포트 결과와 보정 내용이 그대로 있다.
