# OE-WF-06 임포트 결과 = 임시 저장본

## 요구사항
> User story : 구축 담당자가 초기 구축 모드에서 BIM을 임포트하면 그 결과가 임시 저장본으로 보관되고, R2부터 IDF나 gbXML 임포트 시에도 동일하다. 임포트 시 바로 온톨로지가 생성되는 것이 아닌, 사용자가 임포트 결과를 확인하고 결과를 수동으로 보정한 뒤 생성할 수 있다. 임포트와 보정이 며칠에 걸쳐도 에디터를 닫았다 다시 열면 임포트 결과와 보정 내용이 그대로 있어, 큰 파일을 다시 파싱하거나 사용자 변경사항을 다시 반복하지 않아도 된다. 사용자는 임포트에서 보정, 생성까지가 끊기지 않는 하나의 흐름으로 이어지는 것을 기대할 수 있어야 한다.

초기 구축 모드의 BIM 임포트 결과도(R2 부터 IDF 임포트 결과도) 임시 저장본으로 보관하고(#5·#6), 수동 보정한 뒤 온톨로지를 생성한다(#8).

## 수용 기준

임포트 뒤 에디터를 닫았다 다시 열면 임포트 결과와 보정 내용이 그대로 있다.
