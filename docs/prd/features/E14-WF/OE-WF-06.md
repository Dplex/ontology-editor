# OE-WF-06 임포트 결과 = 임시 저장본

## 관련 티켓

- [OE-UI-02](../E03-UI/OE-UI-02.md): 프로젝트 기반 모드 분기
- [OE-UI-15](../E03-UI/OE-UI-15.md): 초기 구축 화면 흐름
- [OE-WF-03](./OE-WF-03.md): 층별 임시 저장본
- [OE-GEN-05](../E08-GEN/OE-GEN-05.md): 구축 뒤 v1 기록
- [OE-GEN-01](../E08-GEN/OE-GEN-01.md): [구축하기] 온톨로지 생성

## 요구사항
> User story : 구축 담당자가 새 프로젝트의 시작 화면에서 BIM을 올리면 사이트 전체의 임포트 결과가 그 프로젝트의 작업본으로 보관된다. 사용자는 임포트 결과를 바로 온톨로지로 만들지 않고 층마다 편집·보정하며 임시 저장한 뒤 구축한다. 임포트와 보정이 며칠에 걸쳐도 프로젝트 목록에서 그 프로젝트를 누르면 시작 화면을 거치지 않고 임포트 결과와 층별 보정 내용이 그대로 열려, 큰 파일을 다시 파싱하거나 손본 내용을 반복하지 않아도 된다.

초기 구축의 BIM 임포트 결과는 그 프로젝트의 작업본으로 보관한다(R2 부터 IDF 임포트 결과도 같다). 임포트 결과가 각 층의 시작 상태이고, 층별 임시 저장본(OE-WF-03)이 그 위에 쌓인다. 보정을 마치고 [구축하기]로 온톨로지를 생성한다(OE-GEN-01).
- 프로젝트 목록에서 프로젝트를 누르면 시작 화면을 거치지 않고 에디터가 열린다(OE-UI-02).
- 새 작업본은 [새 프로젝트]로만 만든다.
- 구축이 끝나면 v1 으로 기록되고(OE-GEN-05) 이후는 운영 편집 규칙을 따른다.

## 수용 기준

- **AC1** 임포트 뒤 에디터를 닫았다가 프로젝트를 다시 열면 임포트 결과와 층별 임시 저장 내용이 그대로 있다.
- **AC2** 프로젝트를 다시 열면 시작 화면 없이 에디터가 열린다.
