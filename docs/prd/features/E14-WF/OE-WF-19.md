# OE-WF-19 되돌리기

## 요구사항

히스토리에서 버전을 골라 [되돌리기] 하면 그 버전의 레이아웃을 새 반영으로 적용한다 — 새 버전이 생기고 이력은 보존된다(KPI_2). 배너·GNB 알림은 반영과 같이 보낸다(OE-WF-15·16). 반영 결과 리포트에서 바로 들어올 수도 있다(OE-SYNC-05).

## 수용 기준

되돌리기 뒤 히스토리에 새 버전이 생기고 되돌린 대상 버전도 남아 있다.
