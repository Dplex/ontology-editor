# OE-WF-19 되돌리기

## 관련 티켓

- [OE-WF-15](./OE-WF-15.md): 되돌리기 배너
- [OE-WF-16](./OE-WF-16.md): 되돌리기 GNB 알림
- [OE-SYNC-05](../E15-SYNC/OE-SYNC-05.md): 리포트에서 바로 진입

## 요구사항
> User story : 고객사 관리자가 어제 반영한 레이아웃에서 설비 소속이 대거 잘못 바뀐 것을 발견하고 버전 히스토리에서 그제 버전을 골라 [되돌리기]한다. 되돌리기는 그 버전을 새 반영으로 적용하므로 새 버전이 생기고 잘못된 버전도 이력에 남아 '무엇이 잘못됐었는지' 나중에 추적할 수 있다. 배너·GNB 알림이 반영과 똑같이 나가 관제 사용자가 변경을 인지하고, 반영 결과 리포트에서 바로 들어올 수도 있다. 되돌리기도 하나의 반영이므로 미리보기·확인 팝업·반영 결과 리포트가 같은 흐름으로 제공되고, 되돌린 결과가 또 문제면 다시 다른 버전으로 되돌릴 수 있어 복구 경로가 끊기지 않는다.

히스토리에서 버전을 골라 [되돌리기] 하면 그 버전의 레이아웃을 새 반영으로 적용한다 — 새 버전이 생기고 이력은 보존된다(KPI_2). 배너·GNB 알림은 반영과 같이 보낸다(OE-WF-15·16). 반영 결과 리포트에서 바로 들어올 수도 있다(OE-SYNC-05).

## 수용 기준

되돌리기 뒤 히스토리에 새 버전이 생기고 되돌린 대상 버전도 남아 있다.
