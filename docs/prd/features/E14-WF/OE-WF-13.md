# OE-WF-13 반영 시 새 버전

## 관련 티켓

- [OE-WF-18](./OE-WF-18.md): 새 버전 히스토리 기록
- [OE-SYNC-04](../E15-SYNC/OE-SYNC-04.md): 버전에 붙는 결과 리포트
- [OE-GEN-05](../E08-GEN/OE-GEN-05.md): 초기 구축 v1

## 요구사항

반영이 성공하면 즉시 새 버전을 만들고 버전 히스토리(OE-WF-18)에 기록한다. 버전에는 반영 일시·반영자·변경 요약·대상 층·반영 결과 리포트(OE-SYNC-04)를 붙인다. 초기 구축의 v1 은 OE-GEN-05.

## 수용 기준

반영 1회에 버전 1개가 생기고 메타 항목이 모두 채워져 있다.
