# OE-WF-13 반영 시 새 버전

## 관련 티켓

- [OE-WF-18](./OE-WF-18.md): 새 버전 히스토리 기록
- [OE-SYNC-04](../E15-SYNC/OE-SYNC-04.md): 버전에 붙는 결과 리포트
- [OE-GEN-05](../E08-GEN/OE-GEN-05.md): 초기 구축 v1

## 요구사항

### User story

고객사 관리자가 반영에 성공하면 즉시 새 버전이 만들어져 버전 히스토리에 반영 일시·반영자·변경 요약·대상 층·반영 결과 리포트가 붙는다. 일주일 뒤 '3층 회의실 센서 위치가 왜 바뀌었지' 하는 질문이 나오면 히스토리에서 해당 버전을 찾아 누가 언제 무엇을 바꿨는지 리포트로 설명한다. 반영 1회에 버전 1개가 생겨 변경 단위가 명확하고, 초기 구축의 v1부터 이어진다. 변경 요약과 리포트가 버전에 붙어 있어 되돌리기 대상을 고를 때 어떤 버전이 어떤 변경을 담았는지 비교할 수 있고, 시스템 로그의 버전 번호와도 맞아 감사 추적이 끊기지 않는다.

반영이 성공하면 즉시 새 버전을 만들고 버전 히스토리(OE-WF-18)에 기록한다. 버전에는 반영 일시·반영자·변경 요약·대상 층·반영 결과 리포트(OE-SYNC-04)를 붙인다. 초기 구축의 v1 은 OE-GEN-05.

## 수용 기준

반영 1회에 버전 1개가 생기고 메타 항목이 모두 채워져 있다.
