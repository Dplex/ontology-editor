# OE-WF-16 시스템 알림(GNB)

## 관련 티켓

- [OE-XPRD-02](../E22-XPRD/OE-XPRD-02.md): 레이아웃 변경 알림 종류 추가

## 요구사항
> User story : 일반 관제 사용자가 DT 다른 메뉴에서 작업 중이라 배너를 못 봤더라도 GNB 시스템 알림에 '레이아웃 변경 반영' 항목이 생겨 대상 층·반영자·버전 번호를 확인한다. 나중에 '언제 누가 5층 레이아웃을 바꿨는지' 알림 이력에서 찾을 수 있고, 다른 종류의 시스템 알림과 같은 자리에 쌓여 레이아웃 변경을 별도 채널로 챙기지 않아도 된다. 알림 유형이 PRD_002에 정식으로 추가되므로 사용자가 알림 설정에서 이 유형의 수신 여부를 다른 시스템 알림과 같은 방식으로 관리할 수 있고, 알림을 눌러 해당 버전의 리포트로 이동하는 것도 가능하다.

반영 사실을 GNB 시스템 알림으로 보낸다. 알림 종류는 PRD_002 에 '레이아웃 변경 반영' 을 더한다(OE-XPRD-02). 알림에 대상 층·반영자·버전 번호를 넣는다.

## 수용 기준

반영 뒤 GNB 알림에 '레이아웃 변경 반영' 항목이 생긴다.
