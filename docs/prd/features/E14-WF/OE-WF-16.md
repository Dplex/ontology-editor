# OE-WF-16 시스템 알림(GNB)

## 관련 티켓

- [OE-XPRD-02](../E22-XPRD/OE-XPRD-02.md): 레이아웃 변경 알림 종류 추가

## 요구사항
> User story : 일반 관제 사용자는 레이아웃이 반영되면 GNB 시스템 알림에서 '레이아웃 변경 반영' 항목을 볼 수 있다. 알림에는 대상 건물·층·반영자·버전 번호가 들어 있다. 다른 메뉴에서 작업 중이라 배너를 못 봤더라도 알림으로 확인할 수 있고, 나중에 언제 누가 어느 건물의 어느 층 레이아웃을 바꿨는지 알림 이력에서 찾을 수 있다. 알림 종류는 알림 PRD에 정식으로 추가되므로 사용자는 알림 설정에서 이 유형의 수신 여부를 다른 시스템 알림과 같은 방식으로 관리할 수 있어야 한다.

반영 사실을 GNB 시스템 알림으로 보낸다. 알림 종류는 PRD_002 에 '레이아웃 변경 반영' 을 더한다(OE-XPRD-02). 알림에 대상 건물·층·반영자·버전 번호를 넣는다.

## 수용 기준

- **AC1** 반영 뒤 GNB 알림에 '레이아웃 변경 반영' 항목이 생긴다.
