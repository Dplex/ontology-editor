# OE-WF-02 임시 저장본 자동 동기화

## 관련 티켓

- [OE-WF-04](./OE-WF-04.md): 임시 저장본 버리고 새로 시작
- [OE-WF-01](./OE-WF-01.md): 층별 임시 저장본

## 요구사항

임시 저장본이 있는 층에 들어가면 묻지 않고 임시 저장본을 열어 이어서 편집한다. 임시 저장본을 버리고 현재 레이아웃에서 시작하려면 폐기(OE-WF-04)한다.

## 수용 기준

임시 저장본이 있는 층에 들어가면 저장했던 편집 상태가 보인다.
