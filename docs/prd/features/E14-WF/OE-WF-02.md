# OE-WF-02 임시 저장본 자동 동기화

## 관련 티켓

- [OE-WF-04](./OE-WF-04.md): 임시 저장본 버리고 새로 시작
- [OE-WF-01](./OE-WF-01.md): 층별 임시 저장본

## 요구사항

### User story

고객사 관리자가 어제 임시 저장한 3층에 오늘 다시 들어가면 '임시 저장본을 여시겠습니까?' 같은 질문 없이 바로 저장했던 편집 상태가 열려 이어서 작업한다. 매번 묻는 팝업이 없어 작업 재개가 빠르고, 임시 저장본을 버리고 현재 반영된 레이아웃에서 새로 시작하고 싶을 때만 폐기 기능을 명시적으로 쓴다. 임시 저장본이 있다는 사실을 잊고 반영된 레이아웃을 중복 편집하는 일이 없다. 자동으로 열리는 저장본은 상단에 임시 저장본임이 표시되어 사용자가 현재 보는 것이 반영된 레이아웃이 아님을 인지하고, 저장본에서 계속 편집하거나 폐기할지 스스로 판단한다.

임시 저장본이 있는 층에 들어가면 묻지 않고 임시 저장본을 열어 이어서 편집한다. 임시 저장본을 버리고 현재 레이아웃에서 시작하려면 폐기(OE-WF-04)한다.

## 수용 기준

임시 저장본이 있는 층에 들어가면 저장했던 편집 상태가 보인다.
