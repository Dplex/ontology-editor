# OE-WF-02 임시 저장본 자동 동기화

## 관련 티켓

- [OE-WF-04](./OE-WF-04.md): 임시 저장본 버리고 새로 시작
- [OE-WF-01](./OE-WF-01.md): 층별 임시 저장본
- [OE-WF-06](./OE-WF-06.md): 초기 구축 프로젝트 작업본
- [OE-HIST-04](../E19-HIST/OE-HIST-04.md): 비정상 종료 뒤 자동 저장 복구

## 요구사항
> User story : 고객사 관리자가 임시 저장본이 있는 층에 들어가면 묻지 않고 바로 저장했던 편집 상태가 열려 이어서 작업할 수 있다. 매번 묻는 팝업이 없어 작업 재개가 빠르고, 임시 저장본이 있다는 사실을 잊고 반영된 레이아웃을 중복 편집하는 일이 없다. 임시 저장본을 버리고 현재 반영된 레이아웃에서 새로 시작하고 싶을 때는 폐기 기능을 명시적으로 쓴다. 사용자는 자동으로 열린 것이 임시 저장본이라는 것을 화면에서 인지하고, 계속 편집할지 폐기할지 스스로 판단할 수 있어야 한다.

임시 저장본이 있는 층에 들어가면 묻지 않고 임시 저장본을 열어 이어서 편집한다. 임시 저장본을 버리고 현재 레이아웃에서 시작하려면 폐기(OE-WF-04)한다.
초기 구축 프로젝트를 열 때도 층별 임시 저장본을 묻지 않고 연다(OE-WF-06).
다만 서비스가 비정상으로 종료된 뒤에 다시 열면 복구용 자동 저장이 있을 때 먼저 그것을 반영할지 묻는다(OE-HIST-04). 아니오를 고르면 이 티켓대로 임시 저장본을 연다.

## 수용 기준

- **AC1** 임시 저장본이 있는 층에 들어가면 저장했던 편집 상태가 보인다.
- **AC2** 비정상 종료 뒤 다시 들어가면 자동 저장을 반영할지 먼저 묻고, 아니오를 고르면 임시 저장본이 열린다.
