# OE-WF-21 알림 위치 = 현재 버전

## 관련 티켓

- [OE-SYNC-01](../E15-SYNC/OE-SYNC-01.md): 반영된 버전의 설비 소속

## 요구사항
> User story : 일반 관제 사용자가 이상 알림을 열면 '발생 위치'가 알림 당시 저장된 문자열이 아니라 현재 로드한 레이아웃 버전에서 그 설비의 소속을 조회한 값으로 보인다. 설비를 다른 방으로 옮겨 반영했으면 과거 알림의 위치도 새 방으로 보여 3D에서 보이는 위치와 항상 일치하고, 레이아웃을 되돌리면 알림 위치도 되돌린 버전 기준이 된다. 사용자는 3D와 알림 표기가 어긋나지 않는다는 것을 신뢰할 수 있어야 하며, 알림 발생 당시의 위치가 필요하면 버전 히스토리와 함께 참고한다.

이상 알림의 '발생 위치' 는 알림에 저장된 문자열이 아니라 현재 로드한 레이아웃 버전에서 설비 소속을 조회해 보인다. 되돌리면 알림의 위치 표기도 되돌린 버전 기준이 된다. 3D 와 알림 표기는 항상 같다.

## 수용 기준

설비를 다른 방으로 옮겨 반영하면 그 설비의 기존 알림 위치가 새 방으로 보인다.
