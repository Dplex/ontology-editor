# OE-WF-17 재진입 적용

## 관련 티켓

- [OE-WF-14](./OE-WF-14.md): 새로고침 시점 적용 원칙

## 요구사항
> User story : 일반 관제 사용자가 레이아웃 반영 후 배너의 새로고침을 누르지 않고 다른 메뉴로 갔다가 3D View로 돌아오면 새 레이아웃이 자동 적용되어 있다. 일정 시간 뒤 강제로 갱신하는 타이머가 없어 보고 있는 도중 화면이 바뀌는 일은 없되, 페이지를 벗어났다 돌아오는 자연스러운 시점에는 최신 상태가 되어 오래된 레이아웃을 계속 보는 일도 없다. 재진입 적용은 사용자가 의식적으로 새로고침하지 않아도 자연스럽게 최신 레이아웃으로 수렴하게 하는 장치로, 배너를 무시한 채 며칠간 옛 레이아웃을 보는 상황을 막는다.

페이지를 벗어났다 다시 들어오면 새 레이아웃을 무조건 적용한다. 일정 시간 뒤 강제로 갱신하는 타이머는 두지 않는다(OE-WF-14).

## 수용 기준

반영 뒤 다른 메뉴로 갔다 3D View 로 돌아오면 새 레이아웃이 보인다.
