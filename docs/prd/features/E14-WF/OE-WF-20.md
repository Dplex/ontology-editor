# OE-WF-20 1주일 보관

## 관련 티켓

- [OE-COM-04](../E01-COM/OE-COM-04.md): 기간과 무관한 로그 보존

## 요구사항
> User story : 고객사 관리자가 버전 히스토리를 열면 최근 1주일 안의 버전만 보이고 되돌리기도 그 안에서만 가능하다. 레이아웃 되돌리기는 실수 복구용이지 장기 아카이브가 아니므로 목록이 끝없이 길어지지 않고, 오래전 버전으로 되돌려 현재 운영과 크게 어긋나는 레이아웃이 적용되는 위험도 줄인다. 누가 언제 반영했는지의 감사 기록은 시스템 로그가 기간 제한 없이 따로 보관한다. 보관 기간이 짧다는 점은 사용자에게 명시되어 있어, 중요한 레이아웃 상태를 장기 보존하려면 편집 파일로 따로 내보내 두는 식으로 대응한다.

반영 뒤 1주일이 지난 버전은 히스토리에서 뺀다. 되돌리기 대상도 1주일 안의 버전이다(KPI_2). 로그(OE-COM-04)는 이 기간과 무관하게 남는다.

## 수용 기준

8일 전 버전이 히스토리에 보이지 않는다.
