# OE-WF-20 1주일 보관

## 관련 티켓

- [OE-COM-04](../E01-COM/OE-COM-04.md): 기간과 무관한 로그 보존
- [OE-GEN-05](../E08-GEN/OE-GEN-05.md): 1주일 제한에서 빠지는 초기 구축 v1

## 요구사항
> User story : 고객사 관리자가 버전 히스토리를 열면 반영 뒤 1주일 안의 버전만 보이고 되돌리기도 그 안에서만 가능하다. 1주일이 지난 버전은 히스토리에서 빠진다. 레이아웃 되돌리기는 실수 복구용이지 장기 보관용이 아니므로 목록이 끝없이 길어지지 않고, 오래전 버전으로 되돌려 현재 운영과 크게 어긋나는 레이아웃이 적용되는 위험도 줄어든다. 누가 언제 반영했는지의 감사 기록은 시스템 로그가 기간 제한 없이 따로 남긴다. 다만 사이트를 처음 구축한 v1 은 이 1주일 제한에서 빠져 계속 남는다. 사용자는 몇 달 뒤에도 구축 당시와 지금을 비교하고, 구축 당시 리포트를 열어 보고, 필요하면 v1 으로 되돌릴 수 있어야 한다. 그 밖에 중요한 레이아웃 상태를 장기 보존하려면 편집 파일로 따로 내보내 둘 수 있어야 한다.

반영 뒤 1주일이 지난 버전은 히스토리에서 뺀다. 되돌리기 대상도 1주일 안의 버전이다(KPI_2). 초기 구축 v1(OE-GEN-05)은 예외다 — 기간과 무관하게 히스토리에 남고 되돌리기 대상이며, v1 에 붙은 구축 리포트도 같이 남는다. 로그(OE-COM-04)는 이 기간과 무관하게 남는다.

## 수용 기준

- **AC1** 8일 전 반영 버전이 히스토리에 보이지 않는다.
- **AC2** 구축한 지 8일이 넘어도 v1 이 히스토리에 보이고, v1 으로 되돌리기와 v1 의 구축 리포트 열기가 된다.
