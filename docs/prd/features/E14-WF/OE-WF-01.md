# OE-WF-01 임시 저장

## 관련 티켓

- [OE-WF-03](./OE-WF-03.md): 층별 단일 임시 저장본
- [OE-HIST-04](../E19-HIST/OE-HIST-04.md): 임시 저장본과 구분하는 복구용 자동 저장
- [OE-HIST-05](../E19-HIST/OE-HIST-05.md): 임시 저장·자동 저장·완료 작업의 역할 구분

## 요구사항
> User story : 고객사 관리자는 [임시 저장]으로 편집 중인 내용을 보관할 수 있다. 임시 저장본은 DT 3D 맵과 온톨로지에 반영되지 않으므로 관제 중인 동료에게 미완성 레이아웃이 보이지 않는다. 임시 저장본은 층마다 하나이며, 같은 층에 다시 들어가면 저장본이 열려 이어서 작업할 수 있다. 사용자는 작업을 절반쯤 진행한 상태에서 자리를 비워야 할 때 안심하고 저장하고, 돌아와 어느 저장본이 최신인지 고민하지 않고 이어서 작업할 수 있어야 한다. 임시 저장본을 서버·로컬·브라우저 어디에 둘지는 개발 구현 방식에 따르며, 사용자는 위치와 무관하게 같은 층에 들어가면 이어서 편집할 수 있으면 된다. 서비스가 비정상 종료될 때를 위한 복구용 자동 저장은 임시 저장본과 별개다.

[임시 저장] 은 편집 중인 내용을 보관한다. 임시 저장본은 DT 3D 맵과 온톨로지에 반영되지 않는다. 층마다 하나다(OE-WF-03).
저장 위치는 개발 구현 방식에 따른다(OE-HIST-05). 복구용 자동 저장(OE-HIST-04)은 임시 저장본이 아니다.

## 수용 기준

- **AC1** [임시 저장] 뒤 DT 3D View 가 바뀌지 않는다.
- **AC2** 같은 층에 다시 들어가면 임시 저장본이 열린다(OE-WF-02).
