# OE-WF-01 임시 저장

## 관련 티켓

- [OE-WF-03](./OE-WF-03.md): 층별 단일 임시 저장본
- [OE-HIST-03](../E19-HIST/OE-HIST-03.md): 임시 저장본 대용 편집 파일
- [OE-HIST-04](../E19-HIST/OE-HIST-04.md): 임시 저장본 대용 자동 저장
- [OE-HIST-05](../E19-HIST/OE-HIST-05.md): 결정 전 임시 저장 대체
- [OE-INT-01](../E20-INT/OE-INT-01.md): 저장 위치 결정

## 요구사항
> User story : 고객사 관리자는 [임시 저장]으로 편집 중인 내용을 보관할 수 있다. 임시 저장본은 DT 3D 맵과 온톨로지에 반영되지 않으므로 관제 중인 동료에게 미완성 레이아웃이 보이지 않는다. 임시 저장본은 층마다 하나이며, 같은 층에 다시 들어가면 저장본이 열려 이어서 작업할 수 있다. 사용자는 작업을 절반쯤 진행한 상태에서 자리를 비워야 할 때 안심하고 저장하고, 돌아와 어느 저장본이 최신인지 고민하지 않고 이어서 작업할 수 있어야 한다. 저장 위치는 데이터 교환 방식 결정에 따르며, 결정 전까지는 편집 파일과 브라우저 자동 저장이 임시 저장본 역할을 한다.

[임시 저장] 은 편집 중인 내용을 보관한다. 임시 저장본은 DT 3D 맵과 온톨로지에 반영되지 않는다. 층마다 하나다(OE-WF-03).
저장 위치는 D-INT 에 따르며, 결정 전까지는 편집 파일(OE-HIST-03)과 브라우저 자동 저장(OE-HIST-04)이 임시 저장본 역할을 한다(OE-HIST-05).

## 수용 기준

- [임시 저장] 뒤 DT 3D View 가 바뀌지 않는다.
- 같은 층에 다시 들어가면 임시 저장본이 열린다(OE-WF-02).
