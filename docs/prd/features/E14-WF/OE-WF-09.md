# OE-WF-09 미리보기 영향 목록

## 관련 티켓

- [OE-MAP-01](../E11-MAP/OE-MAP-01.md): 사람 지정 소속 해제 판정

## 요구사항
> User story : 고객사 관리자가 미리보기의 영향 목록에서 소속이 바뀌는 설비마다 '설비명 · 현재 물리존 → 변경될 물리존'을 한 줄씩 확인한다. 예전에 손으로 소속을 지정했던 설비가 이번 경계 수정으로 외곽선 안에 들어와 자동 판정으로 바뀌면 '사람 지정 해제'와 이유가 따로 표시되어 의도치 않은 변경을 잡는다. 목록에서 설비를 누르면 3D에서 그 설비가 선택되어 어디 있는지 바로 보며 판단한다. 영향 목록은 이상 알림 발생 위치가 바뀌는 설비를 미리 보여 주는 것이기도 하므로, 관제 운영에 영향이 큰 설비가 포함되어 있으면 반영 시점을 조정하거나 관제 담당자에게 사전 공지할 수 있다.

미리보기에 영향 목록을 보인다 — 소속이 바뀌는 설비마다 설비명 · 현재 물리존 → 변경될 물리존. 사람이 지정한 소속이 풀리는 설비(OE-MAP-01, K17)는 "사람 지정 해제" 로 따로 표시하고 이유(외곽선 안에 듦·설비 이동 등)를 같이 보인다. 목록에서 설비를 누르면 3D 에서 그 설비가 선택된다.

## 수용 기준

- 소속이 바뀌는 설비마다 현재→변경 물리존이 한 줄로 보인다.
- 사람 지정이 풀리는 설비는 "사람 지정 해제" 와 이유가 함께 보인다.
