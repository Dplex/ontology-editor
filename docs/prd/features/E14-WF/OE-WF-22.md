# OE-WF-22 별도 에디터에서의 반영 경로 (Q2)

## 관련 티켓

- [OE-INT-01](../E20-INT/OE-INT-01.md): 반영 경로 결정
- [OE-WF-10](./OE-WF-10.md): 한 번에 반영하는 반영하기

## 요구사항
> User story : 고객사 관리자가 별도 프로그램인 에디터에서 [반영하기]를 눌렀을 때 결과가 DT로 넘어가는 경로(파일 내보내기와 가져오기, 온톨로지 서버 API, 공유 DB)는 개발 구현에 맡긴다. 사용자 관점에서는 어느 경로든 [반영하기] 한 번으로 끝나야 하고, 경로가 바뀌어도 반영 결과와 버전·알림 동작은 같아야 한다.

별도 에디터(Three.js)에서 DT 로 반영하는 경로(① 파일 export→DT import, ② 온톨로지 서버 API, ③ 공유 DB, PRD 1.7)는 개발 구현에 맡긴다(D-INT, Q2). 어느 경로든 [반영하기] 한 번으로 DT 3D 맵과 온톨로지에 반영되고(OE-WF-10), 반영 결과·새 버전·배너·알림 동작은 같다.

## 수용 기준

- **AC1** [반영하기] 한 번으로 DT 3D 맵과 온톨로지 반영이 끝난다. 사용자가 반영 경로를 고르거나 따로 내보내는 단계가 없다.
- **AC2** 반영 경로가 달라져도 반영 뒤 새 버전·배너·알림이 같게 나온다.
