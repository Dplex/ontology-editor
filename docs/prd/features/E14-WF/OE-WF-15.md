# OE-WF-15 상단 배너

## 관련 티켓

- [OE-WF-19](./OE-WF-19.md): 되돌리기 시 같은 배너

## 요구사항
> User story : 일반 관제 사용자는 다른 관리자가 레이아웃을 반영하면 즉시 상단에 '새 레이아웃이 적용되었습니다. 새로고침하면 반영됩니다.' 배너와 [새로고침] 버튼을 볼 수 있다. 배너는 접속 중인 모든 사용자에게 보이고 새로고침하기 전까지 유지되어 잠시 자리를 비웠다 와도 변경 사실을 놓치지 않는다. 버튼을 누르면 새 레이아웃이 적용되고 배너가 사라진다. 되돌리기도 같은 배너로 알린다. 사용자는 여러 관제 담당자가 서로 다른 레이아웃을 보는 상황을 빠르게 해소하면서도 새로고침 전까지는 현재 화면이 유지되어 작업을 방해받지 않아야 한다.

반영 즉시 접속 중인 모든 사용자에게 상단 배너를 보인다 — "새 레이아웃이 적용되었습니다. 새로고침하면 반영됩니다." 와 [새로고침] 버튼. 배너는 사용자가 새로고침하기 전까지 유지된다. 되돌리기(OE-WF-19)도 같은 배너를 보낸다.

## 수용 기준

- **AC1** 반영 직후 다른 사용자 화면에 배너가 뜨고 [새로고침] 을 누르면 새 레이아웃이 적용되며 배너가 사라진다.
