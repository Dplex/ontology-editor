# OE-WF-15 상단 배너

## 관련 티켓

- [OE-WF-19](./OE-WF-19.md): 되돌리기 시 같은 배너

## 요구사항

반영 즉시 접속 중인 모든 사용자에게 상단 배너를 보인다 — "새 레이아웃이 적용되었습니다. 새로고침하면 반영됩니다." 와 [새로고침] 버튼. 배너는 사용자가 새로고침하기 전까지 유지된다. 되돌리기(OE-WF-19)도 같은 배너를 보낸다.

## 수용 기준

반영 직후 다른 사용자 화면에 배너가 뜨고 [새로고침] 을 누르면 새 레이아웃이 적용되며 배너가 사라진다.
