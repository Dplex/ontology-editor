# OE-WF-14 타 사용자 적용 시점

## 관련 티켓

- [OE-WF-15](./OE-WF-15.md): 새 레이아웃 배너 알림

## 요구사항
> User story : 일반 관제 사용자가 야간 관제 중 3D View에서 이상 알림 위치를 추적하고 있을 때, 다른 관리자가 레이아웃을 반영해도 화면이 갑자기 바뀌지 않는다. 새 레이아웃은 사용자가 새로고침하는 시점에 적용되므로 보고 있던 설비가 사라지거나 방 이름이 바뀌어 상황 판단이 흔들리는 일이 없고, 배너로 변경 사실만 알린 뒤 사용자가 적절한 시점에 스스로 전환한다. 반영 직후 다른 사용자의 화면은 그대로이고 새로고침 후에만 바뀐다는 규칙이 명확해, 관제 담당자는 중요한 상황 처리 중에는 새로고침을 미루고 안정된 시점에 전환하는 선택권을 가진다.

반영은 다른 사용자의 화면을 즉시 바꾸지 않는다. 다른 사용자는 새로고침하는 시점에 새 레이아웃을 받는다 — 관제 중 예고 없이 화면이 바뀌는 것을 막기 위해서다. 알림은 배너(OE-WF-15)로 한다.

## 수용 기준

반영 직후 다른 사용자의 3D View 는 그대로이고 새로고침 뒤 바뀐다.
