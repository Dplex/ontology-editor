# OE-WF-14 타 사용자 적용 시점

## 관련 티켓

- [OE-WF-15](./OE-WF-15.md): 새 레이아웃 배너 알림

## 요구사항
> User story : 일반 관제 사용자가 DT를 보고 있는 동안 다른 관리자가 레이아웃을 반영해도 화면이 즉시 바뀌지 않는다. 새 레이아웃은 사용자가 새로고침하는 시점에 적용되므로, 보고 있던 설비가 갑자기 사라지거나 방 이름이 바뀌어 상황 판단이 흔들리는 일이 없다. 변경 사실은 배너로 알린다. 사용자는 중요한 상황을 처리하는 중에는 새로고침을 미루고 안정된 시점에 스스로 전환하는 선택권을 가질 수 있어야 하며, 반영 직후 다른 사용자의 3D 뷰는 그대로이고 새로고침 뒤에 바뀐다는 규칙을 신뢰할 수 있다.

반영은 다른 사용자의 화면을 즉시 바꾸지 않는다. 다른 사용자는 새로고침하는 시점에 새 레이아웃을 받는다 — 관제 중 예고 없이 화면이 바뀌는 것을 막기 위해서다. 알림은 배너(OE-WF-15)로 한다.

## 수용 기준

- **AC1** 반영 직후 다른 사용자의 3D View 는 그대로이고 새로고침 뒤 바뀐다.
