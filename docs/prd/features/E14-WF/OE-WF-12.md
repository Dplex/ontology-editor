# OE-WF-12 반영 전 변경 요약

## 관련 티켓

- [OE-WF-11](./OE-WF-11.md): 요약을 띄울 확인 팝업
- [OE-WF-08](./OE-WF-08.md): 같은 변경 요약 값

## 요구사항
> User story : 고객사 관리자는 반영 확인 팝업에서 변경 요약을 간단히 볼 수 있다. 영향 받는 층, 바뀌는 물리존 수, 소속이 바뀌는 설비 수 세 가지만 보이고, 각 수치는 미리보기 변경 요약의 수치를 합산한 값이다. 미리보기를 봤던 사용자는 숫자가 일치하는지로 미리보기 이후 추가 편집이 없었는지 확인할 수 있고, 미리보기를 건너뛴 사용자도 반영 직전에 최소한의 영향 범위를 확인할 수 있다. 사용자는 숫자가 예상과 크게 다르면 반영을 멈추고 미리보기로 원인을 확인할 수 있어야 하며, 요약이 비어 있으면 편집한 내용이 없다는 신호로 삼을 수 있다.

반영 확인 팝업(OE-WF-11)에 변경 요약을 세 가지로 줄여 보인다. 미리보기 변경 요약(OE-WF-08)을 바탕으로 하며, 각 수치는 그 요약의 수치를 합산한 값이다.
- 영향 받는 층 — OE-WF-08 의 영향 받는 층(건물·층 목록)의 수.
- 바뀌는 물리존 수 — OE-WF-08 의 생성·삭제·분할·병합한 물리존 수를 합한 값.
- 소속이 바뀌는 설비 수 — OE-WF-08 의 전체 사이트 소속 변경 설비 수.

## 수용 기준

- **AC1** 팝업에 영향 받는 층·바뀌는 물리존 수·소속이 바뀌는 설비 수 세 가지가 보인다.
- **AC2** 각 수치가 미리보기 변경 요약에서 구한 값과 같다 — 영향 받는 층 수, 생성·삭제·분할·병합한 물리존 수의 합, 전체 사이트 소속 변경 설비 수.
