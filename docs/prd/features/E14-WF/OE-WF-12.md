# OE-WF-12 반영 전 변경 요약

## 관련 티켓

- [OE-WF-11](./OE-WF-11.md): 요약을 띄울 확인 팝업
- [OE-WF-08](./OE-WF-08.md): 같은 변경 요약 값

## 요구사항
> User story : 고객사 관리자는 반영 확인 팝업에서 변경 요약을 볼 수 있다. 영향받는 층, 바뀌는 공간 수, 소속이 바뀌는 설비 수가 보이며 값은 미리보기 변경 요약과 같다. 미리보기를 봤던 사용자는 숫자가 일치하는지로 미리보기 이후 추가 편집이 없었는지 확인할 수 있고, 미리보기를 건너뛴 사용자도 반영 직전에 최소한의 영향 범위를 확인할 수 있다. 사용자는 숫자가 예상과 크게 다르면 반영을 멈추고 미리보기로 원인을 확인할 수 있어야 하며, 요약이 비어 있으면 편집한 내용이 없다는 신호로 삼을 수 있다.

반영 확인 팝업(OE-WF-11)에 변경 요약을 보인다 — 영향 받는 층, 바뀌는 공간 수, 소속이 바뀌는 설비 수. 값은 OE-WF-08 과 같다.

## 수용 기준

팝업의 수치가 미리보기 변경 요약과 같다.
