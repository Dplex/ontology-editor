# OE-WF-12 반영 전 변경 요약

## 관련 티켓

- [OE-WF-11](./OE-WF-11.md): 요약을 띄울 확인 팝업
- [OE-WF-08](./OE-WF-08.md): 같은 변경 요약 값

## 요구사항

### User story

고객사 관리자가 반영 확인 팝업에서 영향받는 층, 바뀌는 공간 수, 소속이 바뀌는 설비 수를 본다. 이 숫자는 미리보기 변경 요약과 같은 값이라, 미리보기를 봤던 사용자는 숫자가 일치하는지로 '미리보기 이후 추가 편집이 없었나'를 확인하고, 미리보기를 건너뛴 사용자도 최소한의 영향 범위를 반영 직전에 확인한다. 요약 수치가 비어 있거나 0이면 편집한 내용이 없다는 신호이므로 불필요한 빈 버전이 쌓이는 것을 막고, 숫자가 예상과 크게 다르면 사용자가 반영을 멈추고 미리보기로 원인을 확인한다.

반영 확인 팝업(OE-WF-11)에 변경 요약을 보인다 — 영향 받는 층, 바뀌는 공간 수, 소속이 바뀌는 설비 수. 값은 OE-WF-08 과 같다.

## 수용 기준

팝업의 수치가 미리보기 변경 요약과 같다.
