# OE-WF-11 반영 확인 팝업

## 관련 티켓

- [OE-WF-12](./OE-WF-12.md): 팝업 내 변경 요약

## 요구사항
> User story : 고객사 관리자가 [반영하기]를 누르면 '레이아웃 변경사항을 반영하시겠습니까? 3D 맵에 즉시 반영됩니다.' 팝업이 뜨고 영향 층·공간 수·소속 변경 설비 수 요약이 함께 보인다. 요약을 보고 예상보다 영향이 크면 [미리보기]로 넘어가 확인하고, 아니다 싶으면 [취소]로 아무것도 반영하지 않는다. 운영 중인 DT에 즉시 적용되는 중요한 동작이라 실수 클릭 한 번으로 반영되지 않게 한 번 더 확인한다. 팝업 문구에 '즉시 반영'이 명시되어 있어 임시 저장과 반영의 차이를 모르는 신규 사용자도 이 동작의 무게를 이해하며, 세 버튼의 의미가 명확해 잘못 누를 여지가 적다.

[반영하기] 를 누르면 확인 팝업을 띄운다 — "레이아웃 변경사항을 반영하시겠습니까? 3D 맵에 즉시 반영됩니다." 버튼은 [반영하기]·[미리보기]·[취소] 다. 팝업에 변경 요약(OE-WF-12)을 함께 보인다.

## 수용 기준

팝업의 [취소] 를 누르면 아무것도 반영되지 않고, [미리보기] 를 누르면 OE-WF-07 로 간다.
