# OE-WF-11 반영 확인 팝업

## 관련 티켓

- [OE-WF-12](./OE-WF-12.md): 팝업 내 변경 요약

## 요구사항
> User story : 고객사 관리자가 [반영하기]를 누르면 '레이아웃 변경사항을 반영하시겠습니까? 3D 맵에 즉시 반영됩니다.'라는 확인 팝업이 뜬다. 버튼은 [반영하기]·[미리보기]·[취소]이며 팝업에 변경 요약이 함께 보인다. 사용자는 요약을 보고 영향이 예상보다 크면 [미리보기]로 넘어가 확인하고, 아니다 싶으면 [취소]로 아무것도 반영하지 않을 수 있다. 운영 중인 DT에 즉시 적용되는 중요한 동작이므로 실수 클릭 한 번으로 반영되지 않도록 한 번 더 확인하며, 임시 저장과 반영의 차이를 모르는 사용자도 문구로 동작의 무게를 알 수 있어야 한다.

[반영하기] 를 누르면 확인 팝업을 띄운다 — "레이아웃 변경사항을 반영하시겠습니까? 3D 맵에 즉시 반영됩니다." 버튼은 [반영하기]·[미리보기]·[취소] 다. 팝업에 변경 요약(OE-WF-12)을 함께 보인다.

## 수용 기준

- **AC1** 팝업의 [취소] 를 누르면 아무것도 반영되지 않고, [미리보기] 를 누르면 OE-WF-07 로 간다.
