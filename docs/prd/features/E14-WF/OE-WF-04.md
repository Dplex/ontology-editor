# OE-WF-04 임시 저장본 폐기

## 요구사항
> User story : 고객사 관리자는 [임시 저장본 폐기]를 눌러 임시 저장본을 지우고 현재 반영된 레이아웃으로 돌아갈 수 있다. 폐기 전에 확인 팝업이 뜨며 폐기는 되돌릴 수 없으므로, 확인 단계가 있어 실수로 몇 시간치 작업을 날리지 않는다. 폐기 후 층을 다시 열면 깨끗한 반영 레이아웃이 보인다. 폐기는 임시 저장본만 지우고 반영된 레이아웃과 버전 히스토리에는 영향을 주지 않으므로, 사용자는 잘못된 방향으로 진행된 시도를 안전하게 정리하고 처음부터 다시 시작할 수 있어야 한다.

[임시 저장본 폐기] 를 누르면 임시 저장본을 지우고 현재 반영된 레이아웃으로 돌아간다. 폐기 전에 확인 팝업을 띄운다. 폐기는 되돌릴 수 없다.
초기 구축 프로젝트에서 층의 임시 저장본을 폐기하면 그 층은 임포트 결과로 돌아간다.

## 수용 기준

- **AC1** 폐기 뒤 층을 다시 열면 현재 반영된 레이아웃이 보인다.
- **AC2** 초기 구축 프로젝트에서 층의 임시 저장본을 폐기하면 그 층이 임포트 결과로 돌아간다.
