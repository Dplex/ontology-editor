# OE-WF-04 임시 저장본 폐기

## 요구사항
> User story : 고객사 관리자가 임시 저장해 둔 편집이 잘못된 방향이었음을 깨닫고 처음부터 다시 하기로 한다. [임시 저장본 폐기]를 누르면 확인 팝업이 뜨고, 확인하면 저장본이 지워져 현재 반영된 레이아웃으로 돌아간다. 폐기는 되돌릴 수 없으므로 확인 단계가 있어 실수로 몇 시간치 작업을 날리지 않으며, 폐기 후 층을 다시 열면 깨끗한 반영 레이아웃에서 시작한다. 폐기는 임시 저장본만 지우고 반영된 레이아웃과 버전 히스토리에는 영향을 주지 않으므로, 작업 중 실패한 시도를 정리하는 안전한 방법으로 쓸 수 있다.

[임시 저장본 폐기] 를 누르면 임시 저장본을 지우고 현재 반영된 레이아웃으로 돌아간다. 폐기 전에 확인 팝업을 띄운다. 폐기는 되돌릴 수 없다.

## 수용 기준

폐기 뒤 층을 다시 열면 현재 반영된 레이아웃이 보인다.
