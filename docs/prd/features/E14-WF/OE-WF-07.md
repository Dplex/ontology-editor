## 요구사항

### User story

고객사 관리자가 물리존 분할과 설비 재배치를 마치고 반영하기 전에 [미리보기]로 실제 DT 뷰와 같은 형태의 결과를 확인한다. 미리보기 동안 실제 DT 3D View와 온톨로지는 바뀌지 않아 관제 사용자에게 영향이 없고, 변경 요약과 영향 목록이 함께 보여 어떤 설비의 소속이 바뀔지 반영 전에 안다. Phase 1은 변경한 층만, Phase 2는 전체 빌딩 뷰로 확장된다. 미리보기에서 문제를 발견하면 편집으로 돌아가 수정하고 다시 확인하는 반복이 DT에 아무 흔적을 남기지 않으므로, 고객사 관리자는 운영 중인 관제에 영향을 줄 걱정 없이 충분히 검토한 뒤 반영한다.

[미리보기] 는 반영 전 결과를 실제 DT 뷰와 같은 형태로 보여 준다. 실제 DT 는 바뀌지 않는다. Phase 1 은 변경한 층을, Phase 2 는 전체 빌딩 뷰를 보인다(OE-UI-12). 미리보기에 변경 요약(OE-WF-08)과 영향 목록(OE-WF-09)을 함께 둔다.

## 수용 기준

미리보기를 여는 동안 DT 3D View 와 온톨로지가 바뀌지 않는다.
