# OE-WF-07 미리보기 3D

## 관련 티켓

- [OE-UI-12](../E03-UI/OE-UI-12.md): Phase별 표시 범위
- [OE-WF-08](./OE-WF-08.md): 미리보기 변경 요약
- [OE-WF-09](./OE-WF-09.md): 미리보기 영향 목록

## 요구사항
> User story : 고객사 관리자는 [미리보기]로 반영 전 결과를 실제 DT 뷰와 같은 형태로 확인할 수 있다. 미리보기 동안 실제 DT 3D 뷰와 온톨로지는 바뀌지 않아 관제 사용자에게 영향이 없다. Phase 1은 변경한 층을, Phase 2는 전체 빌딩 뷰를 보여 준다. 미리보기에는 변경 요약과 영향 목록이 함께 있어 어떤 설비의 소속이 바뀔지 반영 전에 알 수 있다. 사용자는 미리보기에서 문제를 발견하면 편집으로 돌아가 수정하고 다시 확인하는 반복을 DT에 흔적을 남기지 않고 할 수 있어야 하며, 충분히 검토한 뒤 반영할 수 있다.

[미리보기] 는 반영 전 결과를 실제 DT 뷰와 같은 형태로 보여 준다. 실제 DT 는 바뀌지 않는다. Phase 1 은 변경한 층을, Phase 2 는 전체 빌딩 뷰를 보인다(OE-UI-12). 미리보기에 변경 요약(OE-WF-08)과 영향 목록(OE-WF-09)을 함께 둔다.

## 수용 기준

- **AC1** 미리보기를 여는 동안 DT 3D View 와 온톨로지가 바뀌지 않는다.
