# OE-WF-18 버전 히스토리

## 관련 티켓

- [OE-WF-20](./OE-WF-20.md): 1주일 보관 범위
- [OE-SYNC-04](../E15-SYNC/OE-SYNC-04.md): 버전별 결과 리포트 열기
- [OE-INT-01](../E20-INT/OE-INT-01.md): 히스토리 저장 위치 결정

## 요구사항
> User story : 고객사 관리자가 버전 히스토리에서 최근 1주일간의 반영 버전을 번호·일시·반영자·변경 요약·대상 층과 함께 본다. 각 버전에서 반영 결과 리포트를 열어 소속 변경 설비나 Z-01 경고를 확인하고, 문제가 있는 버전을 골라 되돌리기로 넘어간다. 저장 위치(D-INT)가 어디든 같은 방식으로 동작해 사용자는 저장 구조를 몰라도 된다. 다섯 항목이 모두 채워져 있어 '누가 언제 어느 층을 왜 바꿨는지'를 히스토리 목록만으로 파악하고, 상세가 필요하면 리포트를 열어 설비 단위 변경까지 확인한다.

버전 히스토리는 최근 1주일(OE-WF-20)의 반영 버전을 보인다. 항목은 버전 번호·반영 일시·반영자·변경 요약·대상 층이며, 각 버전에서 반영 결과 리포트(OE-SYNC-04)를 열 수 있다. 저장 위치는 D-INT 에 따르고 위치와 무관하게 동작한다(S6).

## 수용 기준

반영 뒤 히스토리에 새 버전이 보이고 다섯 항목이 채워져 있다.
