# OE-WF-08 미리보기 변경 요약

## 관련 티켓

- [OE-SYNC-06](../E15-SYNC/OE-SYNC-06.md): 변경 집계 규칙

## 요구사항
> User story : 고객사 관리자는 미리보기에서 변경 요약을 볼 수 있다. 면적 변화, 생성·삭제·분할·병합한 물리존과 룸 수, 소속이 바뀔 설비 수가 보인다. 집계 규칙은 편집 리포트 규칙과 같아 미리보기 숫자와 반영 후 리포트 숫자가 어긋나지 않는다. 사용자는 물리존 하나를 나눴을 뿐인데 소속 변경 설비가 수십 개로 나오면 분할선이 설비 밀집 구역을 지났음을 깨닫고 반영 전에 조정할 수 있어야 하며, 요약 숫자와 미리보기 화면을 대조하며 변경 범위를 이해할 수 있다.

미리보기에 변경 요약을 보인다 — 면적 변화, 생성·삭제·분할·병합한 물리존·룸 수, 소속이 바뀔 설비 수. 집계 규칙은 편집 리포트 규칙(OE-SYNC-06)과 같다.

## 수용 기준

물리존을 하나 분할한 미리보기에 '분할 1' 과 소속 변경 설비 수가 보인다.
