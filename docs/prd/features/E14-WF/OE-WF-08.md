# OE-WF-08 미리보기 변경 요약

## 관련 티켓

- [OE-SYNC-06](../E15-SYNC/OE-SYNC-06.md): 변경 집계 규칙
- [OE-WF-12](./OE-WF-12.md): 이 요약을 줄여 보이는 반영 확인 팝업

## 요구사항
> User story : 고객사 관리자는 미리보기에서 변경 요약을 자세히 볼 수 있다. 영향 받는 층, 면적 변화, 생성·삭제·분할·병합한 물리존과 룸 수, 소속이 바뀔 설비 수가 보이고, 면적 변화와 설비 수는 층·건물·전체 사이트 단위로 각각 집계되어 보인다. 소속이 바뀔 설비 수는 물리존 단위로도 보인다. 집계 규칙은 편집 리포트 규칙과 같아 미리보기 숫자와 반영 후 리포트 숫자가 어긋나지 않는다. 사용자는 물리존 하나를 나눴을 뿐인데 소속 변경 설비가 수십 개로 나오면 분할선이 설비 밀집 구역을 지났음을 깨닫고 반영 전에 조정할 수 있어야 하며, 어느 층·건물에서 얼마나 바뀌는지 단위별 숫자와 미리보기 화면을 대조하며 변경 범위를 이해할 수 있다. 반영 확인 팝업(OE-WF-12)은 이 요약을 더 단순하게 줄여 보여 준다.

미리보기에 변경 요약을 보인다. 집계 규칙은 편집 리포트 규칙(OE-SYNC-06)과 같다.
- 영향 받는 층 — 이번 반영에서 편집이 들어간 층의 건물·층 목록과 수.
- 면적 변화 — 물리존 면적의 합이 변경 전보다 얼마나 늘거나 줄었는지를 층·건물·전체 사이트별로 보인다.
- 생성·삭제·분할·병합한 물리존 수와 룸 수.
- 소속이 바뀔 설비 수 — 물리존별·층별·건물별·전체 사이트별로 각각 집계해 보인다. 물리존별은 그 물리존에서 나가는 설비와 들어오는 설비를 따로 센다. 층·건물·전체 사이트 수는 한 설비를 한 번만 세며, 층 수의 합이 건물 수, 건물 수의 합이 전체 사이트 수가 된다.

## 수용 기준

- **AC1** 물리존을 하나 분할한 미리보기에 '분할 1' 과 소속 변경 설비 수가 보인다.
- **AC2** 여러 층을 고친 미리보기에서 영향 받는 층 목록이 보이고, 면적 변화와 소속 변경 설비 수가 층·건물·전체 사이트별로 각각 보인다. 층 수의 합이 건물 수와, 건물 수의 합이 전체 사이트 수와 같다.
- **AC3** 소속이 바뀌는 설비 수가 물리존별로 나가는 수와 들어오는 수로 나뉘어 보인다.
