# OE-IDF-09 BIM 無 참조선

## 관련 티켓

- [OE-MAN-01](../E07-MAN/OE-MAN-01.md): 참조선 보며 물리존 그리기

## 요구사항
> User story : R2에서 구축 담당자는 3D 스캔·BIM·평면도가 모두 없고 IDF만 있는 사이트에서 층 구분·건물 외곽선·존 외곽을 참조선으로 볼 수 있다. 참조선은 그리기 보조일 뿐 온톨로지에 나가지 않으며, 물리존은 사용자가 참조선을 보며 직접 그린다. 이를 통해 시뮬레이션용 존이 공간 단위로 잘못 등록되는 일 없이, 빈 층에서 그릴 때보다 위치와 비례를 잡기 쉬운 상태로 수동 구축을 진행할 수 있어야 한다. 참조선만 있는 층에서 생성한 온톨로지에는 참조선에서 비롯한 물리존이 없다.

3D 스캔·BIM·평면도가 모두 없고 IDF 만 있을 때, 층(Z 그룹)·건물 외곽선(Outdoors 면)·존 외곽을 참조선으로만 그린다(PRD 1.6). 물리존은 사용자가 참조선을 보며 직접 그린다(OE-MAN-01). 참조선은 온톨로지에 나가지 않는다.

## 수용 기준

- **AC1** 참조선만 있는 층에서 생성한 온톨로지에 참조선에서 비롯한 물리존이 없다.
