# OE-IDF-09 BIM 無 참조선

## 요구사항

3D 스캔·BIM·평면도가 모두 없고 IDF 만 있을 때, 층(Z 그룹)·건물 외곽선(Outdoors 면)·존 외곽을 참조선으로만 그린다(PRD 1.6). 물리존은 사용자가 참조선을 보며 직접 그린다(OE-MAN-01). 참조선은 온톨로지에 나가지 않는다.

## 수용 기준

참조선만 있는 층에서 생성한 온톨로지에 참조선에서 비롯한 물리존이 없다.
