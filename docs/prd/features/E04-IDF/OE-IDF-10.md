# OE-IDF-10 벽 두께 적용 순서

## 요구사항

벽 두께는 다음 순서로 정한다 — ① BIM 두께, ② 사이트 기본값(내벽 150mm / 외벽 300mm, 사이트 설정으로 바꿀 수 있다), ③ IDF 의 Construction·Material 합산(보조). 어느 것을 썼는지 출처로 표시한다.

## 수용 기준

사이트 설정에서 내벽·외벽 기본 두께를 바꾸면 BIM 두께가 없는 벽이 그 값으로 그려진다.
