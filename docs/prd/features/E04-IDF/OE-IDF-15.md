# OE-IDF-15 gbXML 임포트

## 요구사항
> User story : R2에서 구축 담당자는 IDF는 없지만 BIM에서 내보낸 gbXML이 있는 사이트에서 gbXML의 존 정보를 공조존의 2순위 출처로 읽어 초안을 만들 수 있다. IDF가 있으면 IDF를 우선하고 gbXML은 쓰지 않는다. 사용자는 공조존을 전부 수동으로 그리는 것과 IDF 자동 생성 사이의 중간 선택지로 이 기능을 쓸 수 있다. gbXML에서 만든 초안도 다른 자동 생성과 같이 검토·보정을 거쳐야 반영되며, 구체적인 범위와 동작은 gbXML 범위 결정 후 보강한다.

gbXML 의 Zone(Spaces 경로)을 공조존의 2순위 출처로 읽는다. IDF 가 있으면 IDF 를 쓰고 gbXML 은 쓰지 않는다. 범위는 D-gbXML 에 따른다.

## 수용 기준

D-gbXML 결정 후 적는다.
