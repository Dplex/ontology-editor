# OE-IDF-04 층 매핑

## 관련 티켓

- [OE-IDF-11](./OE-IDF-11.md): 층 매핑 결과 표시·수동 수정

## 요구사항
> User story : R2에서 구축 담당자가 IDF를 임포트하면 존의 바닥 높이와 높이로 각 존이 어느 층에 속하는지 자동 매핑되어 검토 화면에 보인다. 층고가 특이한 로비나 기계실 존이 다른 층에 붙었으면 사용자가 수동으로 고칠 수 있고, 어느 층에도 맞지 않는 존은 미매핑 목록에 모여 하나씩 확인할 수 있다. 층 매핑 결과는 존과 물리존 매칭의 전제가 되므로, 사용자가 이 단계에서 틀린 층을 바로잡아 두면 뒤따르는 매칭 초안의 오류가 줄어들어 전체 검토 시간을 아낄 수 있어야 한다.

존의 바닥 Z 좌표와 높이로 존을 층에 매핑한다. 매핑 결과를 검토 화면(OE-IDF-11)에 보이고 사용자가 수동으로 고칠 수 있다. 어느 층에도 맞지 않는 존은 미매핑으로 둔다.

## 수용 기준

- **AC1** 존별 매핑 층이 화면에 보이고 사용자가 바꿀 수 있다.
- **AC2** 미매핑 존이 목록으로 보인다.
