# OE-IDF-14 플랜트 계통

## 요구사항

IDF 에 담긴 열원 설비(냉동기·보일러·냉각탑·펌프·열교환기 등)와 수(水) 계통(냉수·온수·냉각수)을 가져와, 공조 계통(OE-IDF-02)과 이어진 하나의 계통으로 만든다. 사용자는 계통도에서 "냉각탑 → 냉동기 → 냉수 → 공조기·FCU" 처럼 열원에서 말단 설비까지 끊기지 않은 흐름을 볼 수 있어야 한다.

- **범위** — 냉수·온수 계통과 냉각수 계통을 모두 가져온다. 열원 설비가 어느 공조기·FCU 에 물을 공급하는지까지 이어야 한다.
- **설비 하나는 하나로** — 냉동기처럼 두 계통(냉수·냉각수)에 동시에 걸친 설비도 설비 하나로 만들고 두 계통 모두에 속하게 한다. 하나의 설비가 두 개의 계통에 해당하는 경우 두 계통을 모두 소유할 수 있다. 
- **실물만 설비로** — 시뮬레이션용으로만 존재하는 가상 요소(바이패스 배관 등)는 설비로 만들지 않는다.
- **방향** — IDF 가 흐름 방향을 명시하므로 사람의 방향 확정 없이 반영한다. 공급 방향만 쓴다.
- **추정하지 않음** — 계통 종류(냉수·온수·냉각수)나 설비 용량이 IDF 에 명시되지 않았으면 비워 두고 "미정"으로 표시한다. 에디터가 짐작해 채우지 않는다. Flow Type 범례에 없는 계통(증기·급탕·지열수)도 설비와 연결은 가져오되 종류는 "미정"이다(glossary "Flow Type").
- **BIM 과의 관계** — IDF 설비는 이름으로 BIM 설비와 이어 위치를 얻는다(OE-IDF-08). 이어지지 않은 설비는 위치 없이 온톨로지에만 들어가고 미배치 목록에 보인다. 지역냉난방 수전처럼 건물 안에 실물이 없는 설비는 매칭하지 않는다. BIM 과 IDF 의 연결 정보가 서로 다르면 BIM을 우선하고 IDF는 BIM에서 제공하지 못한 정보를 채우는 역할을 한다. 
- **사람의 보정** — 사용자가 고친 연결·계통은 같은 IDF 를 다시 가져와도 유지된다(OE-IDF-13). 가져온 수 계통도 완전성 검사(OE-BIM-18)를 받는다.
- **검토 화면** — 가져오기 결과를 반영 전에 확인할 수 있도록 검토 화면(OE-IDF-11)에 보인다: 가져온 계통 수(종류별), 계통별 설비 수, 종류 "미정" 계통, 용량이 빈 설비, BIM 에 이어지지 않은 설비, BIM 과 어긋난 연결.
- **범위 밖** — 열원 설비의 운전 순서·대수 제어 같은 운전 정책은 가져오지 않는다.

## 수용 기준

- IDF 의 수 계통이 빠짐없이 에디터의 계통으로 생기고, 수가 검토 화면에 보인다.
- 계통도에서 냉각탑부터 냉동기를 거쳐 공조기·FCU 까지 흐름이 끊기지 않고 이어져 보인다.
- 냉수·냉각수 두 계통에 걸친 냉동기가 설비 목록에 한 번만 나오고, 두 계통 모두에서 보인다.
- 바이패스 배관 같은 가상 요소가 설비 목록에 없다.
- 종류가 명시되지 않은 계통과 용량이 명시되지 않은 설비가 "미정"·빈 값으로 보이고, 검토 화면 목록에 있다.
- BIM 에 이어지지 않은 IDF 설비가 미배치 목록에 있다.
- 사용자가 고친 연결이 같은 IDF 를 다시 가져온 뒤에도 남아 있다.
