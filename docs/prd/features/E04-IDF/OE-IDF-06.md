# OE-IDF-06 N:M 허용

## 관련 티켓

- [OE-MAP-03](../E11-MAP/OE-MAP-03.md): N:M 일반 규칙

## 요구사항

N:M 일반 규칙은 OE-MAP-03 을 따른다. 공조존 1 : 물리존 N 이 정상이고, 한 물리존이 여러 공조존에 걸칠 수 있다(N:M). 
IDF 로 불러온 것과 공조존 도구에서 만들거나 고친 것 모두 같다. 
두 개 이상 공조존이 각각 물리존 바닥면적의 10%를 초과해 덮으면 다중 매핑 후보로 표시화고, 사용자가 확인한 복수 담당 관계를 저장할 수 있다.
