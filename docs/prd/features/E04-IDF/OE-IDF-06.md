# OE-IDF-06 N:M 허용

## 관련 티켓

- [OE-MAP-03](../E11-MAP/OE-MAP-03.md): N:M 일반 규칙

## 요구사항
> User story : R2에서 구축 담당자가 IDF를 임포트하면 공조존 하나가 물리존 여럿을 담당하는 것이 정상으로 처리되고, 한 물리존이 여러 공조존에 걸치는 것도 허용된다. 두 개 이상의 공조존이 한 물리존을 상당 부분 덮으면 다중 매핑 후보로 표시되며, 사용자가 확인한 뒤 복수 담당 관계로 저장할 수 있다. IDF로 불러온 공조존과 공조존 도구에서 직접 만들거나 고친 공조존 모두 같은 규칙을 따른다. 사용자는 실제 공조 설계가 1:1이 아니어도 억지로 맞추지 않고 그대로 표현할 수 있어야 한다.

N:M 일반 규칙은 OE-MAP-03 을 따른다. 공조존 1 : 물리존 N 이 정상이고, 한 물리존이 여러 공조존에 걸칠 수 있다(N:M). 
IDF 로 불러온 것과 공조존 도구에서 만들거나 고친 것 모두 같다. 
두 개 이상 공조존이 각각 물리존 바닥면적의 10%를 초과해 덮으면 다중 매핑 후보로 표시화고, 사용자가 확인한 복수 담당 관계를 저장할 수 있다.
