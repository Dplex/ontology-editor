# OE-IDF-06 N:M 허용

## 요구사항

공조존 1 : 물리존 N 이 정상이고, 한 물리존이 여러 공조존에 걸칠 수 있다(N:M). IDF 로 불러온 것과 공조존 도구에서 만들거나 고친 것 모두 같다. 두 존에 각 10% 넘게 걸친 방은 따로 센다

## 수용 기준

두 존에 10% 넘게 걸친 물리존이 두 공조존 모두의 담당 물리존으로 매핑된다.
