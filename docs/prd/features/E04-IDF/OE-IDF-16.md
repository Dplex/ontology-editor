# OE-IDF-16 IDF↔BIM 좌표 정합

## 관련 티켓

- [OE-IDF-04](./OE-IDF-04.md): 정합된 층 대응으로 존을 층에 매핑
- [OE-IDF-05](./OE-IDF-05.md): 정합된 좌표로 존이 물리존을 덮는 비율 계산
- [OE-IDF-11](./OE-IDF-11.md): 오프셋·층별 Z 대응 표를 검토 화면에 표시
- [OE-IDF-13](./OE-IDF-13.md): 사용자가 고친 정합값을 재임포트에도 유지
- [OE-ZON-07](../E10-ZON/OE-ZON-07.md): 계산 출처 값의 사용자 확인 플로우
- [OE-BIM-22](../E05-BIM/OE-BIM-22.md): BIM 파일 간 좌표 정합 경고(같은 방식을 IDF 로 확장)
- [OE-INT-04](../E20-INT/OE-INT-04.md): 에디터·DT 공통 좌표계, 정합은 임포트 단계에서 맞춤

## 요구사항
> User story : R2에서 구축 담당자가 BIM과 IDF를 함께 가져오면, IDF가 BIM과 같은 자리에 겹쳐 보이도록 평면 오프셋과 층별 높이 대응이 자동으로 계산되어 경고와 함께 보인다. IDF는 BIM과 원점이 달라 그대로 얹으면 존이 건물 밖에 놓이고, 층 높이도 달라 위쪽 층일수록 어긋나기 때문이다. 구축 담당자는 계산된 값을 확인하고 고친 뒤에 적용하며, 확인하지 않은 정합값은 존↔물리존 매칭에 쓰이지 않는다.

IDF 좌표는 IDF 자체 원점에서 잰 값이라 BIM 좌표와 같다고 가정하지 않는다. BIM·IDF 를 함께 가져올 때 아래를 계산해 검토 화면(OE-IDF-11)에 보인다.

1. **평면 오프셋** — 층별 IDF 존 바닥과 BIM 공간 바닥의 겹침(IoU)이 가장 커지는 X·Y 이동량과 회전. 전 층이 같은 값으로 모이면 건물 공통값으로 삼고, 층마다 다르면 경고한다.
2. **층 대응과 높이 환산** — 층은 이름(`4F_…` 접두와 BIM 층 이름)으로 먼저 맞춘다. IDF 층 간격과 BIM 층 간격이 다를 수 있으므로(성수: IDF 3m, IFC 4.3m) 높이는 같은 층 안의 상대 높이로 환산한다. `z_BIM = BIM 층 바닥 + (z_IDF − IDF 층 바닥)`.
3. **대응 없음 표시** — IDF 에 없는 BIM 층, BIM 에 없는 IDF 층은 "대응 없음" 목록으로 보인다.
4. **확인 후 적용** — 계산한 정합값은 출처가 '계산'이라 사용자 확인(OE-ZON-07)을 거친 뒤 OE-IDF-04 층 매핑과 OE-IDF-05 매칭에 쓰인다. 사용자가 고친 값은 같은 IDF 를 다시 가져와도 유지된다(OE-IDF-13).
5. **정합 품질 표시** — 정합 후 층별 겹침률을 화면에 보이고, 기준 아래이면 OE-BIM-22 와 같은 방식으로 경고한다.

## 수용 기준

- **AC1** 원점이 다른 BIM·IDF 를 함께 열면 경고와 X·Y·회전 오프셋 값이 보인다.
- **AC2** IDF 와 BIM 의 층 간격이 다르면 층별 높이 대응 표가 보이고, 사용자가 층 대응과 값을 고칠 수 있다.
- **AC3** 사용자가 확인하지 않은 정합값은 OE-IDF-04 층 매핑과 OE-IDF-05 매칭에 쓰이지 않는다.
- **AC4** 한쪽에만 있는 층이 "대응 없음" 목록에 보인다.

## 메모

성수(`Factorial.idf` ↔ `Factorial_건축.ifc`)로 확인한 값은 다음과 같다. 회전은 필요 없었고, 평면 오프셋은 3F~10F 8개 층이 같은 값(IFC = IDF + (16.8, 18.1) m, 겹침 0.83)으로 모였다. 높이는 3F 까지 IDF 와 BIM 이 같고 4F 부터 층마다 1.3m 씩 누적된다(10F +9.1m). B2F~B5F·RFT·RF 는 IDF 에 없다.

열린 결정(PM): 경고를 띄울 겹침률 기준 · 층 이름 규칙이 없는 IDF 의 층 대응 방식 · IDF 와 BIM 이 회전까지 다를 때 자동 탐색할지 사용자 입력으로 둘지.
