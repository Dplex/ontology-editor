# OE-IDF-05 존↔물리존 매칭 초안

## 요구사항

IDF 존과 물리존의 매칭 초안을 낸다. 기준은 이름 유사도와, 존 다면체가 물리존 평면을 덮는 비율(방 바닥의 절반 넘게 덮을 때)이다.
존↔물리존 매칭은 출처 '계산' 이므로 사용자 확인 플로우(OE-ZON-07)를 거친 뒤 반영한다. IDF 에 적힌 설비↔존 담당은 명시된 값이므로 확인 없이 반영한다(D13).

## 수용 기준

- 사용자가 확인하지 않은 존↔물리존 매칭은 온톨로지에 나가지 않는다.
- IDF 에 명시된 설비↔존 담당은 확인 없이 온톨로지에 나간다.
