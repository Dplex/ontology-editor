# OE-IDF-05 존↔물리존 매칭 초안

## 관련 티켓

- [OE-ZON-07](../E10-ZON/OE-ZON-07.md): 매칭 초안 사용자 확인

## 요구사항
> User story : R2에서 구축 담당자가 IDF 존과 BIM 물리존을 연결할 때, 이름 유사도와 존 다면체가 방 바닥의 절반 넘게 덮는지를 기준으로 매칭 초안이 자동으로 나온다. 초안은 출처 '계산'이라 담당자가 확인 플로우에서 승인해야 온톨로지에 나가고, 확인하지 않은 매칭은 반영되지 않는다. IDF에 명시된 설비↔존 담당은 확인 없이 반영되어 담당자는 추정으로 잡힌 존↔방 연결에만 검토를 집중한다. 매칭 기준(이름 유사도·바닥 절반 이상 덮음)이 명시되어 있어 담당자가 왜 그 초안이 나왔는지 이해하고 판단할 수 있고, 기준에 못 미쳐 매칭되지 않은 존은 미매칭 목록에서 따로 처리한다.

IDF 존과 물리존의 매칭 초안을 낸다. 기준은 이름 유사도와, 존 다면체가 물리존 평면을 덮는 비율(방 바닥의 절반 넘게 덮을 때)이다.
존↔물리존 매칭은 출처 '계산' 이므로 사용자 확인 플로우(OE-ZON-07)를 거친 뒤 반영한다. IDF 에 적힌 설비↔존 담당은 명시된 값이므로 확인 없이 반영한다(D13).

## 수용 기준

- 사용자가 확인하지 않은 존↔물리존 매칭은 온톨로지에 나가지 않는다.
- IDF 에 명시된 설비↔존 담당은 확인 없이 온톨로지에 나간다.
