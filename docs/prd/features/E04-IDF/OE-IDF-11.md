# OE-IDF-11 IDF 검토 화면

## 관련 티켓

- [OE-IDF-04](./OE-IDF-04.md): 층 매핑 결과
- [OE-IDF-05](./OE-IDF-05.md): 존↔물리존 매칭 초안

## 요구사항

### User story

R2에서 구축 담당자가 IDF 임포트를 마치면 검토 화면에서 가져온 공조존·설비·담당 관계 수, 이름이 안 맞거나 좌표 범위 밖인 미매칭 공조존, 용량이 빈 설비, 층 매핑 결과, 존↔물리존 매칭 초안을 한눈에 확인한다. 문제가 없으면 그대로 반영하고 아니면 수정한 뒤 반영하며, 확인 전에는 어떤 결과도 온톨로지에 나가지 않는다. 자동 임포트 결과가 검토 없이 운영 DT에 들어가 잘못된 공조존이 관제에 쓰이는 일을 막는다.

IDF 검토 결과 화면에서는 다음 내용을 포함한다. 
- 가져온 공조존 수·설비 수·담당 관계 수
- 미매칭 공조존 목록(이름 불일치·좌표 범위 밖)
- 용량이 비어 있는 설비 목록(기본값 적용을 고를 수 있다)
- 층 매핑 결과(OE-IDF-04)
- 존↔물리존 매칭 초안(OE-IDF-05)

사용자가 확인한 뒤 그대로 반영할 수 있고 임의로 수정을 진행할 수 있다. 
IDF 검토 결과가 사용자 확인 없이 바로 온톨로지에 적용 되어서는 안된다.  

## 수용 기준

- 위 항목이 전부 화면에 보인다.
- 확인 전에는 임포트 결과가 온톨로지에 나가지 않는다.
