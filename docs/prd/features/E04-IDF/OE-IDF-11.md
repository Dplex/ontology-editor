# OE-IDF-11 IDF 검토 화면

## 관련 티켓

- [OE-IDF-04](./OE-IDF-04.md): 층 매핑 결과
- [OE-IDF-05](./OE-IDF-05.md): 존↔물리존 매칭 초안

## 요구사항
> User story : R1에서 구축 담당자는 IDF 임포트를 마친 뒤 검토 화면에서 결과를 확인할 수 있다. 가져온 공조존·설비·담당 관계 수, 이름이 맞지 않거나 좌표 범위 밖인 미매칭 공조존 목록, 용량이 비어 있는 설비 목록, 층 매핑 결과, 존과 물리존 매칭 초안이 한 화면에 보인다. 사용자는 문제가 없으면 그대로 반영하고, 필요하면 수정한 뒤 반영할 수 있다. 사용자가 확인하기 전에는 어떤 임포트 결과도 온톨로지에 적용되지 않아야 하며, 이를 통해 자동 임포트 결과가 검토 없이 운영 DT에 들어가는 일을 막는다.

IDF 검토 결과 화면에서는 다음 내용을 포함한다. 
- 가져온 공조존 수·설비 수·담당 관계 수
- 미매칭 공조존 목록(이름 불일치·좌표 범위 밖)
- 용량이 비어 있는 설비 목록(기본값 적용을 고를 수 있다)
- 층 매핑 결과(OE-IDF-04)
- 존↔물리존 매칭 초안(OE-IDF-05)

사용자가 확인한 뒤 그대로 반영할 수 있고 임의로 수정을 진행할 수 있다. 
IDF 검토 결과가 사용자 확인 없이 바로 온톨로지에 적용 되어서는 안된다.  

## 수용 기준

- **AC1** 위 항목이 전부 화면에 보인다.
- **AC2** 확인 전에는 임포트 결과가 온톨로지에 나가지 않는다.
- **AC3** 3D·평면에서 공조존(IDF 에너지존과 같은 것)을 누르면 선택 상태가 표시되고 상세정보(이름·층·담당 설비·담당 물리존)가 보인다. 설계 급기 풍량은 IDF 에 값이 있을 때만 보이고, 없으면 '값 없음' 으로 표시한다.

## 메모

- 공조존 상세정보 항목은 2026-10-15 회의에서 "클릭 시 보여 줄 정보를 정의한다" 로 남긴 것을 1차로 정한 것이다(Q17). 추가 항목은 Q17 에서 정한다.
- IDF 에너지존과 공조존은 같은 것이다(2026-10-15). 화면·온톨로지 이름은 '공조존' 하나로 쓴다.
