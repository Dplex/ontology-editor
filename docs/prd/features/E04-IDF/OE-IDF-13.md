# OE-IDF-13 출처 구분·재임포트

## 관련 티켓

- [OE-HIST-03](../E19-HIST/OE-HIST-03.md): 재임포트 시 편집분 보존

## 요구사항
> User story : R2에서 구축 담당자는 IDF 임포트로 자동 생성된 항목은 출처 'IDF', 사람이 보정한 항목은 출처 '사람'으로 구분해 볼 수 있다. 설계 모델이 갱신되어 IDF를 다시 가져오면 편집 파일 규칙에 따라 임포트 생성분만 새 값으로 바뀌고 사람이 고친 담당 설비·경계는 그대로 남는다. 사용자는 설계 변경을 반영하면서도 현장 보정을 다시 하지 않아도 되며, 출처가 구분되어 있으므로 설계 모델과 현장 보정 사이의 차이를 뽑아 설계사에게 피드백하고 재임포트 뒤 어떤 값이 새로 바뀌었는지 추적할 수 있어야 한다.

원본 파일/판본 식별 정보와 편집 파일 형식 버전을 보관한다. 동일 ID 또는 유일하게 매칭되는 보조 식별자만 재적용하고 미매칭·복수·충돌·삭제 대상을 보고한다. 사람 소속 재판정 K17과 연결 해제·유체·방향·형상 보정 보존을 구분한다.

## 수용 기준

- 동일 기준 모델에서는 산출물·확정·검토·해제 상태가 복원된다. 새 판본에서 미매칭은 조용히 버리지 않고 보고하며 충돌은 확인 전 활성화되지 않는다. 덧붙이기 실패 시 기존 모델·편집·이력은 유지되고 성공 후 이력 초기화를 안내한다.
