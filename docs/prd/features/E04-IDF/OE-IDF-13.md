# OE-IDF-13 출처 구분·재임포트

## 요구사항

원본 파일/판본 식별 정보와 편집 파일 형식 버전을 보관한다. 동일 ID 또는 유일하게 매칭되는 보조 식별자만 재적용하고 미매칭·복수·충돌·삭제 대상을 보고한다. 사람 소속 재판정 K17과 연결 해제·유체·방향·형상 보정 보존을 구분한다.

## 수용 기준

- 동일 기준 모델에서는 산출물·확정·검토·해제 상태가 복원된다. 새 판본에서 미매칭은 조용히 버리지 않고 보고하며 충돌은 확인 전 활성화되지 않는다. 덧붙이기 실패 시 기존 모델·편집·이력은 유지되고 성공 후 이력 초기화를 안내한다.
