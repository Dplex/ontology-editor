# OE-IDF-13 출처 구분·재임포트

## 관련 티켓

- [OE-HIST-03](../E19-HIST/OE-HIST-03.md): 재임포트 시 편집분 보존

## 요구사항

### User story

R2에서 구축 담당자가 IDF로 자동 생성된 공조존과 사람이 보정한 담당 설비를 출처 'IDF'·'사람'으로 구분해 본다. 설계 모델이 갱신되어 IDF를 다시 가져오면 OE-HIST-03 규칙에 따라 임포트 생성분만 새 값으로 바뀌고 사람이 고친 담당 설비·경계는 그대로 남아, 설계 변경을 반영하면서도 현장 보정을 다시 하지 않는다. 출처가 구분되어 있으므로 설계 모델과 현장 보정 사이의 차이를 리포트로 뽑아 설계사에게 피드백할 수 있고, 재임포트 뒤 어떤 값이 새로 바뀌었는지도 추적된다.

임포트 생성분은 IDF, 사용자 수정분은 사람으로 표시한다. 재임포트 시 편집분 보존은 OE-HIST-03 을 따른다.
