# OE-IDF-07 존 바닥 조각 합침

## 요구사항

### User story

R2에서 구축 담당자가 DesignBuilder로 만든 삼성 IDF를 임포트하면 존 162개의 바닥이 321개 조각으로 나뉘어 들어오는데, 에디터가 맞닿은 조각을 자동으로 합쳐 존당 외곽선 하나로 만든다. 담당자가 조각을 하나씩 합칠 필요가 없고, 맞닿지 않아 합치지 못한 조각이 있는 존은 검토 화면 목록에 보여 그 존만 확인한다. 이렇게 정리된 외곽선이 존↔물리존 겹침 매칭의 입력이 되므로 매칭 정확도도 함께 올라간다.

DesignBuilder 출력처럼 한 존의 바닥이 여러 조각으로 나뉘어 있으면 맞닿은 조각을 합쳐 외곽선 하나로 만든다(삼성 IDF: 존 162 → 조각 321). 맞닿지 않은 조각은 따로 두고 검토 화면에 알린다.

## 수용 기준

삼성 IDF 에서 존당 외곽선이 1개가 된다. 합치지 못한 조각이 있으면 그 존이 목록으로 보인다.
