# OE-PIP-13 좌표 조건

## 요구사항

배관의 공간 형상은 공통 좌표계와 단위로 변환된 유효한 x·y·z 경로가 있을 때만 3D·GeoJSON에 반영한다(R11·R15). 설비의 단일 배치점만으로 배관 경로를 만들지 않는다. 정상 폴리라인에는 서로 다른 위치의 점이 최소 두 개 필요하며, 좌표 누락·유효하지 않은 수치·변환 불가·길이 0인 경로는 미반영 목록에 사유와 원본 식별 정보를 표시한다.

좌표 없는 배관은 형상 미반영 대상이며 위치를 임의로 (0,0,0)에 두거나 양 끝을 추정하여 그리지 않는다. 원본에 실제로 기록된 좌표 (0,0,0)는 유효성 검사 후 사용할 수 있다. 사용자가 유효한 경로를 보정하면 검토 후 형상에 반영한다.

형상 미반영과 의미 정보 제외를 구분한다. 좌표가 없어도 BIM에 명시된 계통·연결·흐름 방향은 보존하며, 유효하고 해제되지 않은 관계는 해당 내보내기 기준에 따라 사용한다. 형상이 없다는 이유로 확정 관계를 삭제하거나 새 관계를 만들지 않는다. 층간 배관(라이저·분기·오프셋, OE-ML-12~14)도 같은 좌표 기준을 적용한다.

## 수용 기준

- 유효한 경로 좌표가 있는 배관만 3D·GeoJSON에 출력되고 공통 좌표계·단위로 표시된다.
- 좌표 없는 배관과 길이 0·점 부족 등 유효하지 않은 경로는 출력되지 않고 미반영 목록에 원인과 원본 식별 정보가 표시된다.
- 좌표 누락을 (0,0,0)으로 대체하지 않으며, 원본의 유효한 영점 좌표를 누락으로 오인하지 않는다.
- 형상 미반영 배관의 명시된 연결·계통·방향 정보는 유지되고 해제된 관계는 추적·TTL에서 제외된다.
- 경로 보정 후 형상 반영 여부와 검토 결과가 갱신되고 층간 배관에도 같은 조건이 적용된다.

## 검증 (이 repo)

- IFC 세그먼트 형상 표시를 확인한 기존 상태 표기는 경로 유효성·미반영 목록·좌표 없는 의미 정보 보존의 완료 근거가 아니다. 각 수용 기준의 검증이 필요하다.

## 메모

- '좌표 없는 배관 미반영'은 형상을 그리지 않는다는 의미로 명확히 한다. 원본의 설비·계통 연결 정보는 별도로 보존한다.
