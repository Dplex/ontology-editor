# OE-PIP-06 BIM 원본 보존·연결 해제 보정

## 관련 티켓

- [OE-PIP-04](./OE-PIP-04.md): 방향 화살표 수정 제한
- [OE-PIP-07](./OE-PIP-07.md): 해제·취소 후 규칙 방향 재계산

## 요구사항

(PRD #14-A) BIM 포트에 명시된 원본 연결과 방향은 보존한다(K13). 운영 중 현장 변경이나 BIM 오류를 반영할 수 있도록, 에디터에서 '연결 해제 보정'과 '해제 보정 취소'를 제공한다. 원본 BIM 파일이나 원본 연결·방향을 직접 삭제·변경하지 않는다. 방향 화살표로 BIM 원본 방향을 바꾸는 동작은 허용하지 않는다(OE-PIP-04).

연결 해제 보정에는 원본 연결 식별 정보와 수행자·시점·사유를 기록한다. 해제된 연결은 비활성 상태로 확인할 수 있고, 현재 온톨로지의 유효 계통·방향 계산·공급 관계(`feeds`)에서는 제외한다. 해제 보정을 취소하면 보존된 원본 연결과 방향을 복원한다. 두 동작 모두 규칙 방향과 일치율을 다시 계산한다(OE-PIP-07).

저장·불러오기와 BIM 재임포트 시 해제 보정을 유지한다. 재임포트한 BIM에서 동일한 연결이 확인되면 보정을 재적용하여 연결을 자동 활성화하지 않는다. 원본 연결을 찾지 못하거나 연결 대상·방향이 바뀐 경우에는 재검토 대상으로 표시하고, 기존 보정 이력은 보존한다. 충돌하는 연결은 사용자 확인 전 담당 관계로 확정하거나 내보내지 않는다.

## 수용 기준

- BIM 포트 연결의 원본 연결·방향은 보존되고, '연결 해제 보정'과 '해제 보정 취소'를 실행할 수 있다. 원본 방향의 직접 수정은 차단된다.
- 연결 해제 후 해당 연결은 비활성 상태로 표시되고, 유효 계통·규칙 방향 계산·TTL `feeds`에서 제외된다.
- 해제 보정을 취소하면 원본 연결·방향이 복원되고 규칙 방향과 일치율이 다시 계산된다.
- 보정·취소의 수행자·시점·사유를 편집 이력에서 확인할 수 있다.
- 저장·불러오기 뒤에도 해제 상태와 이력이 유지된다.
- 동일한 BIM 연결을 재임포트해도 해제 보정이 유지된다. 대상 또는 방향이 바뀌거나 원본 연결을 찾지 못하면 재검토 항목이 표시되고 이력은 유지된다.
- 재임포트 충돌은 사용자 확인 전 유효 담당 관계나 TTL `feeds`로 출력되지 않는다.

## 검증 (이 repo)

- 기존 구현 검증: BIM 포트 연결의 끊기가 차단된다 — `e2e/connect.spec.ts`, 성수 G-8. 이는 개정 전 동작이며 새 수용 기준을 충족하지 않는다.
- 연결 해제 보정·취소·이력·저장 복원·재임포트 보정 유지 및 충돌 처리·TTL 제외는 구현과 검증이 필요하다.

## 메모

- 원본 자료의 보존과 현재 온톨로지의 연결 보정을 구분한다. 이 티켓은 PRD 개정이며, 기존 연결 차단 구현을 변경한 것은 아니다.
