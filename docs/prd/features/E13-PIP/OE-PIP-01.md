# OE-PIP-01 연결 잇기·끊기 (E8)

## 관련 티켓

- [OE-PIP-04](./OE-PIP-04.md): 연결별 방향 지정
- [OE-PIP-05](./OE-PIP-05.md): 규칙 방향 추정·확정
- [OE-PIP-06](./OE-PIP-06.md): BIM 연결 해제 보정·재임포트 유지
- [OE-PIP-07](./OE-PIP-07.md): 연결 변경 후 규칙 방향 재계산

## 요구사항

(PRD #14-A) 설비와 설비 사이의 연결을 사람이 추가하고 지운다(E8). 사람이 이은 연결은 출처 `manual` 이고 방향 없이 시작한다 — 방향은 OE-PIP-04(연결별) 또는 OE-PIP-05(규칙)로 정한다.

BIM 포트에 명시된 연결에는 일반 삭제 대신 '연결 해제 보정'을 제공한다(K13, OE-PIP-06). 원본 연결과 방향은 보존하고, 보정한 연결은 현재 온톨로지의 유효 연결에서 제외한다. 사용자는 해제 보정을 취소하여 원본 연결을 복원할 수 있다. 보정·취소 시 수행자·시점·사유를 편집 이력에 기록한다.

연결 추가·삭제·해제 보정·보정 취소 후에는 현재 유효 연결을 기준으로 규칙 방향과 일치율을 다시 계산한다(OE-PIP-07). 해제된 연결은 계통 추적과 TTL의 공급 관계(`feeds`)에서 제외한다. 저장·불러오기와 BIM 재임포트 시 해제 보정은 OE-PIP-06의 기준으로 유지한다.

## 수용 기준

- 사람이 이은 연결은 출처 `manual` 이고 방향이 비어 있으며, 사용자가 삭제할 수 있다.
- BIM 포트 연결에는 원본을 지우는 일반 삭제 대신 '연결 해제 보정'을 실행할 수 있다. 해제 후 원본 연결·방향은 보존되지만 유효 계통과 TTL `feeds`에서는 제외된다.
- '해제 보정 취소'를 실행하면 원본 연결·방향이 복원된다. 보정·취소의 수행자·시점·사유를 이력에서 확인할 수 있다.
- 연결 추가·삭제·해제 보정·보정 취소 후 규칙 방향과 일치율이 다시 계산된다.

## 검증 (이 repo)

- 기존 구현 검증: 사람이 이은 연결은 방향 없이 시작하고, 포트 연결은 끊을 수 없다. 잇거나 끊으면 규칙 방향이 다시 계산된다 — `e2e/connect.spec.ts`, 성수 G-6·G-7·G-8.
- 새 수용 기준 중 BIM 연결 해제 보정·취소·이력·유효 계통/TTL 제외는 구현과 검증이 필요하다. 위 기존 검증은 새 동작의 완료 근거가 아니다.

## 메모

- K13·OE-PIP-06을 원본 불변에서 '원본 보존 + 연결 해제 보정 허용'으로 개정했다. BIM 원본 방향의 직접 수정 제한은 유지한다(OE-PIP-04).
