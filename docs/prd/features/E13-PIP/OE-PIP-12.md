# OE-PIP-12 배관 끝점 추종

## 요구사항

(PRD #14-B) 설비를 옮기면 연결 배관의 끝점이 따라온다. 바로 붙은 이음쇠는 같이 옮기고, 그 너머 구간은 먼 끝을 두고 늘인다. 사용자가 배관을 끌어 수동으로 고칠 수도 있다(OE-PIP-10). 되돌리기·편집 파일을 거쳐도 같다.

## 수용 기준

설비를 옮긴 뒤 배관의 한 끝이 설비에 붙어 있고 다른 끝은 제자리다.
