# OE-PIP-12 배관 끝점 추종

## 관련 티켓

- [OE-PIP-06](./OE-PIP-06.md): 해제된 연결의 추종 제외
- [OE-PIP-10](./OE-PIP-10.md): 배관 형상 보정
- [OE-PIP-13](./OE-PIP-13.md): 좌표 없는 끝점의 추종 불가

## 요구사항

(PRD #14-B) 설비를 이동하면 현재 유효하게 연결된 배관의 끝점이 해당 설비의 연결점을 따라간다. 연결점의 설비 기준 상대 위치를 유지하며, 방향이 아니라 실제 연결 대상을 기준으로 추종한다. 사용자가 연결 해제한 BIM 배관 연결은 추종하지 않는다(OE-PIP-06).

설비에 바로 붙은 이음쇠와 그 다음 배관 구간의 영향을 미리 표시한다. 다른 설비·분기에도 연결된 이음쇠는 무조건 함께 이동하지 않고 영향을 검토할 수 있도록 안내한다. 배관의 반대쪽 연결점과 무관한 분기·설비는 유지하며, 필요하면 사용자가 배관 형상을 보정한다(OE-PIP-10). 원본 BIM 형상과 연결 정보는 보존한다.

연결점 좌표나 편집 가능한 경로가 없으면 임의 좌표를 만들지 않고 '끝점 자동 추종 불가' 사유를 표시한다(OE-PIP-13). 길이 0·연결 불일치·미완료 경로가 발생하면 검증 결과를 표시한다. 위치 변경만으로 연결 대상이나 흐름 방향을 반전시키지 않는다. 설비·이음쇠·배관의 관련 변경은 하나의 편집 이력으로 되돌리고 저장·불러오기 후 함께 복원한다.

## 수용 기준

- 설비 이동 후 연결된 배관의 해당 끝점은 연결점을 따라가고 반대쪽 끝점은 유지된다.
- 바로 붙은 이음쇠의 영향이 표시되고, 공유 분기점이나 무관한 설비는 무조건 이동하지 않는다.
- 사용자가 연결 해제한 BIM 배관 연결의 배관 끝점은 추종하지 않는다.
- 필요한 좌표가 없으면 자동 추종 불가 사유가 표시되고 좌표가 임의로 생성되지 않는다.
- 이동 후 연결·형상 위반을 확인할 수 있고, 기존 연결 대상과 흐름 방향은 위치 이동만으로 변경되지 않는다.
- 되돌리기와 저장·불러오기 후 설비·배관·이음쇠 및 보정 상태가 함께 복원된다.

## 검증 (이 repo)

- 연결점 추종, 공유 이음쇠 영향, 해제 보정 제외, 좌표 누락 처리 및 저장 복원 검증이 필요하다.

## 메모

- 설비 중심으로 모든 배관 끝점을 모으지 않고, 해당 연결점의 위치를 기준으로 이동한다.
