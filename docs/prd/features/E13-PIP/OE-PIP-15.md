# OE-PIP-15 층간 위임

## 요구사항

(PRD #14-C) 층을 넘나드는 배관(라이저)은 층 편집 화면에서 그리지 않고 다중층 뷰(OE-ML-12~18)에서 다룬다. 층 편집 화면에는 분기점(OE-ML-13)만 보인다. 라이저는 설비 편집 모드 팔레트의 [라이저] 도구로 시작하며, 고르면 다중층 뷰로 바뀐다(OE-ML-01 ③, OE-UI-04).

## 수용 기준

- 층 편집 화면에서 다른 층으로 이어지는 배관을 그릴 수 없고 분기점만 보인다.
- 설비 편집 모드에서 [라이저] 를 고르면 다중층 뷰가 열린다.
