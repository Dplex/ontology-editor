# OE-PIP-15 층간 배관 작성·편집

## 요구사항

(PRD #14-C) 층을 넘나드는 배관은 다중층 편집 모드의 설비 편집 모드에서 배관 그리기(OE-PIP-11)와 배관 편집(OE-PIP-10)으로 작성·수정한다. 라이저는 층을 지나는 수직 배관 구간을 뜻하며, 별도 생성·편집 도구로 구분하지 않는다. 시작·종료 연결 대상과 층 범위를 지정하고 수직 구간·층간 오프셋·층별 분기를 작성하거나 수정할 수 있다(OE-ML-12~14).

다중층 편집 모드에서 각 층의 설비·배관을 연결 대상으로 선택하고 수평 분기까지 작성할 수 있다. 기존 배관에 분기 연결을 완료하면 필요한 분기점을 생성하거나 기존 분기점을 사용한다. 형상이 교차하거나 접촉했다는 이유만으로 연결 관계를 만들지 않는다.

층 편집 화면에서는 해당 층의 배관과 층간 배관의 분기점을 표시하고 편집한다. 다른 층으로 이어지는 경로를 작성하려면 [다중층 편집에서 계속]으로 이동한다(OE-ML-01 ③, OE-UI-04). 현재 층·선택 대상·작성 중 경로를 유지하고 대상 층 범위를 선택하며, 전환을 취소하면 원래 화면의 작성 상태를 유지한다. 층 편집 화면에서 다른 층까지 이어지는 경로를 직접 완료하지 않는다.

두 화면은 동일한 배관·분기점·연결 식별 정보와 편집 이력을 사용한다. 연결 해제 보정·취소·방향 확정·형상 수정 결과를 공유하며, 화면 전환 자체로 편집 결과가 사라지거나 객체가 중복 생성되지 않는다. 경로 추적은 사용자가 연결 해제한 BIM 배관 연결을 포함한 비활성 연결을 통과하지 않으며 미확정 방향은 확정 방향과 구분한다. 색·경로 추적·샤프트 소속·좌표 검증은 OE-ML-15~18을 따른다.

층 편집에서 다중층 모드로 진입하기 전에 완료된 층 편집을 별도 작업으로 저장·검증·확정한다(OE-WF-03). 성공한 확정 버전을 기준으로 새로운 다중층 세션 작업 ID를 만든다. 진입부터 종료까지의 모델 변경은 층·공간/설비 모드와 관계없이 하나의 작업으로 저장하며, 자동 동기화는 서버 초안과 복구 기록만 갱신한다. 개별 편집의 undo/redo는 현재 세션 안에서 유지한다. 이전 층 작업의 완료 이력은 보존하되 현재 세션의 undo로 이전 확정 작업을 되돌리지 않는다. 다중층 종료 시 전체 영향 층을 검증하여 한 번에 저장·확정하고 성공 후 층 편집으로 돌아간다. 실패하면 세션과 편집을 유지한다. 작성 중인 미완료 배관 경로는 확정 모델에서 제외하고 전환용 작성 상태로 보존하여 새 세션에서 계속한다. 진입 취소·실패 시 원래 작성 상태로 돌아간다.

## 수용 기준

- 다중층 편집 모드에서 기존 배관 그리기·편집 도구를 사용할 수 있고, 별도의 라이저 도구 버튼은 없다.
- 서로 다른 층의 연결 대상을 잇는 배관과 각 층의 수평 분기를 같은 다중층 화면에서 작성할 수 있다.
- 배관 편집으로 수직 구간과 층간 오프셋을 수정할 수 있다.
- 분기 연결 완료 시 필요한 분기점이 생성되고 기존 분기점은 중복 생성되지 않는다. 작성 취소 후 임시 배관·연결·분기점은 남지 않는다.
- [다중층 편집에서 계속]으로 이동하면 현재 층·선택 대상·작성 중 경로가 유지된다. 전환 취소 후 원래 화면에서 작성을 계속할 수 있다.
- 두 화면의 배관·분기점 ID와 연결·방향·해제 보정 상태가 일치하고, 경로 추적은 비활성 연결을 통과하지 않는다.
- 화면 전환·되돌리기·저장 복원 후 완료된 편집 상태가 유지되고 객체가 중복 생성되지 않는다.

- 층 작업과 다중층 작업은 다른 ID로 저장되고, 여러 층·모드의 변경은 다중층 종료 시 하나의 완료 작업으로 기록된다. 자동 저장이 완료 버전을 추가하지 않고, 개별 undo는 현재 세션의 변경만 되돌린다. 진입 전 저장이나 종료 저장 실패 시 편집이 보존된다. 작성 중 경로는 확정 데이터에 포함되지 않고 성공한 진입 후 이어서 작성할 수 있다.

## 검증 (이 repo)

- 공통 배관 도구의 다중층 사용, 작성 중 화면 전환, 분기 생성·취소, 오프셋 편집 및 화면 간 상태·이력 공유 검증이 필요하다. 문서 반영은 해당 UI의 구현 완료를 뜻하지 않는다.

## 메모

- OE-PIP-10·11은 공통 배관 편집·그리기 동작을, OE-ML-12~18은 층간 작업의 추가 기준을 정의한다. 이 티켓은 두 화면 사이의 진입·상태 공유 기준을 정한다.
