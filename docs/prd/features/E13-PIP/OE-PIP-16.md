# OE-PIP-16 규칙 방향 알려진 오류 보정

## 요구사항

규칙 방향의 알려진 오류를 보정한다 — 전열교환기(급기·배기 모두 연결), 천장형 배기팬(흡입구). 보정 규칙은 성수·병원·Duplex 세 파일에서 동시에 비교해 일치율이 떨어지지 않을 때만 넣는다.

## 수용 기준

배기 계통의 포트 일치율이 75% 보다 높아지고 다른 계통의 일치율이 떨어지지 않는다.
