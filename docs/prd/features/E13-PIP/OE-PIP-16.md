# OE-PIP-16 규칙 방향 알려진 오류 보정

## 요구사항

규칙 흐름 방향의 알려진 오류를 보정한다. 전열교환기는 급기·배기 경로를 구분하고, 흡입구가 포함된 천장형 배기팬은 해당 연결의 유입·유출 역할을 구분한다. 설비 이름 하나만으로 모든 연결의 방향을 뒤집지 않는다. 역할을 판정할 근거가 부족하거나 서로 충돌하면 방향을 미확정·추정 불가로 표시한다.

BIM에 명시된 원본 방향과 사용자가 연결별로 확정한 방향은 보정 규칙으로 변경하지 않는다. 해제된 연결은 계산·비교에서 제외하고, 기존에 확정한 규칙과 새 추정이 다르면 OE-PIP-07에 따라 재검토한다.

보정 전후를 성수·병원·Duplex의 고정된 파일 버전과 동일한 비교 기준으로 평가한다. 파일·계통별 비교 연결 수, 일치·불일치 수, 추정 불가 수와 추정 범위를 기록한다. BIM 원본 방향과 비교할 수 없는 파일은 일치율을 만들지 않고 별도로 검토한다. 어려운 연결을 추정 대상에서 빼는 것만으로 일치율을 높이지 않는다.

## 수용 기준

- 동일한 성수 기준 샘플의 배기 계통 일치율이 기존 75%보다 높아지고, 동일 비교 집합에서 다른 계통의 일치율이 떨어지지 않는다.
- 병원 천장형 배기팬 오류 사례에서 연결 역할에 맞는 추정이 이루어지고, 전열교환기의 급기·배기 경로가 혼동되지 않는다.
- 성수·병원·Duplex 각각의 파일 버전·비교 건수·일치율 또는 비교 불가 사유·추정 범위가 보고된다.
- 추정 대상 감소가 있으면 제외 사유와 변경 전후 결과가 함께 제공되며, 분모 축소만을 개선으로 판정하지 않는다.
- BIM 원본·수동 확정 방향은 유지되고, 해제된 연결은 제외되며, 충돌한 기존 규칙 확정은 재검토 후에만 내보낼 수 있다.

## 검증 (이 repo)

- 세 기준 파일에서 오류 사례 개선, 다른 계통의 회귀, 추정 범위와 분모 변화 및 확정 보존 검증이 필요하다. 현재의 75%는 요구사항에 제시된 기준값이며 이번 문서 개정에서 재측정한 결과가 아니다.

## 메모

- R2의 규칙 개선은 R1의 연결별 보정·계통 확정 절차를 대체하지 않는다.
