# OE-PIP-17 환수·급탕 원천 규칙

## 관련 티켓

- [OE-PIP-03](./OE-PIP-03.md): Flow Type·공급/환수 구분
- [OE-PIP-05](./OE-PIP-05.md): 계통 단위 확정
- [OE-PIP-07](./OE-PIP-07.md): 규칙 재검토·feeds 반영

## 요구사항

기존 규칙이 원천 또는 환수 대상을 찾지 못하는 순환수 환수·급탕 계통에 흐름 방향 추정 규칙을 추가한다. Flow Type과 공급·환수 구분은 OE-PIP-03의 정의를 사용한다. 순환수는 유체별 열원·열 사용 설비와 연결 경로를 확인하고, 환수는 열 사용 설비에서 해당 열원으로 돌아가는 방향으로 추정한다.

급탕은 공급과 순환 환수를 구분한다. 급탕 공급은 확인된 급탕 열원에서 사용 설비로, 급탕 순환 환수는 해당 순환 구성에 따라 열원으로 돌아가는 방향으로 추정한다. 원천을 찾지 못하거나 서로 다른 유체·원천이 혼재하여 경로를 구분할 수 없으면 방향을 임의로 만들지 않고 사유를 표시한다. 냉수·온수·냉각수 계통을 한 경로로 합치지 않는다.

BIM 원본 방향과 수동 확정 방향을 우선 보존하고, 사용자가 연결을 해제하면 해당 계통은 규칙 계산에서 제외한다. 새 추정은 미확정 상태로 표시하며 계통 단위 확정 후에만 TTL `feeds`에 반영한다(OE-PIP-05·07). 형상이나 원천이 없는 구간을 잇기 위해 연결을 임의로 시스템이 자동으로 새로 만들지 않는다.

## 수용 기준

- 열원과 열 사용 설비가 확인된 냉수·온수·냉각수 환수 사례에서 사용 설비 → 해당 열원 방향으로 추정된다.
- 급탕 공급과 순환 환수의 흐름 방향이 각각의 Flow Type과 연결 구성에 맞게 구분된다.
- 원천 누락·복수 원천 충돌·유체 혼재 사례는 추정 불가 사유가 표시되고 잘못된 단방향 관계가 생성되지 않는다.
- BIM 원본·수동 확정 방향과 연결 해제 보정은 유지되며 기존 공기 및 순환수 공급 계통 결과가 악화되지 않는다.
- 새 규칙 방향은 확정 전 TTL에 출력되지 않고, 확정 후 해당 유효 관계만 출력된다.

## 검증 (이 repo)

- 유체별 환수·급탕 공급·순환 환수의 정상 및 원천 누락·충돌 사례와 기존 계통 회귀 검증이 필요하다.

## 메모

- 급탕 Flow Type은 OE-PIP-03에 이미 요구사항으로 명시되어 있다. 지원 범례와 공급·환수 구분이 구현되어 있어야 이 규칙을 사용할 수 있다.
