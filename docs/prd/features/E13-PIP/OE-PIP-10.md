# OE-PIP-10 배관 형상 수정

## 요구사항

(PRD #14-B) 배관 폴리라인의 꼭짓점을 이동·추가·삭제하고, 구간을 삭제하거나 양 끝의 연결 대상을 변경할 수 있다. 끌기 인터랙션은 OE-OBJ-15, 배관의 기본 형식과 Flow Type은 OE-OBJ-12를 따른다.

형상 편집과 연결 관계 편집을 구분한다. 중간 꼭짓점 이동은 기존 연결 대상과 확정 방향을 바꾸지 않는다. 끝점을 이동할 때는 연결점에 붙여 유지하거나 새 연결 대상을 명시적으로 선택한다. 실제 연결 대상 변경·삭제는 OE-PIP-01·06에 따라 처리하며, BIM 원본 형상과 연결 정보는 보존하고 편집 결과를 별도 보정으로 기록한다. 형상 접촉만으로 BIM 연결을 삭제하거나 새 연결을 확정하지 않는다.

완료된 배관의 양 끝은 설비·다른 배관·분기점에 연결되어야 한다. 수정 중 열린 끝은 미완료 상태로 표시한다. 연결 해제 보정으로 발생한 열린 끝도 검증 위반과 사유를 표시하고, 자동으로 다시 연결하지 않는다. 꼭짓점이 부족하거나 길이가 0인 경로는 정상 배관으로 완료할 수 없다. 중간 구간 삭제가 다른 분기의 연결에 미치는 영향을 실행 전에 표시한다.

같은 배관 편집 도구를 다중층 편집 모드에서도 제공한다. 수직 구간·층간 오프셋·층별 분기를 해당 화면에서 수정할 수 있으며(OE-ML-12~14), 층 편집 화면에서 층간 작업을 계속할 때는 OE-PIP-15의 화면 전환·상태 유지 기준을 따른다.

형상·연결 수정 후 길이·높이·연결 검사와 필요한 규칙 방향 재계산을 수행한다. 관련 수정은 함께 되돌릴 수 있고 저장·불러오기 후에도 유지된다.

## 수용 기준

- 다중층 편집 모드에서도 같은 배관 편집 도구로 수직 구간·층간 오프셋·층별 분기를 수정할 수 있고, 화면 전환 후 동일 객체와 편집 상태가 유지된다.
- 꼭짓점 이동·추가·삭제 후 경로·길이·높이가 갱신되고, 중간점 편집만으로 연결 대상이나 확정 방향이 바뀌지 않는다.
- 끝점의 연결 대상 변경 시 기존·변경 대상을 확인할 수 있고 BIM 원본 연결 변경은 해제 보정으로 처리된다.
- 열린 끝·점 부족·길이 0인 경로는 미완료 또는 검증 위반으로 표시되며 정상 배관으로 완료되지 않는다.
- 해제된 연결은 형상 접촉이나 형상 재계산으로 자동 복원되지 않는다.
- 구간 삭제 영향이 표시되고 관련 없는 분기의 연결은 유지된다.
- 되돌리기와 저장·불러오기 후 형상·연결·보정 상태가 함께 복원된다.

## 검증 (이 repo)

- 형상 편집, 원본 보존, 연결 해제 보정 연동, 구간 삭제 영향 및 저장 복원 검증이 필요하다.

## 메모

- 좌표만 바꾸는 동작과 실제 계통 연결을 바꾸는 동작을 혼동하지 않는다.
