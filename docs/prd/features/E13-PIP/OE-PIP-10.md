# OE-PIP-10 배관 형상 수정

## 요구사항

(PRD #14-B) 배관의 꼭짓점을 옮기고 넣고 지운다. 구간을 지우고, 양 끝이 연결된 설비를 바꾼다. 수정 뒤에도 양 끝은 설비 또는 다른 배관에 연결되어 있어야 한다(OE-OBJ-12). 끌기 인터랙션은 OE-OBJ-15.

## 수용 기준

꼭짓점을 옮기면 배관이 그 점을 지나도록 다시 그려지고, 끝점이 끊긴 상태로는 놓이지 않는다.
