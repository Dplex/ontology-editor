# OE-PIP-02 계통 변경·생성·삭제

## 요구사항
> User story : 구축 담당자는 설비의 계통을 바꾸고, 계통을 새로 만들거나 지울 수 있다. 설비는 공기 계통 자리와 물 계통 자리를 따로 가지므로 한 계통을 고쳐도 다른 계통은 유지된다. 계통을 지우면 그 계통에 속했던 설비는 계통 없음이 되고, 되돌리면 색까지 돌아온다. 사람이 만든 계통의 종류와 유체는 원천 기기로 짐작한 값이 덮어쓰지 않는다. 사용자가 계통을 바꾸면 3D 색·리포트·규칙 방향이 함께 바뀌어, 운영 담당자가 보는 계통도가 즉시 정확해지는 것을 확인할 수 있어야 한다.

(PRD #14-A) 설비의 계통을 바꾼다. 설비는 공기 계통 자리와 물 계통 자리를 따로 가지므로 한 계통을 수정해도 다른 계통은 유지된다. 
사용자는 계통을 새로 만들거나 지울 수 있다 — 지우면 해당 설비는 "공기 계통 없음"이 된다.
사람이 만든 계통의 종류·유체는 원천 기기로 짐작한 값이 덮지 않는다. 계통을 바꾸면 3D 색·리포트·규칙 방향이 함께 바뀐다.

## 수용 기준

- 설비의 공기 계통을 바꿔도 물 계통 자리가 그대로다.
- 계통을 지우면 구성원이 계통 없음이 되고 되돌리면 색까지 돌아온다.
