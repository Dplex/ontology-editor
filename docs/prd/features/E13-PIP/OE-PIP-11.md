# OE-PIP-11 수동 배관 그리기

## 요구사항

(PRD #14-B) 점(x·y·z)을 차례로 지정하여 배관 폴리라인을 그린다. 시작과 끝은 설비·다른 배관·분기점에 연결하며, Flow Type을 선택한다(OE-OBJ-12). 같은 배관 그리기 도구를 다중층 편집 모드에서도 제공하여 층간 배관과 층별 수평 분기를 해당 화면에서 완료할 수 있다. 층 범위·수직 구간·분기·오프셋은 OE-ML-12~14를, 층 편집 화면에서 [다중층 편집에서 계속]으로 이동할 때의 작성 상태 유지는 OE-PIP-15를 따른다.

사용자는 적합한 기존 계통을 선택하거나 새 수동 계통을 만든다(OE-PIP-02·03). 연결 대상의 매체·Flow Type·기존 계통을 확인하고, 서로 다른 계통을 임의로 합치지 않는다. 공기 계통과 물 계통이 함께 있는 설비는 해당 매체의 연결 대상을 구분한다. 대상 계통이 충돌하거나 불명확하면 검토 후 선택하도록 안내한다.

경로와 연결은 출처 `manual`로 기록한다. 수동 확정 방향은 미지정 상태로 시작하고, 규칙 추정 방향은 확정 전 화면에만 표시한다. 연결되었다는 사실만으로 담당 관계나 TTL `feeds`를 생성하지 않으며, 담당 판정에는 유효하고 확정된 흐름 방향을 사용한다(OE-PIP-04·05, OE-ZON-01).

좌표가 유효하고 길이가 0이 아닌 경로만 완료할 수 있다. 취소하면 임시 경로와 연결을 남기지 않는다. 완료 후 관련 계통·규칙 방향·완전성 검사를 갱신하고 하나의 편집 이력으로 되돌릴 수 있다. 해제된 BIM 연결을 다시 사용하려면 OE-PIP-06의 보정 취소 절차를 따른다.

## 수용 기준

- 다중층 편집 모드에서 같은 배관 그리기 도구로 층간 배관과 층별 분기를 작성할 수 있고, 층 편집 화면에서 이동해도 작성 중 경로와 선택 대상이 유지된다.
- 양 끝 연결 대상과 Flow Type·계통을 선택하면 배관 형상과 수동 연결이 생성된다.
- 같은 계통을 선택한 A·B 사이의 배관은 해당 계통에 속한다. 다른 기존 계통은 자동 병합되지 않고 무관한 매체의 소속은 유지된다.
- 생성 직후 수동 확정 방향은 미지정이고, 미확정 규칙 방향은 TTL `feeds`에 출력되지 않는다.
- 설비와 연결되지 않은 열린 끝·유효하지 않은 좌표·길이 0인 경로는 완료할 수 없고 취소 후 임시 객체가 남지 않는다.
- 생성·되돌리기·저장 복원 후 형상·연결·계통·방향 상태가 일치하며 해제 보정은 자동으로 취소되지 않는다.

## 검증 (이 repo)

- 수동 배관 그리기, 계통 선택·충돌 처리, 미확정 방향 출력 제외 및 저장 복원 검증이 필요하다.

## 메모

- 배관 생성은 물리적 연결을 편집하는 기능이다. 계통 구성과 흐름 방향 확정은 각각의 절차를 따른다.
