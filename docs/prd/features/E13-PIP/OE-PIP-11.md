# OE-PIP-11 수동 배관 그리기

## 요구사항

(PRD #14-B) 점(x·y·z)을 차례로 눌러 배관 폴리라인을 그린다. 시작과 끝은 설비 또는 다른 배관에 연결한다(분기는 OE-ML-13). Flow Type 을 고른다(OE-OBJ-12).
연결 관계는 계통이 되어 담당 판정(OE-ZON-01)에 쓰인다.

## 수용 기준

설비 A 에서 시작해 설비 B 에서 끝나는 배관을 그리면 A·B 가 같은 계통으로 묶인다.
