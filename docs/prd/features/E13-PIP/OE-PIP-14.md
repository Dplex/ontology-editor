# OE-PIP-14 BIM 배관· 계통 자동 가져오기

## 관련 티켓

- [OE-BIM-08](../E05-BIM/OE-BIM-08.md): 배관 초안 임포트
- [OE-PIP-13](./OE-PIP-13.md): 배관 좌표 조건
- [OE-PIP-06](./OE-PIP-06.md): 연결 해제 보정 유지
- [OE-HIST-03](../E19-HIST/OE-HIST-03.md): 재임포트 보정 유지·충돌 검토

## 요구사항
> User story : 구축 담당자가 배관 좌표가 있는 BIM을 임포트하면 원본 경로를 따라 배관이 자동으로 그려지고 배관 종류와 계통이 함께 유지된다. 좌표가 없거나 읽을 수 없는 구간은 임의로 메우지 않고 미반영 목록에 사유를 보이며, 틈을 잇는 자동 라우팅은 하지 않는다. 같은 BIM을 다시 임포트하면 동일 배관이 중복 생성되지 않는다. BIM에 명시된 연결·방향은 원본으로 보존되고 형상 접촉으로 추정한 연결은 추정 출처와 미확정 상태로 표시된다. 사용자는 해제하거나 보정한 내용이 재임포트 뒤에도 유지되고 충돌은 검토 대상으로 표시되는 것을 확인할 수 있어야 한다.

(PRD #14-B) BIM에 유효한 배관 세그먼트 좌표나 추출 가능한 경로가 있으면 임포트 때 원본 경로를 따라 자동으로 그린다(OE-BIM-08, OE-PIP-13). 좌표계와 단위를 공통 기준으로 변환하고 원본 식별 정보·Flow Type·계통을 함께 유지한다.

좌표가 없거나 유효한 경로를 읽을 수 없는 구간은 임의로 메우지 않고 미반영 목록에 사유를 표시한다. 원본 경로 사이의 틈을 연결하기 위한 자동 라우팅은 범위 밖이다(PRD 1.4). 재임포트한 동일 세그먼트는 식별 정보를 기준으로 갱신하며 중복 생성하지 않는다.

형상을 그리는 것과 연결·방향을 확정하는 것을 구분한다. BIM에 명시된 연결과 흐름 방향은 원본 정보로 보존하고, 형상 접촉으로 추정한 연결은 추정 출처와 미확정 상태를 표시한다. 사용자의 연결 해제·형상 보정은 재임포트 보정 유지 기준에 따라 보존하며 충돌은 검토 대상으로 표시한다(OE-PIP-06, OE-HIST-03).

## 수용 기준

- **AC1** 유효한 세그먼트가 있는 BIM을 열면 변환된 원본 경로와 Flow Type에 따라 배관이 표시된다.
- **AC2** 경로가 없는 구간은 그려지지 않고 이유가 표시되며, 틈을 메우는 배관이 자동 생성되지 않는다.
- **AC3** 재임포트해도 동일 세그먼트가 중복 생성되지 않고 기존 사용자 보정이 임의로 사라지지 않는다.
- **AC4** 형상 표시만으로 새 방향이나 담당 관계가 확정되지 않으며 원본·추정 연결을 구분할 수 있다.
- **AC5** 사용자가 연결 해제한 BIM 배관 연결은 원본 형상이 다시 표시되어도 자동 활성화되지 않는다.

## 메모

- '자동 그리기'는 있는 형상을 재현하는 기능이며, 없는 배관 경로를 설계하는 기능이 아니다.
