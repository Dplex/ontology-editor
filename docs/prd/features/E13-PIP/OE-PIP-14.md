# OE-PIP-14 자동 배관 그리기(초기 모드)

## 요구사항

(PRD #14-B) BIM 에 배관 좌표(세그먼트)가 있으면 임포트 때 배관을 자동으로 그린다(OE-BIM-08). 자동 라우팅(좌표 없는 배관을 지어 그리는 것)은 하지 않는다(PRD 1.4 제외).

## 수용 기준

세그먼트가 있는 BIM 을 열면 배관이 그려지고, 없는 구간은 그려지지 않는다.
