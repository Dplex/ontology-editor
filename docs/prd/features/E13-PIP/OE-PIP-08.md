# OE-PIP-08 위반 한 번에 고치기

## 요구사항

(PRD #14-A) 완전성 검사(OE-BIM-18)의 위반 원인에 맞는 보정 동작을 제공한다. 위치·소속 문제에는 [방 안으로 옮기기], 실제 연결 누락에는 [연결 후보 확인 후 잇기]를 제공한다. 단순히 방향이 없거나 연결이 의도적으로 해제된 경우를 연결 누락과 구분한다.

연결 후보에는 대상 이름·거리·계통 및 매체 정보를 표시한다. 가까운 것만을 근거로 다른 매체·서로 맞지 않는 Flow Type·흐름 없는 기기를 연결하지 않는다(OE-PIP-18). 적합한 후보가 없거나 계통을 판정할 수 없으면 사유와 수동 검토 경로를 표시한다. 사용자가 해제한 BIM 연결은 보정 기능이나 후보 추천으로 자동 복원하지 않는다(OE-PIP-06).

사용자가 후보를 확인하고 실행하면 OE-PIP-01과 같은 경로로 출처 `manual`의 연결을 추가한다. 방향은 수동 확정 전 미지정이며, 규칙으로 추정한 방향은 미확정 상태로 표시한다. 위치 변경·연결 추가 후 소속·완전성 검사·규칙 방향을 다시 계산하고 하나의 되돌리기 이력으로 기록한다(OE-MAP-06, OE-PIP-07). 거리 기반 잇기는 배관 형상을 자동으로 그리는 기능이 아니다.

## 수용 기준

- 위반 원인과 실행 가능한 보정 동작이 표시되고, 적합한 후보가 없으면 임의 연결을 만들지 않는다.
- 연결 실행 전 대상·거리·계통을 확인할 수 있고, 실행 후 연결 출처는 `manual`이며 수동 확정 방향은 비어 있다.
- 사용자가 해제한 연결을 자동 복원하지 않고, 다른 매체나 흐름 없는 기기를 가까운 후보라는 이유로 연결하지 않는다.
- [방 안으로 옮기기] 또는 연결 보정 후 소속·완전성 검사·규칙 방향이 갱신된다.
- Ctrl+Z로 위치와 연결이 보정 전 상태로 돌아가며, 다시 실행하면 같은 결과가 복원된다.

## 검증 (이 repo)

- 기존 구현 검증: 위반 이유 표시와 위치·가까운 이웃 연결 보정의 되돌리기 — `checks.test.ts`, 성수 J-1·J-2·J-3.
- [방 안으로 옮기기] 는 배관 없는 설비끼리 겹치는 자리(OE-OBJ-16)를 권하지 않는다. 바로 안쪽이 겹치면 1.5m 안쪽까지 들어가며 겹치지 않는 자리를 찾고, 없으면 버튼 대신 겹치는 설비를 알린다 — `checks.test.ts`, 성수 J-1
- 계통·매체 적합성, 후보 확인, 의도적 연결 해제 존중 및 방향 상태 구분은 추가 구현·검증이 필요하다.

## 메모

- '한 번에 고치기'는 원인별 보정을 하나의 편집 동작으로 실행한다는 뜻이며, 거리만으로 실제 연결이나 흐름 방향을 확정하지 않는다.
