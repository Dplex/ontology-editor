# OE-PIP-05 규칙 방향 추정·확정

## 관련 티켓

- [OE-GEN-04](../E08-GEN/OE-GEN-04.md): 미확정 규칙 방향의 TTL 제외

## 요구사항
> User story : 구축 담당자는 BIM에 포트 방향이 없는 연결에 대해 계통 종류(급기는 나감, 리턴·배기는 들어옴)와 원천 설비 종류를 근거로 자동 추정된 흐름 방향을 화면에서 확인할 수 있다. 추정 방향은 사용자가 확정해야만 내보내지며 확정은 계통 단위로 한다. 확정 버튼 옆에 BIM 포트 방향과의 일치율이 보여 추정이 얼마나 믿을 만한지 판단할 수 있고, 비교 연결이 충분히 많고 일치율이 높은 계통은 일괄 확정할 수 있다. 사용자는 확정하지 않은 규칙 방향이 온톨로지에 나가지 않는다는 것을 신뢰할 수 있어야 하며, 수백 개 연결에 방향을 하나씩 지정하지 않고도 계통 방향을 정리할 수 있다.

(PRD #14-A) BIM에 포트 방향이 없는 연결은 계통 종류(급기는 나감, 리턴·배기는 들어옴)와 설비 종류(원천)를 근거로 포트 방향을 자동 추정하여 화면에 표시하고, 사용자가 확정한 방향만 내보낸다(glossary "규칙 방향").
확정은 계통 단위다. 확정 버튼 옆에 포트 방향과의 일치율을 보이고, 확정한 계통의 규칙 방향만 `feeds` 로 나간다(K14, OE-GEN-04). 포트와 비교할 연결이 20개 이상이고 일치율 90% 이상인 계통은 일괄 확정할 수 있다.

## 수용 기준

- **AC1** 확정 전 계통의 규칙 방향은 TTL 에 없다.
