# OE-PIP-04 연결별 방향 지정

## 요구사항

(PRD #14-A) BIM 포트에 방향이 명시되지 않은 연결에 대해 사용자가 방향을 지정할 수 있다. 연결 양 끝의 설비명을 기준으로 ‘A → B’, ‘B → A’를 표시하며, 사용자가 ‘적용’을 실행하면 해당 연결의 방향을 확정한다. 적용 전 방향 변경은 미리보기 상태로 유지한다.

사용자가 연결별로 확정한 방향은 규칙으로 추정한 방향보다 우선한다(K14). 규칙 재계산으로 수동 확정 방향을 덮어쓰지 않는다. 규칙 방향과 다르면 두 방향의 차이를 표시하고, 사용자가 보정 사유를 기록한 뒤 적용할 수 있다.

연결별로 확정한 방향은 계통 단위의 추가 확정 없이 내보내기 시 TTL `feeds`에 반영한다. 방향 적용은 운영 데이터 게시와 구분하며, 게시에는 기존 편집·검증·반영 절차를 따른다.

‘수동 지정 해제’를 실행하면 수동 확정 방향을 제거하고 규칙 방향이 있으면 그 방향으로 돌아간다. 확정된 규칙 방향은 내보내기에 반영하고, 미확정 규칙 방향은 화면에만 표시한다. 규칙 방향도 없으면 ‘방향 미지정’ 상태로 표시한다.

BIM 포트에 명시된 원본 방향은 직접 수정하지 않는다(OE-PIP-06). 연결 해제 보정이 적용된 연결에는 방향을 적용할 수 없으며, 기존 방향 정보가 남아 있어도 계통 추적과 TTL `feeds`에서 제외한다.

방향 적용·변경·수동 지정 해제의 수행자·시점·변경 내용을 편집 이력에 기록한다. 수동 확정 방향과 보정 사유는 저장·불러오기 후에도 유지한다.


## 수용 기준

- BIM 포트 방향이 없는 연결에서 ‘A → B’ 또는 ‘B → A’를 선택할 수 있다. ‘적용’ 전 미리보기 방향은 TTL `feeds`에 반영되지 않는다.
- ‘적용’ 후 수동 확정 방향이 규칙 방향보다 우선하며, 규칙 재계산 후에도 유지된다.
- 규칙과 반대 방향을 선택하면 두 방향의 차이가 표시된다. 보정 사유를 기록하고 적용하면 수동 방향으로 확정된다.
- 수동 확정 방향은 계통 단위의 추가 확정 없이 내보내기 시 TTL `feeds`에 반영된다. 방향 적용만으로 운영 데이터가 게시되지는 않는다.
- ‘수동 지정 해제’ 후 확정된 규칙 방향이 있으면 해당 방향으로 내보낸다. 미확정 규칙 방향은 화면에만 표시하며, 규칙 방향이 없으면 ‘방향 미지정’으로 표시한다.
- BIM 포트에 명시된 원본 방향은 방향 선택·적용으로 변경할 수 없다.
- 연결 해제 보정이 적용된 연결은 방향 적용이 차단되고, 계통 추적과 TTL `feeds`에서 제외된다.
- 방향 편집 이력을 확인할 수 있고, 저장·불러오기 후 수동 확정 방향과 보정 사유가 유지된다.
