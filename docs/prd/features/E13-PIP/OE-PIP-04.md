# OE-PIP-04 연결별 방향 지정

## 요구사항

(PRD #14-A) 연결 하나하나의 방향을 사람이 지정한다. 화살표를 누를 때마다 하류 → 상류 → 지움 순으로 돈다. 포트가 방향을 말한 연결은 바꿀 수 없다(OE-PIP-06).
사람이 정한 방향은 규칙 방향보다 우선하고(K14), 계통 단위 확정 없이 바로 `feeds` 로 나간다.

## 수용 기준

- 사람이 방향을 정한 연결은 확정 버튼 없이 TTL `feeds` 에 나간다.
- 포트가 방향을 말한 연결은 화살표를 눌러도 바뀌지 않는다.

## 검증 (이 repo)

- 연결 하나의 방향은 하류 → 상류 → 지움으로 돌고, 포트가 방향을 말한 연결은 바뀌지 않는다 — `e2e/edit-3d.spec.ts` "연결 화살표를 누르면", 성수 G-1·G-2
