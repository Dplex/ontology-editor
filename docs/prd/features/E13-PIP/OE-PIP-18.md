# OE-PIP-18 흐름 없는 기기 연결 추정 제외

## 요구사항

흐름이 없는 기기(조명·감지기·비치품, `flow:{}`)는 형상 접촉으로 연결을 추정하지 않는다(K3 예외). 제외 규칙을 넣기 전에 재현율을 함께 재어 결정한다.

## 수용 기준

조명·감지기가 형상 접촉만으로 `feeds`·연결에 들지 않는다.
