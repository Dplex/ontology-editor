# OE-PIP-18 흐름 없는 기기 연결 추정 제외

## 요구사항

실제로 유체 흐름이 없는 것으로 분류된 조명·감지기·비치품 등은 형상 접촉을 근거로 배관·덕트의 유체 흐름 연결을 추정하는 대상에서 제외한다(K3 예외). 코드의 `flow:{}`만으로 흐름이 없다고 판정하지 않는다. 현재 공기·물 규칙의 대상이 아닌 냉매 설비와 종류 미지정 설비는 '미지원 또는 미판정'으로 구분하며, 원본 연결을 보존한다.

이 제외 기준은 형상 기반 연결 추정과 가까운 연결 후보 추천(OE-PIP-08)에 적용한다. BIM에 명시된 연결은 원본 정보로 보존하고, 실제 유체 흐름과 맞지 않는 경우 검토 대상으로 표시한다. 포트가 있다는 사실만으로 전기·신호 연결을 공기·물 공급 관계로 취급하지 않는다. 사용자가 명시적으로 등록한 관계도 출처를 보존하고 종류·매체 적합성을 검토하며, 이 규칙으로 자동 삭제하지 않는다.

종류가 변경되면 형상 기반 추정과 완전성 검사·규칙 방향을 다시 계산한다. 사용자가 해제한 연결은 종류 변경이나 재추정으로 자동 복원하지 않는다. 유체 흐름 관계가 아닌 연결은 TTL `feeds`에 출력하지 않는다.

제외 전후를 동일한 기준 모델과 정답 연결 집합에서 평가하여 잘못된 연결 감소와 실제 유체 연결의 누락을 함께 확인한다. 정밀도·재현율과 종류별 제외 건수를 기록하고, 종류를 모르는 설비를 제외하여 수치를 높이지 않는다.

## 수용 기준

- 조명·감지기·비치품은 형상 접촉만으로 유체 연결이나 TTL `feeds`에 포함되지 않고 가까운 유체 연결 후보에서도 제외된다.
- 종류 미지정 설비와 냉매 설비를 `flow:{}`라는 이유로 흐름 없는 기기로 단정하지 않으며, VRF 실외기 등 실제 흐름이 있는 설비의 원본·명시 관계는 유지된다.
- BIM 명시·사용자 등록 관계는 자동 삭제되지 않고, 매체가 맞지 않거나 유체 흐름 관계가 아닌 경우 검토 대상으로 표시되며 `feeds`로 출력되지 않는다.
- 종류 변경 후 추정 연결·검사 결과가 갱신되고, 연결 해제 보정은 유지된다.
- 동일 기준 모델에서 정밀도·재현율·종류별 제외 건수가 보고되며, 실제 유체 연결의 신규 누락 사례가 설명 없이 통과되지 않는다.

## 검증 (이 repo)

- 흐름 없는 기기의 형상 추정 제외, 후보 추천 제외, 종류 미지정 처리, 명시 관계 보존, `flow:{}`인 냉매 설비의 오제외 방지 및 정밀도·재현율 비교 검증이 필요하다.

## 메모

- '흐름 없음'은 이 에디터가 다루는 공기·물·냉매 등 유체 흐름이 없다는 뜻이다. 전기·신호·설치 관계 전체가 없다는 뜻은 아니다.
