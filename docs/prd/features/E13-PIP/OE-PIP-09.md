# OE-PIP-09 계통 이름 규칙

## 요구사항

BIM 계통 이름은 고치지 않는다 — 분야별 파일을 합칠 때 이름으로 맞추기 때문이다(OE-BIM-10). 사람이 만든 계통만 이름을 자유롭게 붙인다.

## 수용 기준

BIM 계통의 이름 칸이 읽기 전용이고 사람이 만든 계통은 편집할 수 있다.
