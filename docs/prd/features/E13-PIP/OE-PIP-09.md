# OE-PIP-09 계통 이름 규칙

## 관련 티켓

- [OE-BIM-10](../E05-BIM/OE-BIM-10.md): 병합·재임포트 매칭용 원본 이름
- [OE-PIP-02](./OE-PIP-02.md): 수동 계통 생성

## 요구사항
> User story : 구축 담당자는 BIM에서 가져온 계통의 원본 이름을 읽기 전용으로 보고, 사람이 만든 계통에는 이름을 붙이고 고칠 수 있다. 원본 이름은 파일 병합과 재임포트 매칭에 쓰이므로 바꿀 수 없다. 수동 계통 이름을 바꾸면 화면·리포트·내보내기 명칭이 함께 갱신되지만 식별자·구성원·확정 방향·연결 해제 보정은 유지되며, 이름 변경으로 흐름 방향이나 계통 종류가 확정되지는 않는다. 빈 이름은 저장할 수 없고 중복 이름은 안내를 받으며 계통은 식별자로 구분된다. 사용자는 이름이 같다는 이유로 출처나 매체가 다른 계통이 자동 병합되지 않는 것을 신뢰할 수 있어야 한다.

BIM에서 가져온 계통의 원본 이름과 식별 정보를 보존한다. 분야별 파일 병합·재임포트의 매칭에 사용하는 원본 이름은 읽기 전용으로 표시한다(OE-BIM-10). 사람이 만든 계통은 이름을 지정하고 수정할 수 있다(OE-PIP-02).

계통 이름 변경으로 흐름 방향이나 Flow Type을 확정하지 않는다. 수동 계통 이름을 바꾸면 관련 화면·리포트·내보내기 명칭을 함께 갱한신하되 계통 ID, 구성원, 확정 방향, 연결 해제 보정은 유지다. 빈 이름은 저장할 수 없고 같은 이름이 있으면 중복을 알리며 계통을 ID로 구분한다. 이름이 같다는 이유만으로 서로 다른 출처·매체의 계통을 자동 병합하지 않는다.

## 수용 기준

- BIM 원본 계통 이름은 읽기 전용이고 수동 계통 이름은 편집할 수 있다.
- 빈 이름은 저장되지 않으며 중복 이름은 경고와 식별 정보로 구분된다.
- 수동 계통 이름 변경 후 화면·리포트·TTL 명칭이 갱신되고 계통 ID·구성원·확정 방향·해제 보정은 유지된다.
- 저장·불러오기 후 이름과 식별 정보가 유지되며, 원본 이름으로 수행하는 BIM 매칭에 수동 이름 변경이 영향을 주지 않는다.

## 메모

- 원본 이름 보존과 사람이 만든 계통의 명칭 편집을 구분한다.
