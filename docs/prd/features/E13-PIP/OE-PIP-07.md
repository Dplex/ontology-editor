# OE-PIP-07 규칙 재계산

## 요구사항

목적 : PIP-07은 연결이나 설비 정보가 바뀐 뒤에도, 계통의 흐름 방향이 이전 상태로 남지 않도록 갱신하는 기능이다. 

(PRD #14-A) 연결 추가·삭제·BIM 연결 해제 보정·보정 취소·계통 변경·설비 및 계통 종류 변경 후에는 현재 유효 연결을 기준으로 규칙 흐름 방향과 BIM에 명시된 흐름 방향과의 일치율을 다시 계산한다. 사용자가 연결 해제한 BIM 배관 연결은 계통 추적·규칙 계산·일치율 비교·TTL `feeds`에서 제외한다(OE-PIP-06).

BIM 원본 방향과 사용자가 연결별로 적용한 수동 확정 방향은 재계산으로 덮어쓰지 않는다(OE-PIP-04). 계통 단위로 확정한 규칙 방향도 보존하되, 근거가 바뀌어 새 추정과 다르거나 원천·연결을 확인할 수 없어진 경우에는 해당 확정을 재검토 상태로 표시한다. 재검토 대상의 규칙 방향은 사용자가 다시 확정하기 전까지 내보내지 않는다. 새로 추가한 연결에는 기존 계통 확정을 자동 적용하지 않는다.

일치율은 현재 유효 연결 중 BIM 원본 방향과 규칙 추정 방향을 모두 단방향으로 비교할 수 있는 연결을 대상으로 '일치 연결 수 ÷ 비교 연결 수'로 계산한다. 비교 수·일치 수·불일치 수·추정 불가 수를 함께 표시하며, 비교 대상이 없으면 0%가 아닌 '비교 불가'로 표시한다. 수동 확정 방향으로 규칙 추정 값을 대체하여 일치율을 높이지 않는다.

수동 방향 취소·규칙 재확정은 각각 OE-PIP-04·05에 따르며, 저장·불러오기 후에도 확정·해제 보정·재검토 상태가 유지된다.

## 수용 기준

- 연결 추가·삭제·해제 보정·보정 취소 후 현재 유효 연결에 대해 규칙 흐름 방향과 일치율이 다시 계산된다.
- BIM 원본 방향과 수동 확정 방향은 재계산 후 유지되고, 해제된 연결은 방향 정보가 남아 있어도 추적·계산·TTL에서 제외된다.
- 확정 근거가 유지된 규칙 방향은 보존된다. 근거 변경으로 충돌하거나 추정 불가가 된 규칙 방향은 재검토 대상으로 표시되고 재확정 전 TTL에 출력되지 않는다.
- 기존 확정 계통에 새 연결을 추가해도 그 연결의 규칙 방향은 미확정이며, 추가 확정 전 TTL에 출력되지 않는다.
- 일치율과 비교 건수가 정의된 계산식과 일치하고, 비교 대상이 없으면 '비교 불가'로 표시된다.
- 저장·불러오기와 되돌리기 후 방향 및 보정 상태와 TTL 출력이 해당 편집 시점과 일치한다.

## 검증 (이 repo)

- 기존 구현 검증: 확정한 방향을 연결별로 저장하고 종류 변경·저장 복원 후 유지한다 — `edit.test.ts`, `edit-file.test.ts`, 성수 O-5.
- 연결 해제 보정 반영, 확정 근거 변경 시 재검토·출력 제외, 신규 연결의 미확정 유지 및 일치율 분모 검증은 추가 구현·검증이 필요하다. 기존의 '확정 방향을 무조건 유지'하는 동작만으로 새 수용 기준을 충족하지 않는다.

## 메모

- '확정 보존'은 값과 이력을 보존한다는 뜻이다. 근거가 바뀐 규칙 방향을 검토 없이 계속 유효한 것으로 내보낸다는 뜻은 아니다.
