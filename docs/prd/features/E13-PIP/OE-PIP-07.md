# OE-PIP-07 규칙 재계산

## 요구사항

(PRD #14-A) 잇기·끊기·계통 변경·종류 변경이 있으면 규칙 방향을 다시 계산한다. 확정한 규칙 방향은 연결마다 저장해(`confirmedFlows`) 재계산에 덮이지 않는다 — 확정 뒤 계통 종류를 바꿔도 확정한 방향은 그대로다. 저장·불러오기 뒤에도 같다.

## 수용 기준

- 확정한 계통의 종류를 바꿔도 확정한 방향이 뒤집히지 않는다.
- 무작위 편집 퍼징 뒤 TTL 이 일관된다.

## 검증 (이 repo)

- 확정 뒤 계통의 종류를 바꿔도 확정한 방향은 뒤집히지 않는다(연결마다 방향을 적는다). 저장·불러오기 뒤에도 같다 — `edit.test.ts` "사람이 정한 방향과 확정한 계통은 종류를 바꿔도 남는다", `edit-file.test.ts`, 성수 O-5
