# OE-GEN-02 생성 게이트

## 관련 티켓

- [OE-BIM-21](../E05-BIM/OE-BIM-21.md): 수용 기준선 미달 판정

## 요구사항
> User story : 구축 담당자가 수용 기준선(게이트) 등급에 미달한 BIM으로 [구축하기]를 누르려 하면 버튼이 비활성이라 품질 기준 아래의 온톨로지가 운영 DT에 들어가지 않는다. 반면 권장 요구사항 누락이나 완전성 검사 위반만 있으면 경고만 뜨고 생성은 진행되어, 완벽하지 않아도 운영에 쓸 만한 수준이면 구축이 막히지 않는다. 사용자는 어떤 미달이 구축을 막는지 명확히 알고 고객사 재제출 요청과 자체 보정 작업의 우선순위를 정할 수 있어야 한다. 통과선은 결정 확정 후 반영된다.

수용 기준선(게이트, 누적 등급 0~3) 미달 파일은 온톨로지 생성을 막는다(OE-BIM-21). 권장 요구 누락과 완전성 검사 위반은 경고만 하고 막지 않는다. 통과선은 D1.

## 수용 기준

게이트 미달 상태에서 [구축하기] 가 비활성이다. 권장 누락만 있는 파일은 생성된다.
