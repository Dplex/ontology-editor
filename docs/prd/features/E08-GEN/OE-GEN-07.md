# OE-GEN-07 생성 리포트 (B-2)

## 요구사항

생성 리포트(B-2, 구축 담당자용)는 11항이다 — ① 파일 요약 ② 판정 등급 ③ 자동 생성 범위(출처별 분해) ④ 요구사항 판정 ⑤ 보정 항목 ⑥ 자동 보정 내역 ⑦ 좌표 정합 ⑧ BIM 밖 항목 ⑨ 사람 확정 현황 ⑩ 검증 결과(OE-GEN-03) ⑪ 산출물(엔티티 수·해시·파서 확인).
생성 때 자동으로 만들어 화면에 보이고 버전에 붙인다(OE-GEN-09).

## 수용 기준

생성 뒤 11항이 모두 채워진 리포트가 보인다.
