# OE-GEN-07 생성 리포트 (B-2)

## 관련 티켓

- [OE-GEN-03](./OE-GEN-03.md): 검증 결과 항목
- [OE-GEN-09](./OE-GEN-09.md): 버전에 붙여 저장

## 요구사항
> User story : 구축 담당자가 [구축하기] 후 자동 생성되는 11항 리포트(파일 요약·등급·자동 생성 범위·요구사항 판정·보정 항목·자동 보정 내역·좌표 정합·BIM 밖 항목·사람 확정 현황·검증 결과·산출물)를 화면에서 확인한다. 어디까지 BIM에서 자동으로 왔고 어디부터 사람이 보정·확정했는지가 출처별로 분해되어 있어, 구축 품질을 그룹장이나 고객사에 설명할 때 근거 자료로 쓴다. 리포트는 버전에 붙어 나중에 '그때 왜 이렇게 구축했는지' 추적할 수 있다.

생성 리포트(B-2, 구축 담당자용)는 11항이다 — ① 파일 요약 ② 판정 등급 ③ 자동 생성 범위(출처별 분해) ④ 요구사항 판정 ⑤ 보정 항목 ⑥ 자동 보정 내역 ⑦ 좌표 정합 ⑧ BIM 밖 항목 ⑨ 사람 확정 현황 ⑩ 검증 결과(OE-GEN-03) ⑪ 산출물(엔티티 수·해시·파서 확인).
생성 때 자동으로 만들어 화면에 보이고 버전에 붙인다(OE-GEN-09).

## 수용 기준

생성 뒤 11항이 모두 채워진 리포트가 보인다.
