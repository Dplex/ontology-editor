# OE-GEN-07 생성 리포트 (B-2)

## 관련 티켓

- [OE-GEN-03](./OE-GEN-03.md): 검증 결과 항목
- [OE-GEN-09](./OE-GEN-09.md): 버전에 붙여 저장
- [OE-UI-15](../E03-UI/OE-UI-15.md): 구축 결과 리포트 화면

## 요구사항
> User story : 구축 담당자는 [구축하기] 후 자동으로 만들어지는 생성 리포트를 화면에서 확인할 수 있다.사용자는 어디까지 BIM에서 자동으로 왔고 어디부터 사람이 보정·확정했는지 구분해 볼 수 있다. 리포트는 온톨로지 생성 버전에 붙어 나중에 왜 이렇게 구축했는지 추적할 수 있다.

생성 리포트(B-2, 구축 담당자용)는 11항이다 — ① 파일 요약 ② 판정 등급 ③ 자동 생성 범위(출처별 분해) ④ 요구사항 판정 ⑤ 보정 항목 ⑥ 자동 보정 내역 ⑦ 좌표 정합 ⑧ BIM 밖 항목 ⑨ 사람 확정 현황 ⑩ 검증 결과(OE-GEN-03) ⑪ 산출물(엔티티 수·해시·파서 확인).
생성 때 자동으로 만들어 구축 결과 리포트 화면(OE-UI-15 ④)에 요약을 보이고, 전체 리포트를 열 수 있으며, 버전에 붙인다(OE-GEN-09).

## 수용 기준

- 생성 뒤 11항이 모두 채워진 리포트가 보인다.
