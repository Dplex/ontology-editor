# OE-GEN-11 사이트 단위 임포트 · 층 단위 편집

## 관련 티켓

- [OE-UI-15](../E03-UI/OE-UI-15.md): 초기 구축 시작 화면
- [OE-UI-04](../E03-UI/OE-UI-04.md): 층 단위 편집 화면
- [OE-UI-12](../E03-UI/OE-UI-12.md): 한 번에 한 층
- [OE-GEN-01](./OE-GEN-01.md): 사이트 단위 생성·등록

## 요구사항
> User story : 구축 담당자가 새 프로젝트에서 사이트를 구성하는 BIM(IFC) 파일들을 올리면 사이트 전체(여러 건물과 층)가 한 번에 임포트된다. 이후 한 층씩 임포트 결과를 확인하며 편집·보정하고 층마다 임시 저장한 뒤, [구축하기]로 사이트 전체의 온톨로지를 한 번에 생성·등록한다. 여러 층에 걸친 오브젝트는 다중층 편집으로 수정한다.

온톨로지 임포트·생성·등록은 사이트 단위이고, 편집은 층 단위다.
- 사이트를 구성하는 IFC 파일(건물별·분야별)을 시작 화면(OE-UI-15 ①)에서 올리면 사이트 전체가 임포트된다.
- 편집·보정은 한 층씩 하고 층마다 임시 저장한다(OE-UI-04·12). 초기 구축에는 층별 반영이 없다. 여러 층에 걸친 오브젝트(계단·샤프트·라이저·EL·ES)는 다중층 편집(E18)을 따른다.
- [구축하기]는 사이트 전체를 대상으로 한 번에 생성·등록한다(OE-GEN-01).

## 수용 기준

- 여러 건물·층이 담긴 IFC 들을 올리면 모든 건물·층이 임포트된다.
- 에디터에서 층을 바꿔 가며 편집하고 층마다 임시 저장할 수 있다.
- [구축하기] 한 번으로 사이트의 모든 층이 생성·등록된다.
