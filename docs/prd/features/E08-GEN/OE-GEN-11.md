# OE-GEN-11 사이트 단위 생성

## 요구사항
> User story : 구축 담당자는 BIM(IFC) 파일을 업로드 시, 전체 사이트(여러 건물과 층) 온톨로지 구축이 자동으로 이뤄진다. 파일이 임포트 되고 나서는 사용자가 한 층씩 임포트 결과를 확인하며 수정 할수 있다. 


온톨로지 생성·등록은 사이트 단위다. 임포트하면 사이트 전체의 편집 모델이 만들어지고, [구축하기]는 사이트 전체를 생성한다. 사이트 생성 후 각 건물의 층 단위로 편집을 진행할 수 있다. '다중층 편집 모드'를 통해서 특정 건축 및 설비 오브젝트 수정 시 여러 층을 동시에 수정할 수 있다. 

## 수용 기준

BIM 파일 업로드 시 해당 사이트 전체 층의 온톨로지가 구축된다.
