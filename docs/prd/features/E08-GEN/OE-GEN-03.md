## 요구사항
> User story : 구축 담당자가 [구축하기]를 누르면 생성 전에 여러 검증이 한꺼번에 수행된다. 층마다 물리존이 하나 이상인지, 한 층 안에서 방번호가 고유한지, 좌표 없는 설비·배관 제외 목록, 공조존 검증 결과, 설비 소속 판정, 완전성 검사 결과, 아직 확정하지 않은 규칙 방향 수가 검증되어 생성 리포트의 '검증 결과' 항목에 들어간다. 방번호가 중복인 층은 생성이 막히고 이유를 확인할 수 있다. 사용자는 리포트 한 곳에서 모든 검증 결과를 보고 무엇을 고치고 무엇을 경고로 넘길지 판단할 수 있어야 한다.

생성 전에 다음을 검증한다 — 층당 물리존 ≥ 1, 방번호 고유(한 층 안), 좌표 없는 설비·배관의 제외 목록, 공조존 공백·중복(Z-01~06, OE-ZON-05), 설비 소속 판정(OE-MAP-01), 완전성 검사 8규칙(OE-BIM-18), 미확정 규칙 방향 수(OE-GEN-04).
결과는 생성 리포트(OE-GEN-07)의 '검증 결과' 항에 넣는다.
입력 수용 게이트와 편집모델 생성 차단 검증·경고·측정 불가를 구분한다. 원본/공유 개구부·층간 참조·비활성 연결·미확정 방향·좌표 없는 의미 정보는 최신 ML·PIP 정책을 적용한다. 원본 BIM 수용 등급과 보정 후 편집모델의 생성 가능 여부를 분리한다.

## 수용 기준

- 검증 항목 전부가 생성 리포트에 보인다.
- 방번호가 중복인 층은 생성이 막히고 이유가 보인다.
- 방번호 중복 등 차단 오류는 원인과 함께 생성 불가이고 경고는 출력 제외 사유와 함께 생성 가능하다.
