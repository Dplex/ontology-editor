## 요구사항
> User story : 구축 담당자가 [구축하기]를 누르면 생성 전에 층당 물리존 1개 이상, 한 층 안 방번호 고유, 좌표 없는 설비·배관 제외 목록, 공조존 Z-01~06, 설비 소속 판정, 완전성 8규칙, 미확정 규칙 방향 수가 한꺼번에 검증되어 생성 리포트의 '검증 결과'에 들어간다. 방번호가 중복인 층은 생성이 막히고 이유가 보여 식별자 충돌이 온톨로지에 들어가지 않는다. 담당자는 리포트 한 곳에서 모든 검증 결과를 보고 무엇을 고치고 무엇을 경고로 넘길지 판단한다.

생성 전에 다음을 검증한다 — 층당 물리존 ≥ 1, 방번호 고유(한 층 안), 좌표 없는 설비·배관의 제외 목록, 공조존 공백·중복(Z-01~06, OE-ZON-05), 설비 소속 판정(OE-MAP-01), 완전성 검사 8규칙(OE-BIM-18), 미확정 규칙 방향 수(OE-GEN-04).
결과는 생성 리포트(OE-GEN-07)의 '검증 결과' 항에 넣는다.

## 수용 기준

- 검증 항목 전부가 생성 리포트에 보인다.
- 방번호가 중복인 층은 생성이 막히고 이유가 보인다.
