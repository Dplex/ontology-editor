# OE-GEN-05 버전 v1 기록

## 관련 티켓

- [OE-WF-18](../E14-WF/OE-WF-18.md): v1 기준 버전 히스토리
- [OE-GEN-09](./OE-GEN-09.md): 버전에 붙는 리포트
- [OE-WF-13](../E14-WF/OE-WF-13.md): 반영 때 쌓이는 이후 버전

## 요구사항
> User story : 구축 담당자가 한 층의 온톨로지를 처음 생성하면 그 결과가 버전 1로 기록되고 일시·사용자·산출 파일·리포트가 함께 남는다. 이후 운영 편집에서 반영할 때마다 쌓이는 버전 히스토리가 이 버전을 기준으로 이어진다. 사용자는 몇 달 뒤 구축 당시 원본과 지금이 어떻게 다른지 비교하거나 문제 시 첫 버전으로 되돌릴 수 있어야 하며, 첫 버전에 붙은 리포트로 구축 품질을 그룹장이나 고객사에 설명할 때 당시 등급·검증 결과를 그대로 제시할 수 있다. 저장 위치는 데이터 교환 방식 결정에 따른다.

생성 결과를 버전 v1 로 기록한다. 이후 운영 편집의 버전 히스토리(OE-WF-18)는 v1 을 기준으로 쌓인다. 버전 메타는 일시·사용자·산출 파일·리포트(OE-GEN-09)다. 저장 위치는 D-INT.

## 수용 기준

생성 뒤 버전 히스토리에 v1 이 있고 일시·사용자·파일이 보인다.
