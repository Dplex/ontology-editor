# OE-GEN-05 온톨로지 생성 버전 기록

## 관련 티켓

- [OE-WF-18](../E14-WF/OE-WF-18.md): v1 기준 버전 히스토리
- [OE-GEN-09](./OE-GEN-09.md): 버전에 붙는 리포트
- [OE-WF-13](../E14-WF/OE-WF-13.md): 반영 때 쌓이는 이후 버전

## 요구사항
> User story : 구축 담당자가 특정 사이트의 온톨로지를 처음 생성하면 그 결과가 버전 1로 기록되고 일시·사용자·산출 파일·리포트가 함께 남는다. 이후 운영 편집에서 반영할 때마다 쌓이는 버전 히스토리가 이 버전을 기준으로 이어진다. 사용자는 몇 달 뒤 구축 당시 원본과 지금이 어떻게 다른지 비교하거나 문제 시 첫 버전으로 되돌릴 수 있어야 하며, 첫 버전에 붙은 리포트로 당시 온톨로지 구축 결과(등급·검증 결과)를 그대로 확인 할 수 있다. 

생성 결과를 버전 v1 로 기록한다. 이후 운영 편집의 버전 히스토리(OE-WF-18)는 v1 을 기준으로 쌓인다. 버전 메타는 일시·사용자·산출 파일·리포트(OE-GEN-09)다. 저장 위치는 D-INT.

R1에서 서버에 검증한 작업 결과가 확정 저장되면 통합 온톨로지 버전을 기록한다. 최초 서버 확정 버전은 v1이며 DT 등록 완료 버전과 구분한다. 
버전 관리시에 한 버전 당 기준 버전·작업 ID·영향 층·일시·사용자·산출물 및 리포트를 기록해 버전을 관리한다. 
R2 DT 등록/반영 상태는 같은 작업의 별도 상태로 기록한다.

## 수용 기준

- 서버 확정 저장과 복구용 자동 저장·파일 다운로드 기록이 구분되고 같은 완료 작업은 성공 버전 한 개만 생성된다. 
- DT 등록 상태 미확인이라도 R1 서버 버전 및 산출물을 관리할 수 있다.
