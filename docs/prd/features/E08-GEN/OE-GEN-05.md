# OE-GEN-05 버전 v1 기록

## 관련 티켓

- [OE-WF-18](../E14-WF/OE-WF-18.md): v1 기준 버전 히스토리
- [OE-GEN-09](./OE-GEN-09.md): 버전에 붙는 리포트
- [OE-WF-13](../E14-WF/OE-WF-13.md): 반영 때 쌓이는 이후 버전

## 요구사항

생성 결과를 버전 v1 로 기록한다. 이후 운영 편집의 버전 히스토리(OE-WF-18)는 v1 을 기준으로 쌓인다. 버전 메타는 일시·사용자·산출 파일·리포트(OE-GEN-09)다. 저장 위치는 D-INT.

## 수용 기준

생성 뒤 버전 히스토리에 v1 이 있고 일시·사용자·파일이 보인다.
