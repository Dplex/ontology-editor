# OE-GEN-04 미확정 규칙 방향 제외

## 관련 티켓

- [OE-PIP-05](../E13-PIP/OE-PIP-05.md): 계통 단위 규칙 방향 확정

## 요구사항
> User story : 구축 담당자가 온톨로지를 생성할 때 규칙으로 추정만 되고 사람이 계통 단위로 확정하지 않은 흐름 방향은 온톨로지에 반영되지 않으며 레포트를 통해 확인 가능하다. 사용자는 리포트의 미확정 수를 보고 다음 보정 작업량을 가늠할 수 있어야 하며, 운영 담당자는 계통도에서 보이는 공급 관계가 모두 사람이 확인한 것임을 신뢰할 수 있다.

`feeds`는 유효한 BIM 명시 방향·사용자 적용 방향·현재 계통 확정 규칙 방향만 사용한다. 해제·재검토·재확정 대기·미확정 규칙과 담당 후보를 제외한다.
제외된 후보는 임포트 결과 레포트에 기록되어 사용자에게 제공된다. 

## 수용 기준
- 사용자 확정은 규칙보다 우선하고 해제·재검토·미확정 규칙에서 생성된 feeds가 없다. 제외 수와 사유가 리포트에 일치한다.
