# OE-GEN-06 DT 3D Map 생성

## 요구사항

생성·등록이 끝나면 DT 가 그 층의 3D Map 을 만든다. 이후 그 층은 운영 편집 모드로 들어간다(OE-UI-02). GeoJSON 만으로 Unity 가 그릴 수 있는지, FBX/glTF/IMDF 출력이 더 필요한지와 변환 주체는 D11(OE-INT-03).

## 수용 기준

D11 결정 후 적는다. 생성한 층이 DT 3D View 에 보인다.
