# OE-GEN-06 DT 3D Map 생성

## 관련 티켓

- [OE-UI-02](../E03-UI/OE-UI-02.md): 운영 편집 모드 전환
- [OE-INT-03](../E20-INT/OE-INT-03.md): 3D 형상 출력 형식·변환 주체
- [OE-INT-01](../E20-INT/OE-INT-01.md): DT 등록 경로 결정

## 요구사항
> User story : 구축 담당자가 생성 완료된 온톨로지 파일을 DT에 등록하며 DT 3D Map 이 자동 생성 된다. 사용자는 생성 직후 3D 뷰에서 물리존·설비가 제자리에 보이는지 확인해 좌표계나 형상 문제를 등록 시점에 잡을 수 있어야 한다. 

R1에는 DT 호환 형상·온톨로지 파일 생성·다운로드까지 지원하고 DT 표시 확인은 요구하지 않는다. 

R2에는 온톨로지 생성이 완료되면 DT 자동 반영 시킬 수 있다. 온톨로지 구축 플랫폼 상에서 생성 완료된 온톨로지가 DT에 반영된 결과가 제공된다. 초기 온톨로지 구축 완료 및 DT 등록 여부에 따라 에디터의 초기/운영 모드가 결정된다. 


## 수용 기준

- 온톨로지 생성 결과가 DT 3D View 에 보인다.
- - R2 지원 형식·공통 ID·좌표의 고정 샘플이 DT 3D View에서 같은 위치로 표시되고 실패 사유를 확인할 수 있다. R1 다운로드 성공을 DT 표시 성공으로 혼동하지 않는다.
