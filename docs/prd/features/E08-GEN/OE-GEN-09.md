# OE-GEN-09 리포트 저장·연계

## 관련 티켓

- [OE-GEN-07](./OE-GEN-07.md): 저장할 생성 리포트
- [OE-WF-18](../E14-WF/OE-WF-18.md): 버전 히스토리에서 열람
- [OE-BIM-19](../E05-BIM/OE-BIM-19.md): 판본 비교 입력

## 요구사항
> User story : 구축 담당자는 생성 리포트가 생성 버전에 붙어 저장되는 것을 확인할 수 있다. 운영 담당자나 그룹장은 버전 히스토리에서 어느 버전이든 골라 당시 리포트를 열어 볼 수 있고, 고객사의 새 판본이 들어오면 판본 비교의 입력으로 써서 등급과 위반 수가 이전 대비 얼마나 개선됐는지 수치로 확인할 수 있다. 사용자는 사이트 별 생성 리포트를 버전에 따라 확인할 수 있다. 

생성 리포트(OE-GEN-07)는 온톨로지 생성 버전 별로 관리된다. 버전 히스토리(OE-WF-18)에서 열람하고 판본 비교(OE-BIM-19)의 입력으로 쓴다. 

## 수용 기준

온톨로지 생성 버전 별로 각 리포트를 열 수 있다.
