# OE-GEN-09 리포트 저장·연계

## 관련 티켓

- [OE-GEN-07](./OE-GEN-07.md): 저장할 생성 리포트
- [OE-WF-18](../E14-WF/OE-WF-18.md): 버전 히스토리에서 열람
- [OE-BIM-19](../E05-BIM/OE-BIM-19.md): 판본 비교 입력

## 요구사항

### User story

구축 담당자가 생성 리포트를 JSON으로 생성 버전에 붙여 저장해 두면, 운영 담당자나 그룹장이 버전 히스토리에서 아무 버전이나 골라 당시 리포트를 열어 볼 수 있다. 고객사 2차 판본이 들어왔을 때 판본 비교의 입력으로도 쓰여, 등급·위반 수가 이전 대비 얼마나 개선됐는지 수치로 확인한다. 리포트가 버전과 분리되어 메일함에 흩어지지 않고 항상 해당 버전 옆에 있다. 리포트가 JSON으로 구조화되어 있어 여러 버전·사이트의 리포트를 모아 등급 추이나 반복되는 위반 유형을 분석하는 데도 쓸 수 있고, 전달 형식은 U5에서 확정한다.

생성 리포트(OE-GEN-07)를 JSON 으로 생성 버전에 붙여 저장한다. 버전 히스토리(OE-WF-18)에서 열람하고 판본 비교(OE-BIM-19)의 입력으로 쓴다. 전달 형식은 U5.

## 수용 기준

버전 히스토리의 각 버전에서 리포트를 열 수 있다.
