# OE-GEN-08 고객사 결과 리포트 (B-1)

## 관련 티켓

- [OE-REQ-06](../E06-REQ/OE-REQ-06.md): 요구사항 판정·수정 방법 문구
- [OE-BIM-20](../E05-BIM/OE-BIM-20.md): 재제출·보정 항목 분류 코드

## 요구사항
> User story : 구축 담당자는 고객사 BIM 담당·설계사에게 보낼 결과 리포트를 HTML 또는 PDF로 내보낼 수 있다. 리포트에는 파일 요약, 등급, 자동 생성 범위, 요구사항 판정과 수정 방법, 재제출 항목, 보정 항목, 자동 보정, 좌표 정합, BIM 밖 항목, 다음 단계가 담긴다. 재제출 항목마다 요구사항 번호와 '내보내기 설정 변경'·'값 입력' 같은 구체적 수정 방법이 붙어 있다. 고객사 BIM 담당은 리포트만 보고 모델링 도구에서 무엇을 고쳐 재제출할지 알 수 있어야 하며, 이를 통해 항목을 메일로 설명하는 왕복이 줄어든다. 전달 형식은 확인 후 정한다.

고객사 결과 리포트(B-1)는 고객사 BIM 담당·설계사에게 보내는 것이다 — 파일 요약, 등급, 자동 생성 범위, 요구사항 판정과 수정 방법(OE-REQ-06 문구), 재제출 항목(A·B), 보정 항목(C), 자동 보정, 좌표 정합, BIM 밖 항목, 다음 단계.
HTML 또는 PDF 로 내보낸다. 전달 형식은 U5.

## 수용 기준

고객사에 보낼 수 있는 HTML/PDF 파일이 만들어지고 재제출 항목에 R 번호와 수정 방법이 붙어 있다.
