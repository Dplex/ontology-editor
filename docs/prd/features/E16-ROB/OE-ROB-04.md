# OE-ROB-04 데이터 선행 제공

## 관련 티켓

- [OE-EQP-17](../E12-EQP/OE-EQP-17.md): 선행 산출 통과 속성

- [OE-ROB-02](./OE-ROB-02.md): 로봇 팀 요청 필드를 반영할 R2 티켓

## 요구사항
> User story : 로봇 팀이 R2 로봇 기능을 기획하기 전에, R1 GeoJSON에 이미 들어 있는 통과 속성·방-문-방 연결·층간 연결 포맷을 미리 확인한다. 어떤 필드가 어떤 의미인지 R1 산출물로 검토할 수 있어, 로봇 측 경로 엔진이 요구하는 데이터 형식과의 차이를 R2 설계 전에 조율한다. 구축 담당자는 별도 샘플을 만들 필요 없이 R1에서 내보낸 파일을 공유하면 된다. 포맷 확인 과정에서 로봇 팀이 추가로 필요하다고 요청하는 필드가 있으면 R2 티켓(OE-ROB-01·02)에 반영하며, 이 단계에서 요구를 조기에 받아 R2 개발 중 포맷을 다시 바꾸는 재작업을 줄인다.

통과 속성(OE-EQP-17)·방-문-방·층간 연결은 R1 GeoJSON에 이미 산출환 것을 참고한다. 

## 수용 기준

로봇 팀이 R1 GeoJSON 의 통과·연결 속성 포맷을 확인한다.
