# OE-ROB-04 데이터 선행 제공

## 관련 티켓

- [OE-EQP-17](../E12-EQP/OE-EQP-17.md): 선행 산출 통과 속성
- [OE-EQP-16](../E12-EQP/OE-EQP-16.md): R1 GeoJSON 산출 데이터
- [OE-ROB-01](./OE-ROB-01.md): 로봇 팀 요청 필드를 반영할 R2 티켓
- [OE-ROB-02](./OE-ROB-02.md): 로봇 팀 요청 필드를 반영할 R2 티켓

## 요구사항
> User story : 로봇 관제 사용자는 R2 로봇 기능을 기획하기 전에 R1 레이아웃 산출물에 이미 포함된 통과 속성·방-문-방 연결·층간 연결 정보를 미리 확인할 수 있다. 어떤 항목이 어떤 의미인지 R1 산출물로 검토할 수 있으므로, 로봇 경로 엔진이 요구하는 데이터 형식과의 차이를 R2 설계 전에 조율할 수 있다. 구축 담당자는 별도 샘플을 만들 필요 없이 R1에서 내보낸 결과를 공유하면 되고, 로봇 팀이 추가로 필요하다고 한 항목은 R2 로봇 티켓에 반영할 수 있어야 한다.

통과 속성(OE-EQP-17)·방-문-방·층간 연결은 R1 GeoJSON에 이미 산출환 것을 참고한다. 

## 수용 기준

로봇 팀이 R1 GeoJSON 의 통과·연결 속성 포맷을 확인한다.
