# OE-ROB-01 로봇 1인칭 시점 뷰

## 관련 티켓

- [OE-ROB-02](./OE-ROB-02.md): 뷰에 보일 정보 규격

## 요구사항
> User story : R2에서 로봇 관제 사용자는 로봇 1인칭 시점 뷰를 사용할 수 있다. 바닥 높이에서 위를 보는 카메라로 로봇이 실제로 지나갈 복도를 바라보며 천장 설비·문·벽이 로봇 높이에서 통과 가능한지 눈으로 확인할 수 있다. 평면도만으로는 알기 어려운 낮은 천장 설비나 문틀 간섭을 미리 발견해 경로 설계에 반영하는 것이 목적이다. 이 뷰에서 어떤 정보를 어떤 방식으로 보일지는 로봇 팀의 요구 목적이 확정된 뒤 표시 규격 정의 티켓에서 정하므로, 사용자가 보게 될 세부 내용은 그때 보강된다.

로봇 1인칭 시점 뷰를 제공한다 — 바닥 높이에서 위를 보는 카메라로 천장 설비·문·벽의 통과 가능 여부를 확인한다. 어떤 정보를 보일지는 로봇 팀의 요구 목적(Q3)에 따라 OE-ROB-02 에서 정한다.
