# OE-ROB-01 로봇 1인칭 시점 뷰

## 관련 티켓

- [OE-ROB-02](./OE-ROB-02.md): 뷰에 보일 정보 규격

## 요구사항

### User story

R2에서 로봇 관제 담당자가 로봇이 실제로 지나갈 복도를 바닥 높이 카메라로 바라보며 천장 설비·문·벽이 로봇 높이에서 장애가 되는지 눈으로 확인한다. 평면도만으로는 알기 어려운 낮은 천장 설비나 문틀 간섭을 미리 발견해 경로 설계에 반영하는 것이 목적이다. 어떤 정보를 어떤 방식으로 보일지는 로봇 팀의 요구 목적(Q3) 확정 후 OE-ROB-02에서 정하므로, 세부 시나리오는 그때 보강한다. 로봇 관제 담당자는 평면 뷰와 1인칭 뷰를 오가며 특정 경로의 장애 여부를 확인하고, 문제가 있으면 레이아웃 편집으로 설비 위치를 조정하거나 로봇 경로를 우회시키는 판단 근거로 삼는다.

로봇 1인칭 시점 뷰를 제공한다 — 바닥 높이에서 위를 보는 카메라로 천장 설비·문·벽의 통과 가능 여부를 확인한다. 어떤 정보를 보일지는 로봇 팀의 요구 목적(Q3)에 따라 OE-ROB-02 에서 정한다.
