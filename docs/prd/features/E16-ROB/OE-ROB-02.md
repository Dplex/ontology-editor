# OE-ROB-02 표시 규격 정의

## 요구사항
> User story : R2에서 로봇 관제 사용자가 로봇 1인칭 시점 뷰에서 보게 될 표시 규격을 정한다. 이 뷰를 장애물 회피 확인에 쓸지, 통신 AP 위치 점검에 쓸지, 조명 확인에 쓸지에 따라 강조해야 할 오브젝트와 색·높이 기준이 달라지므로, 요구 목적이 확정되기 전에는 규격을 적지 않는다. 결정 후에는 사용자가 뷰에서 필요한 정보만 빠르게 읽을 수 있도록 어느 오브젝트를 어떤 색과 높이 기준으로 보일지 정의하여, 로봇 팀과 에디터 팀이 같은 표시 기준을 공유할 수 있어야 한다.

로봇 시점 뷰의 표시 규격을 정한다. 요구 목적(장애물 회피 / 통신 AP 위치 / 조명)이 Q3 로 확정된 뒤 어느 오브젝트를 어떤 색·높이 기준으로 보일지 더 적는다.

## 수용 기준

Q3 결정 후 적는다.
