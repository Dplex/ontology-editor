# OE-ROB-02 표시 규격 정의

## 요구사항
> User story : R2에서 로봇 1인칭 시점 뷰에 어떤 오브젝트를 어떤 색과 높이 기준으로 보일지 규격을 정하는 티켓이다. 로봇 팀이 이 뷰를 장애물 회피 확인에 쓸지, 통신 AP 위치 점검에 쓸지, 조명 확인에 쓸지(Q3)에 따라 강조할 대상이 달라지므로, 목적이 확정되기 전에는 규격을 적지 않는다. 결정 후 로봇 관제 담당자가 뷰에서 필요한 정보만 빠르게 읽을 수 있도록 표시 규칙을 보강한다. 규격이 정해지면 로봇 팀과 에디터 팀이 같은 표시 기준을 공유하므로, 로봇 관제 담당자가 뷰에서 본 장애물이 실제 로봇 센서가 인식하는 기준과 어긋나지 않도록 맞출 수 있다.

로봇 시점 뷰의 표시 규격을 정한다. 요구 목적(장애물 회피 / 통신 AP 위치 / 조명)이 Q3 로 확정된 뒤 어느 오브젝트를 어떤 색·높이 기준으로 보일지 더 적는다.

## 수용 기준

Q3 결정 후 적는다.
