# OE-ROB-03 통과 속성 제공

## 관련 티켓

- [OE-EQP-17](../E12-EQP/OE-EQP-17.md): 경로 판단용 통과 속성

## 요구사항
> User story : 로봇 관제 사용자는 에디터가 정한 로봇 통과 속성을 로봇 경로 판단에 참고할 수 있다. 받은 레이아웃 데이터에서 문은 통과 가능, 벽과 창문은 통과 불가로 구분되어 있어 평면도를 보고 장애물을 따로 입력하지 않아도 된다. 통과 속성의 정의는 로봇 통과 속성 정의 티켓을 따르므로 사용자는 데이터의 의미를 PRD로 확인할 수 있다. 레이아웃이 바뀌어 벽이 추가되거나 문이 옮겨지면 다음 반영 때 속성이 갱신되어, 사용자는 건물 현황과 어긋나지 않는 통과 정보를 받을 수 있어야 한다.

OE-EQP-17 이 정한 통과 속성을 로봇 경로 판단에 참고한다. 

## 수용 기준

로봇 팀이 받은 데이터에서 문과 벽의 통과 여부를 구분할 수 있다.
