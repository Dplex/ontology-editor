# OE-ROB-03 통과 속성 제공

## 관련 티켓

- [OE-EQP-17](../E12-EQP/OE-EQP-17.md): 경로 판단용 통과 속성

## 요구사항

### User story

로봇 관제 담당자가 로봇 경로 판단 로직에 쓸 데이터를 받을 때, 에디터가 OE-EQP-17 규칙으로 산출한 통과 속성을 그대로 참고한다. 받은 데이터에서 문은 통과 가능, 벽·창문은 불가로 구분되어 있어 로봇 팀이 평면도를 보고 장애물을 따로 입력하지 않아도 된다. 레이아웃이 바뀌어 벽이 추가되면 다음 반영 때 속성이 갱신되므로, 로봇 경로 데이터가 건물 현황과 어긋나는 기간이 줄어든다. 로봇 팀은 통과 속성의 정의와 출처를 PRD(OE-EQP-17)로 확인할 수 있어 데이터 의미를 따로 묻지 않아도 되고, 에디터 측은 로봇 요구에 맞춘 별도 포맷을 만들지 않고 표준 GeoJSON 하나로 제공한다.

OE-EQP-17 이 정한 통과 속성을 로봇 경로 판단에 참고한다. 

## 수용 기준

로봇 팀이 받은 데이터에서 문과 벽의 통과 여부를 구분할 수 있다.
