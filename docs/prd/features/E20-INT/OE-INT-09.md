# OE-INT-09 요구조건 S1~S8

## 요구사항

저장 방식(D-INT)과 무관하게 충족해야 하는 요구조건 S1~S8(PRD 부록 C)을 테스트로 둔다 — 재임포트 후 편집 유지, 같은 ID 조회, 교집합 질의, 출처 구별, SR 온톨로지 합치기, 잠금·임시 저장·버전, DT 형상 출력, 형상·TTL 같은 ID.

## 수용 기준

S1~S8 각각에 대응하는 테스트가 있다.
