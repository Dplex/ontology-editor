# OE-INT-09 요구조건 S1~S8

## 요구사항
> User story : 구축 담당자가 어떤 저장 방식(D-INT)이 채택되든 재임포트 후 편집 유지, 같은 ID 조회, 교집합 질의, 출처 구별, SR 온톨로지 합치기, 잠금·임시 저장·버전, DT 형상 출력, 형상·TTL 같은 ID라는 S1~S8 요구조건이 테스트로 보장된다는 것을 전제로 작업한다. D-INT가 바뀌어도 테스트가 그대로 돌아 구축 결과의 품질 기준이 흔들리지 않고, 저장 방식 변경이 사용자 작업 흐름을 깨뜨리는지 자동으로 확인된다.

저장 방식(D-INT)과 무관하게 충족해야 하는 요구조건 S1~S8(PRD 부록 C)을 테스트로 둔다 — 재임포트 후 편집 유지, 같은 ID 조회, 교집합 질의, 출처 구별, SR 온톨로지 합치기, 잠금·임시 저장·버전, DT 형상 출력, 형상·TTL 같은 ID.

## 수용 기준

S1~S8 각각에 대응하는 테스트가 있다.
