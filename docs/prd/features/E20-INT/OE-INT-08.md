# OE-INT-08 ttl.go 호환

## 요구사항
> User story : 구축 담당자가 생성한 의미 정보 산출물이 DT 파서에서 읽히지 않으면 등록 후 DT에서 설비가 사라지거나 연결이 끊긴다. 에디터는 DT 파서가 지원하는 표기 규칙과 구조를 지키고, 매 빌드마다 실제 파서로 샘플을 읽어 확인한다. 사용자는 등록 시점에 파서 오류로 되돌아오는 일을 겪지 않아야 하며, 규칙이 명시되어 있어 에디터와 DT 양쪽 개발자가 같은 기준을 참조하고, 파서가 바뀌면 샘플 검사가 먼저 실패해 호환이 깨지는 것을 배포 전에 발견할 수 있다.

TTL 은 DT 파서 ttl.go 의 지원 범위를 지킨다 — `$`·`"` 이스케이프, `ex:X a 클래스` 블록 구조, fso 비엔티티는 하류 기기 직접 기술. 매 빌드마다 실제 파서로 샘플을 읽어 확인한다.
