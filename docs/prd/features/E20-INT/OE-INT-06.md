# OE-INT-06 Revit 요소 ID 보조 식별자

## 관련 티켓

- [OE-HIST-03](../E19-HIST/OE-HIST-03.md): 결정 전 편집 파일 식별 정보 매칭

## 요구사항
> User story : 구축 담당자가 고객사의 재내보내기 판본에서 식별자 대부분이 바뀌어 같은 설비를 찾지 못하는 문제를 겪을 때, 모델링 도구의 요소 ID를 온톨로지에 보조 식별자로 적어 두면 식별자가 바뀌어도 설비를 짝지을 수 있다. 다만 새 술어가 필요하므로 DT 읽기 코드와의 합의가 먼저다. 채택 여부는 결정 대기 중이며, 결정 전에는 편집 파일의 식별 정보 매칭으로 대응한다. 사용자는 보조 식별자가 채택되면 고객사의 잦은 모델 갱신에도 보정이 날아갈 위험이 더 줄어드는 것을 기대할 수 있어야 한다.

GUID 가 바뀐 판본에서도 같은 설비를 찾도록 Revit 요소 ID 를 온톨로지에 보조 식별자로 적을지 정한다. 새 술어가 필요하므로 DT 읽기 코드(ttl.go)와 합의가 선행한다. 결정은 D5.

## 수용 기준

D5 결정 후 적는다.
