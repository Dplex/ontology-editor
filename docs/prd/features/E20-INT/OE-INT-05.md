# OE-INT-05 ID 규칙

## 요구사항
> User story : 구축 담당자는 오브젝트의 식별자만 보고 출처를 구분할 수 있다. BIM에서 온 것은 BIM 식별자를 그대로 쓰고, 에디터에서 사람이 만든 것은 정해진 접두어로 시작하는 식별자를 받으며, R2 IDF 출신은 존과 설비에 각각 다른 접두어를 쓴다. 특정 문자는 DT 파서 호환을 위해 금지된다. 기존 SR 온톨로지의 식별자와 어떻게 매핑할지는 결정 후 정한다. 사용자는 재임포트나 판본 병합 시 식별자 체계가 섞이지 않아 어느 객체가 어디서 왔는지 추적할 수 있어야 하며, 에디터가 만든 모든 식별자가 규칙을 따르는 것을 확인할 수 있다.

ID 규칙 — BIM 에서 온 것은 IfcGlobalId, 사람이 만든 것은 `U_`(22자, `$` 금지), IDF 출신은 `Z_`(존)·`I_`(설비). 기존 SR 온톨로지(`ex:1-AHU-101`)와의 매핑 규칙은 D5(S2·S5).

## 수용 기준

D5 결정 후 적는다. 에디터가 만든 모든 id 가 `U_` 로 시작하고 `$` 가 없다.
