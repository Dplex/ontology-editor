# OE-INT-07 출처 술어 (S4)

## 관련 티켓

- [OE-UI-13](../E03-UI/OE-UI-13.md): 화면 출처 표시

## 요구사항
> User story : 운영 담당자나 AI Agent가 어떤 값이 BIM 원본인지, 계산·사전·사람이 보정한 것인지 알아야 신뢰도를 판단할 수 있다. 이 출처 정보를 온톨로지에 함께 담아 Agent도 읽게 할지, 화면과 리포트에만 둘지를 정한다. 온톨로지에 담으면 새 술어가 필요해 DT 읽기 코드와 합의가 필요하다. 결정 전에는 에디터 화면의 출처 표시로만 보여 주며, 화면 표시는 이 결정과 무관하게 항상 제공된다. 사용자는 결정 후 Agent 답변에 출처가 포함되는지 여부를 수용 기준으로 확인할 수 있어야 한다.

계산·추정 값의 출처(BIM·계산·사전·사람·외부, S4)를 TTL 술어로 담을지, 화면·JSON 리포트로만 둘지 정한다(U4). 새 술어면 DT 읽기 코드 합의가 필요하다. 화면 표시는 이 결정과 무관하다(OE-UI-13).

## 수용 기준

U4 결정 후 적는다.
