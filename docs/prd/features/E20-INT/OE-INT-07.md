# OE-INT-07 출처 술어 (S4)

## 관련 티켓

- [OE-UI-13](../E03-UI/OE-UI-13.md): 화면 출처 표시

## 요구사항
> User story : 운영 담당자나 AI Agent가 어떤 값이 BIM 원본인지, 계산·사전·사람이 보정한 것인지 알아야 신뢰도를 판단할 수 있다. 이 출처(S4)를 TTL 술어로 담아 Agent도 읽게 할지, 화면·JSON 리포트에만 둘지를 U4에서 정한다. 새 술어면 DT 읽기 코드 합의가 필요하므로 결정 전에는 에디터 화면 표시(OE-UI-13)로만 출처를 보여 주고, 결정 후 TTL 포함 여부를 수용 기준에 적는다.

계산·추정 값의 출처(BIM·계산·사전·사람·외부, S4)를 TTL 술어로 담을지, 화면·JSON 리포트로만 둘지 정한다(U4). 새 술어면 DT 읽기 코드 합의가 필요하다. 화면 표시는 이 결정과 무관하다(OE-UI-13).

## 수용 기준

U4 결정 후 적는다.
