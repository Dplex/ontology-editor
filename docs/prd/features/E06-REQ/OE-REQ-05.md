# OE-REQ-05 R25 BAS 매핑 키

## 관련 티켓

- [OE-BIM-17](../E05-BIM/OE-BIM-17.md): 요구사항 보고서에 R25 추가

## 요구사항
> User story : 운영 담당자가 DT에서 설비 이상 알림을 BAS 관제점과 자동으로 연결하려면 BIM 설비 태그에 BAS와 매핑할 수 있는 식별자가 있어야 한다. 이를 권장 요구사항으로 고객사에 요청하기로 했다(D14 채택). 고객사 BIM 담당자는 설비 태그에 BAS 식별자를 넣어 제출하고, 요구사항 보고서에서 빠졌거나 겹친 설비를 확인해 보완한다. 이로써 운영 단계에서 BIM 설비와 실시간 관제점을 수작업으로 매핑하는 비용을 줄일 수 있어야 한다.

고객사 BIM 담당자는 설비 태그(Mark·자산번호)에 BAS 관제점과 매핑할 수 있는 식별자를 넣어 제출한다(R25, 권장, 등급 5). 2026-10-10 D14 에서 채택했다. 요구사항 보고서(OE-BIM-17)에 R25 를 더한다. 개발 정본 4장·IDS 에 반영한 뒤 PRD 부록 A 에서 뺀다 — 그 전까지는 부록 A 에 "채택, 개발 반영 필요"로 남긴다.

## 수용 기준

- 요구사항 보고서(OE-BIM-17)에 R25 가 한 행으로 나오고, 설비 태그(Mark·자산번호)에 값이 있는 설비 비율이 보인다.
- 태그가 비었거나 설비끼리 같은 값이 겹치면 "없음·일부"로 표시하고, 고객사에 "설비 태그에 BAS 식별자를 넣어 달라" 문구가 붙는다.
- R25 는 권장이라 값이 없어도 생성 게이트(등급 0~2)를 막지 않는다.
- 고객사 검사 파일(IDS)과 요구사항 보고서의 R25 판정이 같다.
