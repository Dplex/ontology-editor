# OE-REQ-05 R25 BAS 매핑 키

## 관련 티켓

- [OE-BIM-17](../E05-BIM/OE-BIM-17.md): 채택 시 요구사항 보고서 추가

## 요구사항
> User story : 운영 담당자가 DT에서 설비 이상 알림을 BAS 관제점과 자동으로 연결하려면 BIM 설비 태그에 BAS와 매핑할 수 있는 식별자가 있어야 한다. 이를 권장 요구사항으로 고객사에 요청할지는 결정 대기 중이며, 채택되면 정본·검사 파일·요구사항 보고서에 더해지고 PRD 부록에서는 빠진다. 채택 전에는 제안 상태로만 두어 고객사 전달물에 확정되지 않은 요구가 섞이지 않는다. 채택되면 고객사 BIM 담당은 설비 태그에 BAS 식별자를 넣어 제출하고, 운영 단계에서 BIM 설비와 실시간 관제점을 수작업으로 매핑하는 비용을 줄일 수 있어야 한다.

설비 태그(Mark·자산번호)에 BAS 관제점과 매핑할 수 있는 식별자를 요구하는 R25 를 제안한다(권장, 등급 5). 채택되면 정본 4장·IDS·요구사항 보고서(OE-BIM-17)에 더하고 PRD 부록 A 에서 뺀다. 채택 여부는 D14.
