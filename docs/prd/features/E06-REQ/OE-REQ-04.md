# OE-REQ-04 등급 판정 산식

## 요구사항

등급 0~5 를 PRD 1.8 의 지표와 통과선으로 산출한다. 등급마다 분자·분모를 정의하고, 사전 채움을 포함하는지는 D12 를 따른다(권고: 게이트 0~2 는 BIM+계산만, 목표선 3·4 는 두 수치 병기). 통과선 수치는 D1.
산출 결과는 등급 칩(OE-BIM-16)과 수용 기준선 판정(OE-BIM-21)이 쓴다.

## 수용 기준

D1·D12 확정 값으로 성수 실측 수치(1.8 표)가 재현된다.
