# OE-REQ-04 등급 판정 산식

## 관련 티켓

- [OE-BIM-16](../E05-BIM/OE-BIM-16.md): 산출 등급 칩 표시
- [OE-BIM-21](../E05-BIM/OE-BIM-21.md): 수용 기준선 판정

## 요구사항
> User story : 구축 담당자가 고객사 BIM을 임포트하면 공간·설비·소속·연결망·방향 지표를 바탕으로 등급이 산출된다. 등급마다 분자와 분모가 정의되어 있으며, 이름 사전 등으로 보완한 '사전 채움'을 포함할지는 결정에 따른다. 권고안은 등급마다 판정에 쓰는 숫자를 하나로 두는 것이다 — 게이트 등급(0~3)은 BIM과 계산만으로, 목표 등급(4)은 BIM 포트와 사람이 확정한 방향만으로 산출하고, 사전 후보·사용자 보정·미확정 규칙은 목표에 세지 않는 보조 숫자로 따로 보인다. 산출 결과는 검토 화면의 등급별 통과 현황과 수용 기준선 판정에 그대로 쓰여, 사용자는 고객사와 같은 숫자를 보고 재제출 여부를 논의할 수 있어야 한다. 통과선 수치는 결정 확정 후 실측 데이터로 검증한다.

등급 판정 및 제공 방식은 OE-BIM-16과 OE-BIM-21에 따른다.
