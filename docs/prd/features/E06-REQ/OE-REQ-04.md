# OE-REQ-04 등급 판정 산식

## 관련 티켓

- [OE-BIM-16](../E05-BIM/OE-BIM-16.md): 산출 등급 칩 표시
- [OE-BIM-21](../E05-BIM/OE-BIM-21.md): 수용 기준선 판정

## 요구사항

### User story

구축 담당자가 고객사 BIM을 임포트하면 공간·설비·소속·연결망·방향 지표로 등급 0~5가 산출된다. 등급마다 분자·분모가 정의되어 있고 사전 채움(이름 사전으로 보완한 값)을 포함할지는 D12에 따라 게이트 0~2는 BIM+계산만, 목표선 3·4는 두 수치 병기로 권고된다. 이 산식이 등급 칩과 수용 기준선 판정에 그대로 쓰여, 고객사 BIM 담당과 구축 담당자가 같은 숫자를 보고 재제출 여부를 논의한다. 통과선 수치는 D1 확정 후 성수 실측으로 재현해 검증한다.

등급 0~5 를 PRD 1.8 의 지표와 통과선으로 산출한다. 등급마다 분자·분모를 정의하고, 사전 채움을 포함하는지는 D12 를 따른다(권고: 게이트 0~2 는 BIM+계산만, 목표선 3·4 는 두 수치 병기). 통과선 수치는 D1.
산출 결과는 등급 칩(OE-BIM-16)과 수용 기준선 판정(OE-BIM-21)이 쓴다.

## 수용 기준

D1·D12 확정 값으로 성수 실측 수치(1.8 표)가 재현된다.
