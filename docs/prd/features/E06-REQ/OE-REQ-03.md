# OE-REQ-03 어휘 표

## 요구사항
> User story : 구축 담당자는 설비 종류·계통·용량을 읽을 때 쓰는 BIM 속성값들이 하나의 어휘 표에 모여 있는 것을 확인할 수 있다. 임포터 코드와 고객사 검사 파일이 같은 어휘 표를 쓰므로, 새 고객사 BIM에서 특정 설비가 종류 미상으로 들어오는 문제를 발견해 표에 값을 추가하면 임포터와 검사 파일이 함께 바뀐다. 코드와 검사 파일의 어휘가 달라지면 테스트가 실패해 두 쪽이 어긋나는 것을 미리 잡는다. 사용자는 고객사가 검사 파일로 통과한 값을 에디터가 못 읽는 불일치가 생기지 않는다는 것을 신뢰할 수 있어야 한다.

종류·계통·용량을 읽을 때 쓰는 IFC 값(PredefinedType·USERDEFINED 이름·Pset 이름)을 어휘 표 하나에 두고, 코드(`kinds.ts`·`capacity.ts`)와 IDS 가 같은 표를 쓴다. 표가 바뀌면 둘 다 바뀐다.

## 수용 기준

코드와 IDS 의 어휘가 다르면 테스트가 실패한다.
