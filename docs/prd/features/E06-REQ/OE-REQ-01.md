## 요구사항
> User story : 구축 담당자는 고객사에 요구하는 BIM 항목(필수 11개·권장 14개)이 정리된 정본을 기준으로 전달물을 준비할 수 있다. PRD에는 번호와 링크만 두고 요구사항 본문은 복사하지 않아 정본과 PRD가 어긋나지 않는다. 요구사항을 고객사에 전달하기 전에 제출 주체·재내보내기 비용·보안과 NDA·모델 시점·회신 기한 같은 협의 실무를 먼저 정해야 하며, 이것이 열려 있는 동안에는 고객사 전달본을 발행하지 않는다. 전달물에는 고객사가 스스로 검사할 수 있는 검사 파일과 결과 리포트 양식이 함께 들어가, 고객사 BIM 담당은 무엇을 어떻게 검사받는지 미리 알고 준비할 수 있어야 한다.

고객사에 요구하는 BIM 항목은 R0~R24(필수 11 · 권장 14)다. 정본은 개발 저장소 `bim-to-dt-ontology.md` 4장이고, PRD 는 번호와 링크만 둔다(부록 A). 요구사항 본문을 PRD 에 복사하지 않는다.
요구사항을 고객사에 전달하기 전에 협의 실무 P1(제출 주체)·P2(재내보내기 비용)·P3(보안·NDA)·P6(모델 시점)·P7(회신 기한·SLA)을 정한다. 전달물에는 IDS 검사 파일(OE-REQ-02)과 결과 리포트 양식(OE-GEN-08)을 함께 넣는다.

## 수용 기준

- PRD 부록 A 와 정본 4장의 R 번호 집합이 같다(테스트).
- P1~P7 이 열려 있는 동안 고객사 전달본을 발행하지 않는다.
