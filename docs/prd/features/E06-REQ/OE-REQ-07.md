## 요구사항
> User story : 구축 담당자는 공조존 용량 검증에 필요한 방별 설계 급기 풍량을 에디터가 계산하지 않으므로, 고객사 BIM의 공간에 냉방·난방 설계 풍량을 넣어 달라는 권장 요구사항을 둘 수 있다. 대상은 공조 대상인 방이며 계단실·샤프트 같은 비공조 공간은 해당 없음으로 처리된다. 이 요구는 정본과 검사 파일, 요구사항 보고서, 고객사 요청 문구에 같은 번호로 반영된다. 사용자는 설계 풍량이 없는 파일은 보고서에서 '없음·일부'로, 다른 속성에 들어 있는 파일은 '다른 위치'로 확인할 수 있어야 한다. 모델링 도구에서 이 값이 어떻게 내보내지는지 확인한 결과를 고객사 안내 문구에 넣는다.

고객사 BIM 의 방(IfcSpace)에 사이트가 설계한 급기 풍량을 넣어 달라고 요구하는 R26 을 둔다(권장). 에디터는 이 값을 계산하지 않고 그대로 가져다 용량 검증 Z-03(OE-ZON-05·06)에 쓴다.
공조 대상인 방. 계단실·샤프트 등 비공조 공간은 급기 풍량 입력 요청의 대상이 아니다. 
R26은 지원 IFC 스키마별 풍량 출처·단위·공조 대상·미확인 대상을 구분한다. 
냉난방 풍량 선택은 확정된 Q16을 따르고 비공조 여부가 미확인인 방을 자동 제외하지 않는다.
U7의 Revit 매핑은 확인 전 확정 안내로 발행하지 않는다.


## 수용 기준

- 정본 4장과 IDS 에 R26 이 있고 `requirements-ids.test.ts` 가 통과한다.
- 설계 풍량이 없는 IfcSpace 가 있는 파일의 요구사항 보고서에 R26 이 "없음·일부"로, 다른 Pset 에 있는 파일은 "다른 위치"로 보인다.
- 비공조 공간(방 종류가 계단실·샤프트 등)은 R26 판정에서 "해당 없음"이다.
