# OE-REQ-06 요구사항 상태 집계

## 관련 티켓

- [OE-BIM-17](../E05-BIM/OE-BIM-17.md): 집계할 요구사항 상태

## 요구사항
> User story : 구축 담당자가 실제 BIM 파일을 임포트하면 필수 요구사항 각각이 표준 위치에 있는지, 다른 위치에 있는지, 없는지가 자동으로 집계된다. 집계 결과에 따라 '없음'인 항목에는 '값을 넣어 달라', '다른 위치'인 항목에는 '내보내기 설정을 바꿔 달라'는 요청 문구가 자동으로 붙어 고객사 결과 리포트에 나간다. 사용자는 요구사항마다 어떤 조치를 요청할지 문장을 직접 쓰지 않아도 되고, 고객사 BIM 담당은 리포트를 보고 모델링 도구 설정만 바꾸면 되는 것과 모델에 값을 입력해야 하는 것을 구분해 대응할 수 있어야 한다.

성수 등 실제 고객사 제출 BIM 파일에서 요구사항 상태(OE-BIM-17)를 집계한다 — 필수 13 중 표준 위치 수·다른 위치 수·없음 수. 집계로 고객사 요청 문구를 자동으로 고른다 — "없음" 은 "값을 넣어 달라", "다른 위치" 는 "내보내기 설정을 바꿔 달라".
표준 위치/다른 위치/없음·일부/해당 없음/측정 불가·읽지 않음을 원인과 함께 구분한다. 대상·검사 수를 기록하고 불확실한 원인을 내보내기 설정 오류로 단정하지 않는다. 원본 BIM 게이트 미달 항목에는 고객사 재제출 가이드를 제공한다. 각 R/검증 규칙·대상 ID·필요 정보·현재 상태·설정/속성/관계/기하 보완 방법·확인된 내보내기 안내·재검사 방법을 포함한다. 외부 확인 전인 설정 방법은 확인 필요로 표시한다. 보정 후 생성 가능과 고객사 원본 개선 권고를 구분한다.

## 수용 기준

- R 마다 두 문구 중 하나가 자동으로 붙어 고객사 결과 리포트(OE-GEN-08)에 나온다.
- 적용 대상 R마다 대상·검사·충족 수와 사유를 확인하고 해당 없음과 측정 불가가 미충족으로 혼합되지 않도록 구분한다. 
- 요청 문구가 근거와 일치한다. 
- 원본 미달 파일과 보정 후 생성 가능한 파일 모두 같은 누락 근거의 가이드를 다운로드할 수 있고 사용자 보정으로 원본 누락이 없던 것처럼 표시되지 않는다.
