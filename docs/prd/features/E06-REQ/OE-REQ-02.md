# OE-REQ-02 IDS 검사 파일

## 요구사항
> User story : 고객사 BIM 담당은 모델을 제출하기 전에 에디터가 제공하는 검사 파일(IDS)로 자체 검사를 할 수 있다. 속성과 관계로 확인할 수 있는 요구사항은 검사 파일로 전부 검사되고, 일부만 검사되는 요구사항은 어떤 항목은 검사를 통과해도 별도 확인이 필요하다는 것을 알 수 있다. IDF 검사 파일을 통해서 사용자는 제출 후 등급 미달로 재제출하는 왕복을 줄일 수 있어야 하며, 구축 담당자는 검사 파일과 정본의 요구사항 번호가 어긋나면 테스트가 실패하도록 되어 있어 두 문서가 따로 놀지 않는다는 것을 신뢰할 수 있다.

속성·관계로 확인할 수 있는 R 을 IDS 1.0 명세 파일([`requirements.ids`](../requirements.ids))로 제공한다. 고객사는 제출 전에 ifctester 등으로 자체 검사한다. IDS 로 옮긴 R 과 일부만 옮긴 R 을 구분해 적는다.
IDS·어휘 표·임포터가 사용하는 R 번호와 스키마별 지원 범위를 구분한다. IDS로 확인할 수 없는 형상·공간 교차·실제 값의 충분성은 별도 검사로 표시한다.

## 수용 기준

- IDS 와 정본의 R 번호가 어긋나면 `requirements-ids.test.ts` 가 실패한다.
- 정본의 필수 R 번호가 실패할 경우, IDF 검사 결과에 고객사에게 다시 제출할 것을 기재한다.
