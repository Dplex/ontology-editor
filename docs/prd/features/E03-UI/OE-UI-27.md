# OE-UI-27 겹친 것 순환 선택 · 미리 강조

## 관련 티켓

- [OE-UI-18](./OE-UI-18.md): 상태줄의 커서 아래 표시

- [OE-EQP-04](../E12-EQP/OE-EQP-04.md): 천장 설비가 겹치는 자리
- [OE-UI-09](./OE-UI-09.md): 오브젝트 고르기

## 요구사항
> User story : 고객사 관리자는 커서를 올리면 클릭했을 때 골라질 오브젝트가 옅게 미리 강조되어, 누르기 전에 무엇이 골라질지 안다. 천장 속처럼 덕트 · VAV · 토출구 · 스프링클러가 몇 cm 간격으로 겹친 자리에서는 Tab 을 누를 때마다 커서 아래 겹친 것이 차례로 강조되고 상태줄에 이름이 보여, 숨기기를 거치거나 시점을 돌리지 않고 뒤에 있는 것을 고른다.

- 미리 강조: 3D · 평면도에서 커서 아래 클릭하면 골라질 오브젝트를 옅게 강조한다(색은 OE-UI-17). 고른 것의 강조와 구별된다.
- 순환: 커서 아래 겹친 것이 둘 이상이면 Tab 을 누를 때마다 다음 것으로 미리 강조가 옮겨 간다(Shift+Tab 은 거꾸로). 커서를 움직이면 처음으로 돌아간다.
- 상태줄(OE-UI-18)에 "커서 아래 n개 · i/n 이름(종류)" 를 보인다.
- 클릭하면 미리 강조된 것이 골라진다. 시점은 바뀌지 않는다.
- 그리기 · 배치 도구를 쓰는 중에는 순환하지 않는다(Tab 은 입력 칸 이동, OE-UI-28).
- 천장 편집 모드처럼 지금 모드에서 고를 수 없는 것은 순환에서 뺀다(OE-EQP-04).

## 수용 기준

- **AC1** 겹친 4개 위에서 Tab 을 네 번 누르면 네 개가 차례로 미리 강조되고 상태줄 이름이 바뀐다.
- **AC2** 그 상태에서 클릭하면 미리 강조된 것이 골라지고 시점은 그대로다.
- **AC3** 커서를 올리면 클릭 전에 골라질 것이 미리 강조된다.
