# OE-UI-04 화면 레이아웃

## 요구사항

화면은 네 영역이다.

1번. 왼쪽은 편집 도구 팔레트이며 모드(공간 편집·설비 편집)에 따라 도구가 바뀐다.
- 공간 편집 모드의 팔레트에서는 기본 공간 오브젝트(벽·룸·문·창)와 추가 공간 오브젝트(OE-SPC-14·16)를 골라 추가한다. 물리존 편집(이름·경계·분할·병합·삭제, OE-SPC-01~04), 커스텀존 편집(OE-SPC-06~09), 공조존 편집(설비를 골라 담당 물리존 지정·경계 그리기, OE-ZON-01·02·04) 도구도 이 모드에 둔다. 공조존 도구에서 설비는 담당을 지정하려고 고를 수만 있고 옮기거나 지울 수 없다. 계단·샤프트는 [다중층 뷰에서 편집] 으로 다중층 뷰를 연다(OE-ML-01 ②).
- 설비 편집 모드의 팔레트에서는 배관 없는 설비(OE-OBJ-10)와 배관 있는 설비(OE-OBJ-11)를 배치·이동·삭제한다. 팔레트 하위에 미배치 설비 목록을 두고, 목록에서 설비 하나를 누른 뒤 그 층 바닥을 클릭하면 바로 그 자리에 배치된다. 별도의 [3D 에서 놓기] 버튼이나 안내는 두지 않고, Esc 나 같은 설비를 다시 누르면 취소된다(OE-EQP-02). 배관·계통 도구(연결 잇기·끊기, 계통 변경, 방향 지정·확정, 배관 형상 수정·수동 그리기, OE-PIP-01~05·10~12)는 설비를 추가할 때만이 아니라 늘 쓸 수 있다. 설비 편집 모드에는 [바닥·벽 / 천장] 토글이 있고, 천장 쪽이 천장 편집 모드다(OE-OBJ-08). 층을 넘는 배관은 [라이저] 도구로 그리며, 고르면 다중층 뷰로 바뀐다(OE-ML-01 ③, OE-PIP-15). EL·ES 도 이 모드에서 [다중층 뷰에서 편집] 으로 연다(OE-EQP-07).
- 지금 모드가 아닌 오브젝트는 선택·속성 조회만 되고 편집 핸들은 비활성이며 "공간 편집 모드에서 편집"·"설비 편집 모드에서 편집" 을 안내한다. 모드는 UI 상태라 저장하지 않고, 모드를 바꿔도 되돌리기 이력(OE-UI-05)과 편집 경고는 이어진다.
- 편집 도구 팔레트는 아래와 같이 제공된다. 
공간 편집 모드 
├ 기본 공간 오브젝트: 벽·룸·문·창
├ 추가 공간 오브젝트: 책상·의자… (라이브러리)
├ 물리존: 이름·경계·분할·병합·삭제
├ 커스텀존: 그리기·이름·분할·병합 (서로 겹침 허용, Q4)
├ 공조존: 설비 선택 → 담당 물리존 지정, 경계 그리기   ← 설비는 선택만
└ 계단·샤프트 → [다중층 뷰에서 편집] 모드 전환

설비 편집 모드 → [바닥·벽 | 천장] 토글   
├ 배관 없는 설비: 배치·이동·삭제·이름·종류
├ 배관 있는 설비: 배치·이동(배관 끝점 추종)·삭제
├ 배관·계통: 잇기·끊기, 계통, 방향 확정, 형상, 수동 그리기
├ 미배치 설비 목록: 하나 누르기 → 그 층 바닥 클릭으로 배치 (Esc·다시 누르기로 취소)
└ 라이저 · EL·ES → [다중층 뷰에서 편집] 모드 전환

2번. 가운데는 3D 뷰다(자유 회전·확대·이동, OE-UI-14).

3번. 오른쪽은 레이어 패널이다 — 사용자가 현재 '3D 뷰' 상에서 보고있거나 혹은 마우스로 클릭하여 선택한 물리존·커스텀존·공조존·설비·배관·공간 오브젝트의 속성을 표시하고, 편집 경고를 보인다. 값마다 출처를 표시한다(OE-UI-13).

4번. 위쪽은 액션바다. 운영 편집에서는 [임시 저장]·[미리보기]·[반영하기]·[편집 종료], 초기 구축에서는 [반영하기] 대신 [구축하기](온톨로지 생성·내보내기, OE-GEN-01)를 둔다.

## 수용 기준

- 운영 편집 모드의 액션바에 [임시 저장]·[미리보기]·[반영하기]·[편집 종료] 네 버튼이 보인다.
- 초기 구축 모드의 액션바에는 [반영하기] 대신 [구축하기] 가 보인다.
- 모드를 바꾸면 팔레트의 도구가 바뀐다.
- 공간 편집 모드에서 설비를 끌어도 움직이지 않고 "설비 편집 모드에서 편집" 안내가 보인다. 설비 편집 모드에서 벽·물리존을 끌 때도 같다.
- 공조존 도구에서 설비를 눌러 담당 물리존을 지정할 수 있다.
- 설비 편집 모드 팔레트에 미배치 설비 목록이 보이고, 목록에서 설비를 누른 뒤 바닥을 클릭하면 그 자리에 놓인다. 속성 패널에 [3D 에서 놓기] 버튼은 없다.
- 설비 편집 모드에서 [라이저] 를 고르면 다중층 뷰가 열린다.
- 모드를 바꾼 뒤 Ctrl+Z 를 누르면 앞 모드에서 한 편집이 되돌아간다.

## 검증 (이 repo)

- 편집 모드에서 왼쪽 아래 도구 팔레트(공간·설비·벽·문·창)가 뜨고, 액션바의 편집 종료가 보기 모드로 돌린다 — `e2e/conduit-follow.spec.ts`
