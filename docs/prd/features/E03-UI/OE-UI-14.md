# OE-UI-14 3D 자유 카메라

## 관련 티켓

- [OE-BIM-01](../E05-BIM/OE-BIM-01.md): 파일 열기 전체 시간
- [OE-OBJ-15](../E02-OBJ/OE-OBJ-15.md): 3D 조작 방식(MapControls 배치)

## 요구사항
> User story : 구축 담당자가 정점 1,016만 개 규모의 성수 건축+기계 모델을 열어 3D 뷰를 자유롭게 회전·확대·이동한다. 회전이 60fps를 유지하고 방향키 반응이 0.5초 안이라 대형 모델에서도 끊김 없이 설비를 찾아 다니며, 파일을 여는 동안에도 1초 넘게 입력이 막히지 않아 로딩 중 화면이 멈춘 것으로 오해하지 않는다. GPU가 있는 크롬 기준이므로 담당자는 작업 환경 요건을 미리 안다. 조작 방식은 지도 앱과 같은 MapControls 배치(OE-OBJ-15)라 처음 쓰는 사용자도 빠르게 익히며, 성능 기준이 명시되어 있어 개발·QA가 같은 모델로 측정해 확인한다.

3D 뷰는 자유 회전·확대·이동을 지원한다. 성수 규모(건축+기계, 정점 1,016만)에서 회전이 60fps 를 유지하고, 파일을 열 때 화면이 멈추는 시간이 1초를 넘지 않아야 한다(파일 열기 전체 시간은 OE-BIM-01).
성능은 GPU 가 있는 크롬을 기준으로 잰다.

## 수용 기준

- 성수(건축+기계)에서 방향키 한 번의 반응이 0.5초 안이다.
- 파일을 여는 동안 1초 넘게 입력이 막히지 않는다.

## 검증 (이 repo)

- 성수(건축+기계)에서 방향키 한 번이 0.5초 안이다(GPU 크롬). Ctrl+Z 시간은 아직 기준이 없고 재서 적기만 한다 — `npm run e2e:seongsu`(방향키 기준), `scripts/seongsu.test.ts`(되돌리기 시간 기록), 성수 E-3·I-1
- 3D 음영은 빛 두 개로만 낸다(ADR-0013). 성수에서 회전·확대 중 프레임 간격이 중앙값 17ms · 95% 18ms 로 바꾸기 전과 같다 — `npm run e2e:seongsu` 의 C-11
