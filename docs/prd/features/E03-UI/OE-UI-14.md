# OE-UI-14 3D 자유 카메라

## 관련 티켓

- [OE-BIM-01](../E05-BIM/OE-BIM-01.md): 파일 열기 전체 시간
- [OE-OBJ-15](../E02-OBJ/OE-OBJ-15.md): 3D 조작 방식(MapControls 배치)

## 요구사항
> User story : 구축 담당자는 3D 뷰를 자유롭게 회전·확대·이동할 수 있다. 대형 사옥 규모의 건축+기계 모델에서도 회전이 부드럽게 유지되고 방향키 반응이 즉각적이어야 하며, 파일을 여는 동안에도 입력이 오래 막히지 않아 로딩 중 화면이 멈춘 것으로 오해하지 않는다. 성능은 GPU가 있는 크롬을 기준으로 재므로 사용자는 작업 환경 요건을 미리 알 수 있다. 사용자는 수백만 개 모델에서도 끊김 없이 설비를 찾아 다니며 편집할 수 있어야 하며, 파일 열기 전체 시간은 IFC 파싱 기준을 따른다.

3D 뷰는 자유 회전·확대·이동을 지원한다. 이동 및 회전 수행 시 60fps 를 유지하고, 파일을 열 때 화면이 멈추는 시간이 1초를 넘지 않아야 한다(파일 열기 전체 시간은 OE-BIM-01).
성능은 GPU 가 있는 크롬을 기준으로 잰다.

## 수용 기준

- 이동 및 회전 시 60fps을 유지한다. 
- 파일을 여는 동안 1초 넘게 입력이 막히지 않는다.
