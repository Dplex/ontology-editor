# OE-UI-06 스냅

## 요구사항
> User story : 고객사 관리자가 벽이나 룸 경계를 그릴 때 찍는 점이 그리드와 인접 오브젝트의 변·꼭짓점에 자동으로 붙는다(스냅). 눈대중으로 맞추다 생기는 미세한 틈이나 어긋남이 없어지고, 벽과 룸 경계가 정확히 맞물려 겹침 검사나 면적 계산에서 미세 오차로 인한 경고가 줄어든다. 자유로운 위치에 그려야 할 때는 스냅을 꺼서 찍은 자리에 그대로 놓이게 할 수 있다. 스냅 거리는 사이트 설정으로 조정되어, 사용자는 정밀한 도면 기반 작업과 대략적인 수동 구축 모두에 맞춰 쓸 수 있어야 한다.

'그리드 정렬' 기능과 '스냅' 기능이 동시에 켜져 있고 스냅 반경 내에 그리드 교점과 오브젝트 인접 변이 모두 존재할 경우, 정확한 형상 맞물림을 위해 인접 오브젝트 스냅이 그리드 스냅보다 우선하여 적용된다. 스냅이 작동했을 때는 대상에 달라붙었음을 인지할 수 있는 시각적 피드백(하이라이트 등)을 제공한다.

## 수용 기준

- **AC1** 스냅이 켜진 상태에서 인접 오브젝트 변 가까이 점을 찍으면 그 변 위로 붙는다. 끈 상태에서는 찍은 자리에 그대로 놓인다.
- **AC2** 인접 오브젝트 변/꼭짓점에 스냅 되었을 때, 해당 스냅 포인트를 알 수 있는 시각적인 하이라이트가 화면에 표시된다.
- **AC3** 그리드 정렬(OE-UI-07) 기능과 함께 켜져 있을 때 스냅 반경 내에 두 타겟(그리드, 오브젝트)이 모두 존재하면 인접 오브젝트의 변/꼭짓점 스냅을 우선하여 처리한다.
