# OE-UI-06 스냅

## 요구사항

벽·룸의 경계를 그릴 때 그리드와 인접 오브젝트의 변·꼭짓점에 자동으로 붙인다(스냅). 스냅은 켜고 끌 수 있다. 스냅 거리는 사이트 설정으로 둔다.

## 수용 기준

스냅이 켜진 상태에서 인접 오브젝트 변 가까이 점을 찍으면 그 변 위로 붙는다. 끈 상태에서는 찍은 자리에 그대로 놓인다.
