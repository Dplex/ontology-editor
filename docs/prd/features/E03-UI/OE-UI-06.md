# OE-UI-06 스냅

## 요구사항
> User story : R2에서 고객사 관리자가 벽이나 룸 경계를 그릴 때 점이 그리드와 인접 벽의 변·꼭짓점에 자동으로 붙어, 눈대중으로 맞추다 생기는 미세한 틈이나 어긋남이 없다. 자유로운 위치에 그려야 할 때는 스냅을 꺼서 찍은 자리에 그대로 놓이게 한다. 스냅 거리는 사이트 설정으로 조정되어 정밀한 도면 기반 작업과 대략적인 수동 구축 모두에 맞출 수 있다. 스냅 덕분에 벽과 룸 경계가 정확히 맞물려 겹침 검사나 물리존 면적 계산에서 미세 오차로 인한 경고가 줄어들고, 평면도 뷰에서도 같은 스냅 규칙이 적용된다.

벽·룸의 경계를 그릴 때 그리드와 인접 오브젝트의 변·꼭짓점에 자동으로 붙인다(스냅). 스냅은 켜고 끌 수 있다. 스냅 거리는 사이트 설정으로 둔다.

## 수용 기준

스냅이 켜진 상태에서 인접 오브젝트 변 가까이 점을 찍으면 그 변 위로 붙는다. 끈 상태에서는 찍은 자리에 그대로 놓인다.
