# OE-UI-12 3D 단일 층 표시

## 관련 티켓

- [OE-WF-07](../E14-WF/OE-WF-07.md): 미리보기 전체 빌딩 뷰 (Phase 2)

## 요구사항

### User story

고객사 관리자가 5층을 편집할 때 3D 뷰에 5층만 그려지고 다른 층의 오브젝트는 보이지도 선택되지도 않아, 위층 설비를 5층 것으로 착각해 옮기는 실수가 없다. 여러 층을 함께 봐야 하는 엘리베이터·라이저 작업은 다중층 뷰에서 하므로 층 편집 화면은 가볍고 단순하게 유지된다. 반영 전 전체 빌딩을 미리 보는 것은 Phase 2에서 제공한다. 한 층만 렌더링하므로 대형 모델에서도 3D 조작이 가볍고, 층 선택을 바꾸면 화면이 그 층으로 완전히 전환되어 '지금 어느 층을 편집하고 있는가'가 항상 명확하다.

층 편집 화면의 3D 는 선택한 한 층만 그린다. 다른 층은 그리지도 고르지도 않는다. 여러 층을 함께 보는 것은 다중층 뷰(E18)에서 한다.
미리보기의 전체 빌딩 뷰(OE-WF-07)는 Phase 2 다.

## 수용 기준

층 편집 화면에서 다른 층의 오브젝트가 보이지 않고 선택되지 않는다.
