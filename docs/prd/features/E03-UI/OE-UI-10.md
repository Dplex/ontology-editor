# OE-UI-10 설치면 필터

## 관련 티켓

- [OE-EQP-05](../E12-EQP/OE-EQP-05.md): 설치면 필터 동작

## 요구사항
> User story : 고객사 관리자가 편집 화면 상단의 설치면 필터에서 전체·천장·바닥·벽·미정 중 하나를 골라 지금 작업할 설비만 3D에 남긴다. 벽 센서 재배치 작업이면 '벽'만 켜 천장 조명이나 바닥 AHU에 가려지지 않게 하고, 임포트 직후에는 '미정'으로 설치면을 못 정한 설비를 모아 정리한다. 동작 기준은 OE-EQP-05와 같아 다른 화면의 필터와 결과가 달라지는 혼란이 없다. 설비가 수백 개인 층에서도 지금 손댈 대상만 보이므로 잘못된 설비를 선택해 옮기는 실수가 줄고, 필터를 바꿔 가며 설치면별 배치 현황을 빠르게 점검할 수 있다.

OE-EQP-05 를 따른다. (편집 화면의 필터 자리)

## 수용 기준

OE-EQP-05 의 수용 기준을 따른다.
