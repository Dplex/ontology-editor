# OE-UI-10 설치면 필터

## 요구사항

전체/천장/바닥/벽 선택 필터. 설치면이 "미정"인 설비를 고르는 항목도 둔다. 기준은 판정 설치면(OE-EQP-03)이며 플레넘 설비는 천장으로 센다.

## 수용 기준

전체·천장·바닥·벽 중 하나를 고르면 그 설치면의 설비만 보인다
"미정" 항목을 고르면 설치면을 판정하지 못한 설비만 보인다
