# OE-UI-10 설치면 필터

## 관련 티켓

- [OE-EQP-05](../E12-EQP/OE-EQP-05.md): 설치면 필터 동작

## 요구사항
> User story : 고객사 관리자는 편집 화면의 필터 자리에서 설치면 필터를 사용할 수 있다. 전체·천장·바닥·벽·미정 중 하나를 고르면 해당 설치면의 설비만 3D에 보이고 나머지는 숨겨진다. 동작 기준은 설치면 편집 필터와 같아, 사용자는 어느 화면에서 필터를 쓰든 같은 결과를 기대할 수 있다. 벽 센서 재배치처럼 특정 설치면만 다루는 작업에서 다른 설비에 가려지지 않게 하고, 임포트 직후 설치면을 정하지 못한 설비를 '미정'으로 모아 정리할 수 있어야 한다.

OE-EQP-05 를 따른다. (편집 화면의 필터 자리)
