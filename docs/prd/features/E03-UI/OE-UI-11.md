# OE-UI-11 평면도 뷰

## 관련 티켓

- [OE-SPC-03](../E09-SPC/OE-SPC-03.md): 평면도 꼭짓점 경계 편집

## 요구사항
> User story : 고객사 관리자가 3D에서는 가려져 잘 안 보이는 물리존 경계를 평면도 뷰로 전환해 위에서 내려다보며 꼭짓점을 끌어 수정한다. 평면도에는 외곽선·공간명·벽(내력벽은 진하게)·설비 위치가 그려져 도면과 대조하기 쉽고, 평면도에서 고른 물리존은 3D와 오른쪽 패널에도 함께 선택되어 두 뷰를 오가며 작업해도 맥락이 끊기지 않는다. 평면도에서 꼭짓점을 끌면 3D 외곽선도 즉시 바뀐다. 공간명이 평면도에 함께 표시되어 어느 방을 편집 중인지 즉시 알 수 있고, 설비 위치도 그려져 물리존 경계를 옮길 때 어떤 설비의 소속이 바뀔지 평면에서 미리 가늠한다.

층 평면도 뷰를 3D 와 함께 제공한다. 평면도에는 물리존 외곽선·공간명·벽(내력벽은 진하게)·설비 위치를 그린다. 물리존 꼭짓점을 끌어 편집할 수 있다(OE-SPC-03).
평면도에서 고른 것은 3D 와 오른쪽 패널에 같이 선택된다.

## 수용 기준

- 평면도에서 물리존을 고르면 오른쪽 패널에 그 물리존 속성이 보이고 3D 에서도 같은 것이 선택된다.
- 평면도에서 꼭짓점을 끌면 3D 의 외곽선이 같이 바뀐다.
