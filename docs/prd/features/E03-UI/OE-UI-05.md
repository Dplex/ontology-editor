# OE-UI-05 되돌리기 / 다시 실행

## 관련 티켓

- [OE-WF-19](../E14-WF/OE-WF-19.md): 구별할 이전 버전 되돌리기

## 요구사항
> User story : 고객사 관리자는 편집 화면에서 되돌리기(Ctrl+Z)로 직전 편집을 한 단계씩 되돌리고, 다시 하기(Ctrl+Shift+Z 또는 버튼)로 되돌린 편집을 다시 실행할 수 있다. 설비 배치·배관 수정·분할·병합 등 어떤 편집이든 되돌리기 대상이며 편집 종류가 늘어나면 함께 포함된다. 글자 칸에 입력하는 중의 되돌리기는 텍스트에만 적용되어 3D 편집의 되돌리기 이력에 영향을 주지 않는다. 이 이력은 편집 세션(탭) 안의 것으로, 버전 히스토리에서 이전 버전으로 되돌리는 기능과는 다르다. 공간 편집 모드에서 벽을 그린 뒤 설비 편집 모드로 넘어가 되돌리기를 눌러도 벽 편집이 되돌아가도록 이력은 모드를 바꿔도 이어진다. 분할·병합처럼 여러 오브젝트에 영향을 주는 편집은 한 번에 되돌리고 한 번에 다시 실행해 중간 상태가 생기지 않는다. 되돌린 뒤 새 편집을 하면 다시 하기 이력은 끊긴다. 사용자는 되돌릴 수 없는 작업인지 걱정하지 않고 자유롭게 시도할 수 있어야 한다.

편집 화면에서 되돌리기(Ctrl+Z, 한 단계씩)와 다시 하기(Ctrl+Shift+Z·버튼)를 제공한다. 어느 편집이든 되돌리기 대상이며, 편집 종류가 늘면 같이 들어간다. 탭(편집 세션) 안의 되돌리기 이력이고, #19 의 "이전 버전으로 되돌리기"(OE-WF-19)와 다르다.
되돌리기 이력은 공간 편집 모드와 설비 편집 모드가 하나를 같이 쓴다. 여러 오브젝트에 영향을 주는 편집은 이력에서 한 단계다. 되돌린 뒤 새 편집을 하면 다시 하기 이력은 지워진다.
되돌리기 버튼은 Ctrl+Z와 Ctrl+Shift+Z를 활용해 진행할 수 있고, 화면 내 별도 시각적 버튼으로도 제공해야 한다. 

## 수용 기준

- **AC1** Ctrl+Z 한 번에 직전 편집 하나가 되돌아간다.
- **AC2** Ctrl+Shift+Z 또는 버튼으로 되돌린 편집을 다시 할 수 있다.
- **AC3** 글자 칸에 입력 중일 때 Ctrl+Z 는 되돌리기 이력에 영향을 주지 않는다.
- **AC4** 공간 편집 모드에서 벽을 그린 뒤 설비 편집 모드로 바꿔 Ctrl+Z 를 누르면 벽 편집이 되돌아간다.
- **AC5** 물리존 분할·병합 한 번이 Ctrl+Z 한 번에 통째로 되돌아가고, Ctrl+Shift+Z 한 번에 통째로 다시 실행된다.
- **AC6** 되돌린 뒤 새 편집을 하면 다시 하기가 더 이상 되지 않는다.
