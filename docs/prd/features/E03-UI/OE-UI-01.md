# OE-UI-01 별도 에디터 실행

## 관련 티켓

- [OE-INT-01](../E20-INT/OE-INT-01.md): 사이트·층 컨텍스트 전달 경로

## 요구사항
> User story : 일반 관제 사용자는 DT 스마트 관제의 3D 뷰에서 '레이아웃 에디터' 버튼을 눌러 에디터를 열 수 있다. 에디터는 DT 안에 들어 있지 않은 별도 프로그램이며 버튼은 실행 링크다. 버튼을 누르면 에디터가 새 탭이나 창으로 열리고, 보고 있던 사이트와 층이 그대로 선택되어 있어 다시 찾을 필요가 없다. 구축 담당자는 DT가 아직 없는 신규 사이트에서도 에디터 주소를 직접 열어 초기 구축 모드로 들어갈 수 있어, DT 설치 전에 온톨로지 구축을 먼저 진행할 수 있어야 한다. 사이트·층 정보를 넘기는 경로는 데이터 교환 방식 결정에 따른다.

에디터는 Unity DT 안이 아니라 별도 프로그램(Three.js)이다(PRD 1.7). DT 스마트 관제 > 3D View 의 '레이아웃 에디터' 버튼은 에디터를 여는 실행 링크다.
버튼을 누르면 에디터가 새 탭(또는 창)으로 열리고 현재 보고 있던 사이트·층을 컨텍스트로 받는다. 초기 구축은 DT 없이 에디터를 단독으로 실행해서도 할 수 있다.
사이트·층 컨텍스트를 어떤 경로로 넘기는지는 데이터 교환 방식(D-INT)에 따른다.

## 수용 기준

- 3D View 의 버튼을 누르면 에디터가 새 탭으로 열리고 보고 있던 사이트·층이 선택된 상태다.
- DT 없이 에디터 URL 을 직접 열어 초기 구축 모드로 들어갈 수 있다.
