## 요구사항
> User story : 구축 담당자와 고객사 관리자는 캔버스 아래 가운데의 뷰 컨트롤 바 하나에서 보기와 정렬을 다룬다. 3D 를 돌리다 길을 잃으면 [전체 보기]로 층 전체가 보이게 돌아오고, 마우스로 어떻게 돌리고 확대하는지가 같은 바에 적혀 있다. 그리드 간격, 스냅 켜고 끄기가 한 줄에 모여 있어 자유롭게 그리려고 스냅을 끄는 일을 찾아다니지 않고 바로 한다. 설치면으로 보기는 레이어 패널에서 한다.

캔버스 아래 가운데에 뷰 컨트롤 바를 둔다. 왼쪽부터 아래 순서다.
- [전체 보기] — 층 전체가 보이게 카메라를 되돌린다(OE-UI-14). 확대 비율(%)과 [−]·[+]는 3D 엔진이 정해지면 더한다.
- 조작 안내 — 3D 는 회전·이동·확대 방법, 평면도는 클릭 선택·우클릭 메뉴(OE-UI-11 · OE-UI-21). 보기를 바꾸면 바뀐다.
- 그리드 — 간격을 보이고 켜고 끈다(OE-UI-07).
- 스냅 — 켜고 끈다(OE-UI-06).
- 섹션 박스 — 3D 에서 켜고 끈다(OE-UI-29). 평면도에서는 비활성이다.
3D/평면도 전환은 캔버스 오른쪽 위에 따로 둔다.

## 수용 기준

- **AC1** 3D 를 돌린 뒤 [전체 보기]를 누르면 층 전체가 보이게 돌아온다.
- **AC2** 뷰 컨트롤 바에는 설치면 필터가 없다 — 설치면으로 보기는 레이어 패널(OE-UI-19)에서 한다.
- **AC3** 스냅을 끄면 찍은 자리에 그대로 놓이고 켜면 다시 붙는다.
- **AC4** 3D 에서 뷰 컨트롤 바의 [섹션 박스]를 켜면 상자가 생기고, 평면도에서는 그 단추가 비활성이다.
