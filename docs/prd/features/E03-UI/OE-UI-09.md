# OE-UI-09 오브젝트 조작

## 요구사항
> User story : 고객사 관리자는 오브젝트를 복사·붙여넣기하고, 여러 개를 한 번에 선택하고, 지울 수 있다. 다중 선택한 오브젝트는 한 번에 옮기거나 지울 수 있다. 사용자가 삭제한 오브젝트도 되돌리기로 복구할 수 있으며, 여러 개를 지웠어도 한 번의 되돌리기로 전부 돌아온다. 사용자는 같은 종류의 센서 수십 개를 사무실 전체에 배치할 때 하나를 복사해 늘리고, 대량 편집에서 실수해도 치명적이지 않다는 것을 기대할 수 있어야 한다.

오브젝트는 복사·붙여넣기, 다중 선택, 삭제를 지원한다. 다중 선택한 것을 한 번에 옮기거나 지울 수 있다. 붙여넣은 오브젝트는 새 id(`U_`, OE-INT-05)를 받고 겹침 불가 원칙(OE-OBJ-16)을 따른다. 삭제는 OE-UI-05 로 되돌릴 수 있다.

다른 층에 붙여넣기: 복사한 것을 [다른 층에 붙여넣기]로 같은 건물의 여러 층에 같은 XY 자리로 한 번에 붙인다. 층 목록에서 붙일 층을 고르기 전에, 층마다 몇 개가 어느 물리존에 떨어지는지를 먼저 보이고 원본과 다른 이름의 물리존(또는 소속 없음)에 떨어지는 것은 주의로 표시한다. 붙인 뒤 층마다 소속을 다시 판정하고(OE-MAP-01), 미리보기 변경 요약에 층별 줄로 보인다(OE-WF-08). 붙인 것은 층마다 새 id 를 받는다.

## 수용 기준

- **AC1** 설비 여러 개를 고른 뒤 Delete 로 한 번에 지울 수 있고 Ctrl+Z 로 전부 돌아온다.
- **AC2** 복사·붙여넣기한 설비는 원본과 다른 id 를 가진다.
- **AC3** 3F 에서 복사한 설비 6대를 [다른 층에 붙여넣기]로 고르면, 붙이기 전에 4F~7F 마다 떨어질 물리존과 원본과 다른 곳이 보인다.
- **AC4** 4F·5F 에 붙이면 층마다 새 id 로 같은 XY 에 생기고 그 층 물리존에 소속되며, 미리보기 변경 요약에 층별 줄이 보인다.
