## 요구사항
> User story : 구축 담당자는 [새 프로젝트]로 시작해 네 단계 화면을 따라 초기 구축을 마칠 수 있다. 시작 화면에서 사이트의 IFC 파일을 올리면 사이트 전체가 임포트되고, 검토 화면에서 임포트 결과와 품질을 확인한 뒤, 에디터에서 한 층씩 편집·보정하고 층마다 임시 저장한다. 편집을 마치고 [구축하기]를 누르면 구축 결과 리포트가 요약되어 보이고 구축된 온톨로지 파일을 바로 내려받을 수 있다. 화면 위에는 지금 몇 번째 단계인지 항상 보여, 처음 쓰는 사용자도 다음에 무엇을 해야 하는지 헤매지 않아야 한다.

초기 구축은 프로젝트 목록에서 [새 프로젝트]로 시작하고(OE-UI-02) 네 단계 화면으로 진행한다. 화면 위에 단계 표시(① 시작 · ② 검토 · ③ 편집 · ④ 결과)를 둔다.

① 시작 — 파일 업로드만 둔다.
- 사이트를 구성하는 IFC 파일(건물별·분야별 여러 개)을 한 번에 올린다. 올린 파일마다 인식한 분야(건축·설비)와 건물을 보이고, 빼거나 더할 수 있다.
- IFC 와 IDF 외 형식은 받지 않고 그 이유를 보인다. R1 에는 평면도·3D 스캔·빈 층에서 시작하는 경로를 두지 않는다(E07, R2). IDF 는 IFC 와 함께 올리거나 IFC 를 연 뒤 덧붙일 수 있다(OE-BIM-15 Case 1, E04).

② 임포트 검토 — 임포트 결과를 확인한다.
- 건물별로 묶은 층 목록을 보인다(OE-UI-03 공통 표시 규칙). 건물마다 층 범위·층 수와 물리존·설비·미배치 설비·공간 오브젝트 합계를, 층마다 같은 항목을 보인다. 불러온 분야(건축·설비)는 건물별로 보인다.
- 등급(OE-BIM-16), 요구사항 보고서(OE-BIM-17), 완전성 검사(OE-BIM-18), 수용 기준선 판정(OE-BIM-21), 공조존 생성 방법(OE-BIM-15)을 둔다.
- [에디터에서 확인·수정]으로 ③ 으로 간다. 기준선 미달이어도 ③ 으로 갈 수 있고, 막히는 것은 [구축하기]다(OE-GEN-02).

③ 에디터 — OE-UI-04 의 초기 구축 모드다. 건물별 층 단위로 편집·보정하고 층마다 임시 저장한다. 아직 불러오지 않은 건물이나 그 건물에 아직 없는 분야(건축·설비)의 파일은 [추가 파일 불러오기](OE-HIST-06)로 더한다.

④ 구축 결과 리포트 — [구축하기]가 끝나면 보인다.
- 생성 리포트(OE-GEN-07)의 요약을 보인다 — 건물·층 수, 판정 등급, 생성된 물리존·운영존·공조존·설비·배관·공간 오브젝트 수(사이트 합계와 건물별), 생성 전 검증 결과(OE-GEN-03, 막힌 항목은 건물·층으로 표시), 미확정 규칙 방향 수, 임시 저장하지 않아 구축에서 빠진 편집이 있는 건물·층. 전체 리포트를 열 수 있다.
- 구축된 온톨로지 파일(OE-GEN-01 산출물: GeoJSON·TTL·OBJ·BIN)을 각각 또는 한 번에 내려받을 수 있다.
- 고객사 결과 리포트(OE-GEN-08)를 내보낼 수 있다.
- 이 화면 이후 그 프로젝트는 구축 완료가 되고, 다시 열면 운영 편집으로 들어간다(OE-UI-02).

## 수용 기준

- **AC1** [새 프로젝트]로 들어가면 파일 업로드만 있는 시작 화면이 보인다.
- **AC2** IFC 가 아닌 파일을 올리면 받지 않고 이유가 보인다.
- **AC3** 여러 IFC 를 한 번에 올리면 검토 화면에 사이트의 건물·층이 모두 보인다.
- **AC4** 기준선 미달 상태에서도 에디터로 갈 수 있고 [구축하기]만 비활성이다.
- **AC5** [구축하기] 뒤 구축 결과 리포트 요약이 보이고 GeoJSON·TTL·OBJ·BIN 을 각각 또는 한 번에 내려받을 수 있다.
- **AC6** 네 화면 모두 위에 현재 단계가 표시된다.
- **AC7** 건물이 여럿인 사이트를 임포트하면 검토 화면에 건물별 층 범위와 합계, 건물별 불러온 분야가 보인다.
- **AC8** 구축 결과 리포트에 건물별 생성 수가 보인다.
