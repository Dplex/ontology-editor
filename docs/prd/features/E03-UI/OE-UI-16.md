# OE-UI-16 존 종류별 보기 필터

## 관련 티켓

- [OE-IDF-01](../E04-IDF/OE-IDF-01.md): 공조존(IDF 에너지존)이 화면에 올라오는 출처
- [OE-UI-10](./OE-UI-10.md): 같은 필터 자리의 설치면 필터

## 요구사항
> User story : 구축 담당자와 고객사 관리자는 편집 화면의 필터 자리에서 물리존·커스텀존(운영존)·공조존을 종류별로 켜고 꺼서 원하는 존만 3D·평면에 볼 수 있다. IDF 를 올리면 공조존이 물리존·커스텀존과 한 층 위에 겹쳐 보이는데, 한 종류만 켜면 어느 존이 어느 존과 겹치는지(예: 공조존 하나가 물리존 여러 개에 걸친 것) 구분해서 확인할 수 있다. 필터는 화면에서만 적용되고 편집 파일과 온톨로지에는 남지 않는다.

필터 자리에 존 종류 세 가지(물리존·커스텀존·공조존)를 둔다. 기본은 셋 다 켜짐이다. 끈 종류의 존은 3D·평면에서 그려지지도 선택되지도 않는다. 공조존은 IDF 를 열거나 덧붙였거나 공조존 도구로 만든 것이 있을 때만 칸이 활성이다. 설치면 필터(OE-UI-10)와 함께 쓸 수 있다.

"운영존" 은 이 문서에서 커스텀존을 가리키는 것으로 읽는다(Q18).

## 수용 기준

- **AC1** 물리존·커스텀존·공조존을 각각 켜고 끌 수 있고, 끈 종류는 보이지도 선택되지도 않는다.
- **AC2** 필터 상태는 편집 파일·TTL·GeoJSON 에 남지 않는다.
- **AC3** 공조존이 없는 파일에서는 공조존 칸이 비활성으로 보이고 이유가 안내된다.
