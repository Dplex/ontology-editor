## 관련 티켓

## 요구사항

오브젝트를 고르면 그 크기(가로·세로·높이)와 인접 오브젝트까지의 거리를 3D·평면도에 치수선으로 보인다. 끄는 동안 값이 실시간으로 바뀐다. 단위는 m 다(OE-INT-04).

## 수용 기준

벽을 고르면 길이가 보이고, 끄는 동안 값이 함께 바뀐다.
