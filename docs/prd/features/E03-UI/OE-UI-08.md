# OE-UI-08 치수 표시

## 관련 티켓

- [OE-INT-04](../E20-INT/OE-INT-04.md): 치수 단위 m

## 요구사항
> User story : 고객사 관리자가 새 벽을 그린 뒤 선택하면 길이·높이와 인접 벽까지의 거리가 치수선으로 3D·평면도에 보여 실측값과 맞는지 바로 확인한다. 벽을 끄는 동안 치수가 실시간으로 바뀌어 '3.6m 떨어진 위치'처럼 목표 거리에 정확히 놓을 수 있고, 단위가 m로 통일되어 DT와 어긋나지 않는다. 도면과 대조하며 레이아웃을 맞추는 작업이 눈대중이 아닌 수치 기반으로 진행된다. 인접 오브젝트까지의 거리가 보여 설비 사이 최소 이격이나 문 옆 여유 공간처럼 규정 치수를 지켜야 하는 배치도 수치로 확인하며 놓을 수 있다.

오브젝트를 고르면 그 크기(가로·세로·높이)와 인접 오브젝트까지의 거리를 3D·평면도에 치수선으로 보인다. 끄는 동안 값이 실시간으로 바뀐다. 단위는 m 다(OE-INT-04).

## 수용 기준

벽을 고르면 길이가 보이고, 끄는 동안 값이 함께 바뀐다.
