# OE-UI-21 우클릭 편집 메뉴

## 요구사항
> User story : 고객사 관리자는 캔버스에서 물리존·커스텀존·설비를 우클릭해 그 오브젝트에 할 수 있는 편집을 바로 고른다. 오른쪽 패널까지 가지 않고 이름 바꾸기·선 그어 나누기·지우기를 할 수 있어 같은 동작을 여러 번 반복하는 정리 작업이 빨라진다. 지금 모드에서 고칠 수 없는 오브젝트면 메뉴 맨 위에 어느 모드에서 고치는지가 보이고 항목은 잠겨 있다. 지우기도 되돌리기로 돌아오므로 메뉴에서 바로 지워도 불안하지 않다.

캔버스(평면도부터, 3D 는 선택이 되면)에서 오브젝트를 우클릭하면 그 오브젝트를 고르고 편집 메뉴를 연다.
- 맨 위에 오브젝트 이름과 종류를 보인다.
- 물리존: 이름 바꾸기(OE-SPC-01) · 선 그어 나누기 · 지우기(OE-SPC-02). 커스텀존: 이름 바꾸기 · 선 그어 나누기 · 지우기(OE-SPC-08). 설비: 이름 바꾸기 · 지우기(OE-UI-09). 모든 메뉴에 [3D 에서 보기].
- 지금 모드에서 고칠 수 없으면(OE-UI-04 — 공간 편집 모드의 설비, 설비 편집 모드의 존) 맨 위에 "공간 편집 모드에서 편집" 처럼 안내하고 편집 항목을 비활성으로 둔다.
- 지우기는 빨강으로 구분선 아래에 두고, 되돌리기(OE-UI-05)로 돌아온다. 지우기 제약(마지막 물리존 등)은 버튼과 같다.
- Esc · 메뉴 밖 클릭으로 닫는다. 그리기·배치 도구를 쓰는 중에는 열리지 않는다.

## 수용 기준

- **AC1** 평면도에서 물리존을 우클릭해 [지우기]를 누르면 물리존이 지워지고 Ctrl+Z 로 돌아온다.
- **AC2** 설비 편집 모드에서 물리존을 우클릭하면 "공간 편집 모드에서 편집" 이 보이고 편집 항목이 비활성이다.
- **AC3** Esc 를 누르면 메뉴가 닫힌다.
