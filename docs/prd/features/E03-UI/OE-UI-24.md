# OE-UI-24 선택 필터 · 같은 종류 모두 고르기

## 관련 티켓

- [OE-EQP-14](../E12-EQP/OE-EQP-14.md): 설비 종류
- [OE-UI-21](./OE-UI-21.md): 우클릭 메뉴의 [같은 종류 모두]
- [OE-UI-09](./OE-UI-09.md): 다중 선택
- [OE-UI-04](./OE-UI-04.md): 모드별 편집 잠금
- [OE-UI-18](./OE-UI-18.md): 상태줄의 선택 표시
- [OE-UI-25](./OE-UI-25.md): 고른 것의 일괄 편집

## 요구사항
> User story : 고객사 관리자는 박스나 Ctrl 로 대충 여러 개를 고른 뒤, 우측 패널에 뜬 종류별 개수를 보고 필요 없는 종류를 빼서 원하는 것만 남길 수 있다. 설비 하나를 고른 상태에서 [같은 종류 모두]를 누르면 이 층이나 건물 전체의 같은 종류가 한 번에 골라진다. 성수·병원처럼 같은 패턴의 설비 수십 개를 고쳐야 할 때 하나씩 누르다 빠뜨리는 일이 없다.

여러 오브젝트를 고르는 길과, 고른 것을 종류로 거르는 길을 둔다.
- 선택 필터: 오브젝트를 둘 이상 고르면 우측 패널 위에 "고른 것 N개" 와 종류별 개수 목록을 보인다(설비는 종류(OE-EQP-14), 그 밖은 물리존 · 커스텀존 · 공조존 · 벽 · 문·창 · 배관). 종류의 체크를 끄면 그 종류가 선택에서 빠진다. "종류 모름" 도 한 줄로 센다.
- 같은 종류 모두 고르기: 오브젝트 하나를 고른 상태에서 [같은 종류 모두 — 이 층] · [같은 종류 모두 — 건물 전체]. 우클릭 메뉴(OE-UI-21)와 선택 오브젝트 섹션 둘 다에 둔다. 건물 전체는 다른 층 것도 고르지만 화면에는 지금 층만 그린다.
- 다중 선택은 OE-UI-09 를 따르되 설비만이 아니라 위 종류 전부에 쓴다. 서로 다른 모드의 오브젝트가 섞이면 지금 모드에서 편집할 수 없는 것은 필터에 "보기만" 으로 표시한다(OE-UI-04).
- 고른 개수와 종류 수를 상태줄(OE-UI-18)에 보인다.
- 고른 것은 다음 편집(OE-UI-25 일괄 편집 · 이동 · 삭제)의 대상이 된다. 선택 자체는 저장본 · TTL · GeoJSON 에 남지 않는다.

## 수용 기준

- **AC1** 설비 · 덕트가 섞인 64개를 박스로 고르면 종류별 개수가 보이고, 한 종류의 체크를 끄면 선택이 그 수만큼 준다.
- **AC2** 설비 하나를 고르고 [같은 종류 모두 — 이 층]을 누르면 그 층의 같은 종류 설비가 모두 골라진다.
- **AC3** [같은 종류 모두 — 건물 전체]를 누르면 다른 층의 같은 종류까지 골라지고 상태줄에 전체 개수가 보인다.
- **AC4** 선택은 저장본 · TTL · GeoJSON 에 남지 않는다.
