# OE-UI-02 프로젝트 기반 모드 분기

## 관련 티켓

- [OE-INT-01](../E20-INT/OE-INT-01.md): 온톨로지 존재 여부 읽을 곳
- [OE-UI-03](./OE-UI-03.md): 프로젝트 목록 · 층 선택 화면
- [OE-UI-15](./OE-UI-15.md): 초기 구축 화면 흐름
- [OE-GEN-11](../E08-GEN/OE-GEN-11.md): 사이트 단위 임포트 · 층 단위 편집
- [OE-WF-06](../E14-WF/OE-WF-06.md): 프로젝트 작업본

## 요구사항
> User story : 구축 담당자는 에디터 첫 화면의 프로젝트 목록에서 작업을 시작한다. [새 프로젝트]로 초기 구축을 시작하면 파일 업로드 화면이 열리고, 이미 만든 프로젝트를 누르면 작업본이 있으므로 파일 업로드 화면을 건너뛰고 에디터가 바로 열린다. 파일 기반의 구축을 마친 프로젝트를 누르면 층 선택을 거쳐 운영 편집으로 들어간다. BIM 은 프로젝트 단위로 임포트하므로 같은 IFC 로 여러 프로젝트를 만들어 각각 구축할 수 있다. 구축을 마친 프로젝트는 초기 구축으로 다시 열리지 않아, 운영 중인 온톨로지를 초기 구축으로 덮어쓰는 일이 구조적으로 막힌다. 

에디터의 첫 화면은 프로젝트 목록(OE-UI-03)이다. 모드는 사용자가 고르지 않고 아래처럼 정해진다(glossary).
- [새 프로젝트]: 프로젝트 이름과 사이트 이름을 정하면 초기 구축 모드의 시작 화면(OE-UI-15 ①)이 열린다. 프로젝트마다 사이트 하나를 만든다. 프로젝트는 반드시 BIM(IFC 형식) 파일 업로드를 요구한다. 
- 구축 완료 전 프로젝트: 누르면 작업본(OE-WF-06)이 열려 시작 화면을 거치지 않고 구축 초기 에디터(OE-UI-15 ③)로 들어간다.
- 구축을 마친 프로젝트: 누르면 층 선택 화면을 거쳐 운영 편집 모드로 들어간다. 초기 구축 모드로는 다시 열리지 않는다.
- 새 초기 구축 작업본은 [새 프로젝트]로만 만든다. 같은 IFC 로 여러 프로젝트를 만들 수 있다.
초기 구축은 사이트 단위로 임포트하고 층 단위로 편집한다(OE-GEN-11). 프로젝트의 구축 여부를 어디에서 읽는지는 데이터 교환 방식(D-INT)에 따른다.

## 수용 기준

- [새 프로젝트]로 들어가면 파일 업로드만 있는 시작 화면이 열린다.
- 구축 전 프로젝트를 누르면 시작 화면 없이 에디터가 열리고 이전 편집이 보인다.
- 구축을 마친 프로젝트를 누르면 층 선택 화면이 열리고, 초기 구축 모드로 들어갈 수 없다.
- 이미 다른 프로젝트에 쓴 IFC 로 새 프로젝트를 만들어 임포트할 수 있다.
- [새 프로젝트] 밖에서 새 초기 구축 작업본을 만드는 경로가 없다.
