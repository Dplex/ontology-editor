# OE-UI-02 모드 자동 분기

## 관련 티켓

- [OE-INT-01](../E20-INT/OE-INT-01.md): 온톨로지 존재 여부 읽을 곳

## 요구사항
> User story : 고객사 관리자가 사이트와 층을 골라 에디터에 들어가면 그 층의 온톨로지가 있는지에 따라 모드가 자동으로 정해진다. 온톨로지가 없으면 초기 구축 모드, 있으면 운영 편집 모드이며 사용자가 모드를 고르는 단계는 없다. 이를 통해 이미 운영 중인 층에서 실수로 초기 구축을 시작해 기존 온톨로지를 덮어쓰거나, 아직 구축되지 않은 층에서 운영 편집을 열어 빈 레이아웃을 반영하는 사고가 구조적으로 막힌다. 사용자는 저장 방식과 무관하게 층을 고르는 것만으로 알맞은 모드에서 작업을 시작할 수 있어야 한다.

에디터는 사이트·층을 받아 들어갈 때 그 층의 온톨로지 존재 여부로 모드를 정한다. 온톨로지가 없으면 초기 구축 모드, 있으면 운영 편집 모드다(glossary). 사용자가 모드를 고르는 단계는 두지 않는다.
존재 여부를 어디에서 읽는지는 데이터 교환 방식(D-INT)에 따른다.

## 수용 기준

- 온톨로지가 있는 층에서는 초기 구축 모드로 들어갈 수 없다.
- 온톨로지가 없는 층에서는 운영 편집 모드로 들어갈 수 없다.
