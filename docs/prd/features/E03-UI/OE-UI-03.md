# OE-UI-03 프로젝트 목록 · 층 선택 화면

## 관련 티켓

- [OE-UI-02](./OE-UI-02.md): 프로젝트 기반 모드 분기 결과

## 요구사항
> User story : 구축 담당자는 프로젝트 목록에서 프로젝트마다 사이트, 구축 상태, 층 진행 현황, 마지막 저장 시각과 저장한 사람을 보고 어디서 이어서 작업할지 고를 수 있다. 여러 담당자가 나눠 작업할 때도 몇 개 층을 임시 저장했는지로 진행 현황을 한눈에 안다. 구축을 마친 프로젝트는 층 선택 화면에서 편집할 층을 골라 운영 편집으로 들어가며, 층마다 초기 구축 버튼은 없다.

프로젝트 목록과 층 선택 화면은 OE-UI-02 의 분기를 그대로 보인다.
- 프로젝트 목록: 맨 위에 [새 프로젝트]. 프로젝트마다 이름·사이트·불러온 분야·상태(구축 전 / 구축 완료)·층 진행 현황(임시 저장한 층 수 / 전체 층 수, 구축 완료면 구축 버전)·마지막 저장 시각과 사용자를 보인다.
- 층 선택 화면: 구축을 마친 프로젝트에서만 쓴다. 층마다 [운영 편집]으로 들어가고, 임시 저장본이 있는 층은 표시한다. 층마다 [초기 구축] 버튼은 두지 않는다.
비활성 버튼에는 이유를 툴팁으로 보인다.

## 수용 기준

- 프로젝트 목록에 [새 프로젝트]와 프로젝트별 사이트·상태·층 진행 현황·마지막 저장 정보가 보인다.
- 층 선택 화면에 층별 [초기 구축] 버튼이 없고, 임시 저장본이 있는 층이 표시된다.
- 비활성 버튼에 마우스를 올리면 이유가 보인다.
