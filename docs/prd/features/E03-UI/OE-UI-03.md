# OE-UI-03 모드 전환 버튼 규칙

## 관련 티켓

- [OE-UI-02](./OE-UI-02.md): 모드 자동 분기 결과

## 요구사항
> User story : 구축 담당자가 층 선택 화면에서 10개 층을 보면 온톨로지가 없는 층에는 [초기 구축]만, 있는 층에는 [운영 편집]만 활성화되어 있어 어느 층이 아직 구축 전인지 한눈에 안다. 비활성 버튼에 마우스를 올리면 '이 층은 이미 온톨로지가 있어 초기 구축이 불가합니다' 같은 이유가 툴팁으로 보여, 왜 못 누르는지 몰라 헤매지 않고 다음 작업할 층을 고른다. 버튼 활성 상태가 OE-UI-02의 분기와 같은 기준이라 층 선택 화면에서 본 것과 실제 진입 모드가 어긋나지 않고, 여러 담당자가 나눠 구축할 때 진행 현황판 역할도 한다.

층 선택 화면의 모드 버튼은 OE-UI-02 의 분기를 그대로 보인다. 온톨로지 기반 레이아웃이 없는 층에는 [초기 구축] 만 활성이고, 있는 층에는 [운영 편집] 만 활성이다. 비활성 버튼에는 이유를 툴팁으로 보인다.

## 수용 기준

온톨로지가 있는 층에서 [초기 구축] 이 비활성이고, 없는 층에서 [운영 편집] 이 비활성이다.
