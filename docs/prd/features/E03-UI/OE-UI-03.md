# OE-UI-03 프로젝트 목록 · 층 선택 화면

## 관련 티켓

- [OE-UI-02](./OE-UI-02.md): 프로젝트 기반 모드 분기 결과

## 요구사항
> User story : 구축 담당자는 프로젝트 목록에서 프로젝트마다 진행 현황을 사이트 전체와 건물별로 볼 수 있다. 한 사이트에 A동 1F~10F, B동 B5F~4F처럼 층 구성이 다른 건물이 여럿 있어도 건물마다 층 범위와 몇 개 층을 임시 저장했는지가 따로 보여, 어느 건물에 임시 저장이 존재하는지 바로 알고 담당자를 나눌 수 있다. 층 선택 화면도 건물별로 묶이고 건물 안에서는 낮은 층부터 나열되며, 층은 항상 건물 이름과 함께 보여 두 건물의 같은 이름 층을 헷갈리지 않는다. 구축을 마친 프로젝트는 층 선택 화면에서 편집할 층을 골라 운영 편집으로 들어가며, 층마다 초기 구축 버튼은 없다.

프로젝트 목록과 층 선택 화면은 OE-UI-02 의 분기를 그대로 보인다.

공통 표시 규칙
- 층은 어디서든 건물 이름과 함께 표시한다(예: "B동 1F").
- 층 목록은 건물별로 묶고, 건물 안에서는 낮은 층부터 높은 층 순서(지하층 먼저)로 나열한다.
- 건물의 층 범위는 가장 낮은 층~가장 높은 층으로 표시한다(예: "B5F~4F").

프로젝트 목록
- 맨 위에 [새 프로젝트]를 둔다.
- 프로젝트마다 이름·사이트·불러온 분야·상태(구축 전 / 구축 완료)·마지막 임시 저장 또는 구축 시각과 사용자를 보인다.
- 진행 현황은 두 단계로 보인다.
  - 사이트 합계: 건물 수, 전체 층 수, 그리고 구축 전이면 임시 저장한 층 수 / 전체 층 수, 구축 완료면 최신 버전.
  - 건물별: 프로젝트를 펼치면 건물마다 건물 이름·층 범위·층 수·임시 저장한 층 수 / 층 수(구축 완료면 임시 저장본이 있는 층 수)를 보인다.

층 선택 화면
- 구축을 마친 프로젝트에서만 쓴다.
- 건물별로 묶고, 묶음 머리에 건물 이름·층 범위·임시 저장본이 있는 층 수를 보인다.
- 층마다 [운영 편집]으로 들어가고, 임시 저장본이 있는 층은 표시한다. 층마다 [초기 구축] 버튼은 두지 않는다.

비활성 버튼에는 이유를 툴팁으로 보인다.

## 수용 기준

- 프로젝트 목록에서 사이트 합계(건물 수·층 수·진행 현황)가 보이고, 프로젝트를 펼치면 건물별 층 범위·층 수·임시 저장한 층 수가 보인다.
- 건물이 여럿인 프로젝트의 층 선택 화면에서 층이 건물별로 묶이고, 건물 안에서는 지하층부터 낮은 층 순서로 나열된다.
- 두 건물에 같은 이름의 층이 있어도 건물 이름과 함께 표시되어 구분된다.
- 층 선택 화면에 층별 [초기 구축] 버튼이 없고, 임시 저장본이 있는 층이 표시된다.
- 비활성 버튼에 마우스를 올리면 이유가 보인다.
