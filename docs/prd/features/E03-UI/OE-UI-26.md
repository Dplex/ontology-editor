# OE-UI-26 물리존 색 채우기 범례

## 관련 티켓

- [OE-UI-19](./OE-UI-19.md): 칠하기 기준을 두는 레이어 패널
- [OE-MAP-01](../E11-MAP/OE-MAP-01.md): 소속 설비 수

- [OE-UI-24](./OE-UI-24.md): 범례 항목의 방 고르기

## 요구사항
> User story : 구축 담당자와 고객사 관리자는 레이어 패널에서 칠하기 기준을 골라 층 평면의 물리존을 소속 설비 수 · 방 종류 · 외곽선 출처 같은 값으로 칠하고 범례를 볼 수 있다. 설비가 0대인 방, 종류를 모르는 방, 외곽선이 없는 방이 표를 내려 보지 않아도 한눈에 보이고, 범례 항목을 누르면 그 방들만 강조되고 목록도 그 방들로 걸러져 바로 고치러 간다. 칠하기는 화면에서만이라 파일은 바뀌지 않는다.

레이어 패널(OE-UI-19) 아래에 "칠하기 기준" 을 둔다 — 없음(기본) · 소속 설비 수(OE-MAP-01) · 방 종류(OE-SPC-17) · 외곽선 출처(BIM · 사람 · 없음, OE-MAN-03) · 공조존 담당(있음 · 없음 · 여럿).
- 고르면 3D · 평면도의 물리존 면을 그 기준으로 칠하고 캔버스에 범례(값 · 색 · 방 수)를 띄운다. 칠하는 동안은 물리존 분류 색 대신 범례 색을 쓴다(OE-UI-17).
- 범례 색은 상태 색(선택 · 정상 · 주의 · 위험)과 겹치지 않는 순서 팔레트다. 0 · 없음 · 모름처럼 고칠 후보인 값은 범례 맨 위에 둔다.
- 범례 항목을 누르면 그 값의 방만 강조되고 우측 패널 목록이 그 방들로 걸러진다. 한 번 더 누르면 풀린다. [이 방들 고르기]로 선택에 넣을 수 있다(OE-UI-24).
- 칠하기는 화면에서만 적용되고 저장본 · TTL · GeoJSON 에 남지 않는다. 편집으로 값이 바뀌면 바로 다시 칠한다.

## 수용 기준

- **AC1** 칠하기 기준을 "소속 설비 수" 로 고르면 설비 0대인 방이 범례의 0 색으로 칠해지고 범례에 방 수가 보인다.
- **AC2** 범례 항목을 누르면 그 방들만 강조되고 우측 목록이 그 방들로 걸러진다.
- **AC3** 설비를 옮겨 방의 소속 설비 수가 바뀌면 색이 바로 바뀐다.
- **AC4** 칠하기 상태는 저장본 · TTL · GeoJSON 에 남지 않는다.
