## 요구사항
> User story : 고객사 관리자는 여러 개를 고른 상태에서 속성 칸을 한 번 바꿔 고른 것 전부에 적용할 수 있다. 값이 같으면 그 값이, 다르면 "<다양 — 3종>" 이 보여 지금 상태를 알고, 계통을 바꾸면 50대의 계통이 한 번에 바뀌고 규칙 방향이 다시 계산된다. 소속 물리존처럼 좌표로 계산하는 값은 일괄로 쓸 수 없어 계산값을 사람이 덮어쓰는 실수가 생기지 않는다. 바꾼 값에는 출처 사람이 붙고, 되돌리기 한 번에 전부 돌아온다.

오브젝트를 둘 이상 고르면(OE-UI-24) 선택 오브젝트 섹션이 일괄 편집 칸으로 바뀐다.
- 칸마다 고른 것의 값이 모두 같으면 그 값, 다르면 `<다양 — n종>` 을 보인다. 칸을 펼치면 지금 값별 개수를 보인다.
- 일괄로 쓸 수 있는 칸(R1): 설비 종류(OE-EQP-14) · 공기·물 계통(OE-PIP-02) · 방 종류(OE-SPC-17 — 같은 공간명 일괄도 이 칸으로 들어온다). 이름은 덮어쓰지 않고 [앞에 붙이기] · [번호 매기기]만 둔다.
- 계산값 칸(소속 물리존(OE-MAP-01) · 설치면 판정)은 일괄 칸을 잠그고 "좌표로 계산하는 값이라 일괄로 바꾸지 않습니다" 를 보인다.
- 일괄로 바꾼 값의 출처는 '사람' 이다(OE-UI-13). 고른 것 중 이미 같은 값이던 것은 바뀌지 않은 것으로 센다.
- 일괄 편집 한 번은 되돌리기 한 단계다(OE-UI-05). 계통을 바꾸면 규칙 방향을 다시 계산하고, 확정 전까지는 feeds 로 내보내지 않는다(OE-PIP-05).
- 적용 전에 "N개 중 M개가 바뀝니다" 를 보이고, 적용 뒤 결과를 토스트로 알린다.

## 수용 기준

- **AC1** 계통이 3개로 다른 설비 50대를 골라 계통 칸에 `<다양 — 3개>` 가 보이고, 하나로 바꾸면 50대의 계통이 그것이 된다.
- **AC2** 계통을 바꾸면 규칙 방향이 다시 계산되고 미확정으로 보인다.
- **AC3** 여러 개를 고른 상태에서 소속 물리존 칸은 잠겨 있고 이유가 보인다.
- **AC4** Ctrl+Z 한 번에 50대가 모두 원래 값으로 돌아온다.
- **AC5** 일괄로 바꾼 값 옆 출처가 '사람' 이다.
