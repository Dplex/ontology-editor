# OE-UI-07 그리드 정렬

## 관련 티켓

- [OE-OBJ-16](../E02-OBJ/OE-OBJ-16.md): 형상 기준 겹침 판정

## 요구사항
> User story : 고객사 관리자가 벽과 룸 경계를 그릴 때 3D와 평면도에 보이는 그리드에 점을 끊어 놓아 정렬된 레이아웃을 빠르게 만든다. 그리드 간격은 사이트 설정으로 바꿀 수 있어 모듈 치수가 다른 건물에도 맞춘다. 다만 겹침 판정은 그리드가 아니라 형상 기준이라, 그리드에 맞춰 놓았다고 해서 실제로 겹치는 오브젝트가 통과되지 않는다. 그리드는 3D와 평면도에서 같은 간격으로 보여 두 뷰를 오가며 작업해도 기준이 흔들리지 않고, 간격을 바꾸면 그리드가 즉시 다시 그려져 사용자가 변경 결과를 바로 확인한다.

3D 와 평면도에 그리드를 보이고, 벽·룸 경계를 그릴 때 그리드 단위로 끊어 놓을 수 있다. 그리드 간격은 사이트 설정으로 둔다. 겹침 판정(OE-OBJ-16)은 그리드가 아니라 형상 기준이다.

## 수용 기준

그리드 정렬을 켜면 찍은 점이 그리드 교점으로 옮겨진다. 간격을 바꾸면 그리드가 그에 맞게 다시 그려진다.
