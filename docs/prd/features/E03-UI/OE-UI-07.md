# OE-UI-07 그리드 정렬

## 관련 티켓

- [OE-OBJ-16](../E02-OBJ/OE-OBJ-16.md): 형상 기준 겹침 판정

## 요구사항
> User story : 고객사 관리자는 3D와 평면도에 보이는 그리드를 기준으로 벽과 룸 경계를 그리드 단위로 끊어 놓을 수 있다. 그리드 정렬을 켜면 찍은 점이 그리드 교점으로 옮겨져 정렬된 레이아웃을 빠르게 만들 수 있다. 그리드 간격은 사이트 설정으로 바꿀 수 있어 모듈 치수가 다른 건물에도 맞출 수 있고, 간격을 바꾸면 그리드가 즉시 다시 그려진다. 겹침 판정은 그리드가 아니라 형상 기준이므로, 사용자는 그리드에 맞춰 놓았다고 해서 실제로 겹치는 오브젝트가 통과되지 않는다는 것을 알 수 있어야 한다. 기존에 자유롭게 배치된 오브젝트가 있는 경우에도 강제로 정렬되지 않아 작업자의 기존 의도를 보호할 수 있다.

3D 와 평면도에 그리드를 보이고, 벽·룸 경계를 그릴 때 그리드 단위로 끊어 놓을 수 있다. 그리드 간격은 사이트 설정으로 둔다. 겹침 판정(OE-OBJ-16)은 그리드가 아니라 형상 기준이다.기존에 그리드 정렬을 끄고 배치해 둔(그리드에 어긋난) 오브젝트는 나중에 '그리드 정렬' 기능을 켜더라도 자동으로 그리드 교점으로 강제 이동되지 않고 기존 위치를 유지한다. 해당 오브젝트를 다시 이동시킬 때부터 가장 가까운 그리드 교점으로 스냅된다.

## 수용 기준

그리드 정렬을 켜면 찍은 점이 그리드 교점으로 옮겨진다. 간격을 바꾸면 그리드가 그에 맞게 다시 그려진다.
그리드 정렬이 꺼진 상태에서 배치된 오브젝트는 그리드 정렬을 다시 켜도 원래 위치(좌표)를 유지한다.
기존에 어긋나게 배치된 오브젝트를 선택해 이동(드래그)을 시도하면, 그 시점부터 가장 가까운 그리드 교점으로 스냅되어 이동된다.
