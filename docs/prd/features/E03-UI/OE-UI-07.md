# OE-UI-07 그리드 정렬

## 관련 티켓

- [OE-OBJ-16](../E02-OBJ/OE-OBJ-16.md): 형상 기준 겹침 판정

## 요구사항

3D 와 평면도에 그리드를 보이고, 벽·룸 경계를 그릴 때 그리드 단위로 끊어 놓을 수 있다. 그리드 간격은 사이트 설정으로 둔다. 겹침 판정(OE-OBJ-16)은 그리드가 아니라 형상 기준이다.

## 수용 기준

그리드 정렬을 켜면 찍은 점이 그리드 교점으로 옮겨진다. 간격을 바꾸면 그리드가 그에 맞게 다시 그려진다.
