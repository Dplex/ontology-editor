## 요구사항
> User story : 구축 담당자와 고객사 관리자는 편집하는 내내 지금 무엇을 기준으로 무엇을 고치고 있는지 화면에서 바로 안다. 헤더에서 모드와 편집 기준 버전을, 그 아래 안내 바에서 임시 저장본을 이어서 편집 중인지를 보고, 필요하면 같은 자리에서 임시 저장본을 폐기한다. 캔버스 위에는 지금 도구로 무엇을 할 수 있는지 한 줄 안내가, 아래에는 저장하지 않은 변경이 몇 건인지가, 화면 맨 아래 상태줄에는 커서 좌표·그리드·스냅·선택·편집 단계·저장 상태가 늘 보인다. 사용자는 "지금 저장된 건가?", "이 도구는 어떻게 쓰지?" 를 묻지 않고 작업을 이어 간다.

편집 중 상태를 아래 자리에 늘 보인다(자리와 모양은 OE-UI-17).
- 헤더(OE-UI-04 4번): 위치(사이트 › 건물 › 층) 옆에 모드 배지(초기 구축 · 운영 편집)와 편집 기준 버튼(운영 편집은 기준 버전 `vN`(OE-WF-13), 초기 구축은 "임포트 결과"). 버튼에는 생성 가능 · 보정 필요를 같이 보인다. [구축하기] · [반영하기]가 생성 기준 때문에 막혀 있으면 그 버튼 옆에 첫 이유(예: "구축하기 막힘 · 물리존 외곽선 29/37 (기준 85%)")를 보이고, 누르면 기준 · 검증 패널이 열린다 — 흐린 버튼만 보고 원인을 모르는 일이 없게 한다. 편집 모드 전환(공간 · 설비)은 헤더가 아니라 팔레트 맨 위에 둔다(OE-UI-04 1번).
- 기준 · 검증 패널: 편집 기준 버튼을 누르면 오른쪽에서 패널이 열려 지금 층의 생성 기준(OE-GEN-02) · 수용 기준선 등급(OE-BIM-21) · 규칙 경고(OE-P3-01)를 보인다. 3D 와 캔버스 위 조작을 가리지 않게 정보 패널 자리만 덮는 비모달 패널이다 — 열어 둔 채 3D 를 돌리고 오브젝트를 고를 수 있다. 버튼을 다시 누르거나 ✕ · Esc 로 닫고, 닫으면 포커스가 버튼으로 돌아간다. 편집하면 내용이 바로 다시 계산된다.
- 안내 바(헤더 아래 한 줄): 임시 저장본이 있으면 "임시 저장본에서 이어서 편집 중 — 기준 vN" 과 [임시 저장본 폐기](OE-WF-04)를, 없으면 무엇에서 편집 중인지와 다음 동작([반영하기]·[구축하기])을 한 줄로 보인다. 임시 저장본을 자동으로 연 것(OE-WF-02)을 사용자가 알아볼 수 있어야 한다. 새 버전 배너(OE-WF-15)와 저장 실패 같은 오류는 이 줄 위에 따로 쌓는다.
- 도구 안내(캔버스 위 가운데): 지금 도구로 할 수 있는 것과 끝내는 법(Enter 완성 · Esc 취소)을 한 줄로 보인다. 도구를 바꾸면 바로 바뀐다. 그리기 · 나누기처럼 점을 찍는 도구에서는 지금 단계를 보인다 — "첫 점을 찍으세요" → "다음 점 (3점) · Enter 완성 · Backspace 마지막 점 지우기". 그리는 중 숫자 입력 칸(OE-UI-28)이 있으면 그 사용법도 같은 줄에 보인다.
- 저장 안 된 변경(캔버스 왼쪽 아래): "● 저장되지 않은 변경 N건". N 은 마지막 임시 저장 뒤의 편집 단계 수다(OE-UI-05). 0 이면 숨긴다. [편집 종료] 확인 팝업(OE-COM-08)과 같은 기준이다.
- 상태줄(화면 맨 아래 한 줄): 커서 좌표(건물 로컬 · m, OE-INT-04) · 그리드 간격(OE-UI-07) · 스냅 켜짐(OE-UI-06) · 선택 오브젝트 · 편집 모드 · 편집 단계 수 · 저장 상태(저장 안 된 변경 N건 / 임시 저장됨 / 변경 없음) · 커서 아래 겹친 오브젝트 수와 지금 미리 강조된 것("커서 아래 n개 · i/n 이름", OE-UI-27).
- 결과 알림(토스트): 임시 저장·반영·거절처럼 동작의 결과는 캔버스 아래 가운데 한 줄로 보이고 × 로 닫는다. 층을 바꾸거나 다시 들어오면 앞 층의 알림은 지운다.

## 수용 기준

- **AC1** 운영 편집에서 헤더에 모드 배지와 기준 버전(vN) 버튼이, 초기 구축에서 "임포트 결과" 버튼이 보인다.
- **AC2** 임시 저장본이 있는 층에 들어가면 안내 바에 "임시 저장본에서 이어서 편집 중" 과 [임시 저장본 폐기]가 보이고, 폐기하면 그 줄이 사라진다.
- **AC3** 물리존 그리기 도구를 고르면 도구 안내가 그리기 안내로 바뀌고 Esc 로 취소하면 선택 안내로 돌아온다.
- **AC4** 편집을 하나 하면 "저장되지 않은 변경 1건" 이 캔버스와 상태줄에 보이고, 임시 저장하면 상태줄이 "임시 저장됨" 으로 바뀐다.
- **AC5** 평면도에서 커서를 움직이면 상태줄의 x·y 가 m 단위로 바뀐다.
- **AC6** 물리존 그리기에서 점을 셋 찍으면 도구 안내에 "3점" 과 다음 동작이 보이고, Backspace 를 누르면 마지막 점이 지워져 "2점" 이 된다.
- **AC7** 겹친 오브젝트 위에 커서를 두면 상태줄에 "커서 아래 n개" 와 미리 강조된 것의 이름이 보인다.
- **AC8** 편집 기준 버튼을 누르면 기준 · 검증 패널이 열려 생성 기준 · 수용 기준선 등급 · 규칙 경고가 보이고, 3D 캔버스와 3D/평면도 전환은 가려지지 않는다.
- **AC9** 패널을 연 채 캔버스에서 오브젝트를 고를 수 있고, Esc 를 누르면 패널이 닫히고 포커스가 버튼으로 돌아간다.
- **AC10** 생성 기준 미달로 [구축하기]가 막혀 있으면 그 옆에 첫 이유가 보이고, 누르면 기준 · 검증 패널이 열린다.
