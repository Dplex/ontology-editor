# OE-UI-22 오브젝트 변경 표시

## 관련 티켓

- [OE-WF-13](../E14-WF/OE-WF-13.md): 기준 버전
- [OE-WF-06](../E14-WF/OE-WF-06.md): 초기 구축의 기준(임포트 결과)
- [OE-UI-04](./OE-UI-04.md): 정보 패널 목록
- [OE-WF-08](../E14-WF/OE-WF-08.md): 미리보기 변경 요약
- [OE-WF-12](../E14-WF/OE-WF-12.md): 반영 전 변경 요약
- [OE-UI-17](./OE-UI-17.md): 변경 태그 부품

## 요구사항
> User story : 고객사 관리자는 편집하는 동안 오른쪽 패널의 목록과 선택 오브젝트에서 어떤 물리존·커스텀존·설비가 새로 생겼고 어떤 것이 바뀌었는지 태그로 본다. 목록 머리에는 신규·변경·삭제 개수가 모여 있어, [미리보기]를 열지 않아도 지금까지 몇 개를 고쳤는지 알고, 실수로 건드린 오브젝트를 찾아 되돌린다. 기준은 운영 편집이면 기준 버전, 초기 구축이면 임포트 결과라 미리보기와 반영 전 요약에 나오는 숫자와 같다.

오브젝트마다 기준과 비교한 변경 상태를 보인다 — 신규 · 변경 · 변경 없음. 기준은 운영 편집이면 편집 기준 버전(OE-WF-13), 초기 구축이면 임포트 결과(OE-WF-06)다.
- 목록 행(OE-UI-04 3번): 신규(파랑)·변경(주황) 태그. 변경 없음은 목록에서 생략한다.
- 선택 오브젝트: 이름 옆에 세 상태 중 하나를 늘 보인다.
- 목록 머리: 이 층의 "신규 n · 변경 n · 삭제 n". 변경이 없으면 숨긴다.
- 개수는 미리보기 변경 요약(OE-WF-08)·반영 전 변경 요약(OE-WF-12)과 같은 기준으로 센다. 이름·경계·좌표·종류 등 오브젝트의 어느 값이든 바뀌면 변경이다.
- 되돌리기로 기준과 같아지면 변경 없음으로 돌아간다. 임시 저장본을 폐기하면 모두 변경 없음이 된다.

## 수용 기준

- **AC1** 물리존 이름을 바꾸면 목록 행과 선택 오브젝트에 "변경" 이 보이고 목록 머리에 "변경 1" 이 보인다.
- **AC2** 물리존을 그려 만들면 "신규" 가 보인다.
- **AC3** 목록 머리의 신규·변경·삭제 개수가 [미리보기]의 변경 요약과 같다.
- **AC4** 되돌리기로 원래 값이 되면 "변경 없음" 으로 돌아간다.

## 메모

- 2026-10-15 와이어프레임 v0.2 ⑥ 의 물리존 목록 태그(신규·변경)와 선택 오브젝트 배지(변경 없음)에서 뽑았다. 프로토타입은 반영본(운영 편집) 또는 임포트 결과(초기 구축)와 JSON 으로 비교한다. 공조존은 아직 표시하지 않는다.
