# OE-EQP-05 설치면 편집 필터

## 관련 티켓

- [OE-EQP-03](./OE-EQP-03.md): 필터 기준 판정 설치면

## 요구사항

### User story

고객사 관리자가 천장 조명 교체 공사 결과만 DT에 반영하려 할 때, 설비 필터에서 '천장'을 고르면 바닥·벽 설비가 사라지고 천장 설비만 보여 수백 개 설비 중 대상만 빠르게 다룬다. 임포트 후 설치면이 '미정'으로 남은 설비는 필터에서 '미정'만 골라 모아 보고, 입력폼으로 천장·바닥·벽 중 어디인지 지정해 정리한다. 플레넘 속 VAV도 천장으로 묶여 보이므로, 천장 공사 영향 범위를 한 번에 확인할 수 있다.

설비가 천장/바닥/벽 어디에 있는지 구분하고 전체/천장/바닥/벽으로 고르는 필터를 둔다. 
설치면이 "미정"인 설비의 '설치면'을 어디로 설정할지 고르도록 입력폼을 제공한다. 
기준은 판정 설치면(OE-EQP-03)이며, 플레넘 설비는 천장으로 센다.

## 수용 기준

전체·천장·바닥·벽 중 하나를 고르면 그 설치면의 설비만 보인다.
"미정" 항목을 고르면 설치면을 판정하지 못한 설비만 보인다.
