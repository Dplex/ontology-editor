# OE-EQP-01 설비 마스터에서 배치

## 요구사항

설비 마스터에서 설비를 골라 3D 에 배치한다. 설비 마스터의 출처는 둘이다 — BIM/IDF 임포트로 들어온 설비와 (R2)b.IoT 태그(DT 에 등록된 설비)이다.  배치는 기존에 정의된 방식(OE-OBJ-15)에 따르고 허용 설치면(glossary "설치면 type")을 따른다. 배치 높이는 OE-EQP-02을 따른다. 

b.IoT 태그(DT에 등록된 설비)를 3D에 배치하는 방식은 추후 R2 진행 시 다시 고려한다.
