# OE-EQP-01 설비 마스터에서 배치

## 관련 티켓

- [OE-OBJ-15](../E02-OBJ/OE-OBJ-15.md): 기존 배치 방식
- [OE-EQP-02](./OE-EQP-02.md): 배치 높이 결정

## 요구사항
> User story : 구축 담당자는 설비 마스터에서 설비를 골라 3D에 배치할 수 있다. 설비 마스터에는 BIM 임포트로 들어온 설비가 있으며, R2부터는 IDF 임포트 설비와 DT에 등록된 b.IoT 태그 설비도 포함된다. 배치는 다른 오브젝트와 같은 클릭→클릭 방식으로 하고, 설비 종류별 허용 설치면 규칙이 적용되어 바닥 전용 설비를 벽에 놓을 수 없다. 배치 높이는 미배치 설비 배치와 같은 규칙을 따른다. 사용자는 설비가 어느 출처에서 왔는지와 무관하게 같은 방식으로 배치할 수 있어야 하며, DT 등록 설비의 배치 방식은 R2에서 다시 정한다.

설비 마스터에서 설비를 골라 3D 에 배치한다. 설비 마스터의 출처는 둘이다 — BIM 임포트로 들어온 설비(R2 부터 IDF 임포트 설비도)와 (R2)b.IoT 태그(DT 에 등록된 설비)이다.  배치는 기존에 정의된 방식(OE-OBJ-15)에 따르고 허용 설치면(glossary "설치면 type")을 따른다. 배치 높이는 OE-EQP-02을 따른다. 

b.IoT 태그(DT에 등록된 설비)를 3D에 배치하는 방식은 추후 R2 진행 시 다시 고려한다.
