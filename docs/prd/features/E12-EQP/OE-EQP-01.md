# OE-EQP-01 설비 마스터에서 배치

## 요구사항

설비 마스터에서 설비를 골라 3D 에 배치한다. 설비 마스터의 출처는 둘이다 — b.IoT 태그(DT 에 등록된 설비) 또는 BIM/IDF 임포트로 들어온 설비. 배치는 클릭→클릭(OE-OBJ-15)이고 허용 설치면(glossary "설치면 type")을 따른다. 배치 높이는 OE-EQP-02.

## 수용 기준

b.IoT 태그 목록에서 설비를 골라 3D 에 놓으면 그 태그 id 로 설비가 생긴다.
