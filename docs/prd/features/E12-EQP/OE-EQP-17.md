# OE-EQP-17 로봇 통과 속성 정의

## 관련 티켓

- [OE-ML-04](../E18-ML/OE-ML-04.md): 구조적 층간 연결
- [OE-ML-10](../E18-ML/OE-ML-10.md): 확인된 정차 층
- [OE-ML-19](../E18-ML/OE-ML-19.md): 층별 진입/종료 지점
- [OE-EQP-16](./OE-EQP-16.md): 통과 속성 GeoJSON 내보내기

## 요구사항

로봇 통과 속성은 이 티켓이 정한다. 
문 = 통과 가능(천장 막힘·바닥 뚫림). 
창문·벽(내벽·외벽)·내력벽 = 불가. 
수직 관통 오브젝트는 EL = 확인된 정차 층의 유효 진입/종료 지점에서만 가능, 무정차·정차 미확인 층 = 불가. 설비용 샤프트·ES·계단 = 불가. 층별 상태와 사유를 기록하며 구조적 층간 연결만으로 통과를 허용하지 않는다(OE-ML-04·10·19).
속성은 층별 GeoJSON 표현·연결 지점에 기록한다(내보내기는 OE-EQP-16). 구현·검증 여부는 검증 항목에서 별도로 확인한다.

## 수용 기준

- 문 `passable=true`, 창·벽·ES·계단·설비용 샤프트 `passable=false`.
- EL의 확인된 정차 층·유효 지점만 `passable=true`이고 무정차·정차 미확인 층은 `passable=false`이며 사유가 표시된다.
- 구조적 층간 연결은 통과 불가 속성을 덮어쓰지 않는다.
