# OE-EQP-17 로봇 통과 속성 정의

## 관련 티켓

- [OE-ML-04](../E18-ML/OE-ML-04.md): 구조적 층간 연결
- [OE-ML-10](../E18-ML/OE-ML-10.md): 확인된 정차 층
- [OE-ML-19](../E18-ML/OE-ML-19.md): 층별 진입/종료 지점
- [OE-EQP-16](./OE-EQP-16.md): 통과 속성 GeoJSON 내보내기

## 요구사항
> User story : 로봇 관제 사용자는 에디터가 내보낸 레이아웃에서 각 오브젝트의 로봇 통과 가능 여부를 확인할 수 있다. 문은 통과할 수 있고, 창문·내벽·외벽·내력벽은 통과할 수 없다. 엘리베이터는 정차가 확인된 층의 진입 지점에서만 통과할 수 있으며, 무정차 층이나 정차 여부가 확인되지 않은 층은 통과 불가로 표시되고 그 사유를 확인할 수 있다. 에스컬레이터·계단·설비용 샤프트는 층을 잇더라도 로봇이 통과할 수 없다. 사용자는 구조적으로 층이 이어져 있다는 사실만으로 로봇 통과가 허용되지 않는다는 것을 신뢰하고 경로를 판단할 수 있어야 한다.

로봇 통과 속성은 이 티켓이 정한다. 
문 = 통과 가능(천장 막힘·바닥 뚫림). 
창문·벽(내벽·외벽)·내력벽 = 불가. 
수직 관통 오브젝트는 EL = 확인된 정차 층의 유효 진입/종료 지점에서만 가능, 무정차·정차 미확인 층 = 불가. 설비용 샤프트·ES·계단 = 불가. 층별 상태와 사유를 기록하며 구조적 층간 연결만으로 통과를 허용하지 않는다(OE-ML-04·10·19).
속성은 층별 GeoJSON 표현·연결 지점에 기록한다(내보내기는 OE-EQP-16). 구현·검증 여부는 검증 항목에서 별도로 확인한다.

## 수용 기준

- **AC1** 문 `passable=true`, 창·벽·ES·계단·설비용 샤프트 `passable=false`.
- **AC2** EL의 확인된 정차 층·유효 지점만 `passable=true`이고 무정차·정차 미확인 층은 `passable=false`이며 사유가 표시된다.
- **AC3** 구조적 층간 연결은 통과 불가 속성을 덮어쓰지 않는다.
