# OE-EQP-06 배관 없는 설비 디테일

## 관련 티켓

- [OE-OBJ-10](../E02-OBJ/OE-OBJ-10.md): 배관 없는 설비 범위
- [OE-OBJ-16](../E02-OBJ/OE-OBJ-16.md): 겹침 불가 제약
- [OE-OBJ-08](../E02-OBJ/OE-OBJ-08.md): 천장 전용 종류 편집

## 요구사항
> User story : 고객사 관리자는 센서·조명·CCTV 같은 배관 없는 설비를 배치하고, 옮기고, 지우고, 이름을 고칠 수 있다. 제약은 다른 설비와 겹칠 수 없다는 것과 설비 종류별 허용 설치면뿐이며, 천장 전용 종류는 천장 편집 모드에서 다룬다. 선택한 설비는 앞에 다른 설비가 가리고 있어도 끌어와 배치할 수 있고, 끄는 중 Esc를 누르면 원래 자리로 돌아간다. 사용자가 속성에 좌표를 직접 입력할 때 건물 범위 밖 값을 넣으면 잘못된 입력일 수 있다는 안내를 받고, 칸을 비우면 원래 값으로 돌아갈 수 있어야 한다.

배관 없는 설비(센서·조명·CCTV 등, OE-OBJ-10)는 배치·이동·삭제·명칭 수정을 지원한다. 제약은 겹침 불가(OE-OBJ-16)와 허용 설치면(glossary "설치면 type")이며, 천장 전용 종류는 천장 편집 모드에서 다룬다(OE-OBJ-08).
선택한 설비는 앞에 다른 설비가 가려도 마우스로 끌어와 배치할 수 있다. 건물에서 범위 밖의 좌표를 입력하면 잘못된 입력일 수 있다고 안내를 제공하며, 칸을 비우면 원래 값으로 돌아온다.

## 수용 기준

- 끄는 중 Esc 를 누르면 설비가 원래 자리로 돌아온다.
- 건물 범위 밖 좌표를 넣으면 경고가 보인다.
