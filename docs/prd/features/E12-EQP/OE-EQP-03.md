# OE-EQP-03 설치면 자동 판정

## 요구사항

z(바닥 기준)로 천장/바닥/벽 판정: z ≤ 0.3m → 바닥, z ≥ h_c−0.3m → 천장, 그 위 h_c < z < 층고 → 플레넘(천장 설비로 본다), 사이에서 벽선 0.3m 이내 → 벽, 그 외 "미정". 임계값 사이트 설정. 층고 = Level 차. 용어는 glossary 의 "설치면 type"·"천장 관련 높이".

반자 높이(h_c)는 에디터가 정해 두지 않는다. BIM 에 있으면 그 값을 따르고, 없으면 사용자가 설정한다. 읽는 순서:
① 반자 높이를 직접 말하는 속성(FinishCeilingHeight 등)
② 건축 판본의 방 높이(Unbounded Height·방 형상의 압출 깊이). 설비 판본(MEP Space)의 방 높이는 층고와 같아 쓰지 않는다
③ 천장 부재(IfcCovering CEILING)의 높이
④ 사용자 설정(설정 단위는 Q7)
값마다 출처(BIM·사람)를 표시한다.

h_c 를 모르면 0 이나 "층고−0.6m" 로 채우지 않고 천장 판정을 "미정"으로 둔다. 사용자가 입력한 뒤에 판정한다. 설치면이 반자 부착형인 설비 중 종류를 BIM 의 IFC 클래스·이름으로 정한 설비의 z 로 추정한 값은 입력창의 기본값(후보, 출처 "계산")으로만 보인다.

z 는 설비 형상(바운딩박스)의 최저점으로 읽는다. 패밀리 삽입점이 바닥인지 중심인지에 따라 바닥 설비가 "미정"이 되는 것을 막는다(제안 — Q8).

판정 설치면이 허용 설치면(glossary 의 설치면 type) 밖이면 허용 설치면을 우선하고, 불일치 설비를 임포트 리포트에 표시한다(제안 — Q9).

## 수용 기준

성수 설비 설치면 분포 산출
반자 높이를 모르는 층은 입력 전까지 천장 판정이 "미정"이고 0 으로 채우지 않는다
판정 설치면과 허용 설치면이 다른 설비가 임포트 리포트에 나온다
