# OE-EQP-03 설치면 자동 판정

## 요구사항

z(바닥 기준)로 천장/바닥/벽 판정: z ≥ 층고−0.6m → 천장, z ≤ 0.3m → 바닥, 사이에서 벽선 0.3m 이내 → 벽, 그 외 "미정". 임계값 사이트 설정. 층고 = Level 차(방 높이 미사용)

## 수용 기준
