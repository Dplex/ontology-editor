# OE-EQP-03 설치면 자동 판정

## 관련 티켓

- [OE-BIM-02](../E05-BIM/OE-BIM-02.md): Level 차로 구한 층고
- [OE-BIM-03](../E05-BIM/OE-BIM-03.md): 판정 대상 물리존·방 높이
- [OE-BIM-07](../E05-BIM/OE-BIM-07.md): 판정 대상 설비 좌표
- [OE-BIM-12](../E05-BIM/OE-BIM-12.md): 보정된 설비 배치점

## 요구사항

설비의 설치면(천장·바닥·벽)을 z(층 바닥 기준)로 자동 판정한다 — z ≤ 0.3m 바닥, z ≥ h_c−0.3m 천장, h_c < z < 층고 플레넘(천장 설비로 본다), 그 사이에서 벽선 0.3m 이내 벽, 그 밖은 "미정". 문턱은 사이트 설정이고 층고는 Level 차다(OE-BIM-02). 용어는 glossary "천장 관련 높이"·"설치면 type".

반자 높이 h_c 는 에디터가 미리 정해 두지 않는다. BIM 에 있으면 그 값을 쓰고, 없으면 사용자가 설정한다. 읽는 순서는 ① 반자 높이 속성(FinishCeilingHeight 등) ② 건축 판본의 방 높이(Unbounded Height·방 형상 압출 깊이; 설비 판본은 쓰지 않는다) ③ 천장 부재(IfcCovering CEILING) 높이 ④ 사용자 설정(층 단위, 물리존에서 덮어씀 — Q7). 값마다 출처(BIM·사람)를 표시한다.

h_c 를 모르면 0 이나 "층고−0.6m" 로 채우지 않고 천장 판정을 "미정" 으로 둔다. 반자 부착형 종류 중 IFC 클래스·이름으로 종류가 정해진 설비의 z 로 추정한 값은 입력창의 기본값(출처 '계산')으로만 보인다.

z 는 설비 형상(바운딩박스)의 최저점으로 읽는다(Q8). 판정 설치면이 허용 설치면 밖이면 허용 설치면을 우선하고 불일치 설비를 임포트 리포트에 적는다(Q9).

## 수용 기준

- 설비의 설치면 분포(천장·바닥·벽·미정)가 BIM 임포트 시 자동 산출된다.
- h_c 를 모르는 층은 입력 전까지 천장 판정이 "미정" 이고 0 으로 채워지지 않는다.
- 판정 설치면과 허용 설치면이 다른 설비가 임포트 리포트에 나온다.
