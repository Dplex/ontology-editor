# OE-EQP-07 EL·ES 위임

## 관련 티켓

- [OE-OBJ-14](../E02-OBJ/OE-OBJ-14.md): 수직 관통 오브젝트 편집 제한
- [OE-OBJ-10](../E02-OBJ/OE-OBJ-10.md): 설비 겹침·명칭 규칙
- [OE-ML-05](../E18-ML/OE-ML-05.md): 층 편집 화면 읽기 전용

## 요구사항

엘리베이터·에스컬레이터는 수직 관통 오브젝트이므로(OE-OBJ-14) 층 편집 화면에서는 선택·속성 조회만 되고 이동·삭제는 다중층 뷰(E18)에서 지원한다. 설비로서의 규칙(겹침·명칭)은 OE-OBJ-10 을 따른다.

## 수용 기준

층 편집 화면에서 EL·ES 의 이동·삭제 핸들이 비활성이고 [다중층 뷰에서 편집] 안내가 보인다.
