# OE-EQP-07 EL·ES 위임

## 관련 티켓

- [OE-OBJ-14](../E02-OBJ/OE-OBJ-14.md): 수직 관통 오브젝트 편집 제한
- [OE-OBJ-10](../E02-OBJ/OE-OBJ-10.md): 설비 겹침·명칭 규칙
- [OE-ML-05](../E18-ML/OE-ML-05.md): 층 편집 화면 읽기 전용

## 요구사항
> User story : 고객사 관리자는 층 편집 화면에서 엘리베이터와 에스컬레이터를 선택해 속성을 볼 수 있지만 옮기거나 지울 수는 없다. 이 설비들은 여러 층을 관통하므로 한 층에서 옮기면 위아래 층과 어긋나기 때문이다. 이동·삭제 핸들은 비활성으로 보이고 [다중층 뷰에서 편집] 안내를 받아 다중층 뷰로 넘어가 모든 층을 함께 보며 수정할 수 있다. 겹침 규칙과 이름 수정 같은 설비로서의 규칙은 다른 배관 없는 설비와 같아, 사용자는 설비 목록에서 일반 설비처럼 검색하고 관리할 수 있어야 한다.

엘리베이터·에스컬레이터는 수직 관통 오브젝트이므로(OE-OBJ-14) 층 편집 화면에서는 선택·속성 조회만 되고 이동·삭제는 다중층 뷰(E18)에서 지원한다. 설비로서의 규칙(겹침·명칭)은 OE-OBJ-10 을 따른다.

## 수용 기준

층 편집 화면에서 EL·ES 의 이동·삭제 핸들이 비활성이고 [다중층 뷰에서 편집] 안내가 보인다.
