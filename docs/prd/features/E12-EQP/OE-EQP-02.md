# OE-EQP-02 미배치 설비 배치 (E6)

## 요구사항

좌표가 없는 설비는 0,0,0 으로 두지 않고 미배치 목록에 둔다(K6). 사용자가 [3D 에서 놓기] 로 바닥을 누르면 그 자리에 놓이고 좌표가 생긴다(E6).
놓이는 높이는 같은 패밀리의 높이, 없으면 바닥이다(K15). 천장 전용 종류(조명·감지기 등)는 천장 편집 모드에서 놓으며 그때 z = h_c 다(OE-OBJ-08). h_c 를 모르면 입력을 요청하고 바닥으로 채우지 않는다(OE-EQP-03). 종류를 모르는 설비는 허용 설치면을 알 수 없으므로 바닥에 놓는다.
좌표를 직접 넣을 때는 세 축을 다 넣어야 좌표가 되고, 한 축만 넣으면 좌표가 생기지 않는다.

## 수용 기준

- 좌표 없는 설비가 0,0,0 에 그려지지 않고 미배치 목록에 있다.
- [3D 에서 놓기] 로 놓은 설비의 높이가 같은 패밀리의 높이, 없으면 바닥이다.
- 천장 모드에서 h_c 를 모르는 층에 천장 설비를 놓으려 하면 입력 요청이 뜬다.
