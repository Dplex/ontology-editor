# OE-EQP-02 미배치 설비 배치 (E6)

## 요구사항

좌표 없는 설비는 미배치 목록 → 3D에서 바닥을 눌러 배치, 배치 후 좌표 생성. **높이 = 같은 패밀리의 높이, 없으면 허용 설치면의 높이(값을 지어내지 않음)**
허용 설치면에 바닥이 있으면 바닥, 천장 전용(조명·감지기 등)이면 반자 높이 h_c 다. h_c 를 모르면 입력을 요청하고 바닥으로 채우지 않는다. 종류를 모르는 설비는 허용 설치면을 알 수 없으므로 바닥이다.

## 수용 기준

0,0,0 자동 채움 없음(K6)

## 검증 (이 repo)

- [3D에서 놓기] 로 바닥을 누르면 그 자리에 놓이고, 높이는 같은 패밀리의 높이, 없으면 바닥이다 — `edit.test.ts` "미배치 설비 배치 (E6)", 성수 E-9
