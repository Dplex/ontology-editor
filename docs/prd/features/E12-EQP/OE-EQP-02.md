# OE-EQP-02 미배치 설비 배치 (E6)

## 관련 티켓

- [OE-UI-04](../E03-UI/OE-UI-04.md): 팔레트 하위 미배치 목록
- [OE-EQP-12](./OE-EQP-12.md): 배치 후 소속 물리존 재판정
- [OE-UI-05](../E03-UI/OE-UI-05.md): 배치 되돌리기 이력
- [OE-OBJ-08](../E02-OBJ/OE-OBJ-08.md): 천장 전용 설비 천장 모드 배치
- [OE-EQP-03](./OE-EQP-03.md): h_c 미상 시 입력 요청

## 요구사항
> User story : 구축 담당자가 BIM을 임포트하면 좌표가 없는 설비는 원점에 뭉쳐 그려지지 않고 미배치 목록에 정리된다. 사용자는 설비 편집 모드 팔레트의 미배치 목록에서 설비 하나를 누른 뒤 그 층 바닥을 클릭해 바로 그 자리에 배치할 수 있으며, 바닥을 클릭하기 전 Esc를 누르거나 같은 설비를 다시 누르면 배치가 취소되어 목록에 그대로 남는다. 배치된 설비는 소속 물리존이 자동 판정되고 높이는 같은 종류 설비의 높이를 참고해 채워지며, 참고할 설비가 없으면 바닥에 놓이고 그 사실을 안내받는다. 천장 전용 설비는 천장 편집 모드에서 놓고, 배치는 되돌리기로 미배치 상태로 돌릴 수 있어야 한다.

좌표가 없는 설비는 0,0,0 으로 두지 않고 미배치 목록에 둔다(K6). 설비 편집 모드의 팔레트는 미배치 설비 목록을 하위에 제공한다(OE-UI-04). 미배치 목록에서 설비 하나를 누르면 그 설비가 속한 층의 바닥을 클릭해 바로 배치할 수 있고, 클릭한 자리에 놓이며 좌표가 생긴다(E6). 별도의 [3D 에서 놓기] 버튼이나 배치 안내는 두지 않는다. 바닥을 클릭하기 전에 Esc 를 누르거나 목록에서 같은 설비를 다시 누르면 배치를 취소하고, 설비는 미배치 목록에 그대로 남는다. 바닥에 배치한 뒤에는 소속 물리존을 다시 판정하고(OE-EQP-12), 배치를 되돌리기 이력에 쌓는다(OE-UI-05). 놓이는 높이는 같은 패밀리 설비 높이의 중앙값이고, 같은 패밀리가 없으면 바닥에 두고 그 사실을 알린다(K15). 천장 전용 종류(조명·감지기 등)는 천장 편집 모드에서 놓으며 그때 z = h_c 다(OE-OBJ-08). h_c 를 모르면 입력을 요청하고 바닥으로 채우지 않는다(OE-EQP-03). 종류를 모르는 설비는 허용 설치면을 알 수 없으므로 바닥에 놓는다. 좌표를 직접 넣을 때는 세 축을 다 넣어야 좌표가 되고, 한 축만 넣으면 좌표가 생기지 않는다.

## 수용 기준

- **AC1** 좌표 없는 설비가 0,0,0 에 그려지지 않고 미배치 목록에 있다.
- **AC2** 설비 편집 모드 팔레트의 미배치 목록에서 설비를 누르고 그 층 바닥을 클릭하면, 클릭한 자리에 놓이고 미배치 목록에서 빠진다.
- **AC3** 목록에서 설비를 누른 뒤 Esc 를 누르거나 같은 설비를 다시 누르면, 바닥을 클릭해도 설비가 놓이지 않고 좌표도 생기지 않는다.
- **AC4** 놓은 설비의 높이가 같은 패밀리 설비 높이의 중앙값이다. 같은 패밀리가 없으면 바닥에 놓이고 그 사실이 알림으로 보인다.
- **AC5** 놓은 뒤 소속 물리존이 생기고, Ctrl+Z 한 번으로 미배치 상태로 돌아간다.
- **AC6** 천장 모드에서 h_c 를 모르는 층에 천장 설비를 놓으려 하면 입력 요청이 뜬다.
