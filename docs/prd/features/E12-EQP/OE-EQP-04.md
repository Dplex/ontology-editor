# OE-EQP-04 천장 설비 표시

## 관련 티켓

- [OE-OBJ-08](../E02-OBJ/OE-OBJ-08.md): 천장 편집 모드 표시
- [OE-EQP-03](./OE-EQP-03.md): h_c 미상 시 입력 요청

## 요구사항

공간 편집 모드와 설비 편집 모드의 바닥·벽 쪽에서 천장 설비는 천장 높이에 떠 있는 형상, 바닥의 발자국 링, (선택) 수직 가이드로 보인다. 이때 천장면은 그리지 않는다. 천장 편집 모드의 표시(반투명 천장면)는 OE-OBJ-08.
- 링 정의: 설비의 x·y를 바닥면(z=0)에 투영한 표시이며 크기는 설비 평면 외곽(없으면 고정 크기), 모든 천장 설비에 항상 표시한다.
- 가이드 정의: 선택한 설비에서 링까지 수직 점선을 표시하며, 선택 해제 시 가이드를 숨긴다.
- 구역 구분: 반자 부착과 플레넘 설비의 링은 구별을 위해 색을 다르게 제공한다. 

천장 설비는 두 구역으로 나뉜다(glossary "천장 관련 높이") — 반자 부착(디퓨저·그릴, 감지기, 조명, 스프링클러 헤드, 스피커, 천장형 센서, CCTV, 카세트 실내기: z ≥ h_c−0.3m, 기본 z = h_c), 플레넘(천장 속 VAV·FCU, 덕트형 실내기: h_c < z < 층고, 기본 z = h_c 바로 위). 구역은 설치면 type 표의 종류가 정한다.
천장 설비를 옮겨도 z 는 유지된다. z 는 속성 패널에서 고치고, 구역을 벗어나면 막고 이유를 보인다(Q10). h_c 를 모르면 위치를 지어내지 않고 입력을 요청한다(OE-EQP-03).


## 수용 기준

- 반자 부착 설비는 h_c 에, 플레넘 설비는 h_c 위에 그려진다.
- 천장 설비를 x·y 로 옮긴 뒤 z 가 그대로다.
- h_c 를 모르는 층에서 천장 설비를 놓기 전에 입력을 요청한다.
