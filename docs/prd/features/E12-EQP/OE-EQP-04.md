# OE-EQP-04 천장 설비 표시

## 요구사항

천장 높이에 떠 있는 형태 + 바닥 발자국 링 + 수직 가이드. 천장면 자체는 그리지 않음. **이동 시 z 유지**

천장 설비는 붙는 자리에 따라 두 구역으로 나눈다(glossary 의 "천장 관련 높이").
- 반자 부착: 디퓨저·그릴, 감지기, 조명, 스프링클러 헤드, 스피커, 천장형 센서, CCTV, 카세트 실내기. 허용 z ≥ h_c−0.3m, 기본 z = h_c.
- 플레넘: 천장 속 VAV·FCU, 덕트형 실내기. 허용 h_c < z < 층고, 기본 z = h_c 바로 위.
속성 패널에서 z 를 고쳐 구역을 벗어나면 막고 이유를 보인다(제안 — Q10). 구역은 설치면 type 표의 종류가 정한다. h_c 를 모르면(OE-EQP-03) 천장 설비 위치를 지어내지 않고 입력을 요청한다.

## 수용 기준

반자 부착 설비는 h_c 에, 플레넘 설비는 h_c 위에 표시된다
h_c 를 모르는 층에서 천장 설비를 놓기 전에 입력을 요청한다
