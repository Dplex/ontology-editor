# OE-EQP-08 실내기 디테일

## 요구사항
> User story : 고객사 관리자가 사무실 좌석 재배치로 시스템 에어컨 실내기를 옆 구역으로 옮긴다. 실내기를 끌면 냉매·드레인 배관 끝점이 따라와 배관을 다시 그리지 않아도 되고, 옮긴 뒤 담당 공조존을 다시 지정하지 않으면 Z-06(실내기 위치와 담당 공간 불일치) 경고가 떠 재지정을 잊지 않게 한다. 덕분에 운영 중 '회의실 B가 덥다'는 민원이 들어왔을 때 실제로 그 공간을 담당하는 실내기가 무엇인지 DT에서 정확히 찾을 수 있다.

시스템 에어컨 실내기(DVM 실내기)는 냉매·드레인 배관이 붙는 배관 있는 설비다(OE-OBJ-11). 옮기면 연결 배관의 끝점이 따라온다(OE-PIP-12). 시스템 에어컨 실내기는 옮긴 뒤에는 담당 공조존을 다시 지정해야 하며, 지정 하지 않을 경우 Z-06(실내기 위치와 담당 공간 불일치) 경고 대상이다(OE-ZON-05). 허용 설치면은 천장·바닥·벽(glossary 19a)이다. 

## 수용 기준

실내기를 옮기면 연결 배관 끝점이 같이 움직이고, 담당 공조존이 비거나 불일치하면 Z-06 경고가 뜬다.
