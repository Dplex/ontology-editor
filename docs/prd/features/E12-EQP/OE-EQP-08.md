# OE-EQP-08 실내기 디테일

## 요구사항

시스템 에어컨 실내기(DVM 실내기)는 냉매·드레인 배관이 붙는 배관 있는 설비다(OE-OBJ-11). 옮기면 연결 배관의 끝점이 따라온다(OE-PIP-12). 옮긴 뒤에는 담당 공조존을 다시 지정해야 하며, 지정 전에는 Z-06(실내기 위치와 담당 공간 불일치) 경고 대상이다(OE-ZON-05). 허용 설치면은 천장·벽(glossary 19a).

## 수용 기준

실내기를 옮기면 연결 배관 끝점이 같이 움직이고, 담당 공조존이 비거나 불일치하면 Z-06 경고가 뜬다.
