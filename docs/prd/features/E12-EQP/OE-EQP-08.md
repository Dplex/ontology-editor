# OE-EQP-08 실내기 디테일

## 관련 티켓

- [OE-OBJ-11](../E02-OBJ/OE-OBJ-11.md): 배관 있는 설비 규칙
- [OE-PIP-12](../E13-PIP/OE-PIP-12.md): 이동 시 배관 끝점 추종
- [OE-ZON-05](../E10-ZON/OE-ZON-05.md): Z-06 위치 불일치 경고

## 요구사항
> User story : 고객사 관리자는 시스템 에어컨 실내기를 배관 있는 설비로 다룰 수 있다. 실내기는 냉매·드레인 배관이 붙으며, 사용자가 실내기를 옮기면 연결된 배관의 끝점이 따라와 다시 그릴 필요가 없다. 실내기는 천장·바닥·벽 어디에나 설치할 수 있다. 사용자가 실내기를 옮긴 뒤에는 담당 공조존을 다시 지정해야 하며, 지정하지 않으면 실내기 위치와 담당 공간이 맞지 않는다는 경고를 받는다. 이를 통해 실내기를 옮긴 뒤에도 어느 공간을 담당하는지 정확히 관리할 수 있어야 한다.

시스템 에어컨 실내기(DVM 실내기)는 냉매·드레인 배관이 붙는 배관 있는 설비다(OE-OBJ-11). 옮기면 연결 배관의 끝점이 따라온다(OE-PIP-12). 시스템 에어컨 실내기는 옮긴 뒤에는 담당 공조존을 다시 지정해야 하며, 지정 하지 않을 경우 Z-06(실내기 위치와 담당 공간 불일치) 경고 대상이다(OE-ZON-05). 허용 설치면은 천장·바닥·벽(glossary 19a)이다. 

## 수용 기준

- **AC1** 실내기를 옮기면 연결 배관 끝점이 같이 움직이고, 담당 공조존이 비거나 불일치하면 Z-06 경고가 뜬다.
