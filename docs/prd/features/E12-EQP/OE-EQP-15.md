# OE-EQP-15 외벽 부착 설비

## 관련 티켓

- [OE-MAP-01](../E11-MAP/OE-MAP-01.md): 소속 판정 1단계(외벽 설비)
- [OE-EXT-01](../E17-EXT/OE-EXT-01.md): 외벽 판정 기준

## 요구사항
> User story : 구축 담당자가 BIM을 임포트하면 외벽 루버·외기/배기 그릴처럼 외벽에 붙는 설비를 외벽용 설비로 구분해 불러올 수 있다. 이 설비들은 실내 물리존에 속하지 않으므로 소속이 '외벽'으로 표기되며 층 정보까지만 가진다. 사용자는 외벽 부착 설비가 완전성 검사의 '방 없는 설비' 위반에서 제외되고 등급 산정 분모에서도 빠진다는 것을 확인할 수 있어야 한다. 이를 통해 실제 데이터 문제가 아닌 외벽 설비 때문에 위반 건수가 부풀려지지 않고 진짜 소속 누락 설비에만 집중할 수 있다.

외벽에 붙는 설비(외벽 루버·외기/배기 그릴 등)를 외벽용 설비로 표현한다. 
소속 물리존 없음을 허용하고 "외벽"으로 표기(층까지만). 소속 판정(OE-MAP-01)의 1단계에서 판정 제외되므로, 소속 허용 거리 안에 물리존이 있어도 그 물리존에 붙지 않는다. 
외벽에 붙는 설비는 완전성 검사 "방 없는 설비"에서 제외한다. 

## 수용 기준

- **AC1** 성수 루버 203대가 완전성 위반에서 제외되고 등급 2 분모에서 빠진다.
