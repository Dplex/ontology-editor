# OE-EQP-15 외벽 부착 설비

## 관련 티켓

- [OE-MAP-01](../E11-MAP/OE-MAP-01.md): 소속 판정 1단계(외벽 설비)
- [OE-EXT-01](../E17-EXT/OE-EXT-01.md): 외벽 판정 기준

## 요구사항
> User story : 구축 담당자가 성수 사옥 BIM을 임포트하자 외벽 루버 203대가 어느 방에도 속하지 않아 '방 없는 설비' 위반으로 쏟아진다. 외벽에 붙는 루버·외기/배기 그릴은 원래 실내 물리존을 가질 수 없는 설비이므로, 에디터가 이를 외벽용 설비로 분류해 소속을 '외벽'(층까지만)으로 표기하고 완전성 검사와 등급 2 분모에서 뺀다. 담당자는 실제 데이터 문제가 아닌 203건의 가짜 위반을 걸러 내느라 시간을 쓰지 않고 진짜 소속 누락 설비에만 집중한다.

외벽에 붙는 설비(외벽 루버·외기/배기 그릴 등)를 외벽용 설비로 표현한다. 
소속 물리존 없음을 허용하고 "외벽"으로 표기(층까지만). 소속 판정(OE-MAP-01)의 1단계에서 판정 제외되므로, 소속 허용 거리 안에 물리존이 있어도 그 물리존에 붙지 않는다. 
외벽에 붙는 설비는 완전성 검사 "방 없는 설비"에서 제외한다. 

## 수용 기준

성수 루버 203대가 완전성 위반에서 제외되고 등급 2 분모에서 빠진다.
