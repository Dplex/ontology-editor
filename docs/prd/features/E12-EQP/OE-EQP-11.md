# OE-EQP-11 스프링클러 디테일

## 요구사항

### User story

구축 담당자가 스프링클러 헤드를 천장 편집 모드에서 배치하고 소화(FP) 배관에 연결한다. 헤드를 천장 외 설치면에 놓으려 하면 막히고, FP 배관에 연결되지 않았거나 급수(DCW) 배관에만 붙은 헤드는 생성 전 검증에서 경고가 아닌 위반으로 잡혀 어느 헤드인지 표시된다. 소방 설비는 연결 누락이 곧 안전 문제이므로, 담당자는 미연결 헤드가 하나라도 있으면 온톨로지를 생성할 수 없어 누락 없이 소화 계통을 완성하게 된다.

스프링클러 헤드는 천장 전용 설비다(glossary). 
소화 배관(Flow Type FP, glossary "Flow Type")에 연결되어야 한다. 연결 필수 검사를 켠다 — 소화 배관에 연결되지 않은 헤드는 경고가 아니라 위반이다.

## 수용 기준

- 스프링클러 헤드를 천장이 아닌 설치면에 놓을 수 없다.
- 소화(FP) 배관에 연결되지 않은 스프링클러 헤드는 생성 전 검증(OE-GEN-03)에서 위반으로 나오고, 어느 헤드인지 보인다.
- 다른 Flow Type 배관(예: 급수 DCW)에만 연결된 헤드도 위반이다.
