# OE-EQP-11 스프링클러 디테일

## 요구사항
> User story : 구축 담당자는 스프링클러 헤드를 천장 전용 설비로 배치할 수 있으며, 천장이 아닌 설치면에는 놓을 수 없다. 스프링클러 헤드는 소화 배관에 연결되어야 하며, 연결 필수 검사가 켜져 있어 소화 배관에 연결되지 않은 헤드는 경고가 아니라 위반으로 처리된다. 급수 배관처럼 다른 종류의 배관에만 연결된 헤드도 위반이다. 사용자는 생성 전 검증에서 어느 헤드가 소화 배관에 연결되지 않았는지 확인할 수 있어야 하며, 미연결 헤드가 있으면 온톨로지를 생성할 수 없어 소화 계통을 빠짐없이 완성하게 된다.

스프링클러 헤드는 천장 전용 설비다(glossary). 
소화 배관(Flow Type FP, glossary "Flow Type")에 연결되어야 한다. 연결 필수 검사를 켠다 — 소화 배관에 연결되지 않은 헤드는 경고가 아니라 위반이다.

## 수용 기준

- **AC1** 스프링클러 헤드를 천장이 아닌 설치면에 놓을 수 없다.
- **AC2** 소화(FP) 배관에 연결되지 않은 스프링클러 헤드는 생성 전 검증(OE-GEN-03)에서 위반으로 나오고, 어느 헤드인지 보인다.
- **AC3** 다른 Flow Type 배관(예: 급수 DCW)에만 연결된 헤드도 위반이다.
