# OE-EQP-16 로봇 통과·연결 데이터

## 관련 티켓

- [OE-EQP-17](./OE-EQP-17.md): 내보낼 통과 속성
- [OE-ML-19](../E18-ML/OE-ML-19.md): 층간 연결 명시 지점·구간
- [OE-ROB-04](../E16-ROB/OE-ROB-04.md): 로봇 팀 데이터 선행 제공

## 요구사항
> User story : 로봇 관제 사용자는 에디터가 내보낸 레이아웃에서 각 오브젝트의 로봇 통과 속성, 방과 방이 어떤 문으로 이어지는지, 수직 관통 오브젝트가 어느 층과 어느 층을 구조적으로 잇는지를 함께 받을 수 있다. 층간 연결은 사용자가 명시한 지점과 구간이 우선이고, 정보가 없는 기존 계단실·승강로는 겹침으로 추정하되 모호한 후보는 제외된다. 사용자는 각 연결이 명시된 것인지 추정된 것인지 출처를 구분할 수 있고, 구조적으로 이어져 있다는 것과 로봇이 실제로 지날 수 있다는 것이 별도 정보로 제공되어 둘을 혼동하지 않고 경로를 판단할 수 있어야 한다.

통과 속성(OE-EQP-17), 방-문-방 `connects`, 수직 관통 오브젝트와 연관 공간의 구조적 층간 `verticalConnects`를 GeoJSON에 포함한다. 공간 경계가 없을 때의 문 연결 좌표 판정은 기존 기준을 따른다. 층간 연결은 OE-ML-19의 명시 지점·구간 우선, 정보가 없는 기존 계단실·승강로 공간의 겹침 추정, 모호 후보 제외 기준을 따른다.

층별 표현의 부모 ID·층 ID·실제 출력 ID와 연결 참조를 일관되게 기록하고 명시·추정 출처를 구분한다. 구조적 층간 연결과 로봇 통과 가능 여부는 별도로 출력한다. EL 무정차·미확인 층이나 ES·계단·설비용 샤프트에 구조적 연결이 있다는 이유만으로 로봇 통과를 허용하지 않는다.

## 수용 기준

- **AC1** 병원의 계단실·승강로 7개 중 6개 이상이 `verticalConnects`로 이어진다. 대상 ID·기대 연결·출처를 고정 기준선에 기록하고 모호 후보를 강제 연결하여 수치를 충족하지 않는다.
- **AC2** 출력 연결 참조가 실제 객체를 가리키고 명시·추정 출처와 층별 통과 상태를 구분할 수 있다.
- **AC3** 삭제·구간/형상 수정 후 비활성·재검토·잘못된 참조가 유효 층간 연결로 출력되지 않는다.
