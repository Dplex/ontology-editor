# OE-EQP-16 로봇 통과·연결 데이터

## 요구사항

통과 속성(OE-EQP-17), 방-문-방 `connects`, 수직 관통 오브젝트와 연관 공간의 구조적 층간 `verticalConnects`를 GeoJSON에 포함한다. 공간 경계가 없을 때의 문 연결 좌표 판정은 기존 기준을 따른다. 층간 연결은 OE-ML-19의 명시 지점·구간 우선, 정보가 없는 기존 계단실·승강로 공간의 겹침 추정, 모호 후보 제외 기준을 따른다.

층별 표현의 부모 ID·층 ID·실제 출력 ID와 연결 참조를 일관되게 기록하고 명시·추정 출처를 구분한다. 구조적 층간 연결과 로봇 통과 가능 여부는 별도로 출력한다. EL 무정차·미확인 층이나 ES·계단·설비용 샤프트에 구조적 연결이 있다는 이유만으로 로봇 통과를 허용하지 않는다.

## 수용 기준

- 병원의 계단실·승강로 7개 중 6개 이상이 `verticalConnects`로 이어진다. 대상 ID·기대 연결·출처를 고정 기준선에 기록하고 모호 후보를 강제 연결하여 수치를 충족하지 않는다.
- 출력 연결 참조가 실제 객체를 가리키고 명시·추정 출처와 층별 통과 상태를 구분할 수 있다.
- 삭제·구간/형상 수정 후 비활성·재검토·잘못된 참조가 유효 층간 연결로 출력되지 않는다.
