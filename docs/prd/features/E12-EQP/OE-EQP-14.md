# OE-EQP-14 종류 지정

## 관련 티켓

- [OE-PIP-07](../E13-PIP/OE-PIP-07.md): 종류 변경 후 규칙 방향 재계산
- [OE-BIM-14](../E05-BIM/OE-BIM-14.md): 사전 판정 종류 기본값

## 요구사항
> User story : 구축 담당자는 종류를 모르는 설비에 종류를 지정할 수 있다. 기본은 같은 패밀리(동일 유형 묶음) 단위로 한꺼번에 지정하는 것이며, 원하면 설비 한 대씩 따로 지정할 수도 있다. 에디터는 설비 이름, 같은 건물의 계통, 가까운 위치, 비슷한 높이를 근거로 종류 후보를 제안하지만, 후보는 보이기만 하고 사용자가 확정하기 전에는 아무것도 정해지지 않는다. 확정한 종류는 사용자 설정이 출처로 남는다. 종류가 바뀌면 설비 연결 규칙 방향이 다시 계산되어 포트와 어긋나는 계통을 바로 알 수 있으며, 사전 값으로 되돌리면 편집으로 치지 않는다.

종류 미상 설비는 기본적으로 패밀리(glossary "패밀리 / 유형") 단위로 한꺼번에 종류를 지정할 수 있고, 원할 경우 설비 한개씩 종류를 지정할 수도 있어야 한다. 에디터는 설비 이름, 같은 건물의 계통, 이웃(위치상 근접한지), 높이가 닮은 패밀리로 후보를 제안하고 사용자가  확정한다. 후보는 보이기만 하고 누르기 전에는 아무것도 정하지 않는다. 설비의 종류를 지정하는 것은 사용자가 확정하며, 출처는 '사용자 설정'이다.
설비의 종류가 바뀌면 설비 연결 규칙 방향을 다시 계산하고(OE-PIP-07), 포트와 새로 어긋나기 시작한 계통을 바로 알린다. 사전 값으로 되돌리면 편집으로 간주하지 않는다.

## 수용 기준

- **AC1** 후보 3개 안에 정답이 드는 비율이 성수에서 69~85% 이상.
- **AC2** 한 설비의 종류를 지정하면 같은 패밀리 설비 전체에 붙고 유형 이름만 같은 다른 패밀리에는 붙지 않는다.
- **AC3** 설비 한 대만 따로 종류를 지정하면 그 설비만 바뀌고, 같은 패밀리의 다른 설비는 바뀌지 않는다.
