# OE-ZON-05 검증 Z-01~Z-06

## 요구사항

공조존 검증 6규칙을 둔다 — Z-01 공백(담당 없는 물리존), Z-02 중복(두 존이 담당), Z-03 용량 초과(필요 풍량 > 설비 용량, 기준값은 OE-IDF-03 또는 OE-ZON-06), Z-04 설비 미지정 존, Z-05 토출구 없음, Z-06 실내기 위치와 담당 공간 불일치.
경고는 반영을 막지 않는다. 결과는 생성 전 검증(OE-GEN-03)과 반영 결과 리포트(OE-SYNC-04)에 든다.

## 수용 기준

- 6규칙 각각의 위반이 공조존 도구와 리포트에 경고로 보인다.
- 경고가 있어도 [반영하기] 가 막히지 않는다.
