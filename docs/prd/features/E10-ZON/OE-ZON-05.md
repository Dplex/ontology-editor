# OE-ZON-05 검증 Z-01~Z-06

## 요구사항

공조존 검증 6규칙을 둔다.

- Z-01 공백 — 어느 공조존도 담당하지 않는 물리존.
- Z-02 중복 — 두 공조존이 같은 영역을 담당.
- **Z-03 용량 초과** — 설비의 정격 풍량이 그 설비가 담당하는 공조존의 설계 풍량 합보다 작다. 입력값은 사이트가 설계한 값만 쓴다(OE-ZON-06).
  - 판정 대상은 공조존을 직접 담당하는 설비다(VAV·FCU·실내기·PAC·단일존 공조기 등). 여러 공조존에 급기하는 공조기는 동시 부하를 고려해 설계 풍량 합보다 작게 설계되는 것이 보통이므로 판정 대상에서 뺀다(Q16).
  - 설계 풍량이 물리존 단위(BIM)로만 있으면 공조존의 담당 물리존 값을 더한다. 다른 공조존과 함께 담당하는 물리존이 있으면 나눌 근거가 없으므로 추정하지 않고 "판정 불가"로 둔다.
  - 설계 풍량 또는 설비 용량이 없으면 "판정 불가"로 표시하고 어느 값이 없는지를 보인다. 판정 불가는 경고가 아니다.
- Z-04 설비 미지정 존 — 담당 설비가 없는 공조존.
- Z-05 토출구 없음 — 토출구가 하나도 없는 공조존.
- Z-06 실내기 위치와 담당 공간 불일치.

경고는 반영을 막지 않는다. 결과(경고·판정 불가 수 포함)는 생성 전 검증(OE-GEN-03)과 반영 결과 리포트(OE-SYNC-04)에 든다.

## 수용 기준

- 6규칙 각각의 위반이 공조존 도구와 리포트에 경고로 보인다. 경고가 있어도 [반영하기] 가 막히지 않는다.
- Z-03 — 정격 풍량이 담당 공조존 설계 풍량 합보다 작은 설비에 경고가 뜨고, 같거나 크면 뜨지 않는다.
- Z-03 — 기준 설계 풍량은 냉방·난방 중 큰 값이고(OE-ZON-06), 경고에 어느 값을 기준으로 했는지가 보인다.
- Z-03 — 여러 공조존에 급기하는 공조기는 설계 풍량 합보다 용량이 작아도 경고가 뜨지 않는다(판정 대상이 아니다).
- Z-03 — 설계 풍량이나 설비 용량이 없는 설비는 경고가 아니라 "판정 불가"로 보이고, 없는 값의 이름이 함께 보인다.
- Z-03 — 다른 공조존과 함께 담당하는 물리존이 있고 공조존 단위 설계 풍량이 없으면 "판정 불가"다.
