# OE-ZON-03 자동 생성분 보정

## 요구사항

IDF 임포트(E04)가 만든 공조존과 담당 설비를 수동 생성 기능(OE-ZON-01·02·04)으로 보정할 수 있다. IDF 가 만든 것은 출처 'IDF', 사람이 고친 것은 '사람' 으로 출처를 구분하고 IDF 재임포트시에도 편집 버전을 유지한다(OE-IDF-13).
