# OE-ZON-02 경계 다각형 직접 그리기

## 요구사항
> User story : 구축 담당자가 큰 개방형 사무실 하나를 창가(외주)는 FCU가, 안쪽(내주)은 AHU가 담당하는 설계를 표현하려 할 때, 물리존 경계와 무관하게 경계 다각형을 직접 그려 하나의 물리존을 두 공조존으로 나눈다. 각 공조존은 교집합 기준으로 그 물리존을 담당 물리존으로 가지므로, 창가 온도 이상이 발생하면 FCU 쪽만 점검 대상으로 좁힐 수 있다. 물리존을 억지로 둘로 쪼개지 않아도 되어 공간 관리 단위와 공조 단위를 따로 유지한다.

한 물리존을 여러 공조존으로 나눌 때(예: 외주·내주) 경계를 다각형으로 직접 그린다. 그린 경계는 물리존 경계와 무관하며 물리존 ∩ 공조존 교집합으로 매핑된다(S3).

## 수용 기준

물리존 하나를 두 공조존으로 나눠 그리면 각 공조존이 그 물리존을 담당 물리존으로 가진다.
