# OE-ZON-02 경계 다각형 직접 그리기

## 요구사항
> User story : 구축 담당자는 한 물리존을 여러 공조존으로 나눌 때 경계를 다각형으로 직접 그릴 수 있다. 큰 개방형 사무실의 창가 쪽과 안쪽을 서로 다른 설비가 담당하는 경우처럼, 물리존을 쪼개지 않고도 공조 단위를 나눌 수 있다. 그린 경계는 물리존 경계와 무관하며, 물리존과 공조존이 겹치는 부분을 기준으로 매핑된다. 사용자가 물리존 하나를 두 공조존으로 나눠 그리면 각 공조존이 그 물리존을 담당 물리존으로 가지게 되어, 공간 관리 단위와 공조 단위를 따로 유지할 수 있어야 한다.

한 물리존을 여러 공조존으로 나눌 때(예: 외주·내주) 경계를 다각형으로 직접 그린다. 그린 경계는 물리존 경계와 무관하며 물리존 ∩ 공조존 교집합으로 매핑된다(S3).

## 수용 기준

물리존 하나를 두 공조존으로 나눠 그리면 각 공조존이 그 물리존을 담당 물리존으로 가진다.
