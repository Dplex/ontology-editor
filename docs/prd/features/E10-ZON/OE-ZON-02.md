# OE-ZON-02 경계 다각형 직접 그리기

## 요구사항

한 물리존을 여러 공조존으로 나눌 때(예: 외주·내주) 경계를 다각형으로 직접 그린다. 그린 경계는 물리존 경계와 무관하며 물리존 ∩ 공조존 교집합으로 매핑된다(S3).

## 수용 기준

물리존 하나를 두 공조존으로 나눠 그리면 각 공조존이 그 물리존을 담당 물리존으로 가진다.
