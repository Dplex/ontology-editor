# OE-ZON-01 수동 공조존 생성

## 요구사항

공간 편집 모드의 공조존 도구(OE-UI-04)에서 공조존을 수동으로 만든다(E9). 공조존 지정 시 설비를 선택하여 담당하는 공조존을 지정하게 할 수 있다. 설비를 고르고 담당 물리존을 지정하면 그 물리존들의 합집합이 공조존이 된다. 설비가 놓인 물리존과 담당 공간(serviceSpace)은 다르다. IDF 가 없을 때의 공조존 생성 경로이고, IDF 로 불러온 공조존을 보정할 때도 같은 도구를 쓴다(OE-ZON-03, OE-BIM-15).

## 수용 기준

만든 공조존이 계통도의 서비스 영역에 반영된다.
