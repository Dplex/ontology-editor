# OE-ZON-01 수동 공조존 생성

## 요구사항

### User story

구축 담당자가 R1 사이트에서 공조존을 만들 때 공간 편집 모드의 공조존 도구에서 AHU-1을 고르고 그 설비가 담당하는 물리존들을 클릭해 지정하면, 지정한 물리존의 합집합이 공조존이 된다. 기계실에 놓인 AHU의 설치 위치와 그것이 바람을 보내는 담당 공간이 다르다는 것이 자연스럽게 표현된다. 만든 공조존은 계통도의 서비스 영역에 반영되어, 운영 담당자가 AHU-1 고장 알림을 받으면 영향받는 사무실을 계통도에서 바로 본다.

공간 편집 모드의 공조존 도구(OE-UI-04)에서 공조존을 수동으로 만든다(E9). 공조존 지정 시 설비를 선택하여 담당하는 공조존을 지정하게 할 수 있다. 설비를 고르고 담당 물리존을 지정하면 그 물리존들의 합집합이 공조존이 된다. 설비가 놓인 물리존과 담당 공간(serviceSpace)은 다르다. R1 의 유일한 공조존 생성 경로다(OE-BIM-15). R2 에서 IDF 로 불러온 공조존을 보정할 때도 같은 도구를 쓴다(OE-ZON-03).

## 수용 기준

만든 공조존이 계통도의 서비스 영역에 반영된다.
