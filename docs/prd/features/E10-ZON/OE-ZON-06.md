# OE-ZON-06 용량 검증 입력값(설계 풍량 · 설비 용량)

## 요구사항

용량 검증 Z-03(OE-ZON-05)은 **사이트가 설계한 값**만 쓴다. 에디터는 설계 풍량이나 설비 용량을 추정하지 않고, 기본값을 미리 정해 두지 않는다. 환기 횟수·실 높이로 필요 풍량을 계산하지 않는다.

Z-03 의 입력값은 둘이며, 각각 아래 순서로 읽는다. 앞의 값이 있으면 뒤는 보지 않는다.

**설계 풍량(공간 쪽)**
1. IDF — 존별 설계 풍량(`Sizing:Zone`, OE-IDF-03). 공조존 단위 값이다.
2. BIM — 물리존(IfcSpace)의 설계 급기 풍량. IFC2x3·IFC4 는 `Pset_SpaceThermalDesign`, IFC4.3 은 `Pset_SpaceAirHandlingDimensioning` 에서 읽는다(R26 제안, OE-REQ-07). 냉방·난방 설계 풍량이 둘 다 있으면 큰 값을, 하나만 있으면 그 값을 쓴다(Q16). Z-03 은 공간이 가장 많은 바람을 필요로 하는 순간과 견주는 검사이기 때문이다. 어느 값을 썼는지(냉방/난방)를 Z-03 결과에 같이 보인다.
3. 사용자 입력 — 공조존 또는 물리존 단위로 직접 넣는다. 출처 '사람'.

**설비 용량(설비 쪽)**
1. BIM — 설비의 정격 풍량(R9, OE-BIM-07).
2. IDF — 설비 용량(OE-IDF-02).
3. 사용자 입력 — 설비 단위로 직접 넣는다. 출처 '사람'.

값마다 출처(IDF·BIM·사람)를 표시한다(OE-UI-13). 단위는 읽을 때 환산해 화면에는 CMH 로 보인다(K9).
어느 쪽이든 값이 없으면 비워 두며, 그 공조존·설비의 Z-03 은 "판정 불가"가 된다(OE-ZON-05).

## 수용 기준

- 설계 풍량·설비 용량이 IDF·BIM·사용자 입력 어디에도 없으면 값이 비어 있고, 에디터가 채운 기본값이 없다.
- IDF 와 BIM 에 같은 공조존의 설계 풍량이 모두 있으면 IDF 값을 쓰고 출처가 'IDF' 로 보인다.
- BIM 의 m³/s 값이 화면에 CMH 로 환산되어 보인다.
- 냉방·난방 설계 풍량이 둘 다 있으면 큰 값으로 판정되고, 결과에 "냉방"·"난방" 중 쓴 쪽이 보인다. 하나만 있으면 그 값으로 판정된다.
- 사용자가 값을 넣으면 출처가 '사람'으로 바뀌고 Z-03 이 다시 판정된다.
