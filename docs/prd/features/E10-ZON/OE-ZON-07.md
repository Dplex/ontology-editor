# OE-ZON-07 존↔방 매칭 확인 플로우

## 관련 티켓

- [OE-IDF-05](../E04-IDF/OE-IDF-05.md): IDF 존↔물리존 겹침 매칭

## 요구사항

### User story

R2에서 구축 담당자가 IDF를 임포트하면 존↔물리존 겹침 매칭이 '계산' 출처로 초안으로 나온다. 담당자는 공조존 도구에서 이 초안을 하나씩 확인하고 확정하며, 확인하지 않은 매칭은 온톨로지에 나가지 않아 추정값이 운영 데이터에 섞이지 않는다. 반면 IDF에 명시된 설비↔존 담당 관계는 설계자가 적은 값이라 확인 없이 반영되어, 담당자는 불확실한 부분에만 검토 시간을 쓴다. 확인 플로우에서 승인한 매칭은 출처 '사람'으로 남아 나중에 IDF를 다시 가져와도 유지되므로, 담당자가 수백 개 존을 한 번 검토해 두면 재임포트 때 같은 확인을 반복하지 않는다.

IDF 존↔물리존 겹침 매칭(OE-IDF-05, 출처 '계산')은 공조존 도구(공간 편집 모드)에서 사용자가 확인한 뒤 확정한다. 확인하지 않은 매칭은 온톨로지에 나가지 않는다. IDF 에 적힌 설비↔존 담당은 명시된 값이라 이 확인을 거치지 않는다(D13).
