# OE-ZON-07 존↔방 매칭 확인 플로우

## 관련 티켓

- [OE-IDF-05](../E04-IDF/OE-IDF-05.md): IDF 존↔물리존 겹침 매칭

## 요구사항
> User story : R2에서 구축 담당자는 IDF 존과 물리존의 겹침 매칭 초안을 공조존 도구에서 확인하고 확정할 수 있다. 매칭 초안은 계산으로 만든 것이라 사용자가 확인하기 전에는 온톨로지에 나가지 않는다. 반면 IDF에 명시된 설비와 존의 담당 관계는 설계자가 적은 값이므로 확인 없이 반영된다. 사용자는 불확실한 존↔방 연결에만 검토 시간을 쓸 수 있어야 하며, 한 번 확인한 매칭은 출처 '사람'으로 남아 IDF를 다시 가져와도 유지되어 같은 확인을 반복하지 않는다.

IDF 존↔물리존 겹침 매칭(OE-IDF-05, 출처 '계산')은 공조존 도구(공간 편집 모드)에서 사용자가 확인한 뒤 확정한다. 확인하지 않은 매칭은 온톨로지에 나가지 않는다. IDF 에 적힌 설비↔존 담당은 명시된 값이라 이 확인을 거치지 않는다(D13).
