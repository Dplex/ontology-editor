## 요구사항

물리존은 에디터가 편집하는 공간 구획이며 온톨로지 공간 계층(사이트>건물>층>물리존)의 말단이다(glossary). 임포트 때는 IfcSpace 하나가 물리존 하나가 된다(D15).
물리존은 방번호와 공간명을 가진다. 방번호는 물리존의 식별자(IfcSpace 의 Name, 수동 생성 시 사용자 입력)로 한 층 안에서 고유하다. 공간명(예: 회의실·식당·임원석·사무석)은 물리존마다 하나이며 같은 이름의 방이 여러 개 있을 수 있다. 공간명은 이상 알림의 '발생 위치' 와 탐색기(뷰어마스터)에 연동된다(OE-SPC-05).
물리존은 생성·분할·병합·삭제(OE-SPC-02), 공간명 수정(OE-SPC-01), 경계 꼭짓점 편집(OE-SPC-03)을 지원한다. 각 동작은 설비의 소속 물리존과 공조존 매핑을 바꾸므로 자동 재매핑 대상이다(OE-MAP-01·02).
한 층에는 물리존이 최소 1개 있어야 하고 층 자체는 지울 수 없다. 물리존을 지워도 층에 구멍이 생기지 않는다 — 비는 자리는 사용자가 이웃 물리존과 합치기(OE-SPC-02)로 채우고, 안에 있던 설비는 좌표로 다시 소속을 찾는다(OE-SPC-04).
계통도의 서비스 영역은 공조존 기준이므로 물리존 편집과 직접 연동되지 않고, 물리존↔공조존 매핑을 통해 간접 반영된다.

## 수용 기준

- 한 층 안에서 방번호가 같은 물리존을 두 개 만들 수 없다(중복 입력 차단). 공간명은 중복을 막지 않는다.
- 물리존에 속하지 않은 설비가 없다(외벽 부착 설비 제외, OE-EQP-15).
- 물리존이 하나도 없는 층을 만들 수 없다.
