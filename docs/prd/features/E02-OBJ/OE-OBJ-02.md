# OE-OBJ-02 물리존 편집 범위

## 요구사항

BIM 정보를 기반으로 '물리 존'이 자동 생성되어야 한다.  
사용자는 원하는 층의 물리존을 지정하고 이름을 설정·수정할 수 있다. (예: 회의실, 식당, 임원석, 사무석)
물리존의 생성·분할·병합·삭제· 공간명(물리존 당 고유 1개) 수정 · 이동 · x/y/z 늘리기/줄이기를 지원한다. 각 동작은 설비의 소속 물리존 변경 및 공조존 매핑 갱신을 유발하므로 자동 온톨로지 갱신 대상이다
물리존 공간명은 추후 Digital Twin 서비스에 이상 알림의 '발생 위치', '탐색기(뷰어마스터)' 등에 연동된다. 계통도의 서비스 영역은 공조존 기준이므로 물리존 편집과 직접 연동되지 않으며, 물리존 매핑 온톨로지 갱신을 통해 간접 반영된다.
물리존 삭제 제약 : 한 층당 최소 1개의 물리존이 존재해야 한다.
물리존 삭제 제약 : 층 자체는 삭제될 수 없지만 특정 기본 공간 오브젝트(물리존-룸, 벽/공간존)는 삭제 가능하다.삭제 시 해당 공간에 존재하는 물리존이 사라진다 해서 층에 구멍이 생기는 것은 아니다.특정 오브젝트 삭제로 기존 '물리존'이 사라지게 되는 경우, 바로 근접한 '물리존'으로 해당 공간이 자동 귀속된다. 

## 수용 기준

공간명 중복 입력 차단
물리존에 속하지 않은 설비 존재 방지 
물리존이 없는 층 존재 방지
