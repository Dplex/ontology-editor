# OE-OBJ-04 외벽

## 요구사항
> User story : 구축 담당자가 BIM을 임포트하면 건물 바깥과 접한 벽이 외벽으로 자동 판정된다. 고객사 관리자는 층 편집 화면에서 외벽을 선택해 속성을 볼 수 있지만, 외벽을 옮기거나 지우거나 크기를 바꿀 수는 없다. 외벽 형상은 전체 층을 한 번에 다루는 별도 외벽 에디터에서만 편집할 수 있어 한 층만 고쳐 층간 외곽이 어긋나는 일이 없다. 사용자는 층 편집 화면에서 외벽 위에 외기 온습도 센서·루버 같은 외벽 전용 설비와 문·창을 배치할 수 있어야 한다.

외벽은 건물 바깥과 접한 벽이다(glossary). 외벽 여부는 임포트 때 판정한다(OE-EXT-01).
외벽의 형상(생성·삭제·이동·x·y·z 크기)은 층 단위가 아니라 전체 층을 한 번에 다루는 별도 외벽 에디터에서 편집한다(OE-EXT-03, PRD 1.4). 층 편집 화면에서는 외벽을 선택하고 속성을 볼 수 있을 뿐 옮기거나 지우거나 크기를 바꿀 수 없다(OE-EXT-02).
층 편집 화면에서 외벽에 할 수 있는 것은 외벽 전용 설비(예: 외기 온·습도 센서, 루버)와 문·창의 배치다(OE-EXT-04, OE-OBJ-07).

## 수용 기준

- **AC1** 층 편집 화면에서 외벽의 이동·삭제·크기 조절 핸들이 비활성이다.
- **AC2** 층 편집 화면에서 외벽에 외벽 전용 설비와 문·창을 배치할 수 있다.
