## 요구사항

외벽은 건물 바깥과 접한 벽이다(glossary). 외벽 여부는 임포트 때 판정한다(OE-EXT-01).
외벽의 형상(생성·삭제·이동·x·y·z 크기)은 층 단위가 아니라 전체 층을 한 번에 다루는 별도 외벽 에디터에서 편집한다(OE-EXT-03, PRD 1.4). 층 편집 화면에서는 외벽을 선택하고 속성을 볼 수 있을 뿐 옮기거나 지우거나 크기를 바꿀 수 없다(OE-EXT-02).
층 편집 화면에서 외벽에 할 수 있는 것은 외벽 전용 설비(예: 외기 온·습도 센서, 루버)와 문·창의 배치다(OE-EXT-04, OE-OBJ-07).

## 수용 기준

- 층 편집 화면에서 외벽의 이동·삭제·크기 조절 핸들이 비활성이다.
- 층 편집 화면에서 외벽에 외벽 전용 설비와 문·창을 배치할 수 있다.
