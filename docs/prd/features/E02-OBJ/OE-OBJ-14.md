# OE-OBJ-14 수직 관통 오브젝트

## 요구사항

수직 관통 오브젝트는 엘리베이터(EL)·에스컬레이터(ES)·계단·샤프트다(glossary). 물리존이 아닌 별도 분류이며 전 층에 공통인 평면 위치를 가진다.
수직 관통 오브젝트는 한 층 화면에서 편집하지 않는다. 속한 모든 층을 함께 보이는 수직 관통 오브젝트의 생성·이동·구간 변경·삭제는 다중층 뷰에서만 한다(OE-ML-01~09). 층 편집 화면에서는 선택·속성 조회만 되고, 속성 패널의 [다중층 뷰에서 편집] 으로 다중층 뷰를 연다 — 계단·샤프트는 공간 편집 모드, EL·ES 는 설비 편집 모드에서(OE-UI-04, OE-ML-01 ②).
데이터 모델은 OE-ML-02 를 따른다.

## 수용 기준

- 수직 관통 오브젝트가 관통하는 모든 층에 같은 평면 위치로 표시된다.
- 층 편집 화면에서 수직 관통 오브젝트를 끌면 움직이지 않고 [다중층 뷰에서 편집] 안내가 보인다.
- 다중층 뷰에서 옮기면 관통하는 모든 층에서 같은 평면 위치로 함께 옮겨진다(OE-ML-07).
