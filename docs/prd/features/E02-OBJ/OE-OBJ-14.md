## 요구사항

수직 관통 오브젝트는 엘리베이터(EL)·에스컬레이터(ES)·계단·샤프트다(glossary). 물리존과 구분하는 별도 오브젝트이며 연관 물리존은 ID로 연결한다. 샤프트·EL 승강로는 공통 수직 축을 사용하고, 계단·ES는 R1부터 층별 위치·형상과 서로 다른 진입/종료 지점을 지원한다(OE-ML-02).
수직 관통 오브젝트는 한 층 화면에서 편집하지 않는다. 속한 모든 층을 함께 보이는 수직 관통 오브젝트의 생성·이동·크기/층별 형상 수정·구간 변경·삭제는 다중층 뷰에서만 한다(OE-ML-01~09). 층 편집 화면에서는 선택·속성 조회만 되고, 속성 패널의 [다중층 뷰에서 편집] 으로 다중층 뷰를 연다 — 계단·샤프트는 공간 편집 모드, EL·ES 는 설비 편집 모드에서(OE-UI-04, OE-ML-01 ②).
데이터 모델은 OE-ML-02 를 따른다.

## 수용 기준

- 같은 부모 오브젝트 ID 아래 샤프트·EL 승강로의 공통 축과 계단·ES의 층별 형상·연결 지점이 표시된다.
- 층 편집 화면에서 수직 관통 오브젝트를 끌면 움직이지 않고 [다중층 뷰에서 편집] 안내가 보인다.
- 다중층 뷰에서 전체 이동하면 모든 층별 형상·연결 지점에 같은 이동량이 적용되고 기존 상대 위치가 유지된다. 계단·ES의 층별 형상·크기를 수정할 수 있다(OE-ML-07).
