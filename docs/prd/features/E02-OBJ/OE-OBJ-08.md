# OE-OBJ-08 바닥 / 천장

## 요구사항

기본 편집 모드: 벽·룸·문·창·물리존·커스텀존·바닥 설비·벽 설비를 편집한다. 천장면은 그리지 않고, 천장 설비는 바닥 발자국 링 + (선택) 수직 가이드로만 표시한다. 천장 설비 클릭 시 선택·속성 조회는 되지만 편집 핸들은 비활성, "천장 편집 모드에서 편집" 안내

천장 편집 모드 : 상단 액션바 또는 팔레트의 [천장 편집] 토글(단축키 제공)로 진입·종료. 진입 시 현재 선택 해제·진행 중 조작 종료, 카메라를 상단 시점으로 전환하고 천장면을 반투명으로 그린다(방위는 바닥 평면과 동일 — 반사 천장도 관례). 종료 시 기본 모드로 복귀하고 천장면을 지운다. 모드는 UI 상태이며 저장하지 않는다. 천장 편집 모드에서 벽·룸·문·창·물리존·커스텀존·바닥/벽 설비·배관은 컨텍스트(회색/투과)로 표시하고 선택·속성 조회만 가능, 이동·삭제·크기 조절·추가 불가. 팔레트의 바닥면 도구(벽 그리기·룸·문·창·커스텀존)는 비활성. 클릭 시 "기본 편집 모드에서 편집" 안내한다. 천장 모드에서 천장 설비를 배치·이동·삭제·명칭 수정·종류 지정한다. 이동은 x·y만(z는 속성 패널에서 수정하므로 z는 고정이다). 겹침 불가. 소속 물리존은 x·y 평면으로 판정(천장 속 설비도 아래 방 소속 — K 규칙 유지)


설비 별로 허용 설치면에 ceiling이 없는 종류는 천장 모드에서 배치·드롭·이동 불가하게차단한다. 
차단된 설비 표시 : 설비 붉게 하이라이트 + 툴팁 "천장에 설치할 수 없는 설비입니다". 

설비 마스터 목록도 천장 가능 종류만 필터링 할 수 있어야 한다. 
종류 미상 설비는 종류 지정 후 가능 기본 편집 / 천장 편집 모드에 맞게 제공되어야 한다. 

설비 별 천장, 바닥, 벽 설치 가능 스펙은 [glossary 의 "설치면 type"](../../glossary.md#설치면-type)을 따른다. 이 문서와 glossary 가 다르면 glossary 가 우선한다.

천장 설비의 설치 위치(glossary 의 "천장 관련 높이"):
- 천장은 반자(천장 마감면, h_c) 기준이다. 천장 설비는 반자 부착(디퓨저·그릴, 감지기, 조명, 스프링클러 헤드, 스피커, 천장형 센서, CCTV, 카세트 실내기: z ≥ h_c−0.3m, 기본 z = h_c)과 플레넘(천장 속 VAV·FCU, 덕트형 실내기: h_c < z < 층고)으로 나뉜다. 어느 구역인지는 설치면 type 표의 종류가 정한다.
- h_c 는 BIM 에 있으면 그 값을 따르고, 없으면 사용자가 설정한다(읽는 순서는 OE-EQP-03). h_c 를 모르는 층은 천장 편집 모드로 들어갈 때 또는 천장 설비를 놓기 전에 입력을 요청한다. 입력 전에는 천장 설비를 놓지 못하고, 0 이나 층고로 채우지 않는다.
- 천장 모드의 z 수정이 위 구역을 벗어나면 막고 이유를 보인다(제안 — Q10).
