# OE-OBJ-15 인터랙션 원칙

## 요구사항

드래그 앤 드롭이 아닌 **클릭 → 클릭**으로 설비를 배치할 수 있어야 한다. 
배관 수정 시 배관을 드래그 하면 원하는 방향으로 배관의 길이가 변경된다. 
편집 툴 상에서 설비를 드래그 하면 마우스가 이동한 방향으로 설비 위치가 변경된다. 
기본 공간 오브젝트 및 추가 공간 오브젝트도 설비와 동일한 인터랙션을 제공한다.
