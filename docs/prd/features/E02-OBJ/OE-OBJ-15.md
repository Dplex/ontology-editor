# OE-OBJ-15 인터랙션 원칙

## 관련 티켓

- [OE-PIP-10](../E13-PIP/OE-PIP-10.md): 꼭짓점·구간 끌어 배관 수정

## 요구사항

설비·기본 공간 오브젝트·추가 공간 오브젝트는 같은 인터랙션을 쓴다.
배치는 팔레트나 설비 마스터에서 대상을 고른 뒤 3D 위 자리를 눌러 놓는 클릭→클릭 방식이다. PoC 의 3D 끌기(드래그로 옮기기)도 함께 유지한다(D16).
이동은 고른 오브젝트를 끌어 마우스가 간 방향으로 옮긴다. 배관은 꼭짓점이나 구간을 끌어 길이와 방향을 바꾼다(OE-PIP-10).
**버튼을 떼면 그 자리로 확정한다.** 끄는 중 Esc 를 누르거나 창이 포커스를 잃으면(다른 창으로 전환 등) 취소하고 원래 자리로 돌린다.
시점은 지도식으로 바꾼다(Google Maps 3D·Mapbox 와 같은 배치).

| 입력 | 동작 |
|---|---|
| 왼쪽 클릭 | 고르기 · 놓기 |
| 고른 오브젝트 위 왼쪽 드래그 | 오브젝트 옮기기 |
| 빈 곳·고르지 않은 오브젝트 위 왼쪽 드래그 | 화면 이동(바닥면을 따라) |
| Shift+왼쪽 드래그 | 회전·기울이기(노트북·트랙패드용) |
| 오른쪽 드래그 | 회전·기울이기 |
| 휠 | 확대·축소 |

이렇게 정한 이유는 셋이다.

- 이 앱은 왼쪽 버튼이 고르기·놓기·끌기를 맡는 편집기다.
- 일의 대부분은 층을 내려다보며 하는 일이라 이동이 회전보다 잦다.
- 쓰는 사람은 지도 조작에 익숙하다.

PoC 는 지금 왼쪽 드래그가 회전이고, Shift+왼쪽 드래그와 오른쪽 드래그가 화면 이동이다(three.js `OrbitControls` 기본값). 위 표는 three.js `MapControls` 의 기본 배치와 같다.

끌리는 것은 고른 오브젝트뿐이다. 그래서 빈 곳이나 고르지 않은 오브젝트 위에서 시작한 왼쪽 드래그는 언제나 화면 이동이다. 시점을 바꾸려다 오브젝트를 옮기는 일이 없게 하려는 것이다.

키보드로 시점을 옮기는 것(WASD·Q/E)은 두지 않는다. W·D·E 는 이미 단축키이고, 방향키는 고른 설비를 옮기는 키다. 처음 쓰는 사람을 위해 3D 화면 구석에 "드래그: 이동 · Shift/우클릭 드래그: 회전" 을 보인다.

## 수용 기준

- 설비·벽·룸·문·창·추가 공간 오브젝트를 클릭→클릭으로 놓을 수 있다.
- 고른 오브젝트를 끌다가 버튼을 떼면 그 자리에 남는다. 끄는 중 Esc 를 누르거나 창이 포커스를 잃으면 원래 자리로 돌아간다.
- 빈 곳이나 고르지 않은 오브젝트 위에서 왼쪽 드래그하면 화면이 바닥면을 따라 이동하고, 오브젝트는 움직이지 않는다.
- Shift+왼쪽 드래그와 오른쪽 드래그는 둘 다 시점을 돌리고 기울인다. 휠은 확대·축소다.
- 3D 화면에 시점 조작 안내가 보인다.
