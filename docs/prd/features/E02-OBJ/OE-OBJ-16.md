# OE-OBJ-16 겹침 불가 원칙

## 요구사항

오브젝트는 같은 자리에 겹쳐 존재할 수 없다.
겹침은 두 오브젝트의 점유 영역(형상 외곽을 감싼 상자)이 3차원으로 겹치는 것이다. 맞닿는 것은 겹침이 아니고, 평면에서만 겹쳐 보이고 높이가 다르면 겹침이 아니다. 점유 영역은 그리드(OE-UI-07)와 무관하게 형상 기준이다.

| 오브젝트 | 겹침 |
|---|---|
| 배관 없는 설비(OE-OBJ-10) | 불가 |
| 배관·덕트가 붙는 설비(OE-OBJ-11) | 허용 (이음쇠와 형상이 맞물리는 것이 정상) |
| 추가 공간 오브젝트(OE-OBJ-09) | 불가 |
| 룸(OE-OBJ-03) | 불가 (룸끼리) |
| 벽·문·창 | 이 원칙 밖 (벽은 관통 금지 규칙으로 따로 막는다, OE-OBJ-05) |
| 물리존·커스텀존 | 이 원칙 밖 (커스텀존끼리는 겹칠 수 있다, OE-SPC-07) |

BIM 이 이미 겹치게 둔 오브젝트는 열 때 막지 않고 그대로 둔다. 편집이 새로 만드는 겹침만 막는다.

## 수용 기준

- 이동·배치·좌표 입력·층 이동·추가로 겹침이 생기는 시도는 차단되고 오브젝트는 원래 상태로 남는다.
- 차단 시 표시는 OE-SPC-15 를 따른다.
- 맞닿는 배치와 BIM 이 원래 겹치게 둔 쌍은 차단하지 않는다.

## 검증 (이 repo)

- `src/lib/overlap.test.ts`: 상자(IFC 좌표)·맞닿음 여유 1cm·배관 없는 설비 가르기·새 겹침만 막기·미배치 놓기
- `e2e/overlap.spec.ts`: 좌표 없는 온도센서를 조명 자리에 놓으면 막히고, 비켜 놓으면 놓이며, 다시 조명 쪽으로 옮기면 막힌다
- `e2e/conduit-follow.spec.ts` 등 기존 화면 테스트가 그대로 통과(덕트·배관이 붙는 설비는 규칙 밖)
- 화면: `docs/figures/app-overlap-refused.png` (Duplex MEP Level 1, 벽등 #575490 을 #575488 자리로)

## 메모

- PoC 는 설비부터 적용했다(배관 없는 설비끼리, OE-OBJ-10). 벽끼리는 관통 금지(OE-OBJ-05, 끝 맞대기는 됨)로 따로 막는다.
  "같은 그리드" 는 격자가 아니라 형상 상자(축 정렬, 맞닿음 여유 1cm)로 판정한다. 형상이 없는 설비는 3D 가 그리는 0.4m 상자다.
- 표의 "불가" 중 추가 공간 오브젝트(OE-OBJ-09)·룸(OE-OBJ-03)은 에디터에 아직 그 오브젝트가 없다. 오브젝트를 만들 때 같은 판정
  (`src/lib/overlap.ts` 의 상자 겹침, 룸은 외곽선 겹친 넓이)을 붙일 예정이다. 물리존·커스텀존은 표대로 이 원칙 밖이다.
- 실제 BIM 에서 이미 겹쳐 있는 배관 없는 설비 쌍: ifc4Mep 0 · Duplex MEP 0 · Office_A 0 · 성수 기계 0 · dental_clinic 1(거울과
  손잡이) · 성수 건축 16(같은 자리의 CCTV 등). 원본이 겹치게 둔 것은 막지 않고, 편집이 새로 만드는 겹침만 막는다.
