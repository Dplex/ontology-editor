# OE-OBJ-16 겹침 불가 원칙

## 요구사항

오브젝트는 같은 자리에 겹쳐 존재할 수 없다.
겹침은 두 오브젝트의 점유 영역(형상 외곽을 감싼 상자)이 3차원으로 겹치는 것이다. 맞닿는 것은 겹침이 아니고,
평면에서만 겹쳐 보이고 높이가 다르면 겹침이 아니다. 점유 영역은 그리드(OE-UI-07)와 무관하게 형상 기준이다.

| 오브젝트 | 겹침 |
|---|---|
| 배관 없는 설비(OE-OBJ-10) | 불가 |
| 배관·덕트가 붙는 설비 | 허용 (이음쇠와 형상이 맞물리는 것이 정상) |
| 벽·문·창 | 이 원칙 밖 (벽은 관통 금지 규칙으로 따로 막는다) |
| 룸·공간 오브젝트 | 이 원칙 밖 (룸 겹침은 OE-SPC-07) |

BIM 이 이미 겹치게 둔 오브젝트는 열 때 막지 않고 그대로 둔다. 편집이 새로 만드는 겹침만 막는다.

## 수용 기준

- 이동·배치·좌표 입력·층 이동·추가로 겹침이 생기는 시도는 차단되고, 오브젝트는 원래 상태로 남는다.
- 차단 시 표시는 OE-SPC-15 를 따른다.
- 맞닿는 배치와 BIM 이 원래 겹치게 둔 쌍은 차단하지 않는다.
