## 요구사항

커스텀존(=운영존)은 물리존 위에 운영 편의로 지정하는 다각형 단위다(glossary). 사용자가 원하는 영역을 다각형으로 그려 만들고, 이름과 별명을 붙인다. 
커스텀존은 생성·분할·병합·삭제·이름 수정을 지원한다(OE-SPC-08). 커스텀존을 만들거나 고치면 물리존·공조존과의 매핑이 갱신되어 온톨로지에 자동 반영된다(OE-SPC-09).
커스텀존끼리는 서로 겹칠 수 있다(Q4, OE-SPC-07).
AI Agent 는 커스텀존을 질의 단위로 쓴다 — 커스텀존 기준으로 온도·에너지·설비 위치를 물을 수 있어야 한다(OE-SPC-10).
3D 에서는 물리존과 다른 층(레이어)으로 겹쳐 그린다.

## 수용 기준

- 커스텀존을 그리고 이름·별명을 붙인 뒤 반영하면 온톨로지에 그 커스텀존과 물리존 매핑이 들어간다.
- 분할·병합·삭제 뒤에도 매핑이 갱신된다.
- 커스텀존끼리 겹치게 그려도 차단되지 않는다.
