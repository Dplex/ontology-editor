# OE-OBJ-01 커스텀존 편집 범위

## 요구사항

기존에 존재하는 '커스텀 존'에 대한 분할 · 병합 · 삭제 · 별명(커스텀 존 당 1개) 수정이 가능함. 
'커스텀 존'이 신규 생성 및 수정 되는 경우 온톨로지에 자동 반영됨.
사용자는 원하는 커스텀존을 '다각형' 단위로 지정하고 이름을 설정·수정할 수 있다. (예: 회의실, 식당, 임원석, 사무석)
커스텀 존은 서로 겹쳐서 설정할 수 있다.  
커스텀존의 생성·분할·병합·삭제를 지원한다.
커스텀존의 수정은 물리존-공조존과 모두 매핑되어 온톨로지에 갱신되어야 한다. 
커스텀 존 기준으로 에이전트를 통해 질의 시 온도, 에너지, 설비 위치 등을 전달할 수 있어야 한다. 

## 수용 기준

커스텀 존 자유 편집이 가능해야 함. 
커스텀 존 편집 후 온톨로지에 반영되어야 함.
