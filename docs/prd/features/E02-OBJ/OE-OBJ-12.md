# OE-OBJ-12 배관 오브젝트

## 요구사항

배관의 속성(Flow Type) = 급기(SA), 리턴(RA), 배기(EA), 외기(OA), 냉수 공급(CHWS), 냉수 환수(CHWR), 온수 공급(HWS), 온수 환수(HWR), 냉각수 공급(CWS), 냉각수 환수(CWR), 냉매(REF)
배관은 폴리라인 수동 그리기를 지원한다.
배관의 속성에 따라 배관의 색상이 매핑되어 표시된다. 

배관 수정하더라도 특정 설비에 양 끝 말단이 연결되어야 한다. 
배관은 설비가 이동시 같이 설비에 연결된 상태로 이동되는 방향에 따라 길이/높이 등이 자동 수정되어야 한다.
