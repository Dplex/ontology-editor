# OE-OBJ-13 공조존 오브젝트

## 요구사항

공조존은 HVAC 설비가 담당하는 구역이다. 물리존과 별개 체계(N:M)이며 계통도의 서비스 영역(serviceSpace) 기준이다(glossary).
공조존은 담당 설비와 담당 물리존의 묶음으로 정의한다. 공간 편집 모드의 공조존 도구에서 설비를 고르고 담당 물리존을 지정하면 그 합집합이 공조존이 된다(OE-ZON-01). 한 물리존을 여러 공조존으로 나눌 때는 경계 다각형을 직접 그린다(OE-ZON-02).
공조존은 생성·삭제, 경계·담당 설비·담당 물리존 수정을 지원한다(OE-ZON-04). IDF 가 있으면 IDF 임포트(E04)로 자동 생성하고 공조존 도구에서 보정한다(OE-ZON-03). IDF 가 없으면 공조존 도구에서 수동으로 만든다(PRD 1.5).

## 수용 기준

- 공조존 도구에서 만든 공조존이 계통도의 서비스 영역에 반영된다.
- 공조존 편집 뒤 물리존↔공조존 매핑이 갱신된다(OE-MAP-02).
