# OE-OBJ-03 룸 편집 범위

## 요구사항

'룸'은 물리존에서 생성할 수 있는 하위 대상으로 4면 벽 단위로 이루어 진 것을 말한다. 
룸은 생성 · 삭제 · 이동 · 크기 조절이 가능해야 한다. 
룸은 다른 룸과 겹쳐져서 생성 및 편집이 불가능하다. 

## 수용 기준
룸이 다른 룸과 겹치지 않음.
