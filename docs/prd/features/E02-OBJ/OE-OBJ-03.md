# OE-OBJ-03 룸 편집 범위

## 관련 티켓

- [OE-SPC-11](../E09-SPC/OE-SPC-11.md): 룸 생성·삭제·이동·크기 조절
- [OE-SPC-15](../E09-SPC/OE-SPC-15.md): 룸 겹침 차단 표시

## 요구사항

룸은 물리존 안에서 만드는 하위 편집 단위로, 4면 벽으로 둘러싸인 공간이다(glossary, D15). 수동 구축과 운영 편집에서 물리존을 더 잘게 나눌 때 쓴다. 임포트가 룸을 만들지는 않는다.
룸은 생성·삭제·이동·크기 조절을 지원한다(OE-SPC-11). 룸은 다른 룸과 겹치게 만들거나 옮길 수 없다. 겹침 차단 표시는 OE-SPC-15 를 따른다.

## 수용 기준

룸을 다른 룸과 겹치는 자리에 만들거나 옮기는 시도는 차단되고 룸은 원래 상태로 남는다.
