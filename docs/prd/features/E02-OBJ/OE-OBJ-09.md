# OE-OBJ-09 추가 공간 오브젝트

## 요구사항

추가 공간 오브젝트 = 책상·의자·소파·책장·파티션·칠판·화분 등을 의미한다. 
추가 공간 오브젝트의 종류는 사용자가 3D 에셋을 추가하는 경우 추가 생성 가능하다. 
추가 공간 오브젝트는 생성 · 삭제 · 이동 · 크기 조절이 가능하다. 
추가 공간 오브젝트 간 겹침 불가하다. 

(TBD) Digital Twin의 뷰어 마스터에 추가 공간 오브젝트는 노출되지 않음


## 수용 기준

추가 공간 오브젝트 간 겹침 불가능
