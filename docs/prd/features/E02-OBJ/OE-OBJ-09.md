# OE-OBJ-09 추가 공간 오브젝트

## 요구사항

추가 공간 오브젝트는 기본 공간 오브젝트에 들지 않는, 공간을 꾸미는 사물이다 — 책상·의자·소파·책장·파티션·칠판·화분 등(glossary).
종류는 라이브러리로 제공하고(OE-SPC-16), 사용자가 임의의 3D 모델을 넣어 종류를 늘릴 수 있다(OE-P3-08).
추가 공간 오브젝트는 생성·삭제·이동·크기 조절을 지원하고(OE-SPC-14) 서로 겹칠 수 없다(OE-SPC-15).
DT 뷰어마스터에는 노출하지 않는다(TBD). 레이아웃 편집 단위로는 온톨로지에 저장하고 관리한다.

## 수용 기준

- 추가 공간 오브젝트를 다른 추가 공간 오브젝트와 겹치는 자리에 놓을 수 없다.
- 라이브러리에 없는 3D 모델을 넣으면 그 종류로 배치할 수 있다.
