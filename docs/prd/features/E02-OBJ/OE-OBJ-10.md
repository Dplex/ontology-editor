# OE-OBJ-10 배관 없는 설비

## 요구사항

배관 없는 설비는 센서·조명·CCTV·엘리베이터·에스컬레이터 등 별도 배관이 연결되지 않은 독립 설비를 말한다. 
배관 없는 설비는 배치 · 이동 · 삭제 · 명칭 수정이 가능하다. 
배관 없는 설비는 서로 간 겹쳐서 배치 불가하다.
