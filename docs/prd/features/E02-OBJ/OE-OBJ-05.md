# OE-OBJ-05 내벽

## 요구사항

내벽은 물리존 안에 만드는 하위 대상으로, 1면으로 된 벽이며 건물 내부에 있다(glossary).
내벽은 생성·삭제·이동·크기 조절을 지원한다(OE-SPC-12). 내벽은 다른 내벽을 관통할 수 없다.
내벽은 로봇이 지날 수 없는 영역이다(OE-EQP-17). 내벽에는 내벽 전용 설비(온도조절기·스위치 등, glossary "설치면 type")와 문·창을 배치할 수 있다.

## 수용 기준

- 내벽이 다른 내벽을 관통하는 위치로 옮기거나 만들 수 없다.
- 내벽의 통과 속성이 '불가' 로 GeoJSON 에 나간다.
- 내벽에 벽 전용 설비와 문·창을 배치할 수 있다.

## 메모

- 관통 판정(`edit.ts` 의 `wallsCrossed`): 조각(고리)마다 중심선을 펴서, 두 중심선이 서로의 몸통 안(끝에서 상대 반 두께 + 5cm 넘게)에서
  만나고 **외곽선이 실제로 두께 곱의 절반 넘게 겹칠 때**만 관통이다. L·T 맞닿음과 끝을 상대 벽 안으로 조금 들인 것은 된다.
- 겹친 넓이 조건이 없을 때는 성수에서 외곽선이 전혀 안 겹치는 벽 49쌍을 관통으로 셌다(문·창으로 조각난 벽, 꺾인 벽). 조건을 넣은 뒤
  실제 BIM 의 기존 벽끼리 관통으로 잡히는 것: AC20 0 · Duplex 0 · C20 0 · Office_A 0 · 병원(dental) 15쌍(마감벽이 칸막이를 지난다) ·
  성수 2쌍(콘크리트 벽 X 교차). 둘 다 원본이 그렇게 그린 것이다.
- **BIM 이 이미 가로지르게 그린 벽은 막지 않는다.** 편집이 새로 만드는 관통만 막는다. 그 벽도 다른 쪽으로는 옮길 수 있다.
- 내벽·외벽을 가르지 않고 모든 벽에 같은 관통 규칙을 둔다. 외벽 여부는 IsExternal 이나 건물 외곽 접촉으로 정한다(OE-OBJ-04, OE-EXT-01).
- 크기 조절은 길이만이다. 직사각형 벽(외곽선 고리 하나, 꼭짓점 넷)만 되고, 가운데를 두고 양 끝이 같이 움직인다. 실측에서 직사각형 벽은
  Duplex 40/57, 병원 884/1,080, 성수 915/1,291 이다. 두께·높이는 패널에서 바꾼다(OE-OBJ-04).
- 로봇 이동 불가: GeoJSON 벽 feature 에 `passable: false` 를 적는다(문·창과 같은 열쇠).
- 내벽 전용 설비는 패널의 [벽에 붙이기] 로 누른 자리에서 가장 가까운 벽 면(내벽·외벽 모두)에 붙인다. 벽을 옮기면 같이 간다.
  설치면 표(`src/lib/mount.ts`, glossary "설치면 type")에 벽이 없는 종류(조명·실내기 등)는 붙이지 않고, 벽 전용 종류(콘센트)는
  [3D에서 놓기] 도 벽에 붙이는 것으로 한다. 표의 온도조절기·스위치는 사전에 종류가 아직 없어 표에 없는 종류처럼 막지 않는다(OE-OBJ-08 메모).
