# OE-OBJ-07 문 / 창문

## 요구사항

창문은 벽에만 배치할 수 있다. 
창문은 바닥면과 천장면 모두 막힘혀 있어, 로봇이 이동할 수 없는 통로이다.  
창문의 가로-세로 길이 모두 조절할 수 있다. 
외벽 개구부 = 창, 내벽 개구부 = 문으로 구분한다. 

## 수용 기준
