# OE-OBJ-06 내력벽

## 요구사항

내력벽은 물리존에서 수정이 불가하다. 
내력벽은 별도 속성으로 '내벽'과 구분하여 '내력벽'이라고 표시한다. 
loadBearing=true인 벽을 내력벽으로 본다.
내력벽 정보가 없어 loadBearing이 true인지 false인지 알 수 없는 벽은 '모름'으로 표시하고, 내벽처럼 수정할 수 있다.


## 수용 기준

내력벽 편집 차단. 
내력벽 정보가 없는 벽은 '모름'으로 표시되고 편집할 수 있다.
