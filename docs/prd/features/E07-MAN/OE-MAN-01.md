# OE-MAN-01 배경 위 수동 작성

## 요구사항

IDF·BIM 이 없는 사이트(예: SR)는 3D 스캔 모델 또는 빈 층을 배경으로 물리존·룸·벽·문·창을 수동으로 만든다(PRD 1.6). 도구는 운영 편집의 공간 편집 도구(E09)와 같다. 배경이 평면도 이미지면 OE-MAN-02, IDF 참조선이면 OE-IDF-09 를 따른다.

## 수용 기준

빈 층에서 물리존 1개를 그리고 내보내면 GeoJSON·TTL 에 그 물리존이 나간다.
