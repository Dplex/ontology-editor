# OE-MAN-05 공조존 수동

## 요구사항

공조존은 공간 편집 모드의 공조존 도구에서 설비를 고르고 담당 물리존을 지정해 수동으로 만든다(OE-ZON-01). IDF 가 없을 때의 공조존 생성 경로다. IDF 가 있으면 공조존은 IDF 에서 자동으로 만들어진다(OE-BIM-15, PRD 1.6).
