# OE-MAN-05 공조존 수동

## 관련 티켓

- [OE-ZON-01](../E10-ZON/OE-ZON-01.md): 설비·담당 물리존 지정 수동 생성
- [OE-BIM-15](../E05-BIM/OE-BIM-15.md): R2 IDF 공조존 자동 생성

## 요구사항
> User story : 구축 담당자는 R1 수동 구축 사이트에서 공간 편집 모드의 공조존 도구로 공조존을 수동으로 만들 수 있다. 공조 설비를 고르고 그 설비가 담당하는 물리존을 지정하면 공조존이 된다. IDF가 없으므로 자동 생성은 할 수 없으며, 사용자는 설계 도서나 현장 확인으로 담당 범위를 파악해 입력한다. 이렇게 만든 공조존은 계통도의 서비스 영역과 이상 알림 영향 범위에 쓰인다. R2에서 IDF 임포트로 공조존을 자동 생성하는 기능이 들어와도 사용자는 같은 도구로 보정할 수 있어야 한다.

R1 에서 공조존은 공간 편집 모드의 공조존 도구에서 설비를 고르고 담당 물리존을 지정해 수동으로 만든다(OE-ZON-01).
IDF 에서 공조존을 자동으로 만드는 것은 R2(Phase 2)다(OE-BIM-15, PRD 1.5).

## 수용 기준

- **AC1** OE-ZON-01 과 같다.
