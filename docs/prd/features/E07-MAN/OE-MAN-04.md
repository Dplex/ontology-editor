# OE-MAN-04 설비 수동 배치

## 관련 티켓

- [OE-EQP-02](../E12-EQP/OE-EQP-02.md): 미배치 설비 3D 직접 배치
- [OE-EQP-13](../E12-EQP/OE-EQP-13.md): 설비 새로 추가

## 요구사항
> User story : 구축 담당자가 수동 구축 사이트에서 설비 목록을 받으면 좌표가 있는 설비만 자동으로 배치되고, 나머지는 미배치 목록에 모인다. 사용자는 미배치 목록에서 설비를 눌러 3D 바닥을 클릭해 하나씩 직접 배치하며, 동작 방식은 운영 편집의 미배치 설비 배치와 같다. 목록에 없는 설비를 새로 더하는 것은 설비 추가 기능을 따른다. 배치된 설비는 소속 물리존이 자동 판정되고, 자동 배치된 설비와 사람이 놓은 설비는 출처로 구분되어 어느 위치가 실측 기반인지 나중에 확인할 수 있어야 한다.

좌표가 있는 설비만 자동 배치하고, 나머지는 미배치 목록에서 사용자가 3D 에 직접 배치한다(OE-EQP-02). 설비를 새로 더하는 것은 OE-EQP-13에 따른다.

## 수용 기준

OE-EQP-02 와 같다.
