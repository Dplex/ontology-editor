# OE-MAN-04 설비 수동 배치

## 관련 티켓

- [OE-EQP-02](../E12-EQP/OE-EQP-02.md): 미배치 설비 3D 직접 배치
- [OE-EQP-13](../E12-EQP/OE-EQP-13.md): 설비 새로 추가

## 요구사항

### User story

구축 담당자가 수동 구축 사이트에서 설비 목록을 받았을 때, 좌표가 있는 설비는 자동으로 놓이고 좌표 없는 설비는 미배치 목록에 모인다. 담당자가 현장 도면을 보며 목록에서 설비를 눌러 바닥을 클릭해 하나씩 배치하고, 목록에 없는 새 설비는 OE-EQP-13 방식으로 추가한다. 동작이 운영 편집의 미배치 배치와 같아 구축 단계와 운영 단계를 넘나들어도 같은 방식으로 작업한다. 좌표가 있는 설비와 수동 배치한 설비는 출처가 구분되어 나중에 어느 설비 위치가 실측 기반이고 어느 것이 사람이 놓은 것인지 확인할 수 있으며, 배치 뒤 소속 물리존이 자동 판정된다.

좌표가 있는 설비만 자동 배치하고, 나머지는 미배치 목록에서 사용자가 3D 에 직접 배치한다(OE-EQP-02). 설비를 새로 더하는 것은 OE-EQP-13에 따른다.
