# OE-MAN-06 층 단위 진행

## 관련 티켓

- [OE-GEN-11](../E08-GEN/OE-GEN-11.md): 층 단위 생성·등록 규칙
- [OE-GEN-01](../E08-GEN/OE-GEN-01.md): 층별 온톨로지 생성·등록

## 요구사항
> User story : 구축 담당자는 수동 구축을 층 단위로 진행하고 층마다 온톨로지를 생성·등록할 수 있다. 한 층의 물리존·설비·공조존을 완성하면 그 층을 먼저 등록하고 다음 층으로 넘어가며, 규칙은 층 단위 생성 기능과 같다. 전체 층을 다 그린 뒤에야 등록할 수 있으면 중간 결과를 DT에서 확인하거나 여러 담당자가 나눠 작업하기 어려운데, 층 단위로 진행하면 완성된 층부터 운영 담당자가 모니터링을 시작하고 남은 층은 병행 구축할 수 있다. 사용자는 한 층 구축 중 발견한 문제를 다음 층 구축에 바로 반영할 수 있어야 한다.

수동 구축은 층 단위로 진행하고 층마다 온톨로지를 생성·등록한다. 규칙은 OE-GEN-11 과 같다.
