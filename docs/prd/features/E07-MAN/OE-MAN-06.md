# OE-MAN-06 층 단위 진행

## 관련 티켓

- [OE-GEN-11](../E08-GEN/OE-GEN-11.md): 층 단위 생성·등록 규칙
- [OE-GEN-01](../E08-GEN/OE-GEN-01.md): 층별 온톨로지 생성·등록

## 요구사항

### User story

구축 담당자가 10층 건물을 수동 구축할 때 한 층의 물리존·설비·공조존을 완성하면 그 층의 온톨로지를 먼저 생성·등록하고 다음 층으로 넘어간다. 전체 층을 다 그린 뒤에야 등록할 수 있으면 중간 결과를 DT에서 확인하거나 다른 담당자와 나눠 작업하기 어려운데, 층 단위로 진행하면 완성된 층부터 DT에서 모니터링을 시작하고 남은 층은 병행 구축할 수 있다. 규칙은 OE-GEN-11과 같다. 층마다 생성·등록을 반복하면서 발견한 문제를 다음 층 구축에 바로 반영할 수 있어, 전체를 한 번에 만들었다가 뒤늦게 공통 오류를 발견해 모든 층을 다시 손보는 위험도 줄어든다.

수동 구축은 층 단위로 진행하고 층마다 온톨로지를 생성·등록한다. 규칙은 OE-GEN-11 과 같다.

## 수용 기준

OE-GEN-11 과 같다.
