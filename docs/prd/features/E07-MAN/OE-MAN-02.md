# OE-MAN-02 평면도 배경 이미지

## 관련 티켓

- [OE-IDF-09](../E04-IDF/OE-IDF-09.md): 우선순위가 낮은 IDF 참조선

## 요구사항
> User story : 구축 담당자가 BIM 없이 준공 도면 PDF만 있는 사이트를 구축할 때, 도면을 배경 이미지로 깔고 두 점을 찍어 실제 거리를 입력해 스케일을 맞춘 뒤 원점을 찍어 좌표계에 맞춘다. 그 위에서 물리존을 따라 그리면 벽 위치를 눈대중으로 잡지 않아도 되어 정확도가 올라간다. 배경 이미지는 온톨로지에 나가지 않으므로 도면 저작권이나 용량 걱정 없이 작업 보조로만 쓰고, IDF 참조선보다 우선 적용된다. 스케일과 원점을 한 번 맞춰 두면 같은 층의 물리존·벽·문을 모두 도면 위에서 따라 그릴 수 있어, 도면 없이 그릴 때보다 공간 면적과 설비 위치의 오차가 크게 줄어든다.

준공 도면(PDF·DWG)을 배경 이미지로 깔고 그 위에서 물리존을 그린다. 사용자가 이미지의 스케일과 원점을 맞춘다. 평면도 배경은 IDF 참조선(R2, OE-IDF-09)보다 우선한다. 배경 이미지는 온톨로지에 나가지 않는다.

## 수용 기준
두 점을 찍어 거리를 입력하면 이미지 스케일이 맞고, 원점을 찍어 좌표계에 맞출 수 있다.
