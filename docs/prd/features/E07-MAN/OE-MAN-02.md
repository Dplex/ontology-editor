# OE-MAN-02 평면도 배경 이미지

## 관련 티켓

- [OE-IDF-09](../E04-IDF/OE-IDF-09.md): 우선순위가 낮은 IDF 참조선

## 요구사항
> User story : 구축 담당자는 준공 도면(PDF·DWG)을 배경 이미지로 깔고 그 위에서 물리존을 그릴 수 있다. 사용자는 이미지 위 두 점을 찍어 실제 거리를 입력해 스케일을 맞추고, 원점을 찍어 좌표계에 맞춘다. 한 번 맞춰 두면 같은 층의 물리존·벽·문을 도면 위에서 따라 그릴 수 있어 눈대중으로 그릴 때보다 공간 면적과 설비 위치의 오차가 줄어든다. 평면도 배경은 IDF 참조선보다 우선하며, 배경 이미지는 온톨로지에 나가지 않으므로 사용자는 작업 보조로만 쓸 수 있어야 한다.

준공 도면(PDF·DWG)을 배경 이미지로 깔고 그 위에서 물리존을 그린다. 사용자가 이미지의 스케일과 원점을 맞춘다. 평면도 배경은 IDF 참조선(R2, OE-IDF-09)보다 우선한다. 배경 이미지는 온톨로지에 나가지 않는다.

## 수용 기준
두 점을 찍어 거리를 입력하면 이미지 스케일이 맞고, 원점을 찍어 좌표계에 맞출 수 있다.
