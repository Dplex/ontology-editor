# OE-MAP-04 Z-01 경고·리포트

## 관련 티켓

- [OE-SYNC-04](../E15-SYNC/OE-SYNC-04.md): Z-01 경고의 리포트 기록

## 요구사항
> User story : 고객사 관리자가 공조존을 지우거나 물리존을 새로 만들어 어느 공조존도 담당하지 않는 물리존이 생기면 담당 없음 경고를 받고, 반영 결과 리포트에 그 내용이 기록된다. 경고가 있어도 반영은 막히지 않아 급한 레이아웃 변경을 먼저 반영할 수 있지만, 리포트에 남아 있어 나중에 담당 공조존을 지정하는 작업을 잊지 않을 수 있다. 사용자는 담당 없는 물리존이 공조 이상 시 영향 범위에서 빠진다는 것을 알고, 리포트를 보며 계통도 서비스 영역의 공백을 메울 수 있어야 한다.

어느 공조존도 담당하지 않는 물리존이 생기면 Z-01 경고를 띄우고 반영 결과 리포트(OE-SYNC-04)에 적는다. 반영을 막지는 않는다.

## 수용 기준

담당 없는 물리존이 생긴 반영의 리포트에 Z-01 항목이 있다.
