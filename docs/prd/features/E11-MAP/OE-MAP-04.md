# OE-MAP-04 Z-01 경고·리포트

## 관련 티켓

- [OE-SYNC-04](../E15-SYNC/OE-SYNC-04.md): Z-01 경고의 리포트 기록

## 요구사항

### User story

고객사 관리자가 공조존을 지우거나 물리존을 새로 만들어 어느 공조존도 담당하지 않는 방이 생기면 Z-01 경고가 뜨고 반영 결과 리포트에 기록된다. 반영 자체는 막히지 않아 급한 레이아웃 변경을 먼저 반영할 수 있지만, 리포트에 남아 있어 나중에 담당 공조존을 지정하는 작업을 잊지 않는다. 담당 없는 방은 공조 이상 시 영향 범위에서 빠지므로, 운영 담당자가 이 경고를 보고 계통도 서비스 영역의 공백을 메운다.

어느 공조존도 담당하지 않는 물리존이 생기면 Z-01 경고를 띄우고 반영 결과 리포트(OE-SYNC-04)에 적는다. 반영을 막지는 않는다.

## 수용 기준

담당 없는 물리존이 생긴 반영의 리포트에 Z-01 항목이 있다.
