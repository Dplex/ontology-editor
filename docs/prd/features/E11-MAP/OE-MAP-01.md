# OE-MAP-01 설비 → 물리존 자동 판정

## 요구사항

설비의 소속 물리존은 좌표로 자동 판정한다. 벽·물리존 경계가 바뀌어 소속이 바뀌면 사용자 확인 없이 다시 판정한다.
좌표가 외곽선 밖이라도 5cm 안이면 가장 가까운 방에 속한다(K1, 사이트 설정). BIM 이 명시한 소속은 좌표로 재판정하지 않고 유지한다(K2) — 다만 그 방이 없어지거나(OE-SPC-02·04) 사람이 설비를 옮기면(OE-EQP-12) 좌표를 따른다.
소속은 이상 알림의 발생 위치와 탐색기에 쓰인다.

## 수용 기준

- Duplex MEP 의 정답 소속 대비 일치율 95.8% 이상.
- 경계를 바꾼 뒤 확인 팝업 없이 소속이 갱신된다.
