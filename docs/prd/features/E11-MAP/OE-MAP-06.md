# OE-MAP-06 재계산 트리거

## 요구사항
> User story : 고객사 관리자가 벽을 옮기고 물리존을 합치고 설비를 끌어 놓는 일련의 편집을 하는 동안, 설비 소속·배관 규칙 방향·면적·문이 잇는 방이 편집이 끝날 때마다 자동으로 다시 계산된다. 편집 파일 합치기나 재임포트 뒤에도 같다. 사용자가 '재계산' 버튼을 따로 누를 필요가 없으며, 좌표와 소속이 어긋난 상태로 저장되는 일이 없다. 이를 통해 사용자는 어떤 편집 뒤에도 좌표로 계산한 소속과 저장된 소속이 같다는 것을 신뢰할 수 있어야 하며, 이상 알림 위치나 Agent 답변이 실제 배치와 어긋나지 않는다.

소속·규칙 방향·면적·문이 잇는 방은 편집·파일 합치기·재임포트가 끝날 때마다 편집 함수 안에서 다시 계산한다. 호출부가 따로 재계산을 부르지 않는다. 좌표와 소속이 어긋난 상태로 저장되어서는 안된다.

## 수용 기준

- **AC1** 어떤 편집 뒤에도 좌표로 계산한 소속과 저장된 소속이 같아야 한다.
