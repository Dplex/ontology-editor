# OE-MAP-06 재계산 트리거

## 요구사항

소속·규칙 방향·면적·문이 잇는 방은 편집·파일 합치기·재임포트가 끝날 때마다 편집 함수 안에서 다시 계산한다. 호출부가 따로 재계산을 부르지 않는다. 좌표와 소속이 어긋난 상태로 저장되어서는 안된다.

## 수용 기준

어떤 편집 뒤에도 좌표로 계산한 소속과 저장된 소속이 같아야 한다.

## 검증 (이 repo)

- 어느 편집이든 끝나면 소속·규칙 방향·면적·문이 잇는 방이 다시 계산되어 있다. 호출부가 따로 부를 것이 없다 — `edit.test.ts` "바뀐 것만 다시 판정한다", "좌표를 바꾸면 소속 판정이 함께 돈다"
