## 요구사항
> User story : 운영 담당자가 계통도에서 보는 서비스 영역은 공조존 도구에서 지정한 담당 관계 기준으로 그려진다. 이 관계는 공간 편집 모드의 공조존 도구가 직접 만들고 고치며, 물리존 편집은 매핑 갱신을 통해서만 간접적으로 영향을 준다. 고객사 관리자가 물리존 공간명을 바꾸거나 경계를 조금 손봐도 계통도 서비스 영역의 공조존은 바뀌지 않는다. 사용자는 일상적인 공간 편집이 공조 계통 표현을 흔들지 않아 설비 담당자가 보는 계통도가 안정적으로 유지되는 것을 신뢰할 수 있어야 한다.

계통도와 serviceSpace 는 공조존(담당 관계) 기준이다. 이 관계는 공조존 도구(공간 편집 모드)가 직접 만들고(OE-ZON-01·04), 물리존 편집은 매핑 갱신을 통해서만 간접으로 미친다(OE-SPC-05).

## 수용 기준

물리존 공간명을 바꿔도 계통도 서비스 영역의 공조존이 바뀌지 않는다.
