# OE-MAP-05 serviceSpace 기준 유지

## 요구사항

계통도와 serviceSpace 는 공조존(담당 관계) 기준이다. 이 관계는 공조존 도구(공간 편집 모드)가 직접 만들고(OE-ZON-01·04), 물리존 편집은 매핑 갱신을 통해서만 간접으로 미친다(OE-SPC-05).

## 수용 기준

물리존 공간명을 바꿔도 계통도 서비스 영역의 공조존이 바뀌지 않는다.
