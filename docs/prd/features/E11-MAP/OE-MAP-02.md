# OE-MAP-02 물리존 → 공조존 판정

## 요구사항

물리존↔공조존 매핑의 1차 기준은 공조존 도구에서 지정한 담당 관계(OE-ZON-01·04)다. 기하 연산(물리존 ∩ 공조존, S3)은 물리존 분할·병합 때 매핑을 자동으로 갱신하고 검증(OE-ZON-05)을 돕는 보조 수단이다. IDF 겹침 매칭은 OE-IDF-05.
**연결 기준**도 보조 수단으로 쓴다 — 공조존이 담당하는 설비(VAV·FCU·공조기 등)에서 흐름 방향을 따라 닿는 말단(디퓨저·그릴)이 놓인 물리존을 그 공조존의 담당 후보로 본다(바람이 실제로 오는 방). 흐름 방향은 포트·사람이 정한 방향·확정한 규칙 방향만 따라가고, 확정 전 규칙 방향으로만 닿는 물리존은 후보에 넣지 않는다(K4·K14). 연결 기준은 담당 관계를 대신 정하지 않는다 — 공조존 도구에서 담당을 지정할 때 후보로 보이고, 지정한 담당 물리존과 연결 기준이 다르면 검증 경고로 보인다(OE-ZON-05). 연결이나 흐름 방향이 없는 설비는 이 기준을 쓰지 않는다.

## 수용 기준

- 물리존을 분할하면 두 조각 모두 원래 공조존의 담당 물리존이 된다.
- 공조존 도구에서 담당 설비를 고르면, 그 설비에서 확정된 흐름으로 닿는 말단이 있는 물리존이 담당 후보로 보인다.
- 지정한 담당 물리존에 그 공조존 설비의 말단이 하나도 없거나, 말단이 있는 물리존이 담당에서 빠져 있으면 검증 경고가 보인다.
