# OE-ML-13 층별 분기(tee)

## 요구사항

라이저 위의 층 위치를 누르면 분기점(tee)이 생기고, 그 층 평면에서 수평 배관(OE-PIP-11)을 이어 그린다. 분기점은 층 편집 화면에도 보인다(OE-PIP-15). 다중층 에디터의 핵심 기능이다.

## 수용 기준

분기점을 만든 층의 층 편집 화면에 분기점이 보이고 거기서 수평 배관을 이을 수 있다.
