# OE-ML-13 층별 분기(tee)

## 요구사항

다중층 편집 모드에서 배관 그리기(OE-PIP-11)로 기존 층간 배관의 지정한 위치와 해당 층의 설비·배관을 연결하여 수평 분기를 작성한다. 같은 다중층 화면에서 분기 작성까지 완료할 수 있으며, 해당 층의 층 편집 화면에서도 이어 그릴 수 있다(OE-PIP-15).

분기 연결을 완료하면 수직 주 배관에서 층별 배관이 갈라지는 지점에 필요한 분기점(tee)을 생성한다. 같은 연결 대상 배관에서 위치·매체·Flow Type·계통이 적합한 유효 기존 분기점이면 이를 사용하여 중복 생성하지 않는다. 좌표만 같은 다른 계통이나 비활성 연결의 분기점은 자동 재사용하지 않는다. 분기점의 높이를 지정하고 그 층 바닥 높이에 일률적으로 고정하지 않는다. 단순 클릭·형상 교차·접촉만으로 연결을 만들지 않으며, 매체·Flow Type·계통의 적합성은 OE-PIP-11을 따른다.

작성 중 분기점은 임시 상태로 표시하고, 취소하면 해당 작업의 임시 배관·연결·분기점을 함께 제거한다. 기존 배관과 분기점은 유지한다. 완료된 분기의 형상과 연결 대상은 배관 편집(OE-PIP-10)으로 수정한다. 실제 BIM 연결 변경은 원본 보존·연결 해제 보정 정책(OE-PIP-06)을 따른다.

분기점과 연결 상태는 다중층 화면과 해당 층 편집 화면에서 동일한 ID로 표시한다. 분기 생성과 관련 연결 변경은 하나의 편집 이력으로 되돌릴 수 있다.

분기점과 그 층 수평 경로의 높이는 공통 좌표로 관리하며 층 상대 높이를 지정한 경우 OE-ML-18에 따라 변환한다. 분기 생성·수정으로 연결 관계가 변경되면 OE-PIP-07에 따라 유효 연결 기준으로 재계산하고 원본·수동 확정 방향은 보존한다.

## 수용 기준

- 다중층 화면에서 기존 층간 배관과 해당 층의 설비·배관 사이에 수평 분기를 작성하고 완료할 수 있다.
- 완료 시 지정한 위치·높이에 분기점이 생성되며, 같은 연결 대상 배관에서 위치·매체·Flow Type·계통이 적합한 유효 기존 분기점을 사용하면 중복 생성되지 않는다.
- 클릭·형상 교차만으로 연결이 생성되지 않고, 계통·매체가 충돌하면 OE-PIP-11의 검토 안내가 표시된다.
- 작성 취소 후 새 임시 배관·연결·분기점은 남지 않으며 기존 객체와 연결은 유지된다.
- 생성된 분기를 공통 배관 편집으로 수정할 수 있고, 층 편집 화면에서도 같은 분기점과 연결 상태를 확인하고 배관을 이어 그릴 수 있다.
- 되돌리기·저장 복원 후 분기점·배관·연결 상태가 함께 복원된다.

- 같은 좌표의 다른 계통 배관이나 사용자가 연결 해제한 BIM 배관 연결이 분기 생성으로 자동 병합·복원되지 않는다.
- 분기 관계 변경 후 규칙 재계산이 갱신되고 원본·수동 확정 방향은 유지된다.

## 검증 (이 repo)

- 다중층 화면 내 분기 작성, 분기점 생성·재사용·취소, 높이 지정 및 화면 간 상태 공유 검증이 필요하다.

## 메모

- 분기점은 배관이 갈라지는 연결 위치다. 별도의 라이저 도구나 분기점 선행 생성 절차를 요구하지 않는다.
