# OE-ML-03 슬래브 개구부 자동 생성

## 관련 티켓

- [OE-ML-07](./OE-ML-07.md): 이동·형상 변경 시 개구부 갱신
- [OE-ML-08](./OE-ML-08.md): 구간 변경 시 개구부 갱신
- [OE-ML-09](./OE-ML-09.md): 삭제 시 개구부 갱신

## 요구사항
> User story : 구축 담당자가 다중층 뷰에서 수직 관통 오브젝트를 만들거나 옮기면 실제로 슬래브와 교차하는 층에만 개구부가 계산된다. 관통 층으로 선택했다는 이유만으로 바닥을 뚫지 않는다. 교차가 확인되면 개구부가 확정되고, 정보가 부족하면 사유를 가진 초안으로 표시되어 사용자가 확인한 뒤에만 물리존 면적에 반영된다. BIM 원본 개구부는 보존되고 이미 차감된 면적을 다시 빼지 않으며, 겹친 개구부는 합쳐진 면적만 한 번 차감된다. 오브젝트를 옮기거나 구간을 바꾸면 이전 확인 근거가 무효해져 재확인을 요구하고, 사용자는 변경 전후 면적을 하나의 작업으로 되돌릴 수 있어야 한다.

수직 관통 오브젝트의 층별 형상·경로와 실제 슬래브의 교차를 기준으로 개구부를 계산한다. 선택한 관통 층마다 바닥을 무조건 뚫지 않으며 시작·종료 경계와 실제 관통 슬래브를 구분한다. 슬래브와 교차하는 위치·형상이 유효하게 확인되면 편집 개구부를 확정한다. 확인 정보가 부족하면 대상 층·위치·형상·부족 사유를 가진 개구부 초안으로 표시하고 사용자가 확인하여 적용한 뒤에만 면적에 반영한다. 형상을 정할 근거도 없으면 임의 형상을 만들지 않고 미산정 사유를 표시한다.

BIM 원본 개구부는 보존하고 중복 생성하지 않는다. 대응하는 개구부가 확인되면 원본 ID를 참조하여 재사용하며, 원본/편집 생성 구분·확인 출처·사용 오브젝트 목록·초안/확정/재검토 상태를 기록한다. 같은 개구부를 여러 오브젝트가 사용하면 공유 참조로 관리한다.

물리존 면적은 원본 면적 산정에 이미 반영된 구멍을 다시 차감하지 않는다. 새로 확정한 개구부와 물리존의 실제 겹친 면적을 기준으로 계산하며 중첩 개구부는 합집합 면적을 한 번만 차감한다. 초안·재검토 개구부는 추가 차감하지 않으며, 기준 면적이나 중복 반영 여부를 확인할 수 없으면 면적 재계산 불가 사유를 표시한다.

이동·층별 형상/크기 수정·구간 변경·삭제 시 이전 위치와 새 위치의 개구부·참조·면적을 함께 갱신한다(OE-ML-07~09). 위치·형상 변경으로 이전 확인 근거가 무효해지면 사용자 확인을 승계하지 않고 초안 또는 재검토로 돌린다. 원본 또는 다른 오브젝트가 사용하는 개구부는 유지하고 해당 작업만을 위해 생성한 불필요한 개구부만 제거한다. 변경 전후 면적은 기준 형상과 유효 개구부에서 재계산하고 하나의 작업으로 되돌린다.

## 수용 기준

- **AC1** 실제로 교차하는 슬래브에만 확정 개구부가 생성되고 시작·종료 층이라는 이유만으로 개구부가 생성되지 않는다.
- **AC2** 정보가 부족하면 초안·부족 사유를 표시하며 사용자 확인 전 물리존 면적을 차감하지 않는다.
- **AC3** 기존 BIM 개구부는 재사용·보존되고 이미 차감된 면적을 다시 차감하지 않는다.
- **AC4** 두 개구부가 겹치면 합집합과 물리존의 교차 면적만 한 번 차감한다.
- **AC5** 이동·형상 수정·구간 축소·삭제 후 불필요한 편집 개구부만 제거되고 원본·공유 개구부는 유지된다.
- **AC6** 위치가 변경되어 확인 근거가 사라진 개구부는 재확인을 요구하고, 되돌리기 후 상태·참조·면적이 함께 복원된다.

## 메모

- 개구부는 편집 모델의 형상·면적 정보이며 원본 BIM 파일의 슬래브를 직접 수정하는 기능은 아니다.
