# OE-ML-03 슬래브 개구부 자동 생성

## 요구사항

수직 관통 오브젝트가 지나는 각 층의 바닥에 슬래브 개구부를 자동으로 만든다. 개구부 면적은 그 층 물리존 면적에서 뺀다. 구간이 바뀌면 개구부도 따라 생기고 닫힌다(OE-ML-08).

## 수용 기준

관통 층마다 개구부가 있고 그 층 물리존 면적이 개구부만큼 줄어 있다.
