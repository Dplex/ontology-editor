# OE-ML-09 삭제

## 관련 티켓

- [OE-HIST-03](../E19-HIST/OE-HIST-03.md): 삭제 보정의 재임포트 유지
- [OE-ML-03](./OE-ML-03.md): 개구부 보존·면적 재계산
- [OE-ML-17](./OE-ML-17.md): 샤프트 삭제 시 배관 소속 해제
- [OE-ML-19](./OE-ML-19.md): 삭제 대상 연결 출력 제외

## 요구사항

다중층 편집 모드에서 수직 관통 오브젝트를 삭제한다. 확인 화면에 영향 층·층별 표현·명시 연결·개구부·면적·EL 정차/ES 운행 정보·샤프트 배관 소속을 표시한다. 취소하면 데이터와 이력은 변경되지 않는다.

삭제 적용 시 해당 오브젝트의 현재 모델 표현과 연결·소속 참조를 제거한다. 원본 BIM 기록과 연관 물리존은 보존하며 삭제는 사용자 보정으로 기록한다. 재임포트 시 보정이 임의로 사라지지 않도록 유지하고 충돌은 재검토 대상으로 표시한다(OE-HIST-03). 개구부는 OE-ML-03의 원본·공유 보존 및 면적 재계산 기준을 따른다.

샤프트 삭제 시 내부 배관과 배관 연결은 유지하고 샤프트 소속만 해제한다(OE-ML-17). 삭제된 오브젝트를 대상으로 한 참조는 유효 연결로 출력하지 않는다(OE-ML-19). 하나의 실행 취소로 오브젝트·개구부 참조·면적·연결·소속을 함께 복원하며 저장 복원에도 동일하게 적용한다.

## 수용 기준

- 삭제 확인에서 영향 층과 관련 정보가 표시되고 취소 후 변경이 없다.
- 삭제 후 해당 오브젝트의 층별 표현과 유효 참조는 제거되지만 원본 BIM 기록과 연관 물리존은 유지된다.
- 원본·공유 개구부는 유지되고 해당 작업만의 편집 개구부와 면적만 갱신된다.
- 샤프트 삭제 후 내부 배관·연결은 남고 소속만 해제된다.
- Ctrl+Z·저장 복원 후 모든 관련 상태가 일치하며 삭제 보정된 객체가 재임포트만으로 자동 활성화되지 않는다.
