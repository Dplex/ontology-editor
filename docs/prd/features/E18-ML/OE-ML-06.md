# OE-ML-06 생성

## 요구사항

다중층 편집 모드에서 종류·명칭·시작/종료 층을 지정하고 종류에 맞는 형상·진입/종료 지점을 작성한다(OE-ML-02). 계단·샤프트는 공간 편집 모드, EL·ES는 설비 편집 모드에서 생성한다. 공통 수직 축을 사용하는 샤프트·EL 승강로와 층별 형상을 갖는 계단·ES를 구분한다. 관통 구간은 층 이름이 아닌 같은 건물의 층 ID·높이 순서로 정한다.

관통 층과 실제 슬래브 교차를 계산하여 개구부 초안/확정 상태와 면적 영향을 미리 표시한다(OE-ML-03). EL 정차 층과 ES 운행 구간·방향은 OE-ML-10·11을 따른다. 관련 물리존·층별 지점의 명시 연결을 기록하며 형상 겹침만으로 연결을 확정하지 않는다(OE-ML-19).

위치·형상·높이·구간이 유효해야 완료할 수 있다. 필수 형상이나 층 높이가 부족하면 생성 불가 사유를 표시한다. 개구부 확인 정보만 부족한 경우에는 오브젝트를 생성하고 개구부 초안을 남길 수 있다. 완료 전 취소하면 해당 작업의 임시 오브젝트·연결·개구부를 제거하고, 완료한 관련 변경은 하나의 이력으로 저장·되돌린다.

## 수용 기준

- 샤프트·EL은 공통 수직 축으로, 계단·ES는 서로 다른 층별 형상·연결 지점으로 생성할 수 있다.
- 선택한 층·형상과 실제 슬래브 교차에 따라 개구부가 확정되거나 초안으로 표시되고 초안은 면적에 반영되지 않는다.
- 층 높이 누락·잘못된 구간·유효하지 않은 필수 형상이 있으면 완료할 수 없고 사유가 표시된다.
- 생성 취소 후 새 임시 객체가 남지 않으며 완료 후 저장·되돌리기에서 여러 층의 관련 객체와 면적이 함께 복원된다.

## 검증 (이 repo)

- 종류별 생성, 층별 형상·연결 지점, 초안 개구부, 입력 유효성 및 전체 작업 취소·복원 검증이 필요하다.
