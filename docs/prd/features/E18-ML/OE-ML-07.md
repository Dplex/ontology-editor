# OE-ML-07 이동

## 요구사항

수직 관통 오브젝트를 x·y 로 옮기면 관통하는 전 층이 함께 움직인다(수직성 보장). 층별로 따로 옮기는 것은 없다. 옮긴 자리가 어느 층의 물리존 경계·벽과 충돌하면 V-03 경고를 보인다(막지 않는다).

## 수용 기준

- 한 층에서 옮기면 다른 관통 층에서도 같은 위치로 옮겨져 있다.
- 벽과 겹치는 자리로 옮기면 V-03 경고가 보인다.
