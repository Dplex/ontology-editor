## 요구사항
> User story : 고객사 관리자는 다중층 뷰에서만 수직 관통 오브젝트를 옮기고 크기와 층별 형상을 수정할 수 있다. 전체를 옮기거나 돌리면 모든 층의 형상과 진입/종료 지점에 같은 이동량·회전각이 적용되어 층 사이 상대 위치가 유지되고, 샤프트와 엘리베이터 승강로의 공통 축도 유지된다. 계단과 에스컬레이터는 층별 형상·크기·진입/종료 위치를 따로 수정할 수 있다. 이동 전 영향 층·개구부·면적·층간 연결이 표시되고 적용 후 다시 계산된다. 형상이 닿았다고 새 연결이 자동 확정되지 않고, 물리존 경계나 벽과 충돌하면 경고를 받되 이동은 막히지 않는다. 사용자는 관련 변경을 하나의 이력으로 되돌릴 수 있어야 한다.

수직 관통 오브젝트의 이동·크기 및 층별 형상 수정은 다중층 편집 모드에서만 수행한다(OE-ML-05). 전체 x·y 이동은 모든 층별 형상·진입/종료 지점에 동일한 이동량을 적용하여 층 사이 상대 위치를 유지한다. 샤프트·EL 승강로의 공통 수직 축은 유지한다. 전체 회전은 OE-OBJ-15의 오브젝트 회전(360° 자유 회전, 건물 축·벽 방향 ±3° 자석 스냅, 각도 숫자 입력)으로 하며, 모든 층별 형상·진입/종료 지점을 같은 중심(EL·샤프트 = 공통 축, ES·계단 = 시작점)에서 같은 각도만큼 돌린다. 회전도 이동과 같이 영향 표시·재계산·충돌 경고를 따른다. 연속 연결로 이어진 계단·ES 한 구간을 옮기거나 돌리면 이어진 구간은 따라 움직이지 않으며, 연결 지점이 어긋나면 그 연결을 재검토로 표시하고 다시 붙일 수 있게 연결 지점 스냅을 제공한다(OE-ML-06·19). 계단·ES는 층별 형상·크기·진입/종료 위치를 수정할 수 있으며 관련 층간 연결을 함께 검토한다. 이는 한 층 편집 화면에서의 개별 이동과 구분한다.

이동·크기/형상 변경 전 영향 층·개구부·면적·층간 연결을 표시하고 적용 후 재계산한다(OE-ML-03·19). 형상 접촉으로 새 연결을 자동 확정하지 않는다. 물리존 경계·벽과 충돌하면 V-03 경고를 표시하고 충돌한다고 해서 설비의 이동 자체를 막지는 막지는 않는다. 유효하지 않은 형상·좌표는 적용하지 않는다.

샤프트의 내부 배관 연동 이동은 OE-ML-17을 따른다. 원본 BIM 정보는 보존하고 사용자 보정으로 기록하며, 관련 변경을 하나의 이력으로 되돌리고 저장 복원한다. R2 다중층 잠금은 OE-ML-01·OE-COM-05를 따른다.

## 수용 기준

- **AC1** 다중층 화면의 전체 이동 후 모든 층별 형상·연결 지점이 같은 이동량만큼 이동하고 상대 위치가 유지된다.
- **AC2** 전체 회전 후 모든 층별 형상·연결 지점이 같은 중심에서 같은 각도만큼 돌고, 건물 축·벽 방향 ±3° 안에서는 그 각도에 붙는다.
- **AC3** 계단·ES의 층별 형상·크기·진입/종료 위치를 수정할 수 있고 샤프트·EL 공통 축은 유지된다.
- **AC4** 이동·회전·크기 수정 후 개구부와 면적이 갱신되며 이전 확인 근거가 무효해지면 재확인이 필요하다.
- **AC5** 충돌 위치·층과 V-03 경고가 표시되고, 유효하지 않은 형상은 적용되지 않는다.
- **AC6** 이어진 계단·ES 한 구간을 옮겨 연결 지점이 어긋나면 연결이 재검토로 표시되고, 다시 붙이면 유효 연결로 돌아온다.
- **AC7** 되돌리기·저장 복원 후 형상·개구부·면적·연결·배관 연동 결과가 함께 복원된다.
