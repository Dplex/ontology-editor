## 요구사항

수직 관통 오브젝트의 이동·크기 및 층별 형상 수정은 다중층 편집 모드에서만 수행한다(OE-ML-05). 전체 x·y 이동은 모든 층별 형상·진입/종료 지점에 동일한 이동량을 적용하여 층 사이 상대 위치를 유지한다. 샤프트·EL 승강로의 공통 수직 축은 유지한다. 계단·ES는 층별 형상·크기·진입/종료 위치를 수정할 수 있으며 관련 층간 연결을 함께 검토한다. 이는 한 층 편집 화면에서의 개별 이동과 구분한다.

이동·크기/형상 변경 전 영향 층·개구부·면적·층간 연결을 표시하고 적용 후 재계산한다(OE-ML-03·19). 형상 접촉으로 새 연결을 자동 확정하지 않는다. 물리존 경계·벽과 충돌하면 V-03 경고를 표시하고 충돌한다고 해서 설비의 이동 자체를 막지는 막지는 않는다. 유효하지 않은 형상·좌표는 적용하지 않는다.

샤프트의 내부 배관 연동 이동은 OE-ML-17을 따른다. 원본 BIM 정보는 보존하고 사용자 보정으로 기록하며, 관련 변경을 하나의 이력으로 되돌리고 저장 복원한다. R2 다중층 잠금은 OE-ML-01·OE-COM-05를 따른다.

## 수용 기준

- 다중층 화면의 전체 이동 후 모든 층별 형상·연결 지점이 같은 이동량만큼 이동하고 상대 위치가 유지된다.
- 계단·ES의 층별 형상·크기·진입/종료 위치를 수정할 수 있고 샤프트·EL 공통 축은 유지된다.
- 이동·크기 수정 후 개구부와 면적이 갱신되며 이전 확인 근거가 무효해지면 재확인이 필요하다.
- 충돌 위치·층과 V-03 경고가 표시되고, 유효하지 않은 형상은 적용되지 않는다.
- 되돌리기·저장 복원 후 형상·개구부·면적·연결·배관 연동 결과가 함께 복원된다.

## 검증 (이 repo)

- 전체 이동과 종류별 형상 수정, 개구부 재확인, 충돌 경고 및 복합 작업 복원 검증이 필요하다.
