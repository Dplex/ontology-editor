# OE-ML-04 로봇 통과 속성

## 관련 티켓

- [OE-EQP-17](../E12-EQP/OE-EQP-17.md): 로봇 통과 속성 기준
- [OE-ML-19](./OE-ML-19.md): 구조적 층간 연결 출력
- [OE-EQP-16](../E12-EQP/OE-EQP-16.md): 로봇 이용 가능 여부 출력

## 요구사항
> User story : 구축 담당자는 다중층 뷰에서 수직 관통 오브젝트의 로봇 통과 속성을 층별로 확인할 수 있다. 엘리베이터는 정차가 확인된 층의 진입·종료 지점에서만 통과할 수 있고, 무정차 층과 정차 정보가 확인되지 않은 층은 통과 불가로 표시되며 그 사유가 구분된다. 에스컬레이터·계단·설비용 샤프트는 층을 잇더라도 로봇이 통과할 수 없다. 통과 여부는 오브젝트 전체에 하나의 값으로 복사되지 않고 층마다 따로 기록되며, 사용자가 정차 층·연결 지점·운행 구간을 바꾸면 통과 정보가 함께 갱신되는 것을 확인할 수 있어야 한다.

수직 관통 오브젝트의 로봇 통과 속성은 OE-EQP-17을 따른다. EL은 확인된 정차 층의 유효한 진입/종료 지점에서만 통과 가능하고 무정차·정차 정보 미확인 층은 통과 불가로 표시하며 사유를 구분한다. ES·계단·설비용 샤프트는 로봇 통과 불가다.

통과 여부는 부모 오브젝트의 단일 값으로 모든 층에 복사하지 않고 층별 표현·연결 지점에 기록한다. 구조적 층간 연결과 로봇의 이용 가능 여부는 별도 정보로 출력한다(OE-ML-19, OE-EQP-16). 연결이 있다는 이유만으로 통과 가능으로 변경하지 않는다. 정차 층·연결 지점·운행 구간이 바뀌면 출력과 관련 검증을 갱신한다.

## 수용 기준

- **AC1** EL의 확인된 정차 층과 무정차 층의 통과 속성이 다르게 출력된다.
- **AC2** 정차 정보 미확인 층은 통과 가능으로 추정되지 않고 사유가 표시된다.
- **AC3** ES·계단·설비용 샤프트는 구조적 층간 연결이 있어도 통과 불가로 유지된다.
- **AC4** 정차 층 수정·되돌리기·저장 복원 후 층별 통과 속성이 일치한다.
