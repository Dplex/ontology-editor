# OE-ML-04 로봇 통과 속성

## 요구사항

수직 관통 오브젝트의 로봇 통과 속성은 OE-EQP-17을 따른다. EL은 확인된 정차 층의 유효한 진입/종료 지점에서만 통과 가능하고 무정차·정차 정보 미확인 층은 통과 불가로 표시하며 사유를 구분한다. ES·계단·설비용 샤프트는 로봇 통과 불가다.

통과 여부는 부모 오브젝트의 단일 값으로 모든 층에 복사하지 않고 층별 표현·연결 지점에 기록한다. 구조적 층간 연결과 로봇의 이용 가능 여부는 별도 정보로 출력한다(OE-ML-19, OE-EQP-16). 연결이 있다는 이유만으로 통과 가능으로 변경하지 않는다. 정차 층·연결 지점·운행 구간이 바뀌면 출력과 관련 검증을 갱신한다.

## 수용 기준

- EL의 확인된 정차 층과 무정차 층의 통과 속성이 다르게 출력된다.
- 정차 정보 미확인 층은 통과 가능으로 추정되지 않고 사유가 표시된다.
- ES·계단·설비용 샤프트는 구조적 층간 연결이 있어도 통과 불가로 유지된다.
- 정차 층 수정·되돌리기·저장 복원 후 층별 통과 속성이 일치한다.

## 검증 (이 repo)

- EL 층별 통과 속성, 정보 미확인 처리 및 구조적 연결과 이용 가능 여부의 분리 검증이 필요하다.
