## 요구사항
> User story : 로봇 관제 사용자는 에디터가 내보낸 레이아웃에서 수직 관통 오브젝트가 어느 층과 어느 층을 구조적으로 잇는지와 로봇이 실제로 그 통로를 쓸 수 있는지를 분리된 정보로 받을 수 있다. 구축 담당자가 명시한 층별 연결 지점과 BIM 명시 연결이 우선 사용되고 출처가 보존되며, 서로 충돌하면 자동 선택하지 않고 재검토로 표시된다. 명시 정보가 없는 기존 계단실·승강로에 한해 이웃 층의 같은 종류 공간이 충분히 겹치는 경우를 후보로 추정하되, 유일하게 짝이 맞는 후보만 내보내고 모호한 후보는 확인 전까지 내보내지 않는다. 추정 연결은 출처가 표시되어 명시 연결과 구분되며, 구조적 연결이 곧 로봇 통과 허용을 뜻하지는 않는다.

층간 연결은 구조적 연결과 로봇 통과 가능 여부를 분리한다. 명시된 수직 관통 오브젝트의 층별 연결 지점·관통 구간·연관 공간을 우선 사용한다(OE-ML-02). 수동 작성에서 사용자가 적용한 지점·구간과 BIM에 명시된 연결은 모델에 저장하고 출처를 보존하며, 서로 충돌하면 자동 선택하지 않고 재검토 대상으로 표시한다. 원본 연결의 사용자 보정은 따로 보존한다. 계단·ES를 연결 지점 스냅으로 이어 놓으면(OE-ML-06) 아래 구간의 상층 지점과 위 구간의 하층 지점을 잇는 연속 연결을 사용자 출처의 명시 연결로 저장한다. 연속 연결은 층마다 나뉜 계단·ES를 한 동선으로 읽을 수 있게 하며, 두 지점이 같은 층·같은 종류(ES는 같은 운행 방향)일 때만 유효하다. 이동·회전·형상 수정으로 두 지점이 더 이상 만나지 않거나 ES 방향이 달라지면 자동 삭제하지 않고 재검토로 표시한다.

GeoJSON 출력 때 현재 유효한 층별 표현과 공간 ID를 기준으로 구조적 층간 연결을 계산한다. 동일 부모의 유효한 층별 지점을 명시 경로에 따라 잇고, 연결 참조는 실제 출력된 객체 ID를 가리켜야 한다. 연관 원본 공간이 있으면 별도 중복 공간을 만들지 않는다. EL의 무정차 층을 가로지르는 구조적 경로는 유지할 수 있으나 무정차/미확인 층에 출입 가능한 로봇 연결을 만들지 않는다. 계단·ES·설비용 샤프트의 구조적 연결도 로봇 통과 허용을 뜻하지 않는다(OE-ML-04·10·11).

명시 정보가 없는 기존 계단실·승강로 공간에 한해 겹침 후보를 계산한다. 같은 건물의 층을 높이로 정렬한 뒤 서로 이웃한 두 층의 같은 종류 공간에서 겹친 면적 ÷ 두 공간 중 작은 유효 면적이 50%를 초과하는 경우를 후보로 삼는다. 명시된 단절·삭제·보정·재검토 정보를 겹침 후보로 덮어쓰지 않는다. 서로 다른 종류·건물, 유효하지 않은 면적/높이는 후보에서 제외한다.

복수 후보는 최고 겹침 비율이 하나로 정해지고 반대편에서도 같은 짝이 선택될 때만 일대일 추정 연결로 출력한다. 동률·서로 다른 선택·여러 통로 병합 가능성은 모호한 후보로 표시하고 사용자 확인 전 유효 연결로 출력하지 않는다. 추정 연결은 출처를 표시하며 확인된 명시 연결과 구분한다. 후보 계산 결과는 모델의 원본을 변경하지 않고 출력 때 재계산하지만 사용자가 확인·보정한 결정은 저장한다.

구조적 연결은 양쪽에서 참조할 수 있는 verticalConnects로 출력하고 ES 운행 방향 등 이동 제한은 별도 속성으로 유지한다. 삭제·구간 변경·정차/형상 수정 후 유효 참조를 재계산하고 잘못된 ID·범위 밖 연결·중복을 제외한다. 로봇 이용 가능 여부는 OE-EQP-17 기준으로 별도 출력한다.

## 수용 기준

- **AC1** 수동 생성한 계단·EL·ES·샤프트의 명시된 층별 지점·구간으로 유효한 구조적 연결이 출력되고 참조 대상 ID가 실제 존재한다.
- **AC2** 명시 연결·단절·사용자 보정은 면적 겹침 추정으로 덮어써지지 않으며 충돌 시 재검토로 표시된다.
- **AC3** 겹침 비율은 작은 유효 면적을 분모로 계산하고 정확히 50%인 경우는 연결되지 않는다.
- **AC4** 유일하며 상호 일치하는 후보만 추정 연결로 출력하고 동률·다대일 모호 후보는 확인 전 출력되지 않는다.
- **AC5** 무정차/미확인 EL 층과 ES·계단·설비용 샤프트의 구조적 연결이 로봇 통과 가능으로 오인되지 않는다.
- **AC6** 삭제·형상/구간 변경·되돌리기·저장 복원 후 참조와 출처가 일치하고 비활성·재검토 연결은 유효 출력에 없다.
- **AC8** 이어 놓은 계단·ES의 연속 연결이 명시 연결로 출력되고, 지점이 어긋나거나 ES 방향이 달라지면 재검토로 표시되어 유효 연결로 출력되지 않는다.
- **AC7** OE-EQP-16의 병원 7개 중 6개 이상 연결 기준은 대상 ID·기대 연결·출처를 가진 고정 기준선으로 검증하며 모호 후보를 억지로 연결하여 충족하지 않는다.

## 메모

- 명시된 층간 연결은 저장하고 파생 결과·겹침 후보는 출력 때 계산한다. 구조적 연결과 로봇 경로 이용 가능 여부는 같은 값이 아니다.
