# OE-ML-10 정차 층 설정

## 관련 티켓

- [OE-ML-08](./OE-ML-08.md): 관통 구간 변경
- [OE-ML-04](./OE-ML-04.md): 구조적 연결 갱신
- [OE-ML-19](./OE-ML-19.md): 로봇 통과 정보 갱신
- [OE-ML-06](./OE-ML-06.md): 수동 생성 순서

## 요구사항
> User story : 구축 담당자는 다중층 뷰에서 엘리베이터의 관통 구간 안에서 층별 정차/무정차 여부와 진입 지점을 설정할 수 있다. 수동으로 만들 때는 전 층 정차가 초기값으로 제안되지만 사용자가 확인해야 완료된다. BIM에 명시된 정차 정보는 보존되고, 정보가 없으면 '미확인'으로 표시되며 자동으로 전 층 정차로 확정되지 않는다. 구간을 늘려 새로 들어온 층도 확인 전까지 미확인이다. 정차 층이나 진입점을 바꾸면 구조적 연결과 로봇 통과 정보가 따로 갱신된다. 사용자는 층별 정차/무정차/미확인 상태와 출처를 확인할 수 있어야 하며, 미확인 층은 로봇 통과 가능으로 나가지 않는다.

EL의 관통 구간 안에서 정차/무정차 층과 해당 층 진입 지점을 설정한다. 수동 생성은 시작/종료 층 선택 → 승강로 배치 → 정차 층·진입 지점 확인 → 완료 순서로 진행한다([OE-ML-06](./OE-ML-06.md)). 초기 선택은 관통 구간 전 층 정차, 진입 지점은 승강로의 한 면으로 두고 사용자가 층별로 확인·수정하여 완료한다. BIM 임포트에서 명시된 정차 정보는 보존하고 정보가 없으면 미확인 상태로 표시한다. 미확인을 전 층 정차로 자동 확정하지 않는다.
구간 확대 시 신규 층의 정차 여부는 사용자 확인 전 미확인으로 두고, 축소 시 제외 층은 영향 확인 후 정차 목록에서 제거한다[OE-ML-08](./OE-ML-08.md). 정차 층·진입점 변경 후 구조적 연결과 로봇 통과 정보를 별도로 갱신한다[OE-ML-04](./OE-ML-04.md), [OE-ML-19](./OE-ML-19.md). 층별 표현에 정차/무정차/미확인 상태와 출처를 표시하고 저장·내보내기에서 보존한다.

## 수용 기준
- **AC1** 수동 생성 시 승강로 배치 후 전 층 정차·기본 진입 지점 초기 선택을 확인·수정할 수 있고 BIM의 명시된 정차 목록은 유지된다.
- **AC2** BIM 정차 정보 누락이나 신규 확대 층은 미확인으로 표시되며 통과 가능으로 출력되지 않는다.
- **AC3** 무정차·미확인 층은 확정 정차 목록에 없고 각 층의 상태와 출처를 확인할 수 있다.
- **AC4** 구간 축소·정차 변경·되돌리기·저장 복원 후 정차 목록과 층별 통과 속성이 일치한다.
