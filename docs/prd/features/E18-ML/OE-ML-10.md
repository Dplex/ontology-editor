# OE-ML-10 정차 층 설정

## 요구사항

EL 의 정차/무정차 층을 지정한다. 정차 층은 로봇 통과 속성(OE-ML-04)과 glossary "엘리베이터" 의 정차 층이 된다. 기본값은 관통 구간 전 층 정차다.

## 수용 기준

무정차로 지정한 층이 GeoJSON 의 EL 정차 층 목록에 없다.
