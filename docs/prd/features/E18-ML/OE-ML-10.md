# OE-ML-10 정차 층 설정

## 요구사항

EL의 관통 구간 안에서 정차/무정차 층과 해당 층 진입 지점을 설정한다. 수동 생성의 초기 선택은 관통 구간 전 층 정차로 두고 사용자가 확인하여 완료한다. BIM 임포트에서 명시된 정차 정보는 보존하고 정보가 없으면 미확인 상태로 표시한다. 미확인을 전 층 정차로 자동 확정하지 않는다.

구간 확대 시 신규 층의 정차 여부는 사용자 확인 전 미확인으로 두고, 축소 시 제외 층은 영향 확인 후 정차 목록에서 제거한다(OE-ML-08). 정차 층·진입점 변경 후 구조적 연결과 로봇 통과 정보를 별도로 갱신한다(OE-ML-04·19). 층별 표현에 정차/무정차/미확인 상태와 출처를 표시하고 저장·내보내기에서 보존한다.

## 수용 기준

- 수동 생성 시 전 층 정차 초기 선택을 확인·수정할 수 있고 BIM의 명시된 정차 목록은 유지된다.
- BIM 정차 정보 누락이나 신규 확대 층은 미확인으로 표시되며 통과 가능으로 출력되지 않는다.
- 무정차·미확인 층은 확정 정차 목록에 없고 각 층의 상태와 출처를 확인할 수 있다.
- 구간 축소·정차 변경·되돌리기·저장 복원 후 정차 목록과 층별 통과 속성이 일치한다.

## 검증 (이 repo)

- 수동 초기 선택, BIM 보존·미확인 처리, 구간 변경 및 층별 통과 속성 연동 검증이 필요하다.
