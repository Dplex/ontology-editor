# OE-ML-02 수직 관통 오브젝트 데이터 모델 (#25)

## 요구사항

수직 관통 오브젝트(#25)의 데이터 모델이다. 대상은 EL·ES·계단·샤프트(덕트·배관·전기·통신)다. 물리존이 아닌 별도 분류다 — EL 홀은 물리존, 승강로(샤프트)는 수직 관통 오브젝트다.
속성은 평면 형상·위치(전 층 공통), 관통 구간(시작~종료 층), 정차 층(EL, OE-ML-10), 운행 방향(ES, OE-ML-11), 슬래브 개구부(OE-ML-03), 로봇 통과 여부(OE-ML-04)다. 오브젝트 분류는 OE-OBJ-14.

## 수용 기준

수직 관통 오브젝트가 GeoJSON 에 전 층 공통 평면 형상과 관통 구간을 가진 별도 분류로 나간다.
