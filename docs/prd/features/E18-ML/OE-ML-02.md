## 요구사항
> User story : 구축 담당자는 엘리베이터·에스컬레이터·계단·샤프트를 별도 분류의 수직 관통 오브젝트로 관리할 수 있다. 엘리베이터 홀·계단실 같은 물리존은 공간으로 유지되며 수직 관통 오브젝트와 중복 생성되지 않는다. 하나의 오브젝트에 종류·명칭·출처·시작/종료 층·관통 층·층별 형상과 위치·층별 진입/종료 지점·연관 물리존이 기록된다. 샤프트와 엘리베이터 승강로는 공통 수직 축을 쓰고, 계단과 에스컬레이터는 층마다 다른 형상과 진입/종료 지점을 가질 수 있다. 사용자는 BIM 원본 정보와 자신이 수정한 보정이 구분되고, 재임포트해도 같은 오브젝트가 중복되지 않으며 충돌은 재검토로 표시되는 것을 확인할 수 있어야 한다.

수직 관통 오브젝트(#25)는 EL·ES·계단·샤프트(덕트·배관·전기·통신)를 별도 분류로 관리한다. EL 홀과 계단실 등의 물리존은 공간으로 유지하며, 수직 관통 오브젝트와 원본 공간을 중복 생성하거나 서로 대체하지 않는다(OE-OBJ-14).

하나의 오브젝트 ID 아래 종류·명칭·출처·시작/종료 층·관통 층·층별 형상 및 위치·층별 진입/종료 연결 지점·연관 물리존 ID를 기록한다. 층별 표현은 부모 오브젝트 ID와 층 ID로 식별하며, GeoJSON의 연결 대상은 실제 출력된 식별 정보를 참조한다. 명시된 층간 연결은 모델에 저장하고, 겹침으로 계산한 후보는 그와 구분한다(OE-ML-19).

수직 샤프트와 EL 승강로의 기본 위치는 공통 수직 축을 사용한다. 계단·ES는 R1부터 층별 위치·형상과 서로 다른 진입/종료 지점을 지원하며, 모든 층에 같은 형상을 강제하지 않는다. 전체 이동과 층별 형상 수정은 OE-ML-07을 따른다.

EL 정차 층·ES 운행 구간/방향·개구부 참조 및 확인 상태·층별 로봇 통과 속성·샤프트 배관 소속은 OE-ML-03·04·10·11·17을 따른다. BIM 원본 형상·식별 정보·연결은 보존하고 사용자 수정은 보정 정보로 분리한다. 재임포트는 동일 ID를 중복 생성하지 않으며 변경 충돌은 재검토로 표시한다(OE-HIST-03, 배관 연결은 OE-PIP-06).

## 수용 기준

- **AC1** 별도 오브젝트와 연관 물리존을 구분하고 부모 ID·층 ID·층별 형상·연결 지점을 저장 및 GeoJSON 출력에서 확인할 수 있다.
- **AC2** 서로 다른 1층 진입점과 2층 종료점을 갖는 계단·ES를 생성·저장 복원할 수 있다.
- **AC3** 샤프트·EL 승강로의 공통 축과 계단·ES의 층별 형상을 구분하여 표시한다.
- **AC4** GeoJSON의 층간 연결 대상 ID가 실제 출력된 객체를 참조하며 원본 공간과 중복 출력되지 않는다.
- **AC5** 재임포트 후 원본 정보와 사용자 보정이 구분되고 동일 객체가 중복 생성되지 않는다.
