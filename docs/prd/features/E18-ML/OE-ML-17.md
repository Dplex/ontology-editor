# OE-ML-17 샤프트 내 배치

## 요구사항

샤프트 내부에 놓인 배관은 배관 전체가 아니라 지정한 구간·분기점 단위로 소속을 관리한다. 해당 구간이 샤프트의 유효한 층 범위와 내부 형상에 포함되는지 확인하고 사용자 적용으로 소속을 확정한다. 일부만 포함되거나 여러 샤프트가 겹치면 후보와 범위를 표시하여 선택하게 하며 좌표 접촉만으로 자동 소속시키지 않는다. 소속과 실제 배관 연결·계통은 별도 정보다.

샤프트 전체 이동 전 함께 이동할 내부 구간·분기점, 연결된 외부 배관·설비, 개구부·면적과 영향 층을 미리 표시한다. 적용하면 소속 내부 구간·분기점에 같은 이동량을 적용하고, 유효하게 연결된 외부 배관의 해당 끝점만 따라가게 한다. 외부 설비·반대쪽 끝점·무관한 분기는 유지하며 필요한 수평 경로 수정은 OE-PIP-10·12를 따른다. 선택 모드가 공간 편집이어도 이 명시된 연동 작업은 미리보기·적용으로 함께 처리하되 외부 설비의 직접 편집은 허용하지 않는다.

좌표 부족·편집 불가 경로·공유 분기 영향 때문에 안전하게 연동할 수 없으면 미리보기에서 이유를 표시하고 형상/소속 보정을 마친 뒤 적용한다. 영향을 받는 배관 일부만 누락한 채 일괄 이동을 완료하지 않는다. 사용자 연결 해제 상태는 유지하고 위치 이동으로 연결 대상·흐름 방향을 바꾸거나 비활성 연결을 복원하지 않는다. 원본 BIM 형상과 연결은 보존하고 보정 결과로 기록한다.

샤프트 삭제 시 배관·연결은 보존하고 소속만 해제한다. 구간 축소·배관 형상 수정으로 내부 범위를 벗어나면 영향을 확인하여 이탈 구간의 소속을 해제하고 사유를 표시한다. 샤프트 삭제나 이탈만으로 배관을 삭제·자동 절단하지 않는다. 이동·소속·외부 끝점·개구부·면적의 관련 변경은 하나의 이력으로 저장·되돌린다.

## 수용 기준

- 내부 구간·분기점의 샤프트 ID와 포함 층 범위를 확인할 수 있고 복수 후보는 사용자 선택 없이 확정되지 않는다.
- 이동 전 내부·외부 배관과 영향 층을 확인하고 적용하면 내부 구간·분기점이 같은 이동량만큼 움직인다.
- 연결된 외부 배관의 해당 끝점만 갱신되며 외부 설비·반대쪽 끝점·무관한 분기는 유지된다.
- 필요한 좌표가 없거나 공유 분기 영향이 해결되지 않으면 미리보기에서 사유를 표시하고 작업을 일부만 적용하지 않는다.
- 이동 후 이탈·연결 불일치·길이 0 등을 검사하며 연결 대상·확정 방향·사용자 해제 상태는 임의 변경되지 않는다.
- 샤프트 삭제·구간 축소 시 배관과 연결은 유지되고 해당 소속만 해제되며 되돌리기·저장 복원 후 관련 상태가 함께 복원된다.

## 검증 (이 repo)

- 구간 단위 소속, 복수 후보, 내부 이동·외부 끝점 보존, 연동 불가 처리, 삭제/이탈 보존 및 복합 작업 복원 검증이 필요하다.
