# OE-ML-14 층간 오프셋

## 요구사항

층 사이에서 x·y 가 꺾이는 구간(오프셋)을 지원한다. 꺾임점의 z 를 지정한다. 꺾임 전후 구간은 각각 수직이다.

## 수용 기준

꺾임점을 넣으면 두 수직 구간과 하나의 수평 구간으로 그려진다.
