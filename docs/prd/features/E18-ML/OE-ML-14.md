# OE-ML-14 층간 오프셋

## 관련 티켓

- [OE-PIP-11](../E13-PIP/OE-PIP-11.md): 오프셋 작성용 배관 그리기
- [OE-PIP-10](../E13-PIP/OE-PIP-10.md): 꺾임점·연결 대상 편집
- [OE-ML-18](./OE-ML-18.md): 꺾임점 높이 공통 좌표
- [OE-ML-17](./OE-ML-17.md): 샤프트 밖 구간 소속 재검토

## 요구사항

- User story : 배관 변경사항을 온톨로지에 반영하는 사용자로서, 층 사이에서 배관이 꺾이는 위치나 높이가 바뀌었을 때 플랫폼에서 수정하고 싶다. 연결된 분기와 샤프트에 미치는 영향을 확인하고, 연결 관계에 문제가 없도록 온톨로지에 반영하고 싶다.

다중층 편집 모드의 배관 그리기·배관 편집(OE-PIP-11·10)에서 층 사이에 x·y가 달라지는 구간(오프셋)을 작성·수정한다. 사용자가 꺾임점의 위치와 z 높이를 지정하여 두 수직 구간 사이를 수평 구간으로 잇는다. 별도의 라이저·오프셋 도구를 요구하지 않는다.

배관 편집에서 꺾임점을 이동·추가·삭제하고 높이를 변경할 수 있다. 형상만 수정하면 양 끝 연결 대상과 확정 방향을 유지한다. 연결 대상 변경은 OE-PIP-10의 연결 편집 기준을 따르며, 유효한 좌표·길이 검사와 되돌리기·저장 복원 기준도 동일하게 적용한다.

높이는 OE-ML-18의 공통 좌표계로 관리한다. 오프셋 수정에 영향을 받는 층별 분기·샤프트 소속을 미리 표시하고, 실제 연결점이 변경되는 경우 연결 관계와 경로 유효성을 함께 검사한다. 샤프트 밖으로 나간 구간은 소속을 다시 검토하며 자동으로 새 계통·샤프트에 합치지 않는다(OE-ML-17).

## 수용 기준

- 공통 배관 그리기에서 오프셋을 지정하면 두 수직 구간과 하나의 수평 구간이 사용자 지정 높이로 그려진다.
- 배관 편집으로 오프셋 위치·높이를 바꾸면 형상이 갱신되고, 형상만 수정한 경우 연결 대상과 확정 방향이 유지된다.
- 유효하지 않은 좌표나 길이 0인 경로는 정상 배관으로 완료되지 않는다.
- 되돌리기·저장 복원 후 오프셋 형상과 연결 상태가 함께 복원된다.

- 오프셋 수정 전 관련 층별 분기·샤프트 소속 영향을 확인할 수 있고, 이탈·연결 불일치는 수정 후 표시된다.
- 위치만 겹친 다른 배관이나 샤프트에 자동 병합·소속되지 않는다.

## 검증 (이 repo)

- 공통 배관 도구에서 오프셋 생성·수정, 높이 지정, 연결·방향 보존 및 복원 검증이 필요하다.

## 메모

- 한 수직 구간의 x·y는 고정하되, 오프셋을 포함한 전체 층간 경로의 x·y가 같을 필요는 없다.
