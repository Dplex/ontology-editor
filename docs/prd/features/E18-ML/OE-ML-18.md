# OE-ML-18 좌표 조건

## 요구사항

층간 배관의 형상 반영은 OE-PIP-13의 좌표 유효성·형상과 의미 정보 분리 기준을 따른다. 같은 건물의 층 ID·층 기준 높이·배관의 층 상대 높이를 구분하고 단위와 좌표계를 변환하여 공통 x·y·z로 관리한다. 상대 높이는 해당 층 기준 높이에 더하여 공통 z로 계산하고, 이미 공통 z인 좌표에 층 높이를 다시 더하지 않는다.

층 기준 높이·단위·좌표 변환 정보가 없거나 서로 충돌하면 층 이름이나 순번으로 높이를 추정하지 않는다. 미반영/작성 불가 사유와 원본 ID를 표시하며 사용자 확인으로 유효한 기준을 정한 후 반영한다. 서로 다른 건물은 명시된 공통 좌표 변환 기준 없이는 층간 경로로 연결하지 않는다.

수직 구간·분기·오프셋 모두 같은 기준을 적용하고 실제 높이는 보기의 층 간격·표시 축척과 분리한다. 보기 간격을 바꾸어도 저장된 좌표·길이·연결은 변경되지 않는다. 좌표가 없는 원본의 명시 연결·계통·방향은 별도로 보존하며 임의 형상을 만들지 않는다.

## 수용 기준

- 층 상대 높이와 공통 z를 구분하여 변환하고 수직·수평 구간 및 오프셋의 높이가 두 화면에서 일치한다.
- 이미 공통 z인 경로는 층 기준 높이가 중복 가산되지 않는다.
- 층 높이·단위·변환이 미확인인 경로는 형상 미반영/작성 불가 사유가 표시되고 층 이름으로 좌표가 추정되지 않는다.
- 보기의 층 간격·축척 변경 후 저장 좌표·길이·연결은 유지된다.
- 형상 미반영 연결의 명시된 의미 정보는 OE-PIP-13 기준으로 보존되고 비활성 관계는 유효 출력에서 제외된다.

## 검증 (이 repo)

- 상대/공통 높이 변환, 층 높이 누락·좌표 충돌, 건물 구분, 보기 축척과 실제 좌표 분리 및 의미 정보 보존 검증이 필요하다.
