# OE-ML-16 경로 추적

## 요구사항

설비 또는 배관을 선택하면 같은 계통·매체의 유효 연결을 따라 층 내부와 층간 경로를 연속으로 표시한다. 연결 존재를 보는 연결 탐색과 확정 흐름 방향을 따르는 흐름 추적을 구분한다. 연결 탐색은 방향이 없어도 가능하지만 공급·담당 관계를 확정하는 근거로 사용하지 않는다.

흐름 추적은 선택한 상류/하류와 계통 종류·원천/말단 역할을 기준으로 한다(OE-PIP-04·05·07). 원천은 기계실 설비로 한정하지 않는다. 복수 원천·분기·대체 경로는 도달 대상별로 표시하고 하나를 임의로 유일한 공급자로 확정하지 않는다. 순환 경로는 반복 방문을 종료하고 순환 여부를 표시한다. 원천 역할·방향이 불명확하면 도달 범위와 부족 사유를 표시한다.

현재 유효한 연결만 통과한다. 사용자가 연결 해제한 BIM 배관 연결을 포함한 비활성·재검토 연결은 제외한다(OE-PIP-06). 흐름 추적은 방향 미지정에서 중단하며 미확정 규칙 방향을 사용하는 미리보기는 확정 경로와 구분한다. 연결 탐색과 추적 미리보기는 TTL 확정 관계나 담당을 새로 생성하지 않는다.

중단 사유·해당 연결을 목록에서 확인하고 연결 상세 패널로 이동할 수 있다. [해제 보정 취소]는 사용자가 명시적으로 적용한 뒤 경로를 갱신하며 재검토 상태는 검토 절차를 먼저 따른다. 추적이나 화면 전환만으로 연결이 복원되지 않는다.

## 수용 기준

- 상층 FCU와 B1F 펌프 사이에 같은 계통의 유효한 확정 흐름 경로가 있으면 해당 경로를 하이라이트한다.
- 방향 미지정 연결은 연결 탐색에서 확인할 수 있으나 확정 흐름 추적은 중단되고 사유가 표시된다.
- 복수 원천·대체 경로·순환이 있는 경우 도달 대상과 경로를 구분하고 반복 추적이 종료된다.
- 비활성·재검토 연결은 통과하지 않으며 해제 적용 후 중단 또는 대체 경로로 갱신된다.
- 중단 연결에서 상세 패널을 열어 명시적으로 보정 취소를 적용하면 재계산되며 단순 조회로 복원되지 않는다.
- 미확정 방향 미리보기와 확정 흐름 경로가 구분되고 탐색만으로 TTL·담당 관계가 확정되지 않는다.

## 검증 (이 repo)

- 기존 평면 추적 상태 표기는 층간 추적의 완료 근거가 아니다. 탐색/흐름 추적 구분, 복수 원천·순환, 비활성 제외, 미리보기 및 패널 연동 검증이 필요하다.
