# OE-ML-15 계통 종류 색상

## 요구사항

층간 배관과 각 층 평면 배관은 OE-OBJ-12·OE-PIP-03 및 glossary의 공통 Flow Type 범례와 색상 정의를 사용한다. SA·RA·EA·OA·냉온수·냉각수·냉매뿐 아니라 급탕·급수·소화·스팀·지열수 등 현재 범례에 포함된 값을 같은 기준으로 표시한다. 다중층 전용의 별도 유체 분류·색상 체계를 만들지 않는다.

Flow Type이 미분류이면 공통 미분류 표현과 문자 사유를 표시하고 임의의 유체 색으로 확정하지 않는다. 선택·미확정 방향·연결 해제·재검토 상태는 유체 색과 별도로 선 모양·문자 등으로 구분하며 색만으로 상태를 전달하지 않는다. 해제된 연결을 표시하더라도 유효 경로와 구분한다.

## 수용 기준

- 같은 Flow Type의 수직·수평 배관이 두 화면에서 같은 범례·색으로 표시된다.
- 공통 범례의 DCW·FP 등 급수·소화 값도 동일하게 표시되고 범례 추가를 기다리지 않는다.
- 미분류와 선택·해제·재검토 상태를 문자·선 표현으로 구분할 수 있고 유체 색으로 상태를 오인하지 않는다.
- 계통·유체 변경 후 두 화면의 색·범례가 함께 갱신된다.

## 검증 (이 repo)

- 공통 Flow Type 범례 일치, 미분류·해제·재검토 표현과 화면 간 갱신 검증이 필요하다.
