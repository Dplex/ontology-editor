# OE-ML-12 라이저 생성

## 요구사항

다중층 편집 모드의 설비 편집 모드에서 배관 그리기(OE-PIP-11)로 층을 지나는 수직 배관 구간(라이저)을 작성한다. 별도 라이저 도구는 제공하지 않는다. 시작·종료 연결 대상(설비·다른 배관·분기점)과 대상 층 범위, Flow Type·계통을 선택한다(OE-OBJ-12, OE-PIP-11).

사용자가 수직 구간의 위치와 연결 대상까지의 경로를 지정한다. 하나의 수직 구간은 x·y가 같고 z가 변한다. 시작·종료 대상의 x·y가 다르면 필요한 수평 연결 구간이나 층간 오프셋(OE-ML-14)을 사용자가 지정한다. 자동 라우팅으로 누락 경로를 채우거나 연결 대상을 이동하지 않는다. 선택한 층 범위는 두 연결 대상과 작성 경로의 높이를 포함해야 한다.

완료·취소·방향·연결·되돌리기 기준은 OE-PIP-11을 따른다. 층별 분기는 OE-ML-13으로 작성하며, 두 화면의 식별 정보와 상태 공유는 OE-PIP-15를 따른다.

대상 층 범위는 작업할 층을 표시하는 보기 범위이며 완료 경로가 참조하는 층과 유효한 높이를 포함해야 한다. 보기 범위만 변경하여 배관을 자르거나 실제 경로를 바꾸지 않는다. 경로가 보기 범위 밖이면 범위 확장을 안내하여 필요한 층을 확인한 후 완료한다. 층 상대 높이를 공통 z로 변환하는 기준과 높이 미확인 처리는 OE-ML-18을 따른다.

## 수용 기준

- 공통 배관 그리기에서 시작·종료 연결 대상과 층 범위·Flow Type·계통을 선택하고 수직 구간을 작성할 수 있다.
- x·y가 다른 연결 대상은 사용자가 지정한 수평 구간이나 오프셋을 통해 연결되고 대상 설비의 위치는 바뀌지 않는다.
- 연결 대상이나 경로가 선택한 층 범위 밖이면 범위 조정을 안내하고 그대로 완료하지 않는다.
- 유효한 경로를 완료하면 수동 배관과 연결이 생성되며 수동 확정 방향은 미지정 상태로 시작한다.
- 취소 후 임시 객체가 남지 않고, 완료된 배관은 실행 취소·저장 복원 및 화면 전환 후 동일한 ID와 상태를 유지한다.

- 보기 범위 변경만으로 작성·완료된 경로가 변경되지 않고, 필요한 층을 범위에 포함시킨 뒤 작성을 계속할 수 있다.
- 층 높이가 없거나 상대 높이를 공통 z로 변환할 수 없으면 해당 구간의 완료 불가 사유가 표시된다.

## 검증 (이 repo)

- 공통 배관 그리기를 이용한 층간 생성, 층 범위 검사, 수평 연결·오프셋 지정 및 취소·복원 검증이 필요하다.

## 메모

- 수직 구간은 배관 경로의 일부이며 일반 배관과 별개의 편집 도구나 연결·방향 정책을 갖지 않는다.
