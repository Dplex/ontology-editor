# OE-ML-12 라이저 생성

## 요구사항

라이저(층을 지나는 수직 배관)를 그린다 — 시작점(예: B1F 기계실 펌프)을 누르고 층 범위를 고른 뒤 종료점을 누른다. x·y 는 고정이고 z 만 변하는 수직 구간이다. 자동 라우팅은 없다. Flow Type 은 OE-OBJ-12.

## 수용 기준

시작·종료 설비를 고르면 두 설비를 잇는 수직 배관이 선택한 층 범위에 그려진다.
