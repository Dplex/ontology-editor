# OE-ML-01 진입 경로

## 요구사항

다중층 뷰에 들어가는 길은 셋이다 — ① 층 선택 화면의 [다중층 편집] 에서 층 범위(시작~종료 또는 전체)를 고른다. ② 층 편집 화면에서 수직 관통 오브젝트를 누르고 속성 패널의 [다중층 뷰에서 편집 ›] 를 누른다(관통 범위가 자동 선택된다). ③ 층 편집 화면의 설비 편집 모드 팔레트에서 [라이저] 도구를 고르면 자동으로 전환된다(OE-UI-04).

## 수용 기준

세 경로 모두에서 다중층 뷰가 열리고, ② 는 그 오브젝트의 관통 층이 선택되어 있다.
