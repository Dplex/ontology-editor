# OE-ML-01 진입 경로

## 요구사항

다중층 뷰에 들어가는 길은 셋이다 — ① 층 선택 화면의 [다중층 편집] 에서 층 범위(시작~종료 또는 전체)를 고른다. ② 층 편집 화면에서 수직 관통 오브젝트를 누르고 속성 패널의 [다중층 뷰에서 편집 ›] 를 누른다(관통 범위가 자동 선택된다). ③ 층 편집 화면에서 배관 그리기·편집 중 [다중층 편집에서 계속]을 누르고 대상 층 범위를 선택하여 이동한다(OE-UI-04, OE-PIP-15). ③은 현재 층·선택 대상·작성 중 경로를 유지하며, 전환 취소 시 원래 화면의 작성 상태를 유지한다. 다중층 편집 모드에서도 설비 편집 모드의 공통 배관 그리기·편집을 사용한다(OE-PIP-10·11). 별도의 라이저 도구 버튼은 제공하지 않는다.

다중층 뷰에서도 설비 편집 모드의 [연결 관리]와 오른쪽 연결 상세 패널을 제공한다(OE-UI-04, OE-PIP-06). 선택한 라이저·분기점에 관련된 연결을 목록에서 선택하고, 상태에 따라 [연결 해제 보정] 또는 [해제 보정 취소]를 실행할 수 있다. 해제된 연결도 목록에서 다시 찾아 복원할 수 있다.

층 편집 화면과 다중층 뷰는 같은 연결 식별 정보·보정 상태·편집 이력을 사용한다. 화면 전환은 보정 상태를 바꾸거나 원본 연결을 활성화하지 않는다. 보기 전용 상태와 재임포트 충돌은 OE-UI-04·OE-PIP-06의 실행 제한·검토 안내를 따른다.

다중층 편집 모드는 여러 층을 보는 화면이며 공간/설비 편집 모드와 구분한다. 계단·샤프트의 직접 편집은 공간 편집 모드, EL·ES·배관의 직접 편집은 설비 편집 모드에서 수행한다(OE-OBJ-14, OE-UI-04). 다른 모드 대상은 선택·조회만 가능하다. 샤프트 이동에 따른 배관 변경처럼 명시된 연동 작업은 영향 미리보기와 적용 절차를 따른다(OE-ML-17).

보기 층 범위와 오브젝트의 실제 관통·운행 구간은 별도 값이다. 보기 범위 변경만으로 데이터 구간이나 형상을 변경하지 않는다. 현재 층과 편집 대상의 층·높이를 표시하고, 숨겨진 영향 층은 작업 적용 전에 안내한다. 완료된 여러 층의 관련 변경은 하나의 편집 이력으로 저장·되돌리기하며 일부 층에만 적용하지 않는다(OE-UI-05, OE-HIST-03). R2 층 잠금은 영향받는 모든 층에 대해 확인하고 확보한다(OE-COM-05). R1에 다중 사용자 잠금을 추가 요구하지 않는다.

층 편집에서 다중층 모드로 진입하기 전에 완료된 층 편집을 별도 작업으로 저장·검증·확정한다(OE-WF-03). 성공한 확정 버전을 기준으로 새로운 다중층 세션 작업 ID를 만든다. 진입부터 종료까지의 모델 변경은 층·공간/설비 모드와 관계없이 하나의 작업으로 저장하며, 자동 동기화는 서버 초안과 복구 기록만 갱신한다. 개별 편집의 undo/redo는 현재 세션 안에서 유지한다. 이전 층 작업의 완료 이력은 보존하되 현재 세션의 undo로 이전 확정 작업을 되돌리지 않는다. 다중층 종료 시 전체 영향 층을 검증하여 한 번에 저장·확정하고 성공 후 층 편집으로 돌아간다. 실패하면 세션과 편집을 유지한다. 작성 중인 미완료 배관 경로는 확정 모델에서 제외하고 전환용 작성 상태로 보존하여 새 세션에서 계속한다. 진입 취소·실패 시 원래 작성 상태로 돌아간다.

## 수용 기준

- 세 경로 모두에서 다중층 뷰가 열리고, ②는 해당 오브젝트의 관통 층이 선택되어 있다.
- ③은 선택한 층 범위로 이동하며 현재 층·선택 대상·작성 중 경로를 유지한다. 전환 취소 후 원래 화면에서 작성을 계속할 수 있다.
- 세 경로로 연 다중층 편집 모드에서 같은 배관 그리기·편집 도구로 층간 배관과 층별 분기를 작성·수정할 수 있고, 별도의 라이저 도구 버튼은 없다.

- 세 진입 경로로 연 다중층 뷰에서 같은 연결 관리·상세 패널과 해제 보정·취소 동작을 사용할 수 있다.
- 해제된 라이저·분기 연결을 목록에서 선택할 수 있고, 층 편집 화면으로 돌아가도 연결 ID·보정 상태·이력이 일치한다.
- 화면 전환만으로 해제·재검토 연결이 활성화되지 않는다.

- 다중층 화면에서 공간/설비 편집 모드에 맞는 대상만 직접 편집할 수 있고, 샤프트 연동 작업은 영향 확인 후 적용된다.
- 보기 범위를 변경해도 실제 관통·운행 구간은 유지되고, 적용 전 화면 밖 영향 층을 확인할 수 있다.
- 여러 층에 걸친 하나의 완료 작업을 되돌리거나 저장 복원하면 형상·개구부·면적·연결·소속이 함께 복원된다.
- R2에서는 영향 층 중 다른 사용자가 잠근 층이 하나라도 있으면 작업 전체를 적용하지 않고 이유를 표시한다.

- 층 작업과 다중층 작업은 다른 ID로 저장되고, 여러 층·모드의 변경은 다중층 종료 시 하나의 완료 작업으로 기록된다. 자동 저장이 완료 버전을 추가하지 않고, 개별 undo는 현재 세션의 변경만 되돌린다. 진입 전 저장이나 종료 저장 실패 시 편집이 보존된다. 작성 중 경로는 확정 데이터에 포함되지 않고 성공한 진입 후 이어서 작성할 수 있다.
