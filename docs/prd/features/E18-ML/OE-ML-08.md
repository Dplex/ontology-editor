# OE-ML-08 구간 변경

## 요구사항

시작·종료 층을 바꾼다. 구간을 줄이면 빠진 층의 개구부가 닫히고, 늘리면 새 층에 개구부가 생긴다(OE-ML-03). EL 정차 층(OE-ML-10)이 구간 밖이 되면 지운다.

## 수용 기준

종료 층을 한 층 낮추면 빠진 층의 개구부가 사라지고 물리존 면적이 복원된다.
