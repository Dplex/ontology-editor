# OE-ML-08 구간 변경

## 요구사항

다중층 편집 모드에서 시작·종료 층을 변경한다. 보기 층 범위 변경과 실제 구간 변경을 구분하며 적용 전 추가/제외 층·층별 형상·개구부·면적·정차 층·운행 구간·연결·샤프트 배관 소속의 영향을 표시한다.

구간 확대 시 새 층의 형상·연결 지점을 지정하거나 공통 축에서 유효하게 계산하고 개구부는 OE-ML-03에 따라 확정/초안으로 처리한다. 층별 형상이 필요한 계단·ES에 형상을 임의 복제하여 완료하지 않는다. 구간 축소 시 제외 층의 편집 표현·명시 연결을 보정하고 그 작업만 사용하는 편집 개구부는 제거한다. 원본·공유 개구부는 보존하고 면적을 재계산한다.

EL 정차 층이 구간 밖이면 제거되는 층 목록을 보여주고 적용한다(OE-ML-10). ES의 기존 운행 구간·진입/종료 지점이 범위 밖이면 사용자가 유효한 구간을 다시 지정한 후 적용한다(OE-ML-11). 샤프트 구간 밖 배관은 삭제하거나 자동 절단하지 않고 배관을 보존하며 소속을 해제하고 사유를 표시한다(OE-ML-17). 관련 변경은 한 작업으로 되돌리고 저장 복원한다.

## 수용 기준

- 축소 적용 전 제외 층·정차 층·운행 구간·연결·배관 소속 영향을 확인할 수 있다.
- 확대 후 새 층의 유효한 표현과 개구부 확정/초안 상태가 표시되며 초안은 면적에서 차감되지 않는다.
- 축소 후 해당 작업만의 편집 개구부는 제거되고 원본·공유 개구부와 배관은 유지된다.
- ES 운행 구간이 새 범위 밖이면 조정하기 전 완료할 수 없고, EL의 제외 정차 층은 적용 후 목록에서 제거된다.
- 되돌리기 후 구간·정차/운행 정보·개구부·면적·연결·소속이 함께 복원된다.

## 검증 (이 repo)

- 확대·축소, 원본/공유 개구부 보존, EL·ES 구간 충돌 및 샤프트 배관 소속 변경·복원 검증이 필요하다.
