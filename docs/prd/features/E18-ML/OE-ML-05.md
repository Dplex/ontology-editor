# OE-ML-05 층 편집 화면 읽기 전용

## 요구사항

층 편집 화면에서 수직 관통 오브젝트(EL·ES·계단·샤프트)는 선택·속성 조회 즉 읽기만 가능하고 수정은 불가능하다. 이동·삭제·크기/층별 형상·구간·정차 층·운행 방향 편집은 비활성화하고 [다중층 뷰에서 편집]으로 안내한다(OE-ML-01 ②). 해당 층의 실제 형상과 진입/종료 지점을 표시한다.

층간 배관의 해당 층 수평 구간과 분기점에서 같은 층 배관을 이어 그리는 동작은 OE-PIP-15·OE-ML-13의 예외로 허용한다. 층간 수직 경로·오프셋 변경은 [다중층 뷰에서 편집]으로 이동한다. 예외가 수직 관통 오브젝트 자체의 이동·크기 변경을 허용하지는 않는다. 

## 수용 기준

- 층 편집 화면에서 EL·ES·계단·샤프트를 끌거나 삭제·크기/구간을 바꾸려 해도 데이터는 변경되지 않고 다중층 편집 안내가 보인다.
- 같은 부모 오브젝트의 층별 형상과 진입/종료 위치가 해당 층에 표시된다.
- 같은 층 분기 배관 작성은 가능하고 다른 층 경로의 형상 변경은 다중층 화면으로 안내된다.
