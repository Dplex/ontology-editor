# OE-ML-11 에스컬레이터 방향

## 관련 티켓

- [OE-ML-02](./OE-ML-02.md): 층별 형상과 진입/종료 위치·높이 기록
- [OE-ML-08](./OE-ML-08.md): 관통 구간 변경
- [OE-ML-04](./OE-ML-04.md): 구조적 층간 연결
- [OE-ML-19](./OE-ML-19.md): 로봇 통과 정보
- [OE-ML-06](./OE-ML-06.md): 수동 생성의 시작점·종료층 계산

## 요구사항
> User story : 구축 담당자는 에스컬레이터의 운행 방향(상행/하행)과 운행 구간(시작층·종료층)을 지정할 수 있다. 수동으로 만들 때는 시작 층의 시작점만 정하면 종료층은 바로 위층으로 정해지고, 방향은 상행이 초기값으로 제안되어 사용자가 확인한 뒤 완료된다. 서로 다른 두 층의 진입/종료 위치·높이와 층별 형상이 기록되며 모든 층에 같은 평면 위치가 강제되지 않는다. 구간을 바꾸거나 BIM으로 들어온 에스컬레이터에서 같은 층을 양 끝으로 잡거나 관통 구간 밖 지점을 고르면 완료할 수 없고, 관통 구간이 줄어 운행 구간이 벗어나면 다시 지정한 뒤 적용한다. BIM에 명시된 방향·구간은 보존되고 누락 정보는 '미확인'으로 두어 임의로 정하지 않는다. 사용자는 구조적 층간 연결은 레이아웃에 나가지만 에스컬레이터의 로봇 통과는 항상 불가로 유지되는 것을 확인할 수 있어야 한다.

ES의 운행 방향(상행/하행)과 운행 구간(시작층·종료층)을 지정한다. 서로 다른 두 층의 진입/종료 위치·높이와 층별 형상을 기록한다([OE-ML-02](./OE-ML-02.md)). 높이 기준의 하층/상층과 상행/하행에 따라 이동 시작·종료 지점을 구분하고 모든 층에 같은 평면 위치를 강제하지 않는다.

수동 생성은 시작 층의 시작점만 받고 종료층은 높이 순서상 바로 위층, 종료점은 기본 형상으로 계산한다([OE-ML-06](./OE-ML-06.md)). 이때 방향의 초기 선택은 상행으로 두고 사용자가 확인·수정하여 완료하며, 확인 전에는 완료하지 않는다. 이어지는 ES는 운행 방향이 같은 구간끼리만 연결 지점 스냅으로 잇는다(OE-ML-06). 연결 지점은 높이 기준으로 아래 구간의 상층 지점과 위 구간의 하층 지점이 같은 층에서 만나는 자리다. 상행은 하층 지점이 운행 시작, 상층 지점이 운행 끝이라 1-2층 상행의 끝이 2-3층 상행의 시작과 이어진다. 하행은 상층 지점이 운행 시작이라 3-4층 하행의 끝(3층)이 2-3층 하행의 시작(3층)과 이어진다. 연결된 ES의 방향을 바꾸면 그 연결은 방향이 맞지 않으므로 재검토로 표시하고, 연결을 해제하거나 이어진 구간의 방향도 바꾸도록 안내한다. 생성 후 운행 구간을 바꾸는 것은 [OE-ML-08](./OE-ML-08.md)을 따른다.

운행 구간과 연결 지점은 같은 건물의 관통 구간 안에 있어야 한다. 구간 변경으로 범위를 벗어나면 영향을 표시하고 유효한 구간·지점을 다시 지정한 후 적용한다([OE-ML-08](./OE-ML-08.md)). BIM의 명시된 방향·구간은 보존하고 BIM에서 누락된 정보는 미확인으로 표시하여 방향을 임의로 정하지 않는다. 구조적 층간 연결은 출력할 수 있어도 로봇 통과는 불가다([OE-ML-04](./OE-ML-04.md), [OE-ML-19](./OE-ML-19.md)).

## 수용 기준

- **AC1** 서로 다른 층·위치의 진입/종료 지점과 상행/하행 방향을 설정하여 GeoJSON에 출력할 수 있다.
- **AC2** 수동 생성 시 시작점만 지정하면 종료층이 바로 위층으로 정해지고, 상행 초기 선택을 확인·수정한 뒤에만 완료된다.
- **AC3** 구간 변경이나 BIM 보정에서 같은 층을 양 끝으로 지정하거나 관통 구간 밖의 운행 구간·지점을 지정하면 완료할 수 없다.
- **AC4** 관통 구간 축소 후 운행 구간이 벗어나면 조정 전 적용되지 않는다.
- **AC5** BIM에서 방향이 누락된 ES는 미확인으로 남아 임의 확정되지 않고, ES 로봇 통과 속성은 불가로 유지된다.
- **AC6** 같은 방향 ES끼리만 연결 지점이 이어지고, 연결된 ES 한쪽의 방향을 바꾸면 그 연결이 재검토로 표시된다.
- **AC7** 방향·구간·층별 형상·연결 지점은 되돌리기·저장 복원 후 일치한다.
