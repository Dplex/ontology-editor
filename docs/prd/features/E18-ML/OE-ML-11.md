# OE-ML-11 에스컬레이터 방향

## 관련 티켓

- [OE-ML-02](./OE-ML-02.md): 층별 형상과 진입/종료 위치·높이 기록
- [OE-ML-08](./OE-ML-08.md): 관통 구간 변경
- [OE-ML-04](./OE-ML-04.md): 구조적 층간 연결
- [OE-ML-19](./OE-ML-19.md): 로봇 통과 정보

## 요구사항
> User story : 구축 담당자는 에스컬레이터의 운행 방향(상행/하행)과 운행 구간(시작층·종료층)을 지정할 수 있다. 서로 다른 두 층의 진입/종료 위치·높이와 층별 형상이 기록되며 모든 층에 같은 평면 위치가 강제되지 않는다. 같은 층을 양 끝으로 잡거나 관통 구간 밖 지점을 고르면 완료할 수 없고, 관통 구간이 줄어 운행 구간이 벗어나면 다시 지정한 뒤 적용한다. BIM에 명시된 방향·구간은 보존되고 누락 정보는 '미확인'으로 두어 임의로 정하지 않는다. 사용자는 구조적 층간 연결은 레이아웃에 나가지만 에스컬레이터의 로봇 통과는 항상 불가로 유지되는 것을 확인할 수 있어야 한다.

ES의 운행 방향(상행/하행)과 운행 구간(시작층·종료층)을 지정한다. 서로 다른 두 층의 진입/종료 위치·높이와 층별 형상을 기록한다([OE-ML-02](./OE-ML-02.md)). 높이 기준의 하층/상층과 상행/하행에 따라 이동 시작·종료 지점을 구분하고 모든 층에 같은 평면 위치를 강제하지 않는다.

운행 구간과 연결 지점은 같은 건물의 관통 구간 안에 있어야 한다. 구간 변경으로 범위를 벗어나면 영향을 표시하고 유효한 구간·지점을 다시 지정한 후 적용한다([OE-ML-08](./OE-ML-08.md)). BIM의 명시된 방향·구간은 보존하고 누락 정보는 미확인으로 표시하여 방향을 임의로 정하지 않는다. 구조적 층간 연결은 출력할 수 있어도 로봇 통과는 불가다([OE-ML-04](./OE-ML-04.md), [OE-ML-19](./OE-ML-19.md)).

## 수용 기준

- **AC1** 서로 다른 층·위치의 진입/종료 지점과 상행/하행 방향을 설정하여 GeoJSON에 출력할 수 있다.
- **AC2** 같은 층을 양 끝으로 지정하거나 관통 구간 밖의 운행 구간·지점을 지정하면 완료할 수 없다.
- **AC3** 관통 구간 축소 후 운행 구간이 벗어나면 조정 전 적용되지 않는다.
- **AC4** 방향 미확인은 임의 확정되지 않고 ES 로봇 통과 속성은 불가로 유지된다.
- **AC5** 방향·구간·층별 형상·연결 지점은 되돌리기·저장 복원 후 일치한다.
