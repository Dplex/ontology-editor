# OE-ML-11 에스컬레이터 방향

## 요구사항

ES 의 운행 방향(상행/하행)과 운행 구간(층↔층)을 지정한다(glossary "에스컬레이터"). 운행 구간은 관통 구간 안이어야 한다.

## 수용 기준

방향과 구간이 GeoJSON 의 ES 속성으로 나간다.
