# OE-COM-02 반영 권한

## 관련 티켓

- [OE-WF-07](../E14-WF/OE-WF-07.md): 반영 전 미리보기 확인
- [OE-WF-10](../E14-WF/OE-WF-10.md): 권한자가 실행하는 반영

## 요구사항

### User story

고객사 관리자(편집 권한자)가 레이아웃 변경을 마치면 [미리보기]로 결과를 확인한 뒤 스스로 [반영하기]를 실행한다. 상급자 승인을 기다리는 단계가 없어 급한 센서 재배치를 바로 반영하고, 숙련된 사용자는 미리보기를 건너뛰고 바로 반영할 수도 있다. 승인 워크플로우 대신 반영 결과 리포트와 되돌리기, 시스템 로그로 사후 추적·복구가 보장되므로 속도와 책임 추적을 함께 잡는다. R2에서 권한 제어가 들어와도 승인 단계는 추가되지 않고 '누가 반영할 수 있는가'만 역할로 제한되므로, 편집 권한자는 권한 범위 안에서 계속 자율적으로 반영한다.

편집 권한자는 [미리보기]로 결과를 확인한 뒤 직접 [반영하기]를 실행한다(OE-WF-07·10). 
반영 전에 다른 사람의 승인을 받는 단계는 두지 않는다. 미리보기를 거치지 않고 바로 반영하는 것도 막지 않는다.

## 수용 기준

편집 권한자가 [반영하기]를 누르면 승인 요청 없이 반영이 실행된다.
