# OE-COM-05 층 단위 편집 잠금

## 관련 티켓

- [OE-INT-01](../E20-INT/OE-INT-01.md): 잠금 정보 저장 위치

## 요구사항

편집 잠금은 층 단위다(glossary "편집 잠금"). 사용자가 어느 층의 편집을 시작하면 그 층을 잠그고, 다른 사용자가 같은 층에 들어오려 하면 "OOO님이 편집 중입니다" 를 보이고 편집 진입을 막는다.
다른 층의 편집은 막지 않는다. 잠금은 보기(읽기)를 막지 않는다.
잠금 정보를 어디에 두는지는 데이터 교환 방식(D-INT)에 따른다. 저장 위치와 무관하게 동작해야 한다(S6).

## 수용 기준

- 같은 층을 두 사용자가 동시에 편집할 수 없다. 한 사용자가 N층을 편집 중일 때 다른 사용자는 N층 편집 진입이 거부되고 편집 중인 사용자 이름이 보인다.
- 다른 층은 동시에 편집할 수 있다.
