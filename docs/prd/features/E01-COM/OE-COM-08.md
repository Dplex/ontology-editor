# OE-COM-08 상시 버튼·미저장 확인

- [OE-WF-10](../E14-WF/OE-WF-10.md): DT 3D 맵·온톨로지 반영
- [OE-WF-01](../E14-WF/OE-WF-01.md): DT 미반영 임시 저장
- [OE-WF-03](../E14-WF/OE-WF-03.md): 층마다 하나인 임시 저장본

## 요구사항
> User story : 고객사 관리자는 편집 중 상단 액션바에서 [임시 저장]과 [반영하기] 버튼을 항상 볼 수 있다. [임시 저장]은 작업 내용을 보관하지만 DT에는 반영하지 않고, [반영하기]는 변경을 DT 3D 맵과 온톨로지에 반영해 웹에서 바로 확인할 수 있게 한다. 임시 저장본은 층마다 하나이며, 임시 저장본이 있는 층에 다시 들어가면 자동으로 이어서 편집할 수 있다. 저장하지 않은 변경이 있는 채 에디터를 닫거나 다른 층으로 가려 하면 확인 팝업을 받아 작업을 잃지 않을 수 있어야 한다. R2에서는 다른 사용자가 편집 중인 층은 편집할 수 없고, 임시 저장된 층은 다른 편집 권한자가 이어서 편집할 수 있다.

R1 요구사항 : 편집 중에는 [임시 저장]과 [반영하기] 버튼을 항상 보인다(상단 액션바, OE-UI-04).
[반영하기]를 누르면 변경이 온톨로지에 반영되어 웹에서 바로 확인할 수 있다(OE-WF-10). [임시 저장]은 DT 에 반영하지 않는다(OE-WF-01).
임시 저장본은 층마다 하나이며 목록을 두지 않는다(OE-WF-03). 임시 저장본이 있는 층에 들어가면 자동으로 이어서 편집한다(OE-WF-02).
저장하지 않은 변경이 있는 상태에서 에디터를 닫거나 다른 층으로 가려 하면 확인 팝업을 띄운다.

R2 요구사항 : 다른 사용자가 편집 중(잠금)인 층은 편집할 수 없다(OE-COM-05). 편집을 마치고 임시 저장한 층은 다른 편집 권한자가 이어서 편집할 수 있다(OE-COM-03).편집 내용은 편집 파일로 로컬에 저장하고 불러올 수 있다(OE-HIST-03).

## 수용 기준

- **AC1** 편집 중 액션바에 [임시 저장]·[반영하기]가 항상 보인다.
- **AC2** 저장하지 않은 변경이 있을 때 탭을 닫거나 층을 바꾸려 하면 확인 팝업이 뜬다.
- **AC3** 임시 저장본이 있는 층에 다시 들어가면 임시 저장본이 열린다.
