# OE-COM-08 상시 버튼·미저장 확인

## 요구사항
Phase 1
- 편집 도중 저장 버튼 및 임시 저장 버튼을 제공한다. 
- 저장 시 변경사항을 웹에서 바로 확인할 수 있어야 한다.
- 임시 저장 시 변경사항은 웹에 반영되지 않는다.
- 임시 저장한 내용의 목록을 확인하고, 파일 열기로 불러와 편집을 이어 갈 수 있어야 한다.

Phase 2
-  다른 사용자가 '임시 저장'한 site 혹은 'level(층)' 에 대해서는 온톨로지 편집을 수행할 수 없다. 
- 저장과 임시 저장을 로컬 파일로도 할 수 있어야 한다.

## 수용 기준

미저장 상태에서 종료 시 팝업 노출
임시 저장한 목록에서 불러와 편집을 이어 갈 수 있다
