# OE-COM-08 상시 버튼·미저장 확인

- [OE-WF-10](../E14-WF/OE-WF-10.md): DT 3D 맵·온톨로지 반영
- [OE-WF-01](../E14-WF/OE-WF-01.md): DT 미반영 임시 저장

## 요구사항

R1 요구사항 : 편집 중에는 [임시 저장]과 [반영하기] 버튼을 항상 보인다(상단 액션바, OE-UI-04).
[반영하기]를 누르면 변경이 DT 3D 맵과 온톨로지에 반영되어 웹에서 바로 확인할 수 있다(OE-WF-10). [임시 저장]은 DT 에 반영하지 않는다(OE-WF-01).
임시 저장본은 층마다 하나이며 목록을 두지 않는다(OE-WF-03). 임시 저장본이 있는 층에 들어가면 자동으로 이어서 편집한다(OE-WF-02).
저장하지 않은 변경이 있는 상태에서 에디터를 닫거나 다른 층으로 가려 하면 확인 팝업을 띄운다.

R2 요구사항 : 다른 사용자가 편집 중(잠금)인 층은 편집할 수 없다(OE-COM-05). 편집을 마치고 임시 저장한 층은 다른 편집 권한자가 이어서 편집할 수 있다(OE-COM-03).편집 내용은 편집 파일로 로컬에 저장하고 불러올 수 있다(OE-HIST-03).

## 수용 기준

- 편집 중 액션바에 [임시 저장]·[반영하기]가 항상 보인다.
- 저장하지 않은 변경이 있을 때 탭을 닫거나 층을 바꾸려 하면 확인 팝업이 뜬다.
- 임시 저장본이 있는 층에 다시 들어가면 임시 저장본이 열린다.

## 검증 (이 repo)

- `e2e/exit-edit.spec.ts`: 편집이 없거나 저장한 뒤에는 묻지 않는다 · 취소(버튼·Esc)는 편집을 잇는다 · 끝내는 길(편집 종료·보기·`E`)이 같은 질문을 거친다 · 임시 저장은 브라우저에 남기고 다시 열면 이어서 할지 묻는다 · 저장 안 함은 연 때로 되돌리고 위 줄에서 한 번 되살린다
- `e2e/conduit-follow.spec.ts` 끝: 배관이 따라온 편집을 저장 안 함으로 끝내면 설비 형상 전부가 연 때 자리로 돌아온다(Duplex MEP)
- 화면: `docs/figures/app-exit-edit-dialog.png`, `docs/figures/app-exit-edit-discarded.png`

## 메모

- PoC 에는 반영할 Production 이 없다(PRD 1.7, D10). 그래서 "저장" 은 [구축하기](온톨로지 두 파일)와 [편집 저장](편집 파일)이고,
  둘 중 하나를 한 뒤로 바뀐 것이 없으면 묻지 않는다. 바뀐 것은 편집 파일 내용으로 견주어서, 되돌리기로 저장한 때와 같아지면 묻지 않는다.
- 임시 저장은 이 브라우저(자동 저장과 같은 자리)에 남긴다. 파일로 내려받게 했더니 보기로 바꿀 때마다 다운로드가 생겼다.
  같은 IFC 를 다시 열면 [이어서 하기]를 묻는다. 저장소가 막혀 있으면 파일로 내려받는다.
- 저장 안 함은 연 때(마지막으로 덧붙인 때)로 되돌린다. 잘못 누르면 고친 것이 사라지므로, 버린 편집을 위 줄에 올려 한 번 되살릴 수 있게 둔다.
- 끝내는 길 넷(편집 종료 · 도구막대 보기 · `E` · 전체 화면의 편집 체크)이 전부 `leaveEdit` 을 거친다. 전체 화면에서는 대화상자가 안 보여서 먼저 나온다.
- Phase 2(다른 사람이 임시 저장한 층은 편집 불가)는 편집 잠금이라 저장 위치가 서버로 정해진 뒤의 일이다.
