# OE-COM-03 임시 저장본 공동 접근

## 관련 티켓

- [OE-WF-01](../E14-WF/OE-WF-01.md): 층 단위 임시 저장본
- [OE-COM-05](./OE-COM-05.md): 편집 중인 층 열기 차단

## 요구사항

### User story

임시 저장본은 특정 사용자가 아닌 층의 것이다. R2에서 고객사 관리자 A가 3층 레이아웃을 절반 작업하고 임시 저장 후 퇴근하면, 다음 날 동료 B(Admin)가 3층에 들어가 A의 저장본을 그대로 열어 이어서 편집한다. 다만 A가 아직 편집 중(잠금)이면 B는 열지 못하고 안내를 받아 동시 편집 충돌이 없다. 작업이 개인 계정에 묶이지 않아 교대 근무나 담당자 변경 시에도 레이아웃 변경이 중단되지 않는다.

임시 저장본(OE-WF-01)은 특정 사용자의 것이 아니라 층의 것이다. 
R2 요구사항 : 편집 권한자는 누구나 그 층의 임시 저장본을 열어 보고 이어서 편집할 수 있다.
R2 요구사항 : 다만 다른 사용자가 그 층을 편집 중(잠금, OE-COM-05)인 동안에는 열지 못한다. 잠금이 풀린 뒤에 열 수 있다.

## 수용 기준

- R2 요구사항 : A 가 임시 저장 후 편집을 종료한 층을 B(Admin)가 열면 A 의 임시 저장본이 그대로 보이고 이어서 편집할 수 있다.
- R2 요구사항 : A 가 편집 중인 층은 B 가 열지 못하고 OE-COM-05 의 안내가 보인다.
