# OE-COM-04 시스템 로그

## 관련 티켓

- [OE-XPRD-01](../E22-XPRD/OE-XPRD-01.md): 반영·되돌리기 로그 유형 추가

## 요구사항
> User story : 고객사의 보안·감사 담당자는 시스템 로그에서 에디터의 편집 시작·임시 저장·반영·되돌리기·편집 종료 이벤트를 확인할 수 있다. 기록 항목은 이벤트 유형·일시·사용자·사이트·대상 층·버전 번호(반영과 되돌리기일 때)다. 사용자는 지난달 특정 층 레이아웃을 누가 바꿨는지 로그에서 찾을 수 있어야 하며, 반영과 되돌리기가 1회당 로그 1건으로 남아 버전 히스토리와 건수를 대조할 수 있고, 버전 히스토리와 달리 로그는 기간 제한 없이 남는다.

편집 시작·임시 저장·반영·되돌리기·편집 종료 이벤트를 시스템 로그에 기록한다. 
로그 유형은  '레이아웃 반영 / 되돌리기' 를 관리하며, (R2) 해당 로그는 Digital Twin 시스템 로그와 연동된다(OE-XPRD-01).
기록 항목은 이벤트 유형·일시·사용자·사이트·대상 층·버전 번호(반영·되돌리기일 때)다.

## 수용 기준

반영과 되돌리기 1회마다 로그 1건이 남고, 각 건에 이벤트 유형·일시·사용자·대상 층·버전 번호가 있다.
