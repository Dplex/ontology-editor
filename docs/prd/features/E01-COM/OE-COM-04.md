# OE-COM-04 시스템 로그

## 관련 티켓

- [OE-XPRD-01](../E22-XPRD/OE-XPRD-01.md): 반영·되돌리기 로그 유형 추가

## 요구사항

### User story

R2에서 고객사 보안·감사 담당자가 '지난달 5층 레이아웃을 누가 바꿨는지' 확인할 때 PRD_009 시스템 로그에서 '레이아웃 반영/되돌리기' 유형으로 필터해 이벤트 유형·일시·사용자·사이트·대상 층·버전 번호를 본다. 편집 시작·임시 저장·편집 종료도 기록되어 작업 흐름 전체가 추적되고, 버전 히스토리가 1주일만 보관하는 것과 달리 로그는 기간 제한 없이 남아 감사 요구에 대응한다. 로그 유형이 PRD_009에 정식으로 추가되어 다른 시스템 이벤트와 같은 화면에서 조회·내보내기가 되고, 반영과 되돌리기가 1회당 1건으로 남아 버전 히스토리와 건수를 대조할 수 있다.

편집 시작·임시 저장·반영·되돌리기·편집 종료 이벤트를 시스템 로그에 기록한다. 로그 유형은 PRD_009 시스템 로그에 '레이아웃 반영 / 되돌리기' 를 더해 쓴다(OE-XPRD-01).
기록 항목은 이벤트 유형·일시·사용자·사이트·대상 층·버전 번호(반영·되돌리기일 때)다.

## 수용 기준

반영과 되돌리기 1회마다 로그 1건이 남고, 각 건에 이벤트 유형·일시·사용자·대상 층·버전 번호가 있다.
