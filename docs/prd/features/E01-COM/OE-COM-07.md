# OE-COM-07 잠금 해제 — 비정상 종료

## 관련 티켓

- [OE-COM-05](./OE-COM-05.md): 자동 해제할 층 편집 잠금

## 요구사항
> User story : R2에서 고객사 관리자 A가 3층 편집 중 노트북 배터리가 꺼져 브라우저가 강제 종료되면, heartbeat 중단으로 끊김이 감지되어 60초 뒤 잠금이 자동으로 풀린다. 동료 B는 60초 전에는 들어갈 수 없어 A가 잠깐 네트워크가 끊겼다 복귀하는 경우를 보호받고, 60초 후에는 들어갈 수 있어 A가 연락 두절이어도 층이 영구히 잠기지 않는다. heartbeat 감지 수준과 잠금 서버 위치는 Q1(D-INT 종속)에서 정한다.

브라우저 강제 종료·네트워크 단절처럼 정상 종료 없이 접속이 끊기면, 끊긴 시점 기준 60초 뒤에 잠금을 자동으로 푼다. 끊김은 heartbeat 중단으로 감지한다.
heartbeat 를 어느 수준(클라이언트·서버)에서 감지하고 잠금 서버를 어디에 둘지는 Q1(D-INT 종속)이다.

## 수용 기준

편집 중 브라우저를 강제 종료하면 60초 뒤 다른 사용자가 같은 층 편집에 진입할 수 있다. 60초 전에는 진입할 수 없다.
