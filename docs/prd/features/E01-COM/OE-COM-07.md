# OE-COM-07 잠금 해제 — 비정상 종료

## 관련 티켓

- [OE-COM-05](./OE-COM-05.md): 자동 해제할 층 편집 잠금

## 요구사항
> User story : R2에서 고객사 관리자가 편집 중 브라우저 강제 종료나 네트워크 단절처럼 정상 종료 없이 접속이 끊기면, 끊긴 시점 기준 일정 시간 뒤에 그 층의 잠금이 자동으로 풀린다. 끊김은 주기적 생존 신호(heartbeat) 중단으로 감지한다. 사용자는 잠깐 네트워크가 끊겼다 복귀하는 경우에는 잠금이 유지되어 보호받고, 연락이 두절되어도 층이 영구히 잠기지 않는 것을 기대할 수 있어야 한다. 다른 사용자는 유예 시간 전에는 들어갈 수 없고 지난 뒤에는 들어갈 수 있다. 생존 신호를 어느 수준에서 감지하고 잠금 서버를 어디에 둘지는 데이터 교환 방식에 종속된 결정 사항이다.

브라우저 강제 종료·네트워크 단절처럼 정상 종료 없이 접속이 끊기면, 끊긴 시점 기준 60초 뒤에 잠금을 자동으로 푼다. 끊김은 heartbeat 중단으로 감지한다.
heartbeat 를 어느 수준(클라이언트·서버)에서 감지하고 잠금 서버를 어디에 둘지는 Q1(D-INT 종속)이다.

## 수용 기준

편집 중 브라우저를 강제 종료하면 60초 뒤 다른 사용자가 같은 층 편집에 진입할 수 있다. 60초 전에는 진입할 수 없다.
