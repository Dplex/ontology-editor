# OE-COM-06 잠금 해제 — 정상 종료

## 관련 티켓

- [OE-COM-05](./OE-COM-05.md): 해제할 층 편집 잠금

## 요구사항
> User story : R2에서 고객사 관리자가 [편집 종료]를 누르거나 [반영하기]·[임시 저장] 뒤 화면을 떠나면 그 층의 편집 잠금이 즉시 풀린다. 풀린 층에는 다른 사용자가 바로 들어갈 수 있다. 사용자는 정상적으로 작업을 마친 뒤 잠금을 수동으로 해제하는 절차를 기억할 필요가 없어야 하며, 동료는 아직도 편집 중이라는 메시지를 보며 기다리는 일 없이 바로 작업을 이어받을 수 있다. 반영 후 떠난 층은 이미 DT에 반영된 상태이고 임시 저장 후 떠난 층은 저장본이 남아 있으므로 다음 사용자가 보는 상태가 명확하다.

편집 잠금은 사용자가 [편집 종료]를 누르거나, [반영하기]·[임시 저장] 뒤 화면을 떠나면 즉시 풀린다. 풀린 층에는 다른 사용자가 바로 들어갈 수 있다.

## 수용 기준

- **AC1** [편집 종료] 직후 다른 사용자가 같은 층 편집에 진입할 수 있다.
- **AC2** [반영하기] 또는 [임시 저장] 후 화면을 떠난 직후에도 같다.
