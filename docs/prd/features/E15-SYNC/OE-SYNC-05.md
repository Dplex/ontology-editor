# OE-SYNC-05 리포트에서 되돌리기

## 관련 티켓

- [OE-WF-19](../E14-WF/OE-WF-19.md): 리포트에서 들어갈 되돌리기

## 요구사항
> User story : 고객사 관리자가 반영 결과 리포트에서 문제를 발견하면 리포트 안의 [되돌리기]로 바로 되돌리기 화면에 들어갈 수 있다. 되돌릴 버전은 리포트의 직전 버전이 기본으로 선택되어 있어, 버전 히스토리로 이동해 어느 버전인지 찾는 과정 없이 즉시 복구를 시작할 수 있다. 사용자가 다른 버전을 고를 수도 있어 연속된 여러 반영 중 어디서부터 잘못됐는지 판단한 뒤 적절한 지점으로 돌아갈 수 있다. 사용자는 문제 발견에서 복구까지의 경로가 짧아 잘못된 레이아웃이 관제에 노출되는 시간을 줄일 수 있어야 한다.

반영 결과 리포트에서 문제를 발견하면 리포트 안의 [되돌리기] 로 바로 OE-WF-19 에 들어간다. 되돌릴 버전은 리포트의 직전 버전이 기본 선택된다.

## 수용 기준

리포트의 [되돌리기] 를 누르면 직전 버전이 선택된 되돌리기 화면이 열린다.
