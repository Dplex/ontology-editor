# OE-SYNC-05 리포트에서 되돌리기

## 요구사항

반영 결과 리포트에서 문제를 발견하면 리포트 안의 [되돌리기] 로 바로 OE-WF-19 에 들어간다. 되돌릴 버전은 리포트의 직전 버전이 기본 선택된다.

## 수용 기준

리포트의 [되돌리기] 를 누르면 직전 버전이 선택된 되돌리기 화면이 열린다.
