# OE-SYNC-04 반영 결과 리포트 (#21)

## 관련 티켓

- [OE-MAP-04](../E11-MAP/OE-MAP-04.md): Z-01 미매핑 경고
- [OE-MAP-01](../E11-MAP/OE-MAP-01.md): 사람 지정 해제와 이유
- [OE-SYNC-06](./OE-SYNC-06.md): 리포트 집계 규칙
- [OE-WF-18](../E14-WF/OE-WF-18.md): 히스토리에서 리포트 열기

## 요구사항
> User story : 고객사 관리자가 반영을 마치면 결과 리포트가 열려 소속이 바뀐 설비(이전→새), 생성·삭제·분할·병합한 물리존, 물리존↔공조존 매핑 변경과 Z-01 미매핑 경고, 소속이 없어진 설비, 사람 지정이 풀린 설비와 이유, 배관 변경 여섯 항목을 확인한다. 의도치 않은 소속 변경이나 담당 없는 방이 보이면 바로 되돌리기로 넘어가고, 리포트는 버전 히스토리에 붙어 나중에 누구든 다시 연다. 집계 규칙은 편집 리포트 규칙(OE-SYNC-06)과 같아 미리보기에서 본 요약과 반영 후 리포트가 어긋나지 않고, 여섯 항목이 빠짐없이 있어야 하므로 변경이 없는 항목도 '없음'으로 명시된다.

반영 결과 리포트(#21)는 다음을 적는다 — 소속이 바뀐 설비 목록(이전→새), 생성·삭제·분할·병합한 물리존, 물리존↔공조존 매핑 변경과 미매핑 경고(Z-01, OE-MAP-04), 소속이 없어진 설비, 사람 지정이 풀린 설비와 그 이유(OE-MAP-01, K17), 배관 변경. 집계 규칙은 OE-SYNC-06.
반영 완료 화면과 버전 히스토리(OE-WF-18)에서 연다.

## 수용 기준

반영 뒤 리포트가 열리고 여섯 항목(사람 지정 해제 포함)이 모두 있다.
