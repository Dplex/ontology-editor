# OE-SYNC-04 반영 결과 리포트 (#21)

## 관련 티켓

- [OE-MAP-04](../E11-MAP/OE-MAP-04.md): Z-01 미매핑 경고
- [OE-MAP-01](../E11-MAP/OE-MAP-01.md): 사람 지정 해제와 이유
- [OE-SYNC-06](./OE-SYNC-06.md): 리포트 집계 규칙
- [OE-WF-18](../E14-WF/OE-WF-18.md): 히스토리에서 리포트 열기
- [OE-ZON-05](../E10-ZON/OE-ZON-05.md): 리포트에 들어갈 공조존 검증 결과

## 요구사항
> User story : 고객사 관리자가 반영을 마치면 반영 결과 리포트가 열린다. 리포트는 세 부분이다. 첫째, 소속이 바뀐 설비 목록(이전과 새 물리존), 생성·삭제·분할·병합한 물리존, 물리존과 공조존 매핑 변경, 소속이 없어진 설비, 사람 지정이 풀린 설비와 그 이유, 배관 변경 여섯 항목. 둘째, 소속은 그대로이고 이름·층·좌표만 바뀐 것 같은 그 밖의 변경. 셋째, 담당 없음 경고를 포함한 공조존 검증 결과. 집계 규칙은 편집 리포트 규칙과 같다. 사용자는 의도치 않은 소속 변경이나 담당 없는 방이 보이면 바로 되돌리기로 넘어갈 수 있어야 하며, 리포트는 반영 완료 화면과 버전 히스토리에서 열 수 있어 나중에 누구든 다시 볼 수 있다.

반영 결과 리포트(#21)는 세 부분을 적는다. 집계 규칙은 OE-SYNC-06.
1. 소속·구조 변경 여섯 항목 — 소속이 바뀐 설비 목록(이전→새), 생성·삭제·분할·병합한 물리존, 물리존↔공조존 매핑 변경, 소속이 없어진 설비, 사람 지정이 풀린 설비와 그 이유(OE-MAP-01, K17), 배관 변경.
2. 그 밖의 변경 — 내보내는 파일을 바꾸는 이름·층·좌표 변경을 열었을 때 값과 비교해 적는다(OE-SYNC-06).
3. 공조존 검증 결과 — Z-01~06 경고와 판정 불가 수(OE-ZON-05). 어느 공조존도 담당하지 않는 물리존의 Z-01 경고(OE-MAP-04)는 여기에 적는다.
반영 완료 화면과 버전 히스토리(OE-WF-18)에서 연다.

## 수용 기준

- **AC1** 반영 뒤 리포트가 열리고 첫째 부분의 여섯 항목(사람 지정 해제 포함)이 모두 있다.
- **AC2** 소속은 그대로이고 이름이나 좌표만 바꾼 설비가 둘째 부분에 한 줄로 보인다.
- **AC3** 담당 공조존이 없는 물리존을 만든 뒤 반영하면 셋째 부분에 Z-01 경고가 있고, Z-02~06 경고와 판정 불가 수도 같은 부분에 보인다.
