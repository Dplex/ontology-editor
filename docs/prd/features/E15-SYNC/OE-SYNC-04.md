# OE-SYNC-04 반영 결과 리포트 (#21)

## 요구사항

반영 결과 리포트(#21)는 다음을 적는다 — 소속이 바뀐 설비 목록(이전→새), 생성·삭제·분할·병합한 물리존, 물리존↔공조존 매핑 변경과 미매핑 경고(Z-01, OE-MAP-04), 소속이 없어진 설비, 사람 지정이 풀린 설비와 그 이유(OE-MAP-01, K17), 배관 변경. 집계 규칙은 OE-SYNC-06.
반영 완료 화면과 버전 히스토리(OE-WF-18)에서 연다.

## 수용 기준

반영 뒤 리포트가 열리고 여섯 항목(사람 지정 해제 포함)이 모두 있다.
