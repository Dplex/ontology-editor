# OE-SYNC-02 부분 반영 금지

## 관련 티켓

- [OE-WF-10](../E14-WF/OE-WF-10.md): 한 번에 반영하는 반영하기
- [OE-INT-01](../E20-INT/OE-INT-01.md): 트랜잭션 구현 방식 결정

## 요구사항
> User story : 고객사 관리자가 반영하는 도중 온톨로지 반영이 실패하면 DT 레이아웃 반영도 전체 실패로 처리되어 반영 전 상태로 돌아간다. 둘을 한 트랜잭션으로 묶거나, 저장소가 분리되어 있으면 실패 시 DT 반영을 되돌린다. 부분 반영 상태는 남지 않는다. 사용자는 3D에서는 회의실이 둘로 나뉘었는데 Agent는 여전히 하나로 아는 식의 불일치를 겪지 않아야 하며, 관제 사용자와 Agent 사용자가 서로 다른 건물을 보는 혼란이 없다. 구현 방식은 데이터 교환 방식 결정에 따르지만 사용자가 보는 결과는 전부 되거나 전부 안 되거나 둘 중 하나다.

온톨로지 반영이 실패하면 DT 레이아웃 반영도 전체 실패로 처리한다. 둘은 한 트랜잭션으로 묶거나, 분리된 저장소면 실패 시 DT 반영을 되돌린다. 부분 반영 상태를 남기지 않는다(OE-WF-10). 구현 방식은 D-INT 에 따른다.

## 수용 기준

온톨로지 쓰기를 강제로 실패시키면 DT 3D 맵이 반영 전과 같다.
