# OE-SYNC-06 편집 리포트 규칙

## 관련 티켓

- [OE-WF-08](../E14-WF/OE-WF-08.md): 규칙을 쓰는 미리보기 요약
- [OE-SYNC-04](./OE-SYNC-04.md): 규칙을 쓰는 결과 리포트

## 요구사항

### User story

고객사 관리자가 센서 하나를 세 번 옮겼다가 결국 제자리로 돌려놓고 반영하면, 리포트에는 그 설비가 아예 나오지 않는다. 다른 설비를 세 번 옮겼으면 마지막 위치 한 줄만 보인다. 리포트가 열었을 때 값과 최종 값만 비교해 적으므로 시행착오가 노이즈로 쌓이지 않고, 이름·층·좌표처럼 내보내는 파일을 바꾸는 모든 변경이 빠짐없이 들어간다. 미리보기 요약과 반영 결과 리포트가 같은 규칙을 써 숫자가 일치한다.

편집 리포트는 소속 변경뿐 아니라 내보내는 파일을 바꾸는 모든 변경(이름·층·좌표)을, 열었을 때 값과 비교해 적는다. 같은 설비를 여러 번 옮기면 마지막만 남기고, 제자리로 돌아온 것은 뺀다. 미리보기 변경 요약(OE-WF-08)과 반영 결과 리포트(OE-SYNC-04)가 이 규칙을 쓴다.

## 수용 기준

- 설비를 옮겼다 제자리로 되돌린 편집이 리포트에 없다.
- 세 번 옮긴 설비가 리포트에 한 줄로 마지막 위치만 보인다.
