# OE-SYNC-03 공간 계층 갱신

## 관련 티켓

- [OE-XPRD-03](../E22-XPRD/OE-XPRD-03.md): 탐색기 트리 계층 표시
- [OE-SPC-05](../E09-SPC/OE-SPC-05.md): 물리존 공간명

## 요구사항
> User story : 고객사 관리자가 물리존을 추가·삭제하거나 이름을 바꿔 반영하면 사이트·건물·층·물리존으로 이어지는 공간 계층이 편집 결과에 맞게 갱신된다. 반영 뒤 일반 관제 사용자의 탐색기 트리에 새 계층이 나타난다. 공간명은 공간명 연동 규칙을 따른다. 사용자는 에디터에서 바꿨는데 트리는 옛 이름인 상황이나, 지운 방이 트리에 남아 클릭해도 아무것도 안 뜨는 상황을 겪지 않아야 한다. AI Agent도 같은 계층을 참조해 어느 층에 어떤 방이 있는지 정확히 답할 수 있다.

사이트 > 건물 > 층 > 물리존 공간 계층을 편집 결과와 맞춘다. 반영 뒤 탐색기 트리(PRD_003_00x, OE-XPRD-03)가 새 계층을 보인다. 공간명은 OE-SPC-05.

## 수용 기준

- **AC1** 물리존을 추가·삭제·이름 변경해 반영하면 탐색기 트리가 그에 맞게 바뀐다.
