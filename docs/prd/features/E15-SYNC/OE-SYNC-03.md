# OE-SYNC-03 공간 계층 갱신

## 관련 티켓

- [OE-XPRD-03](../E22-XPRD/OE-XPRD-03.md): 탐색기 트리 계층 표시
- [OE-SPC-05](../E09-SPC/OE-SPC-05.md): 물리존 공간명

## 요구사항

### User story

고객사 관리자가 물리존을 추가·삭제하거나 이름을 바꿔 반영하면 사이트>건물>층>물리존 공간 계층이 편집 결과에 맞게 갱신되어 일반 관제 사용자의 탐색기 트리에 새 구조가 나타난다. 관제 사용자가 트리에서 '세미나실'을 찾는데 에디터에서는 바꿨지만 트리는 옛 이름인 상황이 없고, 지운 방이 트리에 남아 클릭해도 아무것도 안 뜨는 일도 없다. 공간 계층 갱신은 반영 트랜잭션의 일부로 처리되어 온톨로지와 탐색기 트리가 서로 다른 구조를 보이는 순간이 없고, AI Agent도 같은 계층을 참조해 '3층에 어떤 방이 있는지' 정확히 답한다.

사이트 > 건물 > 층 > 물리존 공간 계층을 편집 결과와 맞춘다. 반영 뒤 탐색기 트리(PRD_003_00x, OE-XPRD-03)가 새 계층을 보인다. 공간명은 OE-SPC-05.

## 수용 기준

물리존을 추가·삭제·이름 변경해 반영하면 탐색기 트리가 그에 맞게 바뀐다.
