# OE-SYNC-01 공간 정보 자동 반영

## 관련 티켓

- [OE-GEN-01](../E08-GEN/OE-GEN-01.md): 초기 생성의 같은 산출물 규칙
- [OE-WF-10](../E14-WF/OE-WF-10.md): 자동 반영 시점

## 요구사항

### User story

고객사 관리자가 에디터에서 벽을 옮기고 물리존 이름을 바꾼 뒤 [반영하기]를 누르면 3D 모델링 변경과 공간명 변경이 온톨로지에 자동으로 반영된다. 사용자가 TTL이나 GeoJSON을 따로 열어 고치는 단계가 없어 온톨로지 지식 없이도 레이아웃을 관리하고, 반영 후 TTL·GeoJSON이 에디터 편집 결과와 정확히 같아(KPI_1 불일치 0) AI Agent가 옛 방 이름으로 답하는 일이 없다. 초기 구축의 생성도 같은 산출물 규칙을 쓴다.

3D 모델링(공간 구조·오브젝트)과 물리존 공간명의 변경은 [반영하기] 시점에 온톨로지에 자동으로 반영된다. 사용자가 온톨로지를 따로 고치는 단계는 없다. 초기 구축의 생성(OE-GEN-01)도 같은 산출물 규칙을 쓴다.

## 수용 기준

반영 뒤 TTL·GeoJSON 이 에디터의 편집 결과와 같다(KPI_1 불일치 0).
