# OE-EXT-01 외벽 판정

## 요구사항
> User story : 구축 담당자가 BIM을 임포트하면 각 벽이 외벽인지 자동으로 판정된다. BIM에 외벽 여부 속성이 있으면 그 값을 쓰고, 속성이 없는 파일은 건물 외곽선에 접한 벽을 외벽으로 추정하며 출처를 '계산'으로 표시한다. 둘 다 안 되면 '모름'으로 표시되어 사용자가 확인할 대상임을 알 수 있다. 사용자는 외벽 여부가 BIM에서 왔는지 추정된 것인지 출처로 구분할 수 있어, 추정된 외벽만 골라 검토할 수 있어야 한다. 외벽 판정 결과는 로봇 통과 속성과 외벽 설비 분류의 기준이 된다.

벽의 외벽 여부는 `Pset_WallCommon.IsExternal` 로 읽는다. 속성이 없으면(ArchiCAD 등) 건물 외곽선에 접한 벽을 외벽으로 판정하고 출처를 '계산' 으로 둔다. 둘 다 안 되면 '모름'으로 표시한다(glossary "외벽"). 이 속성이 BIM 수용 기준선(R)에 드는지는 확인이 필요하다.

## 수용 기준

IsExternal 이 있는 파일은 그 값으로, 없는 파일은 외곽선 접촉으로 외벽이 표시되고 출처가 구분된다.
