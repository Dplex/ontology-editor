# OE-EXT-02 에디터 내 외벽 불변

## 관련 티켓

- [OE-EXT-03](./OE-EXT-03.md): 외벽 형상 편집
- [OE-OBJ-04](../E02-OBJ/OE-OBJ-04.md): 외벽 전용 설비·문·창 배치

## 요구사항
> User story : 고객사 관리자는 층 편집 화면에서 외벽을 옮기거나 지우거나 크기를 바꿀 수 없으며, 이동·삭제·크기 핸들이 비활성으로 보인다. 외벽은 전체 층이 공유하는 건물 외곽이라 한 층에서만 바꾸면 다른 층과 어긋나기 때문이며, 외벽 형상 편집은 전체 층을 함께 다루는 외벽 에디터에서 한다. 사용자는 층 편집 화면에서 외벽을 선택해 속성을 조회하고, 외벽 위에 외벽 전용 설비와 문·창을 배치하는 작업은 그대로 할 수 있어야 한다. 이를 통해 일상적인 설비 변경에는 지장 없이 외곽 구조만 보호된다.

층 편집 화면에서 외벽은 옮기거나 지우거나 크기를 바꿀 수 없으며 외벽 형상 편집은 외벽 에디터(OE-EXT-03)에서 한다. 외벽 선택·속성 조회와 외벽 전용 설비·문·창 배치(OE-OBJ-04)는 층 편집 화면에서 수행할 수 있다. 

## 수용 기준

- **AC1** 층 편집 화면에서 외벽의 이동·삭제·크기 핸들이 비활성이다.
