# OE-EXT-02 에디터 내 외벽 불변

## 관련 티켓

- [OE-EXT-03](./OE-EXT-03.md): 외벽 형상 편집
- [OE-OBJ-04](../E02-OBJ/OE-OBJ-04.md): 외벽 전용 설비·문·창 배치

## 요구사항

### User story

고객사 관리자가 층 편집 화면에서 사무실 레이아웃을 손보다가 외벽을 잘못 끌어도 외벽은 움직이지 않고 이동·삭제·크기 핸들이 비활성으로 보인다. 외벽은 전체 층이 공유하는 건물 외곽이라 한 층에서만 바꾸면 위아래 층과 어긋나기 때문이다. 외벽을 선택해 속성을 보거나, 외벽에 외기 센서·루버·문·창을 배치하는 일은 그대로 할 수 있어 일상적인 설비 변경에는 지장이 없다. 외벽 형상이 실제와 다르다는 것을 발견하면 속성 패널에서 외벽 에디터로 넘어가 전체 층을 함께 보며 고치므로, 층 편집에서 임시방편으로 손대 데이터가 어긋나는 일이 구조적으로 막힌다.

층 편집 화면에서 외벽은 옮기거나 지우거나 크기를 바꿀 수 없으며 외벽 형상 편집은 외벽 에디터(OE-EXT-03)에서 한다. 외벽 선택·속성 조회와 외벽 전용 설비·문·창 배치(OE-OBJ-04)는 층 편집 화면에서 수행할 수 있다. 

## 수용 기준

층 편집 화면에서 외벽의 이동·삭제·크기 핸들이 비활성이다.
