# OE-EXT-04 외벽 부착 설비

## 관련 티켓

- [OE-EQP-15](../E12-EQP/OE-EQP-15.md): 요구사항·수용 기준 전체

## 요구사항
> User story : 구축 담당자가 외벽에 붙은 루버와 외기 그릴을 다룰 때, 이 설비들은 OE-EQP-15 규칙대로 소속 물리존 없이 '외벽'으로 표기되고 완전성 검사에서 제외된다. 외벽 Epic 관점에서는 층 편집 화면에서 외벽을 선택한 뒤 외벽 전용 설비를 배치하는 작업이 여기에 해당하며, 담당자는 외벽 설비 때문에 '방 없는 설비' 위반을 처리할 필요가 없다. 외벽 에디터에서 외벽 형상이 바뀌어도 거기 붙은 설비는 외벽을 따라 유지되고, 완전성 검사와 등급 2 분모에서 제외되는 규칙은 OE-EQP-15와 같아 외벽 설비 수가 많은 사옥에서 가짜 위반이 쌓이지 않는다.

OE-EQP-15 를 따른다.

## 수용 기준
