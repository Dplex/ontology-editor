# OE-EXT-04 외벽 부착 설비

## 관련 티켓

- [OE-EQP-15](../E12-EQP/OE-EQP-15.md): 요구사항·수용 기준 전체

## 요구사항
> User story : 구축 담당자는 외벽에 붙는 설비를 외벽 부착 설비 규칙에 따라 다룰 수 있다. 외벽 루버·외기/배기 그릴은 실내 물리존 없이 소속이 '외벽'으로 표기되며, 완전성 검사의 '방 없는 설비' 위반과 등급 산정 분모에서 제외된다. 외벽 Epic 관점에서는 사용자가 층 편집 화면에서 외벽을 선택한 뒤 외벽 전용 설비를 배치하는 작업이 여기에 해당한다. 사용자는 외벽 설비가 많은 건물에서도 외벽 설비 때문에 가짜 위반이 쌓이지 않는다는 것을 확인할 수 있어야 한다.

OE-EQP-15 를 따른다.
