# OE-EXT-03 외벽 에디터 연동

## 관련 티켓

- [OE-MAP-01](../E11-MAP/OE-MAP-01.md): 경계 변경 후 재매핑

## 요구사항

### User story

구축 담당자가 증축으로 건물 외곽이 바뀐 사이트에서 외벽 에디터를 열어 전체 층의 외벽을 한 번에 옮긴다. 저장하면 각 층 레이아웃의 외벽 경계가 자동으로 새 위치로 갱신되어 층마다 다시 그릴 필요가 없다. 외벽 이동으로 물리존 경계가 바뀌면 설비 소속과 공조존 매핑이 재계산되어, 확장된 구역에 들어온 설비가 올바른 물리존에 속하게 된다. 층마다 외벽을 따로 손볼 때 생기는 층간 어긋남이 원천적으로 없고, 외벽 에디터 결과가 각 층에 전파되므로 담당자는 변경 뒤 층 편집 화면에서 외벽이 새 위치에 있는지만 확인하면 된다.

전체 층의 외벽 형상은 별도 외벽 에디터에서 한 번에 편집한다(PRD 1.4·1.9). 외벽 에디터의 결과가 갱신되면 각 층 레이아웃의 외벽 경계를 그에 맞춰 갱신한다. 갱신으로 물리존 경계가 바뀌면 재매핑한다(OE-MAP-01).

## 수용 기준

외벽 에디터에서 외벽을 옮긴 뒤 각 층 편집 화면의 외벽이 새 위치에 있다.
