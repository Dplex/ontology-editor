# OE-EXT-05 건축 Proxy 루버 오인 방지

## 요구사항

건축 파일의 알루미늄·옥상·캐노피 루버(성수 Proxy 339 중 240)가 설비로 들어오지 않게 한다 — 이름 사전 예외 또는 "포트 없는 Proxy 는 루버로 받지 않음" 규칙(OE-BIM-13). 가진 BIM 전부에서 회귀를 확인한다.

## 수용 기준

성수 건축 루버 240개가 설비 목록에 없고, 다른 BIM 의 설비 수가 줄지 않는다.
