# OE-EXT-05 건축 Proxy 루버 오인 방지

## 요구사항

건축 파일의 알루미늄·옥상·캐노피 루버(성수 Proxy 339 중 240)는 차양·외장 마감재이므로 설비로 받지 않는다. **포트(glossary "포트")가 없는 Proxy 는 이름이 루버여도 설비로 받지 않는다** — Proxy 를 이름 사전으로 받는 경로(OE-BIM-13)에서 외부 루버 종류만 뺀다. 진짜 설비 루버(외기·배기)는 덕트에 포트로 붙어 있거나 IFC 클래스(IfcAirTerminal LOUVRE)가 말하므로 그대로 들어온다. 이름 사전에 제외 낱말을 늘리는 방식은 쓰지 않는다.
받지 않은 건축 루버는 기본 공간 오브젝트로도 받지 않는다(온톨로지·로봇 판단에 쓰이지 않는다). 다만 읽지 않은 것이 "없는 것" 으로 보이지 않게, 설비로 받지 않은 건축 Proxy 수를 임포트 리포트에 보인다.
가진 BIM 전부에서 회귀를 확인한다. 걸러진 루버가 OE-EQP-15 의 외벽 부착 설비(성수 루버 203대)와 겹치면 OE-EQP-15 수용 기준과 PRD 1.8 등급 2 분모를 같이 고친다.

## 수용 기준

- 성수 건축 루버 240개가 설비 목록에 없다.
- 다른 BIM 의 설비 수가 줄지 않는다(포트가 있거나 IFC 클래스가 루버인 설비 루버는 그대로 들어온다).
- 임포트 리포트에 설비로 받지 않은 건축 Proxy 수가 보인다.
