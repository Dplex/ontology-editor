# OE-BIM-04 벽 생성

## 요구사항
> User story : 구축 담당자가 BIM을 임포트하면 평면 외곽선(두께 포함)과 위치를 가진 벽을 자동으로 불러올 수 있다. 슬래브는 읽지 않으며 DT 3D 맵은 물리존 판과 벽으로 그려진다. 사용자는 벽마다 위치와 두께가 레이아웃에 나가는 것을 확인할 수 있고, 이 벽 정보는 외벽 여부 판정·내력벽 속성·문과 창의 호스트 벽 판정·로봇 통과 불가 영역의 기준이 된다. 벽 두께가 BIM 값 그대로 들어오므로 사용자가 새 벽을 그을 때 같은 층 내벽 두께를 참고값으로 쓸 수 있어야 한다.

IfcWall 을 벽으로 만든다. 평면 외곽선(두께 포함)과 위치를 읽는다. 슬래브는 읽지 않는다 — DT 3D Map 은 물리존 판과 벽으로 그린다(S7).

## 수용 기준

벽마다 위치·두께가 GeoJSON 으로 나간다.
