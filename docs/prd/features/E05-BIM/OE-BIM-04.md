# OE-BIM-04 벽 생성

## 요구사항
> User story : 구축 담당자가 BIM을 임포트하면 평면 외곽선(두께 포함)과 위치를 가진 벽을 자동으로 불러올 수 있다. 슬래브는 읽지 않으며 DT 3D 맵은 물리존 판과 벽으로 그려진다. 사용자는 벽마다 위치와 두께가 레이아웃에 나가는 것을 확인할 수 있고, 이 벽 정보는 외벽 여부 판정·내력벽 속성·문과 창의 호스트 벽 판정·로봇 통과 불가 영역의 기준이 된다. 벽 두께가 BIM 값 그대로 들어오므로 사용자가 새 벽을 그을 때 같은 층 내벽 두께를 참고값으로 쓸 수 있어야 한다.


DT 3D Map은 물리존 판과 벽으로 그려지며, 벽의 위치·두께가 정확히 들어와 로봇 통과 불가 영역과 문·창 호스트 판정의 기준이 된다. 
벽 두께가 BIM 평면 외곽선 값 그대로 들어오므로 사용자가 새 벽을 그을 때 같은 층 내벽 두께의 최빈값을 기본값으로 쓸 수 있고, 외벽 여부 판정과 내력벽 속성도 이 벽 객체에 함께 붙는다.
IfcWall 을 벽으로 만든다. 평면 외곽선(두께 포함)과 위치를 읽는다. 슬래브는 ML-03의 교차 검사·원본 개구부 보존에 필요한 최소 정보만 읽으며 별도 DT 표시 대상으로 그리지 않는다.만약 슬래브가 벽 밖으로 노출되어 있는 경우에만 표시한다. 

## 수용 기준

- **AC1** 벽마다 위치·두께 값을 가진다.
