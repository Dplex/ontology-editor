# OE-BIM-04 벽 생성

## 요구사항
> User story : 구축 담당자가 BIM을 임포트하면 IfcWall이 평면 외곽선(두께 포함)과 위치를 가진 벽으로 만들어져 GeoJSON으로 나간다. 슬래브는 읽지 않고 DT 3D Map은 물리존 판과 벽으로 그려지므로, 운영 담당자가 보는 3D 뷰가 불필요한 바닥 형상 없이 가볍게 렌더링된다. 벽의 위치·두께가 정확히 들어와 로봇 통과 불가 영역과 문·창 호스트 판정의 기준이 된다. 벽 두께가 BIM 평면 외곽선 값 그대로 들어오므로 사용자가 새 벽을 그을 때 같은 층 내벽 두께의 최빈값을 기본값으로 쓸 수 있고, 외벽 여부 판정과 내력벽 속성도 이 벽 객체에 함께 붙는다.

IfcWall 을 벽으로 만든다. 평면 외곽선(두께 포함)과 위치를 읽는다. 슬래브는 읽지 않는다 — DT 3D Map 은 물리존 판과 벽으로 그린다(S7).

## 수용 기준

벽마다 위치·두께가 GeoJSON 으로 나간다.
