# OE-BIM-19 검토 화면 — 판본 비교

## 관련 티켓

- [OE-BIM-24](./OE-BIM-24.md): 편집 파일 재적용 입력

## 요구사항

### User story

구축 담당자가 고객사로부터 수정된 BIM 판본을 받았을 때 이전 판과 새 판을 비교해 GUID 유지율과 추가·삭제·변경 항목 수를 본다. GUID 유지율이 낮으면 R13(GUID 유지) 위반으로 고객사에 내보내기 설정 점검을 요청하고, 변경 항목을 보고 편집 파일 재적용(OE-BIM-24)이 어디서 실패할지 미리 가늠한다. 재임포트 전에 영향 범위를 파악하므로 보정 작업이 날아가는 것을 사전에 대비한다.

같은 건물의 이전 판과 새 판을 비교한다 — GUID 유지율, 추가·삭제·변경 항목(glossary "판본 비교"). 결과는 R13(GUID 유지) 판정의 근거이고, 편집 파일 재적용(OE-BIM-24)의 입력이다.

## 수용 기준

두 판본을 열면 GUID 유지율과 변경 항목 수가 보인다.
