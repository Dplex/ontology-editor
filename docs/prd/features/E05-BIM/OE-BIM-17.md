# OE-BIM-17 검토 화면 — 요구사항 보고서

## 요구사항

검토 화면에 요구사항 보고서를 둔다. R0~R24(OE-REQ-01) 마다 네 상태 중 하나다 — 표준 위치 / 다른 위치 / 없음·일부 / 해당 없음·측정 불가. "다른 위치" 에는 "내보내기 설정을 바꿔 달라", "없음" 에는 "값을 넣어 달라" 문구를 붙인다(OE-REQ-06). R25 는 D14 채택 후 더한다.

## 수용 기준

R0~R24 마다 네 상태 중 하나가 보이고 "다른 위치" 에 설정 변경 요청 문구가 붙는다.

## 검증 (이 repo)

- `src/lib/requirements.test.ts` "요구사항 보고서": 다른 자리면 요청이 늘 "내보내기 설정을 바꿔 달라" 와 무엇을 바꿀지다 · 표준은 요청 없음, 없음·일부는 값을 넣어 달라
- `scripts/check-sample.test.ts` "요구사항 보고서의 요청 (OE-BIM-17)": 가진 BIM 에서 다른 자리인 줄은 모두 설정 요청이다
- `scripts/check-sample.test.ts` "요구사항 상태 집계 — 필수 11 (OE-REQ-06)"
- `e2e/smoke.spec.ts` "요구사항 칸이 R 번호마다 표준 자리·다른 자리·없음을 가른다" · "벽·문·창은 피처 단위로 골라 읽고, 읽지 않은 것은 요구사항에서 "없음" 이 아니다"

## 메모

- 상태는 표준 자리 · 다른 자리 · 없음·일부 · 해당 없음·잴 수 없음이다(`src/lib/requirements.ts`). 읽지 않은 피처(OE-BIM-25)는 "없음" 이 아니라 잴 수 없음이다.
- R25 는 D14 채택 전이라 표에 없다.
