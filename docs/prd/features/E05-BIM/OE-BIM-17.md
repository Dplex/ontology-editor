# OE-BIM-17 검토 화면 — 요구사항 보고서

## 관련 티켓

- [OE-REQ-01](../E06-REQ/OE-REQ-01.md): 보고할 요구사항 R0~R24
- [OE-REQ-06](../E06-REQ/OE-REQ-06.md): 상태별 고객사 요청 문구
- [OE-REQ-05](../E06-REQ/OE-REQ-05.md): R25 추가 항목

## 요구사항

### User story

구축 담당자가 검토 화면의 요구사항 보고서에서 R0~R24마다 표준 위치·다른 위치·없음·해당 없음 중 어느 상태인지 본다. '다른 위치'에는 '내보내기 설정을 바꿔 달라', '없음'에는 '값을 넣어 달라' 문구가 붙어 있어 담당자가 고객사에 보낼 요청을 R마다 새로 쓰지 않는다. 고객사 BIM 담당은 이 보고서로 Revit 설정 변경만 하면 되는 항목과 모델에 값을 입력해야 하는 항목을 구분해 재제출을 준비한다.

검토 화면에 요구사항 보고서를 둔다. R0~R24(OE-REQ-01) 마다 네 상태 중 하나다 — 표준 위치 / 다른 위치 / 없음·일부 / 해당 없음·측정 불가. "다른 위치" 에는 "내보내기 설정을 바꿔 달라", "없음" 에는 "값을 넣어 달라" 문구를 붙인다(OE-REQ-06). R25 는 D14 채택 후 더한다.

## 수용 기준

R0~R24 마다 네 상태 중 하나가 보이고 "다른 위치" 에 설정 변경 요청 문구가 붙는다.
