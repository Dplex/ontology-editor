# OE-BIM-17 검토 화면 — 요구사항 보고서

## 관련 티켓

- [OE-REQ-01](../E06-REQ/OE-REQ-01.md): 보고할 요구사항 R0~R24
- [OE-REQ-06](../E06-REQ/OE-REQ-06.md): 상태별 고객사 요청 문구
- [OE-REQ-05](../E06-REQ/OE-REQ-05.md): R25 추가 항목

## 요구사항
> User story : 구축 담당자는 검토 화면의 요구사항 보고서에서 각 요구사항이 표준 위치·다른 위치·없음·해당 없음(측정 불가) 중 어느 상태인지 볼 수 있다. '다른 위치'에는 '내보내기 설정을 바꿔 달라', '없음'에는 '값을 넣어 달라' 문구가 붙어 있어 사용자가 고객사에 보낼 요청을 요구사항마다 새로 쓰지 않아도 된다. 고객사 BIM 담당은 이 보고서로 모델링 도구 설정만 바꾸면 되는 항목과 모델에 값을 입력해야 하는 항목을 구분해 재제출을 준비할 수 있어야 한다. 추가 요구사항은 채택 결정 후 보고서에 더해진다.

검토 화면에 요구사항 보고서를 둔다. R0~R24(OE-REQ-01) 마다 네 상태 중 하나다 — 표준 위치 / 다른 위치 / 없음·일부 / 해당 없음·측정 불가. 
표준 위치/다른 위치/없음·일부/해당 없음/측정 불가·읽지 않음을 원인과 함께 구분한다. 대상·검사 수를 기록하고 불확실한 원인을 내보내기 설정 오류로 단정하지 않는다.
"다른 위치" 에는 "내보내기 설정을 바꿔 달라", "없음" 에는 "값을 넣어 달라" 문구를 붙인다(OE-REQ-06). 
R25(BAS 매핑 키, D14 채택)도 보고서 내 별도 행으로 추가한다(OE-REQ-05).

## 수용 기준

- 적용 대상 R마다 대상·검사·충족 수와 사유를 확인하고 해당 없음과 측정 불가가 미충족으로 혼합되지 않는다. 요청 문구가 근거와 일치한다.
