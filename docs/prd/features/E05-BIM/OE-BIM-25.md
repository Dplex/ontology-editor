# OE-BIM-25 임포트 피처 선택

## 요구사항
> User story : 구축 담당자는 BIM 파일을 열 때 벽·문·창 위치 같은 피처별로 임포트 여부를 선택할 수 있다. 임포트 하지 않는 피처는 0으로 세지 않고 '불러오지 않음'으로 표시되며, 등급 칩과 요구사항 보고서에서는 '측정 불가'로 처리되어 그 항목 때문에 등급이 부당하게 깎이지 않는다. 사용자는 정확도가 낮은 것으로 알려진 피처를 빼고 신뢰할 수 있는 피처만 임포트한 뒤 나머지는 수동 구축하는 식으로 BIM 품질에 맞춰 구축 전략을 짤 수 있어야 한다. 끈 피처가 '읽지 않음'으로 명시되므로 리포트를 보는 사람이 BIM에 없었던 것으로 오해하지 않는다.

파일을 열 때 피처별(벽·문·창 위치 등)로 읽기를 끌 수 있다. 끈 피처는 "읽지 않음" 으로 표시하고 0 으로 세지 않는다 — 등급 칩과 요구사항 보고서에서 "측정 불가" 로 둔다.
피처 선택은 읽기 범위와 게이트 평가 가능성을 구분한다. 읽지 않은 필수 피처는 측정 불가로 표시하고 임포트 기준·편집파일과 함께 저장한다.


## 수용 기준

- **AC1** 피처를 끄고 열면 그 피처가 "읽지 않음" 으로 표시되고 등급 산식에서 0 이 아니라 측정 불가로 처리된다.
- **AC2** 필수 피처를 끈 파일이 분모 축소로 게이트를 통과하지 않으며 재진입에서 선택과 사유가 복원된다.
