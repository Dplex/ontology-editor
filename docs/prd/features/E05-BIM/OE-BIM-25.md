# OE-BIM-25 임포트 피처 선택

## 요구사항

### User story

구축 담당자가 문·창 위치가 부정확한 것으로 알려진 고객사 BIM을 열 때 피처 선택에서 문·창 읽기를 끈다. 끈 피처는 0으로 세지 않고 '읽지 않음'·'측정 불가'로 처리되어 등급 칩과 요구사항 보고서에서 그 항목 때문에 등급이 부당하게 깎이지 않는다. 담당자는 신뢰할 수 있는 피처만 임포트해 쓰고 나머지는 수동 구축하는 식으로 BIM 품질에 맞춰 유연하게 구축 전략을 짠다. 끈 피처는 '읽지 않음'으로 명시되므로 나중에 리포트를 보는 사람이 그 항목이 BIM에 없었던 것으로 오해하지 않고, 고객사가 해당 피처를 보완한 판본을 보내면 다시 켜서 임포트하면 된다.

파일을 열 때 피처별(벽·문·창 위치 등)로 읽기를 끌 수 있다. 끈 피처는 "읽지 않음" 으로 표시하고 0 으로 세지 않는다 — 등급 칩과 요구사항 보고서에서 "측정 불가" 로 둔다.

## 수용 기준

피처를 끄고 열면 그 피처가 "읽지 않음" 으로 표시되고 등급 산식에서 0 이 아니라 측정 불가로 처리된다.
