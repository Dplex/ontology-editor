# OE-BIM-16 검토 화면 — 등급 칩

## 관련 티켓

- [OE-REQ-04](../E06-REQ/OE-REQ-04.md): 등급 산식
- [OE-PIP-02](../E13-PIP/OE-PIP-02.md): 사람이 계통을 지정한 보정 값

## 요구사항
> User story : 구축 담당자는 BIM 파일 목록에서 각 파일 옆에 공간·설비·소속·연결망·방향 다섯 가지 등급 칩을 보고, 파일을 열면 검토 화면 위에서 같은 수치를 볼 수 있다. 목록의 칩과 열었을 때의 칩은 같은 임포터로 계산되어 수치가 같다. 칩마다 판정에 쓰는 본 숫자는 하나다 — 게이트 등급(0~3)은 BIM과 계산만으로, 목표 등급(4)은 BIM 포트와 사람이 확정한 방향만으로 센다. 사용자 보정이나 미확정 규칙으로 늘어난 몫은 "목표에 안 셈" 보조 숫자로 따로 보여, 원본 BIM 품질과 보정 성과를 섞지 않고 구별할 수 있다. 사용자는 파일을 열지 않고도 재제출이 필요한 파일을 골라내고, 고객사와의 품질 논의에서 같은 칩 수치를 근거로 쓸 수 있어야 한다.

D1 권고안의 게이트는 누적 등급 0~3, 목표선은 등급 4 이상이다. 등급 0의 외곽선 있는 대상 IfcSpace 비율은 85% 이상·층 이름 매핑은 100%, 등급 1의 유효 형상 배치점 비율은 90% 이상, 등급 2의 대상 기기 물리존 소속 비율은 85% 이상, 등급 3의 대상 기기 계통 소속 비율은 60% 이상이다. 등급 4의 확정 흐름 방향 50%는 목표선이며 생성 차단으로 사용하지 않는다. 
원본 게이트는 BIM+계산만으로 산정하고 사전 제안·사용자 보정 성과는 구분한다(D12). 
외벽 부착 등 지표별 해당 없음 제외와 대상·분자·분모·출처·측정 불가 사유를 표시한다. 
방향의 미확정 규칙 미리보기는 확정 목표 달성률에 포함하지 않는다. 
피처 미읽기로 분모를 줄여 통과시키지 않고 분모 0 또는 미측정 필수 항목은 평가 불가로 둔다. 
파일 목록과 검토 화면은 같은 판본·선택 피처·산식 버전에서 공간·설비·소속·연결망·방향 다섯 칩을 계산한다. 
보정 후 생성 가능 여부와 원본 BIM 등급은 별도다.

칩 숫자는 아래처럼 보인다(D12).

| 칩 | 본 숫자 (판정에 씀) | 보조 숫자 (판정에 안 씀) |
|---|---|---|
| 0 공간 · 1 설비 · 2 소속 | BIM+계산 | 사용자 보정 후 값 |
| 3 연결망 | 계통 소속, BIM+계산 | 사용자 보정 후 값(사람이 계통을 지정한 경우, OE-PIP-02). 이름 사전으로 계통 소속을 추정하지 않으므로 사전 숫자는 없다 |
| 4 방향 | BIM 포트 + 사람이 확정한 방향 | 미확정 규칙(미리보기) 수 |

- 본 숫자는 `분자/분모 (%)` 로 보인다.
- 보조 숫자는 본 숫자와 다를 때만 보이고, 본 숫자와 구별되게 표시하며 "목표에 안 셈" 을 붙인다. 화살표처럼 개선으로 읽히는 표기는 쓰지 않는다.
- 방향 칩의 보조 숫자는 이름 사전이 아니라 규칙 방향에서 나온 값이므로 출처를 "미확정 규칙" 으로 적는다. 사람이 계통 단위로 확정하면 그 수만큼 본 숫자로 옮겨 간다.
- 계통 종류(이름 사전으로 맞힌 비율)는 등급 3 칩의 두 번째 숫자로 두지 않고, 칩 상세에 별도 지표 "계통 종류(사전)" 로 보인다.


## 수용 기준

- **AC1** 파일 목록·검토 칩·리포트의 동일 스냅샷 수치가 일치하고 모든 지표에서 분자·분모·제외 근거를 확인한다. 경계값은 이상 조건으로 판정하며 필수 평가 불가·꺼진 피처는 통과로 표시되지 않는다. 확정/미확정 방향·원본/보정 수치가 구분된다.
- **AC2** 등급 0~3 칩의 본 숫자는 BIM+계산만으로 센 값 하나다. 사전 후보·사용자 보정은 본 숫자에 섞이지 않는다.
- **AC3** 등급 4 칩의 본 숫자는 BIM 포트와 사람이 확정한 방향만 센다. 미확정 규칙 수는 "목표에 안 셈" 과 함께 따로 보이고, 계통을 확정하면 그 수만큼 본 숫자로 옮겨 간다.
- **AC4** 보조 숫자는 본 숫자와 다를 때만 보이고, 화살표 등 개선으로 읽히는 표기를 쓰지 않는다.
- **AC5** 계통 종류(사전) 비율은 등급 3 칩이 아니라 칩 상세의 별도 지표로 보인다.
