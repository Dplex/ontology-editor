# OE-BIM-16 검토 화면 — 등급 칩

## 관련 티켓

- [OE-REQ-04](../E06-REQ/OE-REQ-04.md): 등급 산식

## 요구사항
> User story : 구축 담당자는 BIM 파일 목록에서 각 파일 옆에 공간·설비·소속·연결망·방향 다섯 가지 등급 칩을 보고, 파일을 열면 검토 화면 위에서 같은 수치를 볼 수 있다. 목록의 칩과 열었을 때의 칩은 같은 임포터로 계산되어 수치가 같다. 통과 여부를 가르는 하위 등급은 BIM과 계산만으로, 목표 등급은 사전 포함·미포함 두 수치가 함께 보여 이름 사전으로 얼마나 보완됐는지 알 수 있다. 사용자는 파일을 열지 않고도 재제출이 필요한 파일을 골라내고, 고객사와의 품질 논의에서 같은 칩 수치를 근거로 쓸 수 있어야 한다.

D1의 게이트는 누적 등급 0~3이다. 등급 0의 외곽선 있는 대상 IfcSpace 비율은 85% 이상·층 이름 매핑은 100%, 등급 1의 유효 형상 배치점 비율은 90% 이상, 등급 2의 대상 기기 물리존 소속 비율은 85% 이상, 등급 3의 대상 기기 계통 소속 비율은 60% 이상이다. 등급 4의 확정 흐름 방향 50%는 목표선이며 생성 차단으로 사용하지 않는다. 
원본 게이트는 BIM+계산만으로 산정하고 사전 제안·사용자 보정 성과는 구분한다(D12). 
외벽 부착 등 지표별 해당 없음 제외와 대상·분자·분모·출처·측정 불가 사유를 표시한다. 
방향의 미확정 규칙 미리보기는 확정 목표 달성률에 포함하지 않는다. 
피처 미읽기로 분모를 줄여 통과시키지 않고 분모 0 또는 미측정 필수 항목은 평가 불가로 둔다. 
파일 목록과 검토 화면은 같은 판본·선택 피처·산식 버전에서 공간·설비·소속·연결망·방향 다섯 칩을 계산한다. 
보정 후 생성 가능 여부와 원본 BIM 등급은 별도다.


## 수용 기준

- 파일 목록·검토 칩·리포트의 동일 스냅샷 수치가 일치하고 모든 지표에서 분자·분모·제외 근거를 확인한다. 경계값은 이상 조건으로 판정하며 필수 평가 불가·꺼진 피처는 통과로 표시되지 않는다. 확정/미확정 방향·원본/보정 수치가 구분된다.
- 등급 3·4 칩에 두 수치가 병기된다.
