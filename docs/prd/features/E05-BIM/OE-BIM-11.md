# OE-BIM-11 단위 환산·교차 확인

## 요구사항
> User story : 구축 담당자가 mm 단위 건축 파일과 ft 단위 MEP 파일을 함께 임포트해도 IfcUnitAssignment를 읽어 모두 m로 환산되어 한 좌표계에 놓인다. 같은 건물의 판본끼리 층 높이로 단위가 맞는지 교차 확인해 다르면 경고하므로, 단위 선언이 잘못된 파일 때문에 설비가 1000배 크기로 들어오거나 층이 어긋나는 것을 열자마자 알아챈다. 이 환산이 R6 요구사항 판정의 근거가 된다. 환산 결과는 치수 표시와 좌표 입력 등 에디터 전반에서 m 단위로 일관되게 쓰이고, DT(Unity)와도 같은 단위를 공유해 등록 후 설비 크기나 위치가 어긋나는 일이 없다.

IfcUnitAssignment 를 읽어 모든 길이를 m 로 환산한다(K9, R6). 같은 건물의 판본끼리는 층 높이로 단위가 맞는지 교차 확인하고, 다르면 경고한다.

## 수용 기준

mm·ft 단위 파일이 m 로 들어와 같은 건물의 다른 판본과 층 높이가 맞는다.
