# OE-BIM-24 출처 구분·재임포트

## 관련 티켓

- [OE-HIST-03](../E19-HIST/OE-HIST-03.md): 재임포트 시 편집분 보존

## 요구사항
> User story : 구축 담당자는 검토 화면에서 어떤 값이 BIM에서 왔고 어떤 값을 사람이 고쳤는지 출처로 구분해 볼 수 있다. 고객사와 BIM 품질을 논의할 때 원본이 틀린 것과 구축팀이 보정한 것을 명확히 나눌 수 있다. 고객사가 수정한 판본을 재임포트할 때는 편집 파일 규칙에 따라 사용자 수정분이 보존되고 임포트 생성분만 새 값으로 바뀐다. 사용자는 재임포트 뒤 어떤 값이 새로 바뀌었는지 추적할 수 있어야 하며, 이 구분은 식별자 유지 요구사항 판정과도 연결되어 고객사에 식별자 보존을 요청할 근거가 된다.

BIM 생성분 / 사용자 수정분을 출처로 구분해 표시한다. 재임포트 시 편집분 보존은 OE-HIST-03 을 따른다.

## 수용 기준

OE-HIST-03 의 수용 기준을 따른다.
