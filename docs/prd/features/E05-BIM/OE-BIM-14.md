# OE-BIM-14 이름 사전 종류 판정

## 관련 티켓

- [OE-EQP-14](../E12-EQP/OE-EQP-14.md): 종류 미상 패밀리 단위 지정
- [OE-REQ-03](../E06-REQ/OE-REQ-03.md): 어휘 표·이름 사전 정의와 판정 순서

## 요구사항
> User story : 구축 담당자가 BIM을 임포트하면 설비·방·계통·유체의 종류는 먼저 IFC 표준 값(어휘 표)으로 판정되고, 표준 값이 유효하면 바로 확정된다. 표준 값이 비었을 때만 이름 사전이 후보와 근거를 제안하고, 사용자가 확인해야 확정된다. 어느 쪽에서도 알 수 없으면 종류 미상으로 남아 사용자가 패밀리 단위로 지정한다. 종류마다 출처(BIM·사전·사람)가 표시되어 사용자는 BIM이 명시한 종류와 이름 사전 후보를 구분해 후보만 검토할 수 있다. 종류가 확정되어야 설치면 판정·규칙 방향·공조존 검증이 제대로 돌아가므로, 사용자는 종류 미상 설비가 어느 것인지 바로 확인하고 정리할 수 있어야 한다.

종류는 OE-REQ-03 의 판정 순서를 따른다. 유효한 IFC 표준 값(어휘 표)이 있으면 그 값으로 확정하고 출처는 BIM 이다. 표준 값이 없을 때만 이름 사전 후보를 제안하며, 후보는 사용자가 확인하기 전에는 종류를 확정하지 않는다. 확인한 종류의 출처는 사람이다. 어휘 표와 이름 사전 어느 쪽으로도 알 수 없는 설비는 종류 미상으로 두고 사용자가 지정한다(OE-EQP-14). 설비마다 종류와 출처를 기록해 제공한다.

## 수용 기준
- IFC에 유효한 종류가 있으면 사전 이름 일치만으로 바뀌지 않는다. 
- IFC 값이 없으면 사전 후보·근거를 표시하지만 확인 전 종류 미확정 상태를 유지한다. 
- 개별/패밀리 확인 후 사용자 출처·적용 범위가 기록되고 저장·재임포트에서도 보존된다.
