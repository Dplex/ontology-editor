# OE-BIM-07 설비 생성

## 관련 티켓

- [OE-BIM-14](./OE-BIM-14.md): 설비 종류 판정
- [OE-BIM-12](./OE-BIM-12.md): 배치점 보정
- [OE-EQP-02](../E12-EQP/OE-EQP-02.md): 좌표 없는 설비 미배치 목록

## 요구사항
> User story : 구축 담당자가 BIM을 임포트하면 설비가 종류·위치·용량과 함께 자동으로 생성된다. 종류 판정은 이름 사전 규칙을, 배치점이 형상과 어긋난 경우의 보정은 배치점 보정 규칙을 따른다. 건축 파일과 설비(MEP) 파일을 함께 열면 레이아웃과 설비 배치가 한 번에 만들어진다. 좌표가 없는 설비는 원점에 뭉쳐 그려지지 않고 미배치 목록에 들어가 3D에는 보이지 않는다. 사용자는 원점에 쌓인 설비 더미를 정리하는 대신 미배치 목록에서 설비를 하나씩 제자리에 놓을 수 있어야 한다.

IfcDistributionElement 하위 요소를 설비로 만든다. 종류·위치(x·y·z)·용량을 읽는다(R9·R11). 종류 판정은 OE-BIM-14, 배치점 보정은 OE-BIM-12 를 따른다.
MEP 파일을 함께 열면 레이아웃과 설비 배치가 한 번에 만들어진다. 좌표가 없는 설비는 0,0,0 으로 두지 않고 미배치 목록에 둔다(K6, OE-EQP-02).
설비·토출구와 배관/덕트 세그먼트·이음쇠를 중복 없이 구분한다. 좌표 없는 의미 정보는 보존하고 배관은 PIP-13·14의 원본 경로 재현과 유효 연결 정책을 따른다.

## 수용 기준
- 좌표 없는 설비가 미배치 목록에 보이고 3D 에는 그려지지 않으며, 임의 경로·확정 방향·담당 관계가 생성되지 않는다.
