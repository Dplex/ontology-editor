# OE-BIM-05 문·창 생성

## 관련 티켓

- [OE-OBJ-07](../E02-OBJ/OE-OBJ-07.md): 문·창 통과 속성

## 요구사항
> User story : 구축 담당자가 BIM을 임포트하면 문과 창을 자동으로 불러올 수 있다. 위치·치수와 함께 어느 벽에 뚫렸는지(호스트 벽) 읽히며, 사용자는 실제 문·창의 위치와 크기를 다시 재지 않고 파악할 수 있다. 로봇 통과 속성은 문·창 정의 규칙에 따라 문은 통과 가능, 창은 통과 불가로 붙는다. 호스트 벽을 찾지 못한 문·창은 벽 관계 요구사항 위반으로 집계되어, 사용자는 고객사 BIM 담당에게 벽과 개구부 관계를 고쳐 달라고 요청할 근거를 얻을 수 있어야 한다.

IfcDoor·IfcWindow 를 문·창으로 만든다. 
위치·치수와 함께 어느 벽에 뚫렸는지(개구부 관계)를 읽는다. 
통과 속성은 OE-OBJ-07 을 따라 둔다. 
문·창의 실제 원본 개구부·호스트 벽·좌표·치수·통과 속성을 구분한다. 
호스트 벽을 찾지 못한 문·창은 R4 위반으로 집계한다.

## 수용 기준

- 호스트 벽이 없는 문·창이 R4 집계에 들어간다.
