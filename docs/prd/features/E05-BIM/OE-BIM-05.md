# OE-BIM-05 문·창 생성

## 관련 티켓

- [OE-OBJ-07](../E02-OBJ/OE-OBJ-07.md): 문·창 통과 속성

## 요구사항
> User story : 구축 담당자가 BIM을 임포트하면 IfcDoor·IfcWindow가 위치·치수와 함께 어느 벽에 뚫렸는지 개구부 관계까지 읽혀 문·창으로 만들어진다. 통과 속성은 자동으로 붙어 로봇 관제가 바로 쓸 수 있고, 호스트 벽을 찾지 못한 문·창은 R4 위반으로 집계되어 고객사 BIM 담당에게 벽-개구부 관계를 고쳐 달라고 요청할 근거가 된다. 문·창의 가로·세로 치수가 그대로 들어와 사용자가 다시 재지 않아도 되고, 임포트된 문은 양쪽 방을 좌표로 찾아 connects로 이어져 방-문-방 경로 데이터의 출발점이 된다.

IfcDoor·IfcWindow 를 문·창으로 만든다. 위치·치수와 함께 어느 벽에 뚫렸는지(개구부 관계)를 읽는다. 통과 속성은 OE-OBJ-07 을 따라 둔다. 호스트 벽을 찾지 못한 문·창은 R4 위반으로 집계한다.

## 수용 기준

호스트 벽이 없는 문·창이 R4 집계에 들어간다.
