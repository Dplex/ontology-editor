# OE-BIM-08 토출구·배관 초안

## 관련 티켓

- [OE-GEN-10](../E08-GEN/OE-GEN-10.md): 도관 fso: 내보내기
- [OE-BIM-09](./OE-BIM-09.md): 배관 초안 Flow Type 근거 계통
- [OE-PIP-03](../E13-PIP/OE-PIP-03.md): 계통 종류로 Flow Type 결정

## 요구사항
> User story : 구축 담당자가 설비(MEP) BIM을 임포트하면 토출구(디퓨저·그릴)와 덕트·배관 세그먼트를 자동으로 불러올 수 있다. 토출구는 설비로, 덕트·배관은 형상을 가진 배관 초안으로 만들어지며 기기와 도관이 구분된다. 배관 초안의 종류는 그 배관이 속한 계통 종류에서 정해진다. 사용자는 설비 목록에서 토출구를 좌표와 함께 확인하고, 수백 개 덕트·배관을 손으로 그리지 않고 초안으로 그려진 것을 볼 수 있어야 한다. 토출구가 좌표와 함께 들어오므로 공조존 담당 판정과 토출구 없음 검증에 바로 쓰인다.
배관 초안의 Flow Type 은 계통 종류(OE-BIM-09, OE-PIP-03)에서 정한다.
설비·토출구와 배관/덕트 세그먼트·이음쇠를 중복 없이 구분한다. 
좌표 없는 의미 정보는 보존하고 배관은 PIP-13·14의 원본 경로 재현과 유효 연결 정책을 따른다.

## 수용 기준
- 유효 경로가 있는 덕트·배관 세그먼트는 배관 초안으로 그려지며 좌표 없는 정보는 미배치/형상 미반영 사유와 함께 보존된다.
