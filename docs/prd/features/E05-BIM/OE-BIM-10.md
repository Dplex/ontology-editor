# OE-BIM-10 건축+MEP 합치기

## 관련 티켓

- [OE-BIM-22](./OE-BIM-22.md): 좌표계 정합 판정 경고

## 요구사항
> User story : 구축 담당자가 건축 파일과 설비(MEP) 파일을 따로 받아 임포트하면 두 파일이 하나로 합쳐진다. 층은 식별자가 아니라 층 이름과 높이로, 방은 방번호와 좌표계로 맞춘다. 같은 자리의 방은 하나만 남기고 설비 판본의 방 사본은 제거되며, 외곽선이 없는 방은 다른 판본에서 빌려와 사용자가 직접 그릴 방이 줄어든다. 설비가 건축 공간 안에 들어가는 비율로 두 파일의 좌표계가 맞는지 판정해 낮으면 경고를 받는다. 사용자는 두 파일의 원점이 어긋난 채 설비가 엉뚱한 방에 소속되는 일을 임포트 단계에서 확인하고 수정할 수 있어야 한다.

고객사로 부터 받은 건축, MEP 등 여러 IFC 파일을 합쳐 하나의 레이아웃에서 확인하고 수정할 수 있다. 
여러 IFC 파일을 합칠 때 층은 GUID 가 아니라 Level 이름(+높이)으로(K7), 방은 방번호와 좌표계를 기준으로 합친다.
외곽이 없는 방은 다른 파일에서 확인하며, 확인이 불가능한 방은 사용자가 확정한다(K8).
설비가 건축 공간 범위에 드는 비율로 좌표계 정합을 판정하고, 낮으면 경고한다(OE-BIM-22).

## 수용 기준

- 건축+HVAC 에서 임포트 한 설비는 전부 특정 건물, 층, 물리존에 소속된다.
