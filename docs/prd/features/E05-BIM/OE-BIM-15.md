# OE-BIM-15 공조존 생성 경로

## 요구사항

BIM 임포트 시 함께 제공되는 자료에 따라 공조존을 생성한다. IDF 기반 생성, gbXML 기반 초안 생성, 수동 생성을 모두 지원한다.
- **Case 1 — IDF 기반 생성:** BIM과 IDF를 함께 가져오면 IDF에서 공조존과 지원되는 설비·담당 관계를 생성한다(OE-IDF). 생성 결과는 검토·보정할 수 있다.
- **Case 2 — gbXML 기반 초안 생성:** BIM에서 내보낸 gbXML을 가져오면 공간(`Space`)과 존(`Zone`) 정보를 읽어 공조존 초안을 생성한다(OE-IDF-15). 명시된 공간-존 관계가 있으면 그 관계에 따라 구성하고, 존 정보가 없으면 공간별 공조존 후보를 만든다. 사용자는 후보의 경계·명칭·공간 구성을 검토하고 합치기·나누기·보정 후 적용한다. 파일에 없는 담당 설비 관계는 임의로 생성하지 않고 미지정 상태로 표시한다.
- **Case 3 — 수동 생성:** 자동 생성 자료가 없거나 수동 구성을 원하는 경우, BIM 임포트 뒤 공간 편집 모드의 공조존 도구에서 직접 생성한다(OE-ZON-01).

BIM 임포트 완료 화면에 ‘공조존 생성 방법’을 표시하고 다음 경로를 제공한다. IDF와 gbXML은 BIM 임포트 시 함께 가져오거나, 임포트 완료 후 추가로 가져올 수 있다.

| 화면 항목 | 설명 | 실행 동작 |
|---|---|---|
| IDF 추가로 가져오기 | IDF에서 공조존과 설비·담당 관계를 생성합니다. | IDF 파일 선택 → 생성 결과 검토 → 적용 |
| gbXML 추가로 가져오기 | gbXML의 공간·존 정보로 공조존 초안을 만듭니다. | gbXML 파일 선택 → 초안 검토·보정 → 적용 |
| 공조존 직접 만들기 | 공간 편집 모드에서 공조존을 직접 구성합니다. | 공조존 도구로 이동 |

gbXML 검토 화면에는 공조존 후보의 명칭·경계·포함 공간과 BIM 물리존의 매칭 결과를 표시한다. 존 정보 없이 공간에서 생성한 후보, 물리존과 매칭되지 않은 후보, 담당 설비가 미지정된 후보를 구분하여 표시한다.

파일 선택이나 검토를 취소하면 기존 BIM과 공조존을 유지한다. 기존 공조존이 있는 상태에서 자료를 추가하면 신규·중복·변경 후보를 검토한 뒤 적용하며, 기존 공조존이나 사용자 편집 결과를 자동으로 덮어쓰지 않는다.

공조존 생성을 나중에 진행하더라도 BIM 임포트 결과는 유지한다.

## 수용 기준

- R1에서 ‘IDF 추가로 가져오기’, ‘gbXML 추가로 가져오기’, ‘공조존 직접 만들기’를 모두 실행할 수 있다.
- BIM과 지원되는 상세 IDF를 함께 가져오거나 IDF를 나중에 추가하면, 공조존과 지원되는 설비·담당 관계가 생성되어 검토 화면에 표시된다(Case 1).
- ‘gbXML 추가로 가져오기’를 실행하면 파일 선택 화면이 열리고, 선택한 파일에서 공조존 초안이 생성된다(Case 2).
- 공간-존 관계가 명시된 gbXML은 해당 관계에 따라 초안을 구성한다. 존 정보가 없는 gbXML은 공간별 후보를 생성하고 ‘공간 기반 초안’으로 표시한다.
- gbXML 초안의 경계·명칭·포함 공간과 BIM 물리존 매칭 결과를 확인하고 보정할 수 있다. 적용한 결과는 공조존 도구에서 다시 편집할 수 있다.
- gbXML에 담당 설비 관계가 없으면 ‘담당 설비 미지정’으로 표시하고, 사용자가 공조존 도구에서 지정할 수 있다.
- 읽을 수 없는 파일이나 초안 생성에 필요한 공간·기하 정보가 없는 파일은 실패 사유를 표시하고 기존 데이터를 유지한다.
- 수동 생성 경로를 선택하면 임포트한 BIM의 공간 편집 모드에서 공조존을 생성할 수 있다(Case 3).
- 파일 선택·검토를 취소하거나 생성을 나중에 진행해도 기존 BIM·공조존·사용자 편집 결과가 유지된다.
- 기존 공조존이 있는 상태에서 추가 임포트하면 중복·변경 후보가 표시되고, 사용자 확인 없이 기존 공조존을 덮어쓰지 않는다.
