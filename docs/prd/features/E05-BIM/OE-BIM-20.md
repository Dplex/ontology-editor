# OE-BIM-20 누락 분류 코드

## 요구사항

요구사항 위반과 완전성 위반마다 누락 분류 코드 X/A/B/C(PRD 1.8)와 R 번호를 함께 적는다(예: "A-설정 · R6 단위 선언 없음"). 코드 없는 경고는 두지 않는다. 분류 결과는 고객사 결과 리포트(OE-GEN-08)의 재제출(A·B)·보정(C) 항목이 된다.

## 수용 기준

검토 화면의 모든 경고에 X/A/B/C 코드와 R 번호가 붙어 있다.
