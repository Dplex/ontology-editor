## 요구사항
> User story : 구축 담당자는 검토 화면의 모든 경고에 누락 분류 코드와 요구사항 번호가 함께 붙어 있는 것을 볼 수 있다. 코드는 원인이 고객사 설정 문제인지, 모델링 누락인지, 에디터 보정으로 해결할 것인지를 구분하며, 코드 없는 경고는 두지 않는다. 사용자는 분류되지 않은 채 방치되는 경고가 없고, 재제출이 필요한 항목과 구축팀이 보정할 항목이 고객사 결과 리포트에 자동으로 나뉘어 들어가는 것을 확인할 수 있어야 한다. 이를 통해 고객사와 구축팀의 책임 범위가 명확해진다.

요구사항 위반과 완전성 위반마다 누락 분류 코드 X/A/B/C(PRD 1.8)와 R 번호를 함께 적는다(예: "A-설정 · R6 단위 선언 없음"). 코드 없는 경고는 두지 않는다. 분류 결과는 고객사 결과 리포트(OE-GEN-08)의 재제출(A·B)·보정(C) 항목이 된다.

## 수용 기준

검토 화면의 모든 경고에 X/A/B/C 코드와 R 번호가 붙어 있다.
