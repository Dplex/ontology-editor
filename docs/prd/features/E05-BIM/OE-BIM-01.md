# OE-BIM-01 IFC 파싱

## 요구사항
> User story : 구축 담당자는 대용량 건축·기계 BIM 파일을 별도 서버 없이 브라우저 안에서 열 수 있다. IFC의 두 주요 버전이 모두 지원되며 버전에 따라 처리가 분기되지 않으므로, 고객사가 어느 버전으로 내보냈든 같은 방식으로 임포트해 등급 판정을 받을 수 있다. 온프레미스 환경에서 BIM 파일을 외부 서버로 보내지 않아 보안 검토 부담이 줄어든다. 사용자는 대형 사옥 규모의 파일도 수십 초 안에 열리는 것을 기대할 수 있어야 하며, 파일 크기 상한과 분할 제출 단위는 고객사와의 협의 실무에서 정한다.


IFC2x3 와 IFC4 파일을 브라우저 안에서 백엔드 서버 없이 동작 분석해 레이아웃가 임포트 된다. 
파일 크기 상한과 분할 제출 단위는 P5 에 따라 고객사가 준수하도록다.

IFC2x3/IFC4 지원 범위·스키마 오류·파일 역할·취소와 실패 원인을 표시한다. 성능 기준의 장비·브라우저·파일 조합·측정 시작/종료를 기록한다.

## 수용 기준

- 성수 건축(84MB)+기계(203MB) 파일이 16초 안에 열린다.
- 지원 샘플에서 필수 객체가 생성되고 unsupported·취소·실패는 기존 모델을 훼손하지 않는다. 성수 16초 기준은 동일한 고정 환경에서 판정한다.

## 메모

- 2026-10-08 요구사항 검토 반영. 기존 검증 항목은 이전 동작의 근거이며, 변경된 정책과 추가 수용 기준은 별도 구현·검증이 필요하다.
- 온프레미스 환경에서 BIM 파일을 외부 서버로 보내지 않아 보안 검토 부담이 줄고, 파일 크기 상한과 분할 제출 단위는 P5에서 정한다.
