# OE-BIM-01 IFC 파싱

## 요구사항
> User story : 구축 담당자가 성수 사옥의 건축(84MB)+기계(203MB) IFC 파일을 에디터에 올리면 별도 서버 없이 브라우저 안에서 WASM(web-ifc)으로 16초 안에 파싱된다. IFC2x3든 IFC4든 스키마에 따라 분기하지 않고 같은 방식으로 열리므로, 고객사가 어느 버전으로 내보냈든 등급 0~2 판정을 받을 수 있다. 온프레미스 환경에서 BIM 파일을 외부 서버로 보내지 않아 보안 검토 부담이 줄고, 파일 크기 상한과 분할 제출 단위는 P5에서 정한다.

IFC2x3 와 IFC4 파일을 브라우저 안에서 WASM(web-ifc)으로 파싱한다. 백엔드 서버 없이 동작한다. IFC2x3 도 등급 0~2 를 만족할 수 있으므로 스키마로 분기하지 않는다(PRD 1.6).
파일 크기 상한과 분할 제출 단위는 P5 에 따른다.

## 수용 기준

성수 건축(84MB)+기계(203MB) 파일이 16초 안에 열린다.
