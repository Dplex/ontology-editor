# OE-BIM-01 IFC 파싱

## 요구사항
> User story : 구축 담당자는 대용량 건축·기계 BIM 파일을 별도 서버 없이 브라우저 안에서 열 수 있다. IFC의 두 주요 버전이 모두 지원되며 버전에 따라 처리가 분기되지 않으므로, 고객사가 어느 버전으로 내보냈든 같은 방식으로 임포트해 등급 판정을 받을 수 있다. 온프레미스 환경에서 BIM 파일을 외부 서버로 보내지 않아 보안 검토 부담이 줄어든다. 사용자는 대형 사옥 규모의 파일도 수십 초 안에 열리는 것을 기대할 수 있어야 하며, 파일 크기 상한과 분할 제출 단위는 고객사와의 협의 실무에서 정한다.

IFC2x3 와 IFC4 파일을 브라우저 안에서 WASM(web-ifc)으로 파싱한다. 백엔드 서버 없이 동작한다. IFC2x3 도 등급 0~2 를 만족할 수 있으므로 스키마로 분기하지 않는다(PRD 1.6).
파일 크기 상한과 분할 제출 단위는 P5 에 따른다.

## 수용 기준

성수 건축(84MB)+기계(203MB) 파일이 16초 안에 열린다.
