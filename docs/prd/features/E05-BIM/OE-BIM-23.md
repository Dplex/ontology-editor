# OE-BIM-23 임시 저장본 저장

## 관련 티켓

- [OE-WF-06](../E14-WF/OE-WF-06.md): BIM 임포트 임시 저장본

## 요구사항
> User story : 구축 담당자가 BIM 임포트를 마친 뒤 종류 지정이나 외곽선 채우기 같은 보정을 며칠에 걸쳐 진행할 때, 임포트 결과와 보정 내용은 임포트 결과 임시 저장 규칙에 따라 임시 저장본으로 보관된다. 사용자는 에디터를 닫았다 다시 열어도 그대로 이어서 작업할 수 있어 큰 파일을 재파싱하거나 보정을 반복하지 않아도 되며, 보정을 마치면 그 임시 저장본에서 바로 온톨로지를 생성할 수 있다. 임시 저장본은 DT에 반영되지 않으므로 보정이 끝나지 않은 BIM 데이터가 운영 환경에 노출되지 않는다는 것을 신뢰할 수 있어야 한다.

OE-WF-06 을 따른다. (BIM 임포트)
