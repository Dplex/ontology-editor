# OE-BIM-23 임시 저장본 저장

## 관련 티켓

- [OE-WF-06](../E14-WF/OE-WF-06.md): BIM 임포트 임시 저장본

## 요구사항

### User story

구축 담당자가 BIM 임포트를 마친 뒤 종류 지정·외곽선 채우기 같은 보정을 며칠에 걸쳐 진행할 때, 임포트 결과와 보정 내용이 OE-WF-06 규칙대로 임시 저장본으로 보관된다. 에디터를 닫았다 다시 열어도 그대로 이어지므로 큰 파일을 재파싱하거나 보정을 반복하지 않고, 보정을 마치면 그 임시 저장본에서 바로 온톨로지를 생성한다. 임시 저장본은 DT에 반영되지 않으므로 보정이 끝나지 않은 BIM 데이터가 운영 환경에 노출될 일이 없고, 여러 담당자가 같은 임포트 결과를 두고 날짜를 나눠 보정하는 것도 가능해진다.

OE-WF-06 을 따른다. (BIM 임포트)
