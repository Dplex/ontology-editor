# OE-BIM-21 수용 기준선 판정

## 관련 티켓

- [OE-GEN-02](../E08-GEN/OE-GEN-02.md): 미달 시 생성 비활성

## 요구사항
> User story : 구축 담당자가 BIM을 열면 검토 화면 위 배너에서 수용 기준선(게이트) 통과/미달과 목표선 도달 여부를 볼 수 있다. 미달이면 [온톨로지 생성]이 비활성화되고 재제출이 필요한 항목이 목록으로 보여, 품질이 기준 아래인 BIM으로 온톨로지를 만들어 운영 DT에 들어가는 일을 막는다. 사용자는 재제출 목록을 그대로 고객사에 전달할 수 있어야 한다. 통과선 수치와 분모 정의는 결정 확정 후 반영된다.

검토 화면 위에 수용 기준선 판정 배너를 보인다 — 게이트(등급 2) 통과 / 미달. 미달이면 [온톨로지 생성] 을 비활성으로 하고 재제출 항목(A·B)을 목록으로 보인다(OE-GEN-02). 목표선(등급 3) 도달 여부도 함께 보인다.
통과선 수치는 D1(권고 C안: 게이트 등급 2 ≥ 85%)과 분모 정의 D12 에 따른다.

## 수용 기준

D1·D12 확정 뒤 적는다. 미달 파일에서 [온톨로지 생성] 이 비활성이고 재제출 항목이 보인다.
