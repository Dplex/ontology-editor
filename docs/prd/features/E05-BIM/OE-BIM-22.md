# OE-BIM-22 좌표 정합 경고

## 관련 티켓

- [OE-INT-04](../E20-INT/OE-INT-04.md): 임포트 단계 오프셋 맞춤

## 요구사항
> User story : 구축 담당자가 BIM을 임포트할 때 좌표계가 BIM(IFC)파일과 원점·회전이 어긋나면 경고를 받는다. 좌표계 어긋남은 오류 없이 통째로 틀어지는 문제라 눈치채기 어려우므로 반드시 사람에게 보이며, 경고와 함께 평면 위치·회전 오프셋 값이 표시되어 임포트 단계에서 바로 맞출 수 있다. 사용자는 설비가 옆 방에 소속되거나 로봇 경로가 벽을 뚫고 지나가는 데이터가 DT에 들어가는 것을 미리 막을 수 있어야 한다. 기준점을 누가 정의하는지는 협의 실무에서 정한다.

건물·층·공간 병합 전 단위·축·원점·회전과 건축/MEP 역할을 확인한다. 
명시 좌표 변환을 기록하고 미확인 충돌은 자동 병합하지 않는다. 
좌표 공간 포함률은 정합의 보조 근거로만 쓴다.

## 수용 기준

- **AC1** 원점이 다른 두 파일을 열면 경고와 x·y·회전 오프셋 값이 보인다.
- **AC2** 같은 파일 조합 재진입에서 원본과 편집·출처·검토 상태가 유지된다. 보정만 남아 원본 모델을 복원할 수 없는 경우 완료로 처리하지 않는다.
