# OE-BIM-09 계통·포트 읽기

## 요구사항
> User story : 구축 담당자가 BIM을 임포트하면 계통과 설비 사이의 연결(포트)이 읽히고, 포트에 흐름 방향이 있으면 함께 읽힌다. IFC 두 버전 모두에서 연결이 읽힌다. 포트가 없는 파일은 배관 세그먼트 끝점이 거의 닿아 있고 계통 이름이 같으면 연결로 추정하되 출처를 '형상'으로 구분한다. 사용자는 포트에서 읽은 확실한 연결과 형상에서 추정한 연결을 나눠 볼 수 있어, 추정 연결만 검토하고 규칙 방향을 확정할 때 신뢰도를 판단할 수 있어야 한다.

계통을 읽으면, 계통 종류에 따라 별개 계통으로 구분한다. 
BIM(e.g. IFC4) 파일에 공간 경계·계통·포트가 포함되어 임포트 할 수 있어야 한다. 
계통 정보에 포트가 없을 때는 세그먼트 끝점이 5mm 안에서 닿고 계통 이름이 같으면 미확정 연결 후보로 표시한다(K3, 출처 geometry). 
BIM 명시 포트 연결·명시 흐름 방향·양방향/미지정과 실제 연결이 명시되어 있지 않지만 배관 끝이 서로 연결된 형상으로 추정한 것을 별개로 구분한다. 
형상 추정은 새 연결 후보를 제안만 할 수 있고, 이미 끊긴 것으로 확정된 연결을 다시 잇는 권한은 없다. 끊긴 연결을 되살리는 것은 사람의 명시적 조작으로만 가능하다

## 수용 기준

- BIM 파일에서 계통 임포트 시, 연결된 계통 수가 0 보다 크다.
- 포트에서 읽은 연결과 형상에서 추정한 연결의 출처가 구분된다.
