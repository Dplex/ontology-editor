# OE-BIM-12 배치점 보정

## 요구사항

### User story

구축 담당자가 성수 BIM을 임포트하면 배치점이 자기 형상에서 0.5m 넘게 떨어진 설비 277대가 자동으로 형상 중심으로 보정되고 각 설비에 보정 표시와 집계가 붙는다. Revit에서 패밀리 원점이 형상 밖에 있는 설비가 엉뚱한 방에 소속되거나 바닥 아래로 판정되는 것을 막고, 설치면 판정에는 보정 뒤 형상의 최저점 z를 써 디퓨저가 바닥 설비로 잘못 분류되지 않는다. 담당자는 보정 목록으로 고객사에 패밀리 원점 수정을 요청할 수 있다.

설비 배치점이 자기 형상에서 0.5m 넘게 떨어져 있으면 형상 중심을 배치점으로 쓰고 경고·집계한다(K5). 설치면 판정에 쓰는 z 는 보정 뒤 형상(바운딩박스)의 최저점이다(제안 — Q8).

## 수용 기준

성수에서 보정된 277대가 집계에 보이고 각 설비에 보정 표시가 있다.
