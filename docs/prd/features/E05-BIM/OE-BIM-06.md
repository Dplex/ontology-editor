# OE-BIM-06 내력벽 속성

## 관련 티켓

- [OE-OBJ-06](../E02-OBJ/OE-OBJ-06.md): 내력벽 편집 규칙

## 요구사항
> User story : 구축 담당자가 BIM을 임포트하면 벽마다 내력 여부가 읽혀 들어온다. 값이 없는 벽은 '아니오'가 아니라 '모름'으로 구분되어, 사용자는 구조 도면을 확인해야 할 벽이 어느 것인지 알 수 있다. '모름'과 '아니오'를 섞지 않으므로 실제로는 내력벽인 벽을 사용자가 일반 내벽으로 알고 옮기는 사고를 막을 수 있다. 이 값은 에디터에서 내력벽 이동·삭제·문창 추가를 잠그는 기준이 되며, 편집 규칙은 내력벽 정의 티켓을 따른다. 사용자는 내력 여부가 없는 벽과 아닌 벽이 화면에서 구분되어 보이는 것을 확인할 수 있어야 한다.


벽마다 내력 여부를 검사한다. 
내력벽 관련 값이 없는 경우 "모름" 이다. 내력 여부의 true/false/미확인과 원본·사용자 보정을 구분하고 OBJ-06의 편집 제한을 따른다.


## 수용 기준
- **AC1** LoadBearing 이 없는 벽이 "모름" 으로, false 인 벽이 "아니오" 로 구분되어 사용자가 편집 불가한 이유를 확인할 수 있다.
