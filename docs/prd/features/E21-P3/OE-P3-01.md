# OE-P3-01 규칙 기반 경고 프레임

## 관련 티켓

- [OE-WF-07](../E14-WF/OE-WF-07.md): 경고를 띄울 미리보기 단계
- [OE-P3-02](./OE-P3-02.md): W-01 물리존 최소 면적
- [OE-P3-03](./OE-P3-03.md): W-02 설비 0개 물리존
- [OE-P3-04](./OE-P3-04.md): W-03 공조존 미매핑 물리존

## 요구사항

편집 결과가 사이트별 규칙 테이블을 위반하면 미리보기(OE-WF-07) 단계에서 경고한다. 차단하지 않는다. 규칙은 좌표·개수만으로 판정할 수 있는 것으로 한정한다. 개별 규칙은 W-01~03(OE-P3-02~04).

## 수용 기준

규칙 위반이 있는 편집의 미리보기에 경고가 보이고 반영은 가능하다.
