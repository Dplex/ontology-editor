# OE-P3-08 신규 사무용품 3D 모델링

## 요구사항

임의의 3D 모델(자체 제작 또는 공개 모델)을 바로 넣어 추가 공간 오브젝트로 쓴다. 기존 라이브러리(OE-SPC-16) 항목에 한정하지 않는다. 넣은 모델은 라이브러리에 더해진다.

## 수용 기준

glTF 등 3D 모델 파일을 넣으면 라이브러리에 새 항목이 생기고 배치할 수 있다.
