# OE-SPC-13 문·창 추가·크기 조절

## 요구사항

문·창을 벽에 추가하고 크기를 조절한다. 문·창은 벽선 0.6m 안에만 놓이고 양쪽 방을 좌표로 짚는다. 가로·세로 길이를 모두 조절할 수 있다(OE-OBJ-07).
문은 천장이 막히고 바닥이 뚫려 있다. 창은 천장·바닥이 모두 막혀 있다(디자인 고려). 통과 속성은 OE-OBJ-07.
문이나 방 경계가 바뀌면 문이 잇는 방을 다시 짚는다(relinkDoors).

## 수용 기준

- 벽에서 0.6m 넘게 떨어진 자리에는 문·창이 놓이지 않는다.
- 문·창의 가로와 세로를 각각 바꿀 수 있다.
- 방 경계를 바꾸면 문이 잇는 두 방이 다시 계산된다.

## 검증 (이 repo)

- 문·창은 벽 0.6m 안에만 놓이고, 양쪽 방을 좌표로 짚는다. 문·방 경계가 바뀌면 다시 짚는다 — 같은 describe, `e2e/edit-elements.spec.ts` "벽에서 먼 자리에는", 성수 N-5·N-6
