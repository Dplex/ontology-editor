# OE-SPC-03 물리존 경계 수정 (E2)

## 요구사항

물리존 경계를 꼭짓점 끌기·추가(Insert)·삭제(Delete)로 고친다(E2).
물리존 외곽선은 면이어야 하므로 꼭짓점이 최소 3개(삼각형)다. 꼭짓점이 4개 이상인 물리존에서만 꼭짓점을 지울 수 있고, 3개 남은 물리존에서 Delete 를 누르면 지우지 않고 "꼭짓점이 셋이라 더 지울 수 없습니다" 를 알린다. 물리존 자체를 없애려면 꼭짓점이 아니라 물리존 삭제(OE-SPC-02)를 쓴다.
자기교차(외곽선이 자기 자신을 가로지르는 모양)는 편집 방법에 따라 다르게 다룬다(K10). 3D 에서 꼭짓점을 끄는 동안에는 막지 않고, 자기교차가 되는 자리에 놓으면 놓지 않고 원래 자리로 되돌리며 알린다. 표에서 좌표 숫자로 고칠 때는 고치되 경고를 보인다 — 꼭짓점을 하나씩 고치는 중간에는 잠깐 교차가 생길 수 있어서다. 물리존 전체를 옮겨 자기교차가 되면 옮기고 알린다. 면적과 소속이 함께 갱신되고, 밖으로 밀려난 설비는 좌표로 소속을 다시 찾는다. BIM 이 소속을 명시한 설비는 유지한다(K2).
외곽선이 없는 방은 점을 찍어 그린다(OE-MAN-03).

## 수용 기준

- 꼭짓점을 옮기면 면적이 다시 계산되고 밖으로 나간 설비의 소속이 바뀐다.
- 꼭짓점이 4개인 물리존에서 꼭짓점 하나를 지우면 삼각형이 되고 면적이 다시 계산된다.
- 꼭짓점이 3개인 물리존에서 Delete 를 누르면 꼭짓점이 그대로 3개이고 알림이 뜬다.
- 3D 에서 꼭짓점을 자기교차가 되는 자리에 놓으면 꼭짓점이 원래 자리로 돌아가고 알림이 뜬다. 면적·소속은 바뀌지 않는다.
- 표에서 좌표를 자기교차가 되게 고치면 값은 바뀌고 자기교차 경고가 보인다.

## 검증 (이 repo)

- 꼭짓점을 옮기면 넓이가 다시 계산되고, 밖으로 밀려난 설비의 소속이 바뀐다. BIM 이 소속을 말한 설비는 그대로다 — `edit.test.ts` "물리존 경계 수정 (E2)", `e2e/edit-3d.spec.ts` "꼭짓점을 끌면", 성수 F-3
- 자기 교차가 되는 자리에는 놓지 않고 알린다. 끄는 동안의 교차는 막지 않는다 — `edit.test.ts` "자기 자신과 교차하면 알린다", 성수 F-7
- 꼭짓점을 넣고 지울 수 있고 셋에서 멈춘다. 외곽선 없는 방은 점을 찍어 그리고 그 안 설비가 소속된다 — `edit.test.ts` "물리존 꼭짓점 넣기·지우기, 외곽선 그리기", 성수 F-5·F-6·F-8
