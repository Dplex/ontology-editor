# OE-SPC-14 추가 오브젝트 배치

## 요구사항

추가 공간 오브젝트를 라이브러리(OE-SPC-16)에서 골라 배치한다. 라이브러리에 없는 것은 임의의 3D 모델을 넣어 더할 수 있다(OE-P3-08). 개수 상한은 없다.
생성·삭제·이동·크기 조절을 지원하고 서로 겹칠 수 없다(OE-OBJ-09·16). DT 뷰어마스터에는 노출하지 않는다(TBD). 레이아웃 편집 단위로는 온톨로지에 든다.

## 수용 기준

라이브러리 항목을 고르고 자리를 눌러 놓을 수 있고, 겹치는 자리는 차단된다.
