# OE-SPC-14 추가 오브젝트 배치

## 관련 티켓

- [OE-SPC-16](./OE-SPC-16.md): 오브젝트 라이브러리
- [OE-P3-08](../E21-P3/OE-P3-08.md): 라이브러리에 없는 3D 모델 추가
- [OE-OBJ-09](../E02-OBJ/OE-OBJ-09.md): 추가 오브젝트 편집 범위
- [OE-OBJ-16](../E02-OBJ/OE-OBJ-16.md): 오브젝트 간 겹침 불가

## 요구사항
> User story : 고객사 관리자가 좌석 재배치 후 책상과 파티션 위치를 DT에 맞추려 라이브러리에서 책상을 골라 자리를 눌러 놓고, 크기를 조절하며 필요 없는 것은 지운다. 다른 책상과 겹치는 자리는 차단되어 실제 배치와 다른 레이아웃이 저장되지 않는다. 라이브러리에 없는 특수 가구는 3D 모델을 넣어 추가하며 개수 상한이 없다. 이 오브젝트는 DT 뷰어마스터에 노출되지 않지만 레이아웃 편집 단위로 온톨로지에 관리되어 다음 편집 때 이어서 쓴다.

추가 공간 오브젝트를 라이브러리(OE-SPC-16)에서 골라 배치한다. 라이브러리에 없는 것은 임의의 3D 모델을 라이브러리에 추가하여 더할 수 있다(OE-P3-08).추가 공간 오브젝트 라이브러리 개수 상한은 없다.
생성·삭제·이동·크기 조절을 지원하고 서로 겹칠 수 없다(OE-OBJ-09·16). DT 뷰어마스터에는 추가 공간 오브젝트 목록을 노출하지 않는다(TBD). 레이아웃 편집 단위로는 온톨로지에 추가 오브젝트를 관리한다.

## 수용 기준

라이브러리 항목을 고르고 자리를 눌러 놓을 수 있고, 겹치는 자리는 차단된다.
