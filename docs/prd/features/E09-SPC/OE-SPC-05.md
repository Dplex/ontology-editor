# OE-SPC-05 공간명 연동

## 관련 티켓

- [OE-SYNC-03](../E15-SYNC/OE-SYNC-03.md): 탐색기 트리 이름 연동
- [OE-WF-21](../E14-WF/OE-WF-21.md): 이상 알림 발생 위치 연동

## 요구사항
> User story : 고객사 관리자가 에디터에서 물리존 공간명을 바꾸고 반영하면, 일반 관제 사용자가 보는 이상 알림의 '발생 위치'와 탐색기(뷰어마스터) 트리의 이름이 같은 값으로 바뀐다. 사용자는 이름 하나만 고치면 되고 알림·탐색기·에디터 어디서나 같은 이름을 볼 수 있어, 현장 직원과 소통할 때 혼선이 없다. 계통도의 서비스 영역은 공조존 기준이라 공간명 변경이 직접 영향을 주지 않으므로, 사용자가 방 이름을 바꿔도 설비 계통 표시는 그대로 유지되는 것을 확인할 수 있어야 한다.

물리존 공간명은 이상 알림의 '발생 위치' 와 탐색기(뷰어마스터) 트리의 이름으로 연동된다(OE-SYNC-03, OE-WF-21). 계통도의 서비스 영역은 공조존 기준이라 공간명 변경이 직접 미치지 않는다.

## 수용 기준

반영 뒤 탐색기 트리의 이름이 에디터의 공간명과 같다.
