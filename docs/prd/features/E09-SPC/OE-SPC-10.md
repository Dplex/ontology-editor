# OE-SPC-10 커스텀존 Agent 질의

## 요구사항
> User story : AI Agent 사용자는 커스텀존 이름이나 별명으로 그 영역의 온도·에너지·설비 위치를 물어보고 답을 받을 수 있다. 이를 위해 에디터는 커스텀존과 그 매핑(물리존·공조존·설비)을 온톨로지에 저장하고 관리한다. 고객사 관리자가 에디터에서 커스텀존을 만들거나 고치고 반영하면 이 정보가 온톨로지에 갱신되므로, Agent 사용자는 운영 조직이 실제로 쓰는 구역 이름으로 질문해도 방번호나 물리존 식별자로 바꿔 묻지 않아도 된다. Agent 측 세부 요구는 Agent PRD에 적은 것을 따른다.

AI Agent도 커스텀존 이름·별명으로 물으면 그 영역의 온도·에너지·설비 위치를 답할 수 있어야 한다. Agent 측 요구는 Agent PRD 에 적은 것 기반으로 커스텀존을 질의 단위로 쓸 수 있도록 커스텀존과 그 매핑(물리존·공조존·설비)을 온톨로지에 저장하고 관리한다.

## 수용 기준

Agent에게 커스텀 존으로 질문 시 Agent가 답하 수 있게 온톨로지에 커스텀 존 이름과 별명이 갱신된다.
