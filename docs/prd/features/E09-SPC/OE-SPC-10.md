# OE-SPC-10 커스텀존 Agent 질의

## 요구사항
> User story : AI Agent 사용자가 '임원석 구역 지금 온도 어때?' 또는 '영업팀 구역에 CCTV 몇 대 있어?'라고 물으면, Agent가 온톨로지에 저장된 커스텀존 이름·별명과 그 물리존·공조존·설비 매핑을 바탕으로 답한다. 고객사 관리자가 에디터에서 커스텀존을 만들거나 고치고 반영하면 이 정보가 온톨로지에 갱신되므로, 운영 조직이 쓰는 실제 구역 이름으로 질문해도 Agent가 방번호나 물리존 ID로 바꿔 묻지 않아도 된다.

AI Agent도 커스텀존 이름·별명으로 물으면 그 영역의 온도·에너지·설비 위치를 답할 수 있어야 한다. Agent 측 요구는 Agent PRD 에 적은 것 기반으로 커스텀존을 질의 단위로 쓸 수 있도록 커스텀존과 그 매핑(물리존·공조존·설비)을 온톨로지에 저장하고 관리한다.

## 수용 기준

Agent에게 커스텀 존으로 질문 시 Agent가 답하 수 있게 온톨로지에 커스텀 존 이름과 별명이 갱신된다.
