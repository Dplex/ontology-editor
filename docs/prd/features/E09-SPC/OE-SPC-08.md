# OE-SPC-08 커스텀존 생성·분할·병합·삭제

## 요구사항

(초안 — OE-OBJ-01 범위에서 작성) 커스텀존을 생성·분할·병합·삭제한다. 생성은 다각형을 그려 만들고, 분할은 선으로 둘로 나누며, 병합은 맞닿은 커스텀존끼리 한다.

이름·별명은 OE-SPC-06 의 고유성 규칙을 따른다.

- **분할**: 넓은 커스텀 존이 원래 이름·별명을 그대로 가진다. 다른 조각은 원래 이름 뒤에 두 자리 번호를 붙인 이름을 받는다(`임원석` → `임원석-02`). 번호는 02부터 세어, 건물 안의 이름·별명에 아직 없는 가장 작은 번호를 쓴다. 이미 `-nn` 으로 끝나는 이름을 나누면 그 번호를 늘린다(`임원석-02` → 비어 있으면 `임원석-03`). 새 커스텀 존의 별명은 비어 있고, 이름은 나중에 고칠 수 있다.
- **병합**: 남는 커스텀존은 넓은 쪽, 넓이가 같으면 먼저 고른 쪽이다. 남는 존은 자기 이름·별명을 그대로 가진다. 없어지는 존의 이름·별명은 남는 존의 별명으로 옮긴다(OE-SPC-06).

커스텀존은 물리존 경계와 무관하게 그릴 수 있다. 각 동작은 물리존·공조존 매핑 갱신(OE-SPC-09)을 유발한다. 겹침은 OE-SPC-07.

## 수용 기준

- 생성·분할·병합·삭제 뒤 반영하면 온톨로지의 커스텀존 집합과 매핑이 그에 맞게 바뀐다.
- `임원석` 을 나누면 넓은 커스텀 존은 `임원석`(별명 그대로), 다른 커스텀 존은 `임원석-02`(별명 없음)가 된다. `임원석-02` 가 이미 이름이나 별명으로 쓰이고 있으면 `임원석-03` 이 된다.
- 병합 뒤에는 없어진 존의 이름·별명으로 물어도 남은 존이 조회된다.
