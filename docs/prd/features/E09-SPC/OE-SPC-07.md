# OE-SPC-07 커스텀존 겹침 정책

## 관련 티켓

- [OE-OBJ-16](../E02-OBJ/OE-OBJ-16.md): 커스텀존이 빠지는 겹침 불가 원칙

## 요구사항
> User story : 고객사 관리자는 커스텀존을 다른 커스텀존과 겹치게 그릴 수 있다. 영업팀 구역과 소음 민감 구역처럼 목적이 다른 운영 단위가 같은 공간에 겹칠 수 있으므로, 겹친다는 이유로 커스텀존의 생성·이동·크기 조절이 막히지 않는다. 겹친 영역에 있는 설비와 값은 두 커스텀존 모두에서 조회된다. 사용자는 하나의 공간을 여러 관리 관점으로 겹쳐 지정할 수 있어야 하며, AI Agent 사용자는 어느 커스텀존 이름으로 물어도 겹친 영역의 설비를 답으로 받을 수 있다.

커스텀존끼리는 서로 겹칠 수 있다(Q4). 겹친 영역의 설비·값은 두 커스텀존 모두에서 조회된다. 커스텀존은 겹침 불가 원칙(OE-OBJ-16) 밖이므로, 겹친다는 이유로 생성·이동·크기 조절을 막지 않는다.

## 수용 기준

- 기존 커스텀존과 겹치게 새 커스텀존을 그리거나 옮겨도 차단되지 않는다.
- 겹친 영역에 있는 설비가 두 커스텀존 모두의 조회 결과에 나온다.
