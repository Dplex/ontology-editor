# OE-SPC-07 커스텀존 겹침 정책

## 관련 티켓

- [OE-OBJ-16](../E02-OBJ/OE-OBJ-16.md): 커스텀존이 빠지는 겹침 불가 원칙

## 요구사항
> User story : 고객사 관리자가 3층에 '영업팀 구역' 커스텀존을 그린 뒤, 그 일부와 겹치는 '소음 민감 구역' 커스텀존을 추가로 그린다. 두 운영 단위는 목적이 달라 자연스럽게 겹치는데, 겹친다는 이유로 생성·이동이 막히지 않는다. 겹친 영역에 있는 온도 센서는 AI Agent에게 '영업팀 구역 온도'로 물어도, '소음 민감 구역 설비'로 물어도 함께 조회되어, 운영자가 하나의 공간을 여러 관리 관점으로 겹쳐 볼 수 있다.

커스텀존끼리는 서로 겹칠 수 있다(Q4). 겹친 영역의 설비·값은 두 커스텀존 모두에서 조회된다. 커스텀존은 겹침 불가 원칙(OE-OBJ-16) 밖이므로, 겹친다는 이유로 생성·이동·크기 조절을 막지 않는다.

## 수용 기준

- 기존 커스텀존과 겹치게 새 커스텀존을 그리거나 옮겨도 차단되지 않는다.
- 겹친 영역에 있는 설비가 두 커스텀존 모두의 조회 결과에 나온다.
