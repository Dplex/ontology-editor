# OE-SPC-12 벽 추가·크기·이동·삭제 (E4)

## 요구사항

**물리존 경계는 벽에서 다시 만들지 않는다.** [방 경계도 같이]를 켜면 벽 가까운 방 변이 벽이 움직인 만큼만 따라옴(벽면에 붙이지 않음). 벽 끝을 넘어 이어지는 방 변은 옮기지 않음

## 수용 기준

병원 방 368개 불변 회귀 통과

## 검증 (이 repo)

- 두 점으로 벽을 그으면 두께 0.2m 외곽선이고 내력 여부는 "모름" 이다. 모름과 아니오를 섞지 않는다 — `edit.test.ts` "벽·문·창 편집 (E4)", 성수 N-3·N-4
- 벽을 옮기면 그 벽의 문·창이 같이 가고, 물리존 경계는 기본으로 따라오지 않는다 — 성수 N-2
- [방 경계도 같이] 를 켜면 벽 가까운 방 변이 벽이 움직인 만큼 따라오고, 다섯 걸음 나갔다 돌아오면 넓이가 처음과 같다. 벽 끝을 넘어 이어지는 변은 옮기지 않는다 — `e2e/edit-elements.spec.ts` "[방 경계도 같이]", 성수 N-8a·N-8b
- 벽을 지우면 뚫린 문·창도 빠지고, Ctrl+Z 로 전부 돌아온다 — `e2e/edit-elements.spec.ts` "벽을 긋고 문을 놓으면", 성수 N-7
- 벽·문·창 편집도 저장·불러오기 뒤 GeoJSON 이 같다. 에디터가 지은 `U_` 벽은 지문으로 BIM 벽에 짝지어지지 않는다 — `edit-file.test.ts`, `check:sample`(GUID 를 바꿔 흉내), 성수 N-8·N-9
