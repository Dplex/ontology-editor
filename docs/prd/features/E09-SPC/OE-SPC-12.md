# OE-SPC-12 벽 추가·크기·이동·삭제 (E4)

## 요구사항

벽을 추가·크기 조절·이동·삭제한다(E4).
BIM 에서 가져온 벽의 두께는 BIM 평면 외곽선 값을 그대로 쓴다.
두 점을 찍어 새 벽을 그으면 두께는 1번.같은 층 BIM 내벽 두께의 최빈값 → 2번.사이트 기본값(내벽 150 / 외벽 300mm, 사이트 설정) → 3번.0.2m 순으로 정하고,그은 뒤 속성 패널에서 고칠 수 있다(출처: 사람). 내력 여부는 "모름" 이다. 
벽을 옮기면 그 벽의 문·창이 함께 가고, 벽을 지우면 뚫린 문·창도 빠진다. 내력벽은 OE-OBJ-06 을 따른다.
물리존 경계는 벽에서 다시 만들지 않는다(K16)


## 수용 기준

- BIM 내벽 최빈 두께가 0.24m 인 층에서 새 벽을 그으면 두께 0.24m 로 생긴다.
- BIM 벽이 없고 사이트 기본값이 0.15m 인 층에서 새 벽을 그으면 0.15m 로 생긴다.
- 둘 다 없으면 0.2m 로 생긴다.
- 병원 방 368개의 외곽선이 벽 편집 뒤에도 바뀌지 않는다(회귀).
