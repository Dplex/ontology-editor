# OE-SPC-16 오브젝트 라이브러리 정의

## 관련 티켓

- [OE-P3-08](../E21-P3/OE-P3-08.md): 사용자 3D 모델로 항목 추가

## 요구사항
> User story : 구축 담당자와 고객사 관리자는 책상 여러 종류·의자·소파·책장·파티션·칠판·화분 등이 미리 준비된 추가 공간 오브젝트 라이브러리를 사용할 수 있다. 항목마다 3D 모델과 기본 크기가 설정되어 있어 하나씩 모델링하지 않고 골라 쓰면 된다. 사용자는 고객사 특유의 가구처럼 라이브러리에 없는 것을 임의의 3D 모델로 넣어 항목을 더할 수 있다. 라이브러리 목록 문서가 있어 어떤 오브젝트가 지원되는지 사전에 확인할 수 있고, 수동 구축과 운영 편집에서 같은 라이브러리를 써 사이트 간 표현이 일관되어야 한다.

추가 공간 오브젝트 라이브러리를 정의한다 — 책상 여러 종류·의자·소파·책장·파티션·칠판·화분 등이 이에 해당한다.
항목마다 3D 모델과 오브젝트 기본 크기를 설정할 수 있다. 사용자가 임의의 3D 모델을 넣어 항목을 더할 수 있다(OE-P3-08).

## 수용 기준

라이브러리 목록 문서와 각 항목의 3D 모델이 있다.
