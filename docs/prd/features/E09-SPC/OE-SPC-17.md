# OE-SPC-17 방 종류 사전·일괄 수정

## 요구사항

### User story

구축 담당자가 성수 사옥 BIM을 임포트했더니 방 종류 판정률이 31%에 그치고 'S.T'·'P.S' 같은 약어 방이 많이 미판정으로 남는다. 담당자가 약어의 뜻을 확인해 이름 사전에 보강하면 재판정되어 판정률이 올라가고, 같은 공간명의 방 수십 개는 종류를 한 번에 일괄 수정한다. 방 종류마다 출처가 표시되어 사전·OmniClass·사람 중 어디서 왔는지 알 수 있어, 이후 AHU 기계실 제약이나 Agent 질의에서 방 종류를 신뢰하고 쓸 수 있다.

방 종류는 이름 사전 → OmniClass 순으로 정한다(R14). 약어 방 이름(S.T·P.S 등)은 사용자가 확인한 뒤 사전에 보강한다. 같은 공간명의 방은 종류를 일괄 수정할 수 있다. 방 종류마다 출처를 표시한다.

## 수용 기준

- 성수의 방 종류 판정률이 31% 보다 높아진다.
- 같은 공간명의 방을 한 번에 같은 종류로 바꿀 수 있다.
