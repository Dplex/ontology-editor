# OE-SPC-17 방 종류 사전·일괄 수정

## 요구사항
> User story : 구축 담당자는 방 종류가 이름 사전으로 먼저 판정되고 이름으로 알 수 없을 때만 BIM의 분류 체계를 참고해 정해지는 것을 확인할 수 있다. 약어로 된 방 이름은 사용자가 뜻을 확인한 뒤 사전에 보강할 수 있어, 보강하면 같은 약어의 방이 재판정된다. 같은 공간명을 가진 방들은 종류를 한 번에 일괄 수정할 수 있다. 방 종류마다 출처가 표시되어 사전에서 왔는지, BIM에서 왔는지, 사람이 정했는지 알 수 있다. 사용자는 이 기능으로 임포트 직후 낮은 방 종류 판정률을 끌어올리고, 방 종류에 의존하는 다른 기능을 신뢰하고 쓸 수 있어야 한다.

방 종류는 이름 사전 → OmniClass 순으로 정한다(R14). 약어 방 이름(S.T·P.S 등)은 사용자가 확인한 뒤 사전에 보강한다. 같은 공간명의 방은 종류를 일괄 수정할 수 있다. 방 종류마다 출처를 표시한다.

## 수용 기준

- 성수의 방 종류 판정률이 31% 보다 높아진다.
- 같은 공간명의 방을 한 번에 같은 종류로 바꿀 수 있다.
