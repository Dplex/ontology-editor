# OE-SPC-17 방 종류 사전·일괄 수정

## 요구사항

방 종류는 이름 사전 → OmniClass 순으로 정한다(R14). 약어 방 이름(S.T·P.S 등)은 사용자가 확인한 뒤 사전에 보강한다. 같은 공간명의 방은 종류를 일괄 수정할 수 있다. 종류마다 출처를 표시한다.

## 수용 기준

- 성수의 방 종류 판정률이 31% 보다 높아진다.
- 같은 공간명의 방을 한 번에 같은 종류로 바꿀 수 있다.
