# OE-SPC-09 커스텀존 매핑 갱신

## 요구사항

커스텀존을 만들거나 고치면 그것이 덮는 물리존과 공조존의 매핑을 다시 계산해 온톨로지에 갱신한다. 매핑은 평면 겹침으로 판정한다.

## 수용 기준

커스텀존 경계를 바꾼 뒤 반영하면 TTL 의 커스텀존↔물리존 매핑이 새 경계에 맞게 바뀐다.
