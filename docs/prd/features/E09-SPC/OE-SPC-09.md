# OE-SPC-09 커스텀존 매핑 갱신

## 관련 티켓

- [OE-MAP-01](../E11-MAP/OE-MAP-01.md): 물리존 매핑 기준
- [OE-MAP-02](../E11-MAP/OE-MAP-02.md): 공조존 매핑 기준

## 요구사항
> User story : 고객사 관리자가 커스텀존 경계를 넓혀 옆 회의실 절반을 포함시키면, 평면 겹침으로 그 커스텀존이 덮는 물리존과 공조존의 매핑이 다시 계산되어 반영 시 온톨로지에 갱신된다. 관리자가 매핑을 손으로 적지 않아도 AI Agent 사용자가 '이 구역 온도'를 물을 때 새로 포함된 회의실 센서까지 집계되고, 어느 AHU가 그 구역을 담당하는지도 공조존 매핑을 통해 바로 답할 수 있다. 매핑이 평면 겹침으로 자동 판정되므로 커스텀존 경계를 여러 번 조정해도 사용자가 매핑표를 손볼 필요가 없고, 반영 전 미리보기에서 어느 물리존이 새로 포함·제외되는지 확인할 수 있다.

커스텀존을 만들거나 고치면 그것이 덮는 물리존과 공조존의 매핑을 다시 계산해 온톨로지에 갱신한다. 매핑은 평면 겹침으로 판정한다.

## 수용 기준

커스텀존 경계를 바꾼 뒤 반영하면 TTL 의 커스텀존↔물리존 매핑이 새 경계에 맞게 바뀐다.
