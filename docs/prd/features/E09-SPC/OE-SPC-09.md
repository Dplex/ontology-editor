# OE-SPC-09 커스텀존 매핑 갱신

## 관련 티켓

- [OE-MAP-01](../E11-MAP/OE-MAP-01.md): 물리존 매핑 기준
- [OE-MAP-02](../E11-MAP/OE-MAP-02.md): 공조존 매핑 기준

## 요구사항
> User story : 고객사 관리자가 커스텀존을 만들거나 경계를 고치면 그 커스텀존이 덮는 물리존과 공조존의 매핑이 자동으로 다시 계산되어 반영 시 온톨로지에 갱신된다. 매핑은 평면에서 겹치는지로 판정하므로 사용자가 매핑표를 손으로 적을 필요가 없다. 경계를 여러 번 조정해도 매번 자동으로 따라오며, 사용자는 반영 전 미리보기에서 어느 물리존이 새로 포함되거나 제외되는지 확인할 수 있어야 한다. 이를 통해 AI Agent 사용자가 커스텀존 기준으로 질문할 때 새로 포함된 공간의 설비까지 집계된 답을 받을 수 있다.

커스텀존을 만들거나 고치면 그것이 덮는 물리존과 공조존의 매핑을 다시 계산해 온톨로지에 갱신한다. 매핑은 평면 겹침으로 판정한다.

## 수용 기준

커스텀존 경계를 바꾼 뒤 반영하면 TTL 의 커스텀존↔물리존 매핑이 새 경계에 맞게 바뀐다.
