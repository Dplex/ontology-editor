# OE-SPC-15 겹침 차단 UX

## 관련 티켓

- [OE-OBJ-16](../E02-OBJ/OE-OBJ-16.md): 차단 기준인 겹침 불가 원칙

## 요구사항
> User story : 고객사 관리자가 오브젝트를 다른 오브젝트와 겹치는 자리에 놓거나 옮기려 하면 배치가 차단되고, 겹치는 상대 오브젝트가 붉게 표시되며 '이미 오브젝트가 있는 위치입니다' 안내를 받는다. 끌던 오브젝트는 원래 자리로 돌아간다. 사용자는 왜 배치가 안 되는지 즉시 알 수 있어 같은 시도를 반복하거나 겹침을 모른 채 반영하는 일이 없다. 룸·설비·추가 공간 오브젝트 등 겹침 불가 원칙에 걸리는 모든 오브젝트에 같은 표시가 적용되어, 사용자는 오브젝트 종류마다 다른 반응을 외울 필요가 없어야 한다.

겹침 불가 원칙(OE-OBJ-16)에 걸리는 배치·이동은 차단하고, 겹치는 상대 오브젝트를 붉게 표시하며 "이미 오브젝트가 있는 위치입니다" 를 안내한다. 끌던 오브젝트는 이동한 자리에서 원래 자리로 원복 배치된다.

## 수용 기준

겹치는 자리에 놓으려 하면 상대 오브젝트가 붉게 표시되고 안내 문구가 보이며 오브젝트는 원래 자리에 남는다.
