# OE-SPC-11 룸 추가·크기 조절

## 관련 티켓

- [OE-OBJ-03](../E02-OBJ/OE-OBJ-03.md): 룸 경계·겹침 제약

## 요구사항
> User story : 구축 담당자가 수동 구축 중 넓은 개방형 사무 물리존 안에 임원실 두 개를 표현하려 할 때, 물리존 안에 사각 룸을 그려 넣고 변이나 꼭짓점을 끌어 실측 크기에 맞춘다. 룸이 물리존 경계 밖으로 나가거나 다른 룸과 겹치는 시도는 차단되어 평면상 불가능한 구조가 생기지 않는다. 임원실이 없어지면 룸을 지우고 그 영역은 자동으로 물리존으로 돌아간다. 임포트는 룸을 만들지 않으므로 BIM 데이터와 섞여 혼란이 생기지 않는다.

룸을 물리존 안에 추가하고 크기를 조절한다. 룸은 4면 벽으로 둘러싸인 사각 영역으로 그리며, 물리존 경계 밖으로 나갈 수 없고 다른 룸과 겹칠 수 없다(OE-OBJ-03). 크기 조절은 변 또는 꼭짓점을 끌어 한다. 룸을 지우면 그 영역은 물리존으로 돌아간다.
룸은 수동 구축·운영 편집에서만 만든다 — 임포트는 룸을 만들지 않는다(D15).

## 수용 기준

물리존 경계 밖으로 룸을 늘리거나 다른 룸과 겹치게 하는 시도가 차단된다.
