# OE-SPC-11 룸 추가·크기 조절

## 관련 티켓

- [OE-OBJ-03](../E02-OBJ/OE-OBJ-03.md): 룸 경계·겹침 제약

## 요구사항
> User story : 구축 담당자와 고객사 관리자는 물리존 안에 룸을 추가하고 크기를 조절할 수 있다. 룸은 네 면이 벽으로 둘러싸인 사각 영역으로 그리며, 변이나 꼭짓점을 끌어 크기를 바꾼다. 룸은 물리존 경계 밖으로 나갈 수 없고 다른 룸과 겹칠 수 없으며, 그런 시도는 차단된다. 룸을 지우면 그 영역은 다시 물리존으로 돌아간다. 룸은 수동 구축과 운영 편집에서 사용자가 직접 만드는 것이며 BIM 임포트가 자동으로 만들지는 않으므로, 사용자는 BIM 공간과 직접 나눈 룸을 혼동하지 않고 작업할 수 있어야 한다.

룸을 물리존 안에 추가하고 크기를 조절한다. 룸은 4면 벽으로 둘러싸인 사각 영역으로 그리며, 물리존 경계 밖으로 나갈 수 없고 다른 룸과 겹칠 수 없다(OE-OBJ-03). 크기 조절은 변 또는 꼭짓점을 끌어 한다. 룸을 지우면 그 영역은 물리존으로 돌아간다.
룸은 수동 구축·운영 편집에서만 만든다 — 임포트는 룸을 만들지 않는다(D15).

## 수용 기준

- **AC1** 물리존 경계 밖으로 룸을 늘리거나 다른 룸과 겹치게 하는 시도가 차단된다.
