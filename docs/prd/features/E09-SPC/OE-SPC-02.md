# OE-SPC-02 물리존 생성·분할·병합·삭제 (E3)

## 관련 티켓

- [OE-INT-05](../E20-INT/OE-INT-05.md): 만든 물리존 id 규칙
- [OE-MAP-01](../E11-MAP/OE-MAP-01.md): 설비 소속 자동 재판정
- [OE-MAP-02](../E11-MAP/OE-MAP-02.md): 공조존 매핑 자동 갱신
- [OE-HIST-03](../E19-HIST/OE-HIST-03.md): 병합의 편집 파일 저장

## 요구사항
> User story : 고객사 관리자는 물리존을 새로 만들고, 나누고, 합치고, 지울 수 있다. 분할은 선 하나를 그어 둘로 나누며 넓은 쪽이 원래 이름을 유지하고 새 조각의 방번호는 사용자가 입력한다. 셋 이상으로 잘리는 선은 거절된다. 병합은 맞닿은 물리존끼리만 가능하고 사이 벽 자리까지 포함하며, 일부만 겹친 물리존은 거절된다. 각 동작 뒤 설비 소속과 공조존 매핑이 자동으로 다시 계산되고, 두 방 사이에 있던 문은 남는 방 하나만 잇도록 정리된다. 사용자가 병합 결과를 편집 파일로 저장했다 불러오면 병합 상태와 이후 고친 외곽선이 그대로 복원되어야 한다.

물리존을 생성·분할·병합·삭제한다(E3). 만든 물리존의 id 는 `U_` 로 시작한다(OE-INT-05).
각 동작은 설비 소속과 공조존 매핑을 바꾸므로 자동 재매핑한다(OE-MAP-01·02). 없어진 방을 가리키던 BIM 명시 소속은 버리고 좌표로 다시 판정한다. 분할한 물리존에 명시 소속된 설비도 좌표로 다시 판정한다(OE-MAP-01 3단계, Q13).
분할은 선 하나로 둘로 나누며, 넓은 물리존이 원래 id·공간명을 갖고 새 물리존의 방번호는 사용자가 넣는다. 셋 이상으로 잘리는 선은 거절한다.
병합은 맞닿은 방끼리만 되고 사이 벽 자리까지 포함한다. 두 방 사이 문은 남는 방 하나만 잇는다. 일부만 겹친 방은 거절한다. 병합은 편집 파일에 `into` 로 남아 불러올 때 다시 계산하지 않는다(OE-HIST-03).

## 수용 기준

- **AC1** 분할 뒤 두 물리존 안의 설비 소속이 각 물리존으로 다시 계산된다.
- **AC2** 병합 뒤 사이 벽 자리의 설비가 합친 방에 속한다.
- **AC3** 병합 뒤 두 방 사이에 있던 문은 남는 방 하나만 잇고, 없어진 방을 가리키던 다른 문은 남는 방을 가리킨다(GeoJSON `connects` 에 없어진 방 id 가 없다).
- **AC4** 병합한 뒤 남는 방의 외곽선을 고치고 편집 파일로 저장·불러오면, 병합이 `into` 로 되살아나고 고친 외곽선이 그대로 남는다(OE-HIST-03).
- **AC5** 새 조각의 방번호가 같은 층의 다른 방번호와 겹치면 거절된다(OE-OBJ-02).
