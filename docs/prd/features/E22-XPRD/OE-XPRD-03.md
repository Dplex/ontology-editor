# OE-XPRD-03 PRD_003_00x 탐색기 트리

## 관련 티켓

- [OE-SYNC-03](../E15-SYNC/OE-SYNC-03.md): 공간 계층 변경 반영
- [OE-WF-14](../E14-WF/OE-WF-14.md): 트리 반영 시점을 맞출 타 사용자 적용 시점

## 요구사항
> User story : DT2.0 PM이 에디터에서 물리존을 추가·삭제·이름 변경해 반영했을 때 스마트 모니터링의 탐색기 트리가 새 공간 계층을 반영하는지 확인한다. PRD_003_00x가 레이아웃 변경에 따른 트리 갱신을 전제하지 않았다면 개정해, 관제 사용자가 트리에서 지워진 방을 보거나 새 방을 못 찾는 일이 없도록 두 PRD의 공간 계층 정의를 맞춘다. 공간 계층 변경이 트리에 반영되는 시점(반영 즉시 vs 새로고침)도 에디터의 타 사용자 적용 시점 규칙(OE-WF-14)과 맞춰 두어 3D View와 트리가 서로 다른 레이아웃을 보이는 일을 막는다.

PRD_003_00x 탐색기 트리가 공간 계층 변경(OE-SYNC-03)을 반영하는지 확인하고, 필요하면 PRD_003_00x 를 개정한다.

## 수용 기준

탐색기 트리가 반영 뒤 새 공간 계층을 보인다.
