# OE-XPRD-04 PRD_009 권한 카탈로그

## 관련 티켓

- [OE-COM-01](../E01-COM/OE-COM-01.md): 에디터 편집 권한 항목

## 요구사항
> User story : DT2.0 PM은 R2 에디터 권한 제어를 위해 설정 PRD(PRD_009)의 기능 권한 카탈로그에 에디터 편집 권한 항목(Admin과 Super Admin은 가능, Viewer는 불가)을 정의한다. 카탈로그에 이 행이 있어야 회원 관리 화면에서 역할별 편집 가능 여부가 일관되게 표시되고, 에디터가 화면 진입과 API 호출에서 같은 권한 값을 참조해 다른 DT 기능과 동일한 권한 체계로 관리된다. 사용자는 PRD_009 권한 카탈로그에 에디터 편집 권한 행이 있는 것으로 완료를 확인할 수 있어야 한다.

PRD_009 기능 권한 카탈로그에 에디터 편집 권한 항목(Admin/Super Admin 가능, Viewer 불가)을 정의한다(OE-COM-01).

## 수용 기준

PRD_009 권한 카탈로그에 에디터 편집 권한 행이 있다.
