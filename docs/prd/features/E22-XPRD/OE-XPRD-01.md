# OE-XPRD-01 PRD_009 시스템 로그

## 관련 티켓

- [OE-COM-04](../E01-COM/OE-COM-04.md): 레이아웃 반영 로그 이벤트

## 요구사항
> User story : 사용자가 Digital Twin에 수정된 온톨로지를 업데이트 시,현재 구축된 사이트에 변경사항이 생긴 것을 시스템 로그를 통해 확인할 수 있다.

DT2.0 PM은 에디터의 반영·되돌리기 이벤트를 시스템 로그에 남기기 위해 설정 PRD(PRD_009)의 시스템 로그 이벤트 유형 표에 '레이아웃 반영/되돌리기' 두 유형을 추가한다. 이 개정이 있어야 설정 화면의 로그 조회에서 레이아웃 변경을 다른 시스템 이벤트와 같은 방식으로 필터·조회할 수 있고, 에디터 PRD와 설정 PRD 사이에 정의 불일치가 생기지 않는다. 

## 수용 기준

- **AC1** PRD_009 가 개정되어 두 유형이 시스템 로그 표에 있다.
