# OE-XPRD-01 PRD_009 시스템 로그

## 관련 티켓

- [OE-COM-04](../E01-COM/OE-COM-04.md): 레이아웃 반영 로그 이벤트

## 요구사항
> User story : DT2.0 PM이 에디터의 반영·되돌리기 이벤트를 시스템 로그에 남기려면 PRD_009 시스템 로그의 이벤트 유형 표에 '레이아웃 반영/되돌리기'가 있어야 한다. 이 티켓으로 PRD_009를 개정해 두 유형을 추가하면, 설정 화면의 로그 조회에서 다른 시스템 이벤트와 같은 방식으로 레이아웃 변경을 필터·조회할 수 있고 에디터 PRD와 설정 PRD 간 정의 불일치가 없어진다. 로그 항목(이벤트 유형·일시·사용자·사이트·대상 층·버전 번호)도 함께 정의되어 PRD_009 로그 조회 화면이 이를 표시할 수 있고, 감사 담당자가 레이아웃 변경 이력을 다른 시스템 이벤트와 같은 방식으로 조회한다.

PRD_009 시스템 로그의 이벤트 유형에 '레이아웃 반영 / 되돌리기' 를 더한다(OE-COM-04).

## 수용 기준

PRD_009 가 개정되어 두 유형이 표에 있다.
