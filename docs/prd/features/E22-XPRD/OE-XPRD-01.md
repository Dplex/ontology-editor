# OE-XPRD-01 PRD_009 시스템 로그

## 관련 티켓

- [OE-COM-04](../E01-COM/OE-COM-04.md): 레이아웃 반영 로그 이벤트

## 요구사항
> User story : DT2.0 PM은 에디터의 반영·되돌리기 이벤트를 시스템 로그에 남기기 위해 설정 PRD(PRD_009)의 시스템 로그 이벤트 유형 표에 '레이아웃 반영/되돌리기' 두 유형을 추가한다. 이 개정이 있어야 설정 화면의 로그 조회에서 레이아웃 변경을 다른 시스템 이벤트와 같은 방식으로 필터·조회할 수 있고, 에디터 PRD와 설정 PRD 사이에 정의 불일치가 생기지 않는다. 사용자는 PRD_009가 개정되어 두 유형이 표에 있는 것으로 완료를 확인할 수 있어야 한다.

PRD_009 시스템 로그의 이벤트 유형에 '레이아웃 반영 / 되돌리기' 를 더한다(OE-COM-04).

## 수용 기준

PRD_009 가 개정되어 두 유형이 표에 있다.
