# OE-XPRD-02 PRD_002 알림 종류

## 관련 티켓

- [OE-WF-16](../E14-WF/OE-WF-16.md): 레이아웃 변경 반영 알림

## 요구사항
> User story : DT2.0 PM이 레이아웃 반영 사실을 GNB 시스템 알림으로 보내려면 PRD_002 알림 종류 표에 '레이아웃 변경 반영' 행이 있어야 한다. 이 티켓으로 PRD_002를 개정하면 글로벌 헤더의 알림 센터가 새 알림 유형을 인식해 대상 층·반영자·버전 번호를 표시하고, 사용자가 알림 설정에서 이 유형을 다른 알림과 같은 방식으로 관리할 수 있다. 알림을 누르면 해당 버전의 반영 결과 리포트나 3D View로 이동하는 연계도 PRD_002 알림 동작 규칙에 맞춰 정의되어, 관제 사용자가 레이아웃 변경을 인지하고 확인하는 흐름이 끊기지 않는다.

PRD_002 알림 종류 표에 '레이아웃 변경 반영' 행을 더한다(OE-WF-16).

## 수용 기준

PRD_002 가 개정되어 그 행이 있다.
