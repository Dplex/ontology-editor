# OE-XPRD-02 PRD_002 알림 종류

## 관련 티켓

- [OE-WF-16](../E14-WF/OE-WF-16.md): 레이아웃 변경 반영 알림

## 요구사항
> User story : 사용자가 DT 에 온톨로지 파일을 업로드 시, 사용자는 시스템 알림을 통해 레이아웃 변경 알림을 받을 수 있다. 현재 DT > 스마트 관제 > 3D Map View를 보고 있던 사용자라면 '레이아웃 변경 알림' 새로고침 안내 팝업을 확인할 수 있다. 


DT2.0 PM은 레이아웃 반영 사실을 GNB 시스템 알림으로 보내기 위해 알림 PRD(PRD_002)의 알림 종류 표에 '레이아웃 변경 반영' 행을 추가한다(OE-WF-16). 이 개정이 있어야 글로벌 헤더의 알림 센터가 새 알림 유형을 인식해 대상 층·반영자·버전 번호를 표시하고, 사용자가 알림 설정에서 이 유형을 다른 알림과 같은 방식으로 관리할 수 있다. 사용자는 PRD_002가 개정되어 그 행이 있는 것으로 완료를 확인할 수 있어야 한다.
DT 3D Map View가 활성화 상태인 사용자를 대상으로, 레이아웃을 새로고쳐 최신 온톨로지 기반의 정보를 확인할 수 있게 새로고침 수행 팝업을 제공한다. 

## 수용 기준

- **AC1** 레이아웃 변경 시 안내를 위한 시스템 알림을 제공한다.
- **AC2** 사용자가 3D Map View 이용 중인 경우 레이아웃 업데이트 팝업을 제공한다.
