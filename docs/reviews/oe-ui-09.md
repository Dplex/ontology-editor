## 구현한 것
요구사항은 "복사·붙여넣기, 다중 선택, 삭제" 한 줄이다. 이번 범위: **설비만**, **한꺼번에 옮기기·지우기**,
**Shift+클릭과 Shift+드래그 박스 선택 둘 다**. 복사·붙여넣기는 이번에 하지 않았다.

| 무엇 | 구현 | 확인 테스트 |
|---|---|---|
| 선택 — Shift+클릭 | 편집 모드에서 3D·평면도·설비 목록의 Shift+클릭으로 선택 그룹에 넣고 뺀다. 이미 하나를 선택했으면 그것부터 그룹에 들어간다. 둘 이상이면 그룹, 하나만 남으면 일반 선택으로 돌아간다 | e2e `multi-select.spec.ts` 1·2 |
| 선택 — Shift+드래그 박스 | 3D(형상 중심이 화면 박스 안)와 평면도(점이 박스 안)에서 현재 그룹에 추가한다. 숨긴 층은 빼고, 흐리게 표시된 설비는 넣는다 | e2e 2 |
| 설비만 | 덕트·배관은 넣지 않는다(박스에 수백 개가 같이 잡힌다). Shift+클릭하면 "넣지 않습니다" 를 알린다 | e2e 1 |
| 표시 | 3D 는 선택 색으로 칠하고 나머지를 **흐리게 하지 않는다** — 하나를 선택하면 관계없는 설비가 흐려지는데, 흐린 설비는 선택할 수 없어 Shift+클릭으로 추가하지 못했다. Shift+클릭·박스는 흐린 설비도 선택한다. 평면도는 점을 크게, 목록은 줄에 색을 칠한다. 오른쪽 패널은 "설비 N대 고름"(층·이름·종류) | 스샷 |
| 한꺼번에 옮기기 | 방향키(Shift 1m) 또는 그룹 중 하나를 3D 에서 드래그 → 모두 같은 거리만큼 이동. **하나라도 막히면 아무것도 옮기지 않는다** — 겹침(OE-OBJ-16, 그룹끼리는 비교하지 않음)·외벽 전용 설비(OE-OBJ-04)·좌표 없는 설비. 되돌리기 한 번에 모두 돌아오고, 길게 누른 방향키는 한 단계로 묶인다 | e2e 1·2·3, 단위 `overlap.test.ts` "같이 옮기는 설비(ignore)끼리는 …" |
| 한꺼번에 지우기 | Delete 또는 패널의 [설비 N대 지우기]. 연결도 같이 지워지고 되돌리기 한 번에 모두 돌아온다 | e2e 1 |
| 선택 해제 | Esc, 다른 것(방·계통·벽·커스텀존)을 선택하거나 편집을 끝내면 해제된다. 지운 설비는 그룹에서 빠진다 | e2e 1 |

저장 위치: 선택 상태는 화면에만 있다. 한꺼번에 옮기거나 지운 것은 한 대씩 옮기고 지운 것과 같은 편집이라 편집 파일·TTL·GeoJSON 에 같은 형식으로 남는다
(편집 파일에 "한꺼번에" 라는 표시는 없다).

3. `Shift+→` → 모두 1m 이동하고 편집 줄에 "설비 N대 옮김". `Ctrl+Z` 한 번에 모두 돌아온다

## 남은 것
- **복사·붙여넣기**는 하지 않았다(요구사항에는 있다). 붙여넣은 설비의 id·이름·연결·계통을 어떻게 할지 정해야 한다
- 한꺼번에 옮길 때 연결된 배관은 따라오지 않는다(한 대 옮기기의 [배관도 같이] 는 그룹에 없다). 둘이 같은 배관에 연결됐을 때 어느 끝을 늘일지 정하지 않았다
- 3D 에서 그룹을 드래그하면 드래그하는 동안 잡은 하나만 따라 움직이고, 놓을 때 나머지가 이동한다
- 3D 의 Shift+드래그는 시점 이동(OrbitControls 의 Shift+드래그)을 대체한다 — 시점 이동은 오른쪽 버튼 드래그로 한다
- 평면도·목록의 Shift+클릭과 박스 선택은 편집 모드에서만 된다(보기 모드는 한 대만 선택한다)
- 물리존·벽·문·창의 다중 선택은 범위 밖
- 성수 파일은 이 PC 에 있다(2026-10-06). 화면 측정(e2e)은 이번에 하지 않았다
