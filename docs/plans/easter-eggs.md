# 숨은 연출(이스터에그) — 설계와 제미나이 작업 지침

읽는 사람은 셋이다. 연출을 만드는 제미나이, 그것을 리뷰·수정하는 Claude, 무엇을 넣을지 고르는 사람.
2026-10-24 초안, 같은 날 껍데기를 깔고 맞췄다. Unity 판과 나란히 보이는 자리를 앞두고 썼다.

## 요점

- **에셋·재질로는 겨루지 않는다.** 그 판은 Unity 가 이긴다. 여기 고른 연출은 화면에서 빛나는 것 하나하나가
  **TTL·GeoJSON 의 줄이거나 BIM 이 준 값**인 것뿐이다. 에셋을 사서는 만들 수 없는 장면이다.
- **기본 화면은 오늘 그대로다.** 연출은 전부 일부러 켜는 모드(egg)로만 둔다. PRD 가 리플레이를 모션 시간 한도에서
  뺀 근거(OE-UI-23 4항, "사용자가 일부러 보는 모드")와 같은 자리다. 켜지 않으면 DOM·3D 픽셀·단축키·내보내는 파일이
  하나도 달라지지 않는다. 그래서 PRD 티켓의 수용 기준과 기존 e2e 를 건드리지 않는다.
- **발표는 링크 하나로 연다.** `?open=…&egg=rise,alive,pass` 로 켜 두고, 무대에서는 숨은 손짓으로 하나씩 꺼낸다.
- **일의 나눔.** 껍데기(이음매·시험)는 깔려 있다. 제미나이가 알맹이를 egg 하나에 커밋 하나로 올리고, Claude 가 이 문서의
  규칙으로 리뷰·수정한다. 작업은 브랜치 `feature/easter-eggs` 하나에서 하고 이슈·칸반으로 관리하지 않는다(2026-10-24 결정).

## 1. 왜 이 방향인가

| | Unity 판이 강할 것(짐작) | 우리 판에 실제로 있는 것 |
|---|---|---|
| 겉모습 | PBR 재질, 에셋(가구·사람·나무), 그림자, 후처리, 하늘 | 계통 색·외곽선·모서리 선·바닥 격자(ui-notes "3D 편집 화면의 겉모습") |
| 여는 길 | 설치·빌드 | 브라우저 링크 하나. 성수 19개 층 · 설비 2만 대가 웹에서 돈다 |
| 편집 | ? | 고치면 TTL·GeoJSON 의 그 줄이 바로 바뀐다(고른 것의 "내보내면" 칸, 결과 비교 `B`) |
| 관계 | ? | `brick:feeds`·`hasLocation`·`hasPart` 가 그래프로 있고, 받는 쪽 DT 파서 규칙까지 옮겨 두었다(`lib/export/read-ttl.ts`) |

Unity 판은 아직 못 봤으니 왼쪽 열은 짐작이다. 그래서 카탈로그는 그쪽이 무엇을 해 와도 겹치지 않는 것부터 골랐다.
데이터가 그래픽이 되는 순간들이다.

**연출 원칙 셋.**

1. **빛나는 것은 데이터 한 줄에 묶는다.** 장식 입자나 가짜 흐름을 넣지 않는다. 흐르는 것은 TTL 에 나가는 `brick:feeds` 뿐이고,
   해는 IfcSite 좌표의 해다. 값이 없으면 지어내 채우지 않고 없다고 적는다("이 파일에는 대지 좌표가 없어 서울 기준으로 그렸습니다").
2. **움직임은 뜻이 있을 때 한 번만.** 계속 숨 쉬는 UI, 커서를 따라오는 빛 같은 것은 넣지 않는다.
3. **기본 화면의 차분함은 지킨다.** 디자인 시스템(`docs/prd/design-system.md`: Linear 계열, 강조색 인디고 하나, 그림자 대신 선)은
   egg 밖의 화면 전부에 그대로다. egg 가 화려해도 되는 곳은 3D 칸과 그 위 HUD 안뿐이다(`wipe` 만 화면 전체의 전환이다).

**쓰는 키(G5).** `shortcuts.ts` 가 정본이다. 지금 쓰는 키는 `E S / P N F O V X L B G R W Z Y D C M T K U I . , [ ] 0 ?`,
백틱(성능 표), `Home Enter Insert Delete PageUp PageDown`, 방향키, `Ctrl+\`, 비행 중 `W A S D Q E`, 리플레이 안의 `Space Q V` 다.
egg 가 쓰는 키는 둘뿐이다. 하나는 **`~`(Shift+\`)** 다. `` ` `` 는 성능 표지만 그 조합은 `shift` 를 따로 적지 않아 Shift 가 붙으면
맞지 않는다. 다른 하나는 **3D 위에서 누르고 있는 `Space`** 다. 편집 화면에서 `Space` 는 지금 아무 일도 하지 않는다.
Alt 조합은 `matchShortcut` 이 받지 않지만 OS·브라우저 몫이라 쓰지 않는다.

**지난 제미나이 판에서 되돌린 것(G11).**

- 이모지(⚠️ ⚙️ 🔍): 화면 글꼴과 안 맞고, 스크린리더가 이모지 이름을 읽는다.
- 별칭 표를 따로 두기: `brick:Terminal_Unit` 을 디퓨저라 불렀다. 종류 이름은 `kinds.ts`, 클래스는 `classOf`(`lib/export/ttl.ts`) 하나만 쓴다.
- 모르는 까닭을 단정하기("실제 위치로 옮겼다", "불필요한 설비를 지웠다"): 무엇이 바뀌었는지만 말한다.
- 세는 것의 이름을 틀리기: TTL 줄 수를 관계 수라 불렀다. 수를 보이면 무엇을 세는지를 정확히 적는다.
- 이미 있는 기능의 단추를 하나 더 두기: [2D 도면] 은 평면도와 같고, [1인칭 산책] 은 비행 `G` 와 같았다.
- 툴팁에 티켓 번호 넣기, 화살표 키를 받지 않는 `role="slider"`.

**겉모습 금지(G12).**

- 한쪽 색 막대 카드(`border-left` 강조)와 카드뷰 꾸밈. 사용자가 "LLM 티" 로 본다.
- 그라데이션 장식, 카드마다 그림자(A7), 회색에 색 섞기(따뜻하게 하면 세피아로 보였다).
- 웹폰트·CDN·원격 텍스처(사내망). 글꼴·스크립트·텍스처는 전부 번들 안에 둔다. HDR 하늘 그림도 받지 않는다.
- `/immersive-garden`·`/habrix-theme` 를 이 repo 에 돌리기.

## 3. 껍데기 — egg 가 붙는 자리

**껍데기는 깔려 있다**(브랜치 `feature/easter-eggs`). 이음매와 시험이 먼저 서 있어서 egg 가 G2~G4 를 어길 길이 좁다.
형(type)의 정본은 `src/eggs/types.ts` 다. 이 문서에 다시 적지 않는다.

```
src/editor/eggs.ts      setupEggs(): 주소·콘솔·`~` 판으로 켜고 끄고, EggContext 를 만든다. 리플레이 동안 쉬게 한다.
                        편집기 상태를 읽어도 되는 유일한 egg 파일이다.
src/eggs/types.ts       EggContext · SceneLayer · EggHandle · Egg (정본)
src/eggs/registry.ts    EGGS 목록. 순서가 `~` 판의 숫자다
src/eggs/<id>.ts        알맹이 하나. `export function enable(ctx): EggHandle`
src/eggs/probe.ts       시험용 본보기(e2e 에서만 목록에 든다). 새 egg 는 이것을 베껴 시작한다
src/eggs/hub.ts·hub.css `~` 판. 처음 열 때 내려받는다
src/eggs/eggs.test.ts   G4 — import 허용 목록(LIB_ALLOWED)을 훑는다
e2e/eggs.spec.ts        목록의 egg 를 하나씩 켰다 끄며 G3·G7 을 잰다(새 egg 도 저절로 든다)
```

**viewer.ts 의 이음매는 둘이다: `addLayer` · `setLights`.** tick 이 층마다 `step` 을 불러 dirty 를 모으고, 본 장면을 그린 뒤
외곽선을 그리기 전에 `afterRender` 를 부른다. 외곽선이 그 뒤라서 egg 가 화면을 덮어도 고른 것의 윤곽은 위에 남는다.
이 둘 말고 viewer.ts 안을 고쳐야 하면 그 커밋에 이유를 적는다.

**egg 가 받는 것(EggContext).** 모델 읽기(`model()`·`modelVersion()`), 3D 층(`addLayer`), 바탕 빛(`lights`), 넓게 보기(`wide`),
`still()`·`dark()`, 제 HUD 자리(`hud`), 화면이 이미 센 값(`signals`: 검사 위반 수 · 수용 기준선 · 비행 · 리플레이 · 보는 층)이다.
고치는 함수는 하나도 없다.

**껍데기가 대신 거두는 것.** egg 를 끄면 껍데기가 egg 의 `off()` 를 부른 뒤, 그 egg 가 `ctx` 로 얹은 층·빛·HUD·넓게 보기를 모두 거둔다.
그래서 egg 의 `off()` 는 제가 직접 건 것(`watch`, 타이머, 리스너)만 풀면 된다. 층의 형상·재질은 층의 `dispose` 에서 버린다 —
껍데기는 그 안에 무엇이 있는지 모른다. 빠뜨리면 e2e 의 메모리 비교가 떨어진다.

**새 egg 를 붙이는 법.**

1. `src/eggs/<id>.ts` 를 만든다(`probe.ts` 를 베낀다).
2. `registry.ts` 에 한 줄을 더한다.
3. lib 모듈을 새로 쓰면 `eggs.test.ts` 의 `LIB_ALLOWED` 에 한 줄을 더하고, 그 모듈이 모델을 고치지 않는다는 근거를 커밋에 적는다.
4. `npx vitest run src/eggs` 와 `npx playwright test e2e/eggs.spec.ts` 를 돌린다. 켰다 끄기 시험은 목록 전체를 돌아서 새 egg 도 저절로 잰다.

**켜는 길 셋.**

| 길 | 모양 | 언제 |
|---|---|---|
| URL | `?egg=xray,alive` (쉼표로 여럿) | 발표 링크. 파일이 열리고 3D 가 첫 장을 그린 뒤에 켠다 |
| 콘솔 | `__oe.egg('xray')` 로 켜고 끄기(`eggOn`·`eggOff` 도 있다), `__oe.eggs()` 는 목록 표 | 개발·리허설 |
| 숨은 손짓 | `~` 판, 그리고 egg 마다 하나(카탈로그) | 무대 위 |

- **`window.__oe` 는 말로 편집(`connections.ts` 의 `screen`·`plan`·`apply`)과 같이 쓰는 자리다.** 덮지 않고 이름을 더한다.
- **`~` 판은 콘솔 게임의 `~` 콘솔에 바치는 오마주다.** 3D 위쪽 가운데에 고정폭 글자로 egg 목록이 뜨고, 판이 떠 있는 동안
  `1`~`9` 로 켜고 끈다(`0` 은 건물 전체 보기라 쓰지 않는다). 판이 떠 있을 때만 `Esc` 를 capture 단계에서 받아 판만 닫는다.
  선택 해제까지 같이 일어나면 안 된다. `?` 안내(ShortcutHelp)에는 올리지 않는다. 숨은 것이라서다.
- **끄기는 켠 길로 한 번 더**, 또는 HUD 의 작은 [끄기], 또는 콘솔. `Esc` 로는 끄지 않는다. `Esc` 는 선택 해제다.
- **[링크 복사]는 `egg` 를 싣지 않는다**(`share-link.ts` 그대로). 평소 공유하는 링크가 연출을 퍼뜨리지 않게 하려는 것이다.
- **손짓은 지금 아무 일도 하지 않는 자리에만 건다.** "이 손짓이 지금 하는 일: 없음" 을 e2e 로 보인다.

B 는 숨겨 두는 재미다. 크기는 XS < S < M < L.

고른 것·미리 강조·막힘 외곽선, 모서리 선, 바닥 격자, 떨어져 앉기·흔들기·가라앉기, 고른 계통의 흐르는 빛(`flow-pulse.ts`),
흐름 방향의 연쇄(`playCascade`), 방향 큐브와 비행(`E E`·`Q Q` 층 이동 포함), 종류별 색(`X`), 분해도, IDF 공조존 겹쳐 보기,

`src/editor/intro.ts`·`public/intro/`, `docs/dev/deploy55.md`). egg 는 이것들을 가져다 쓰고, 옆에 비슷한 것을 하나 더 두지 않는다.
인트로는 그림자를 건물이 움직일 때만 다시 그린다. `sun`·`shadow` 를 만들 때 그 수법부터 본다.

### S1. `xray` — 온톨로지 투시

**보이는 것.** 3D 위에서 `Space` 를 누르고 있는 동안 건물이 어두운 막 뒤로 0.25초에 물러나고, 그 자리에 받는 쪽 DT 가 읽는
그래프가 선다. 놓으면 0.2초에 돌아온다(macOS 훑어보기처럼 누르고 있는 동안만).

- 설비는 제자리의 점이다. 색은 종류별 색(`X`)과 같은 팔레트를 쓴다.
- 물리존은 바닥 중심의 고리다. 층은 건물 옆에 세운 기둥의 마디다.
- `feeds` 는 흐르는 빛이라 방향이 보인다. `hasLocation` 은 설비에서 방으로 가는 가는 선, `hasPart` 는 방에서 층 기둥으로 휘는 곡선이다.
- HUD 는 두 줄이다. 첫 줄 `받는 쪽이 읽는 관계 · feeds 1,234 · hasLocation 18,020 · hasPart 512`, 둘째 줄은 옅게
  `덕트·배관(fso:) 15,864개는 받는 쪽이 읽지 않아 그리지 않았습니다`.

**데이터.** `readOntologyTTL(modelToTTL(model))` 의 결과만 쓰고 새로 판정하지 않는다. 그래야 화면의 선 하나가 파일의 줄 하나다.
`read-ttl.ts` 는 받는 쪽 파서(ieum-pipeline `internal/ontology/ttl.go`)의 규칙을 옮겨 둔 것이라, 둘째 줄의 덕트·배관 문장도
그 규칙에서 그대로 나온다. 엔티티의 `key` 는 GeoJSON feature id 와 같은 문자열이라 자리를 거기서 찾는다.

**구현.**

- 그래프는 egg 자신의 `Scene` 하나다. 점은 `Points` 1개, 선은 술어마다 `LineSegments` 1개, `feeds` 는 `flowPulseMesh` 를 다시 쓴다.
- 어두운 막은 재질을 바꾸지 않고 만든다. `afterRender` 에서 화면 전체 사각형 하나(바탕색 85%)를 그린 다음, 그래프 장면을 같은 카메라로 덧그린다.
  건물 재질을 건드리지 않으니 끌 때 되돌릴 것이 없다.
- 모델이 바뀔 때만 다시 짓는다(`modelVersion`). TTL 을 만드는 데 성수에서 시간이 들면, 처음 누를 때 HUD 에 "그래프 짓는 중" 을 띄운다.

**예산.** 성수에서 짓기 1초 안(넘으면 숫자를 남기고 미리 짓는 때를 따로 둔다), 누른 채 돌릴 때 프레임 간격 95% 20ms 이하.

**하지 않는 것.** 힘 기반 배치는 하지 않는다. 점이 실제 자리를 떠나면 "건물 안의 그래프" 가 아니게 된다. 점마다 라벨도 달지 않는다(성수는 2만 개다).

**확인.** TTL 의 `feeds` 수, HUD 의 수, 그래프의 선 수가 같다(`__oe.eggs().inspect.xray`).

### S2. `alive` — 살아 있는 건물

**보이는 것.** TTL 에 `brick:feeds` 로 나가는 연결 전부가 원천 쪽부터 흐른다. 색은 계통 종류(급기·환기·배기·냉수·온수…)별이다.
규칙이 짐작했지만 아직 확정하지 않은 방향은 흐르지 않고 옅은 점선으로 멈춰 있다. 그래서 **흐르는 것은 받는 쪽이 아는 흐름이다.**
여기서 계통을 확정(`C`)하거나 방향을 적용하면, 이미 있는 연쇄 화살표가 퍼진 뒤 그 계통이 그 자리에서 흐르기 시작한다.

**데이터.** `xray` 와 같은 TTL 읽기의 `feeds`. 계통 종류는 `ctx.model()` 의 계통과 `lib/kinds.ts` 에서 읽는다(lib 이라 G4 에 걸리지 않는다).

**구현.** `flowPulseMesh(segments, color, dark)` 를 계통 종류마다 하나씩 쓰므로 그리기 호출은 종류 수만큼이다. 시간은 `setFlowTime` 으로 민다.
켜 있는 동안은 매 프레임 그린다. 지금 고른 계통의 흐르는 빛과 같은 처지다. `still()` 이면 혜성 꼴로 멈춘 채 둔다.

**예산.** 성수 회전 중 프레임 간격 95% 20ms 이하. 끄면 0장.

**하지 않는 것.** 덕트·배관 형상 안을 따라 흐르게 하지 않는다. 지금 흐르는 빛은 설비 중심끼리 잇는 선이다(`flow-pulse.ts` 머리 주석).
형상을 따라가면 더 멋있지만, 그 경로는 TTL 에 없다.

### S3. `pass` — 기준선 통과

**보이는 것.** 켜 둔 동안 편집으로 완전성 검사 위반이 0 이 되거나 수용 기준선이 미달에서 통과로 바뀌는 순간에 한 번만 튼다.
빛의 면이 맨 아래층 바닥에서 꼭대기까지 1.2초에 훑고 올라간다. 지나가는 층판은 **그 층의 위반이 0 일 때만** 잠깐 밝아진다.
기준선만 통과하고 위반이 남은 층은 그대로라 거짓 축하가 되지 않는다. HUD 에는 체크 표시가 0.3초에 그려지고 `완전성 검사 위반 0` 이 뜬다.
진단 칩 같은 기본 화면에는 손대지 않는다.

**데이터.** 위반 수·기준선 상태를 다시 재지 않고 `signals.violations`·`signals.accepted` 로 받는다. 층별 위반은 층 칩이 이미 나눠 센 값이다.

**규칙.** 한 파일에 한 세션 동안 한 번이다. 되돌렸다가 다시 통과해도 다시 틀지 않는다. 되돌리기로 통과가 풀리면 아무것도 하지 않는다.
`still()` 이면 체크 표시만 보인다.

**쓰임.** 무대에서 마지막 위반 하나를 고치는 장면에 쓴다.

**하지 않는 것.** 색종이와 소리.

### S4. `sun` — 해가 지나가는 건물

**보이는 것.** 하늘이 깔리고(three 의 `Sky`), 그 대지에서 지금 해가 있을 자리에서 빛이 들어 그림자가 진다. 바닥에는 진북 화살표가 놓인다.
HUD 아래에 날짜·시각 막대가 있어 가로로 끌면 하루가 지나가며 그림자가 건물 위를 쓸고 간다.

**데이터.**

- 위도·경도는 IfcSite 의 `RefLatitude`·`RefLongitude` 다. 도·분·초·백만분의 일초 묶음(`IfcCompoundPlaneAngleMeasure`)이다.
- 진북은 `IfcGeometricRepresentationContext.TrueNorth` 다. 방향 큐브의 앞은 진북이 아니라는 점(`nav-cube.ts` 머리)과 헷갈리지 않는다.
- 임포터는 지금 좌표가 있는지만 센다(`ifc/import.ts` 의 `siteLatLong`). **값을 읽어 내는 것이 첫 일이다.** 모델에 새 필드를 더하면
  편집 파일·자동 저장이 모델을 통째로 적는지 먼저 보고, 그렇다면 그 직렬화에서 뺀다. G3 시험이 잡는다.
- 값이 없으면 서울시청(37.5665, 126.9780)과 +y 를 북으로 쓰고, HUD 에 그렇게 그렸다고 적는다.
- **먼저 잴 것.** 성수·Duplex·병원에 좌표와 TrueNorth 가 있는지 세어 커밋에 적는다.

**해 자리.** NOAA 근사식으로 외부 라이브러리 없이 60줄 안팎이다. 시험 값은 서울 위도에서 하루 최고 고도가 하지 75.9° · 동지 29.0° (±0.5°)다.

**그림자의 값을 피하는 길.** ui-notes "3D 음영" 이 그림자를 뺀 까닭은 회전할 때마다 장면을 한 번 더 그려 성수에서 값이 두 배가 된다는 것이었다.
그런데 **그림자 맵은 해와 형상에만 달려 있고 카메라와는 상관이 없다.** `renderer.shadowMap.autoUpdate = false` 로 두고, 해가 움직이거나
모델이 바뀔 때만 `shadowMap.needsUpdate = true` 를 건다. 그러면 회전할 때는 그림자 맵을 다시 그리지 않는다.
켤 때 재질 셰이더를 한 번 다시 짓는데, 성수에서 몇 초인지 재서 적는다.

**빛.** 이 egg 동안은 카메라에 붙은 주광을 `ctx.lights` 로 낮추고 세계에 고정한 해를 쓴다. 끄면 원래대로 돌아간다.

**하지 않는 것.** HDR 하늘 그림을 받지 않는다. `Sky` 는 셰이더라 three 패키지 안에 있다.

### A. 다듬기 — 발표 뒤 보고 기본으로 올릴지 고른다

- **`refine` 멈추면 차오르는 화질(걷어냄 — MSAA 위라 차이가 픽셀 0.03%, ui-notes).** 시점이 0.25초 멈추면 다음 8프레임 동안 서브픽셀만큼 흔들어(jitter) 누적한다. 얇은 배관의 계단 현상이 사라진다.
  TAA 와 같은 원리이고 `three/examples/jsm/postprocessing` 의 `TAARenderPass` 를 참고한다. 움직이면 바로 보통 그리기로 돌아간다.
  가만히 있을 때 0장은 이 egg 동안만 "멈춘 뒤 8장, 그다음 0장" 이 된다. 2단계로 누적 뒤 `GTAOPass` 를 한 번 얹을 수 있다.
  예전에 SSAO 를 뺀 까닭이 회전 중의 값이었으니, 멈춘 뒤 한 장이면 그 까닭에 걸리지 않는다. 성수를 비스듬히 본 스샷을 켜기 전후로 붙인다.
- **`shadow` 바닥에 앉는 그림자(걷어냄 — 건물에 가려 안 보였다, ui-notes).** 모델을 열 때 한 번, 건물을 아래에서 정사영으로 512px 에 찍고 두 번 흐려 바닥 판에 붙인다(drei `ContactShadows` 수법).
  그리는 비용은 사각형 하나라 건물이 허공이 아니라 땅에 앉아 보인다. 편집 뒤에는 0.5초를 모았다가 다시 찍는다.
- **`rise` 층이 올라앉는 오프닝.** 인트로(`#intro`)는 파일을 열기 전의 구운 장면이고, 이것은 실제 파일을 연 편집기 3D 다. 인트로의 조립과
  모양이 겹치지 않게 짧고 작게 둔다. 파일을 연 뒤 첫 맞추기 때 층이 아래부터 0.08초 간격으로 한 층 높이 위에서 내려앉는다(0.4m 는 성수에서 안 보였다). 모양만 움직이고
  자리·고르기 상자는 처음부터 끝 자리다(`drop-in.ts` 와 같은 원칙). 열기 완료 신호는 늦추지 않는다. e2e 가 그것을 기다린다.
  tick 이 이미 덩어리를 한 프레임에 하나씩 켜니(`chunks`) 그 순서 위에 얹는다.
- **`wipe` 테마 원형 번짐.** 테마 단추에서 원이 퍼지며 라이트와 다크가 바뀐다(`document.startViewTransition` + `clip-path: circle()`).
  3D 는 `setDark` 가 다시 짓는다. 새 3D 가 한 장 그려진 뒤에 전환을 끝내야 검은 칸이 번쩍이지 않으니, 콜백이 다음 렌더를 기다리는 Promise 를 돌려준다.
  `still()` 이면 바로 바뀌고, 지원하지 않는 브라우저도 그냥 바뀐다.
- **눌림·포커스 상태는 egg 가 아니라 PRD 일이다.** 디자인 시스템 A5 가 정한 `:active` 의 `scale(0.97)` 100ms 와 `:focus-visible` 2px 고리가
  아직 거의 없다(`:active` 규칙이 `styles.css` 에 0개, `shell.css` 에 2개). 가장 싸게 "다듬어진" 느낌이 화면 전체에 들지만 기본 화면을 바꾸므로 OE-UI-23 이슈와 PR(`Closes`)로 간다.
  담당이 `tbd` 라 시작 전에 보드를 확인한다.

### B. 숨겨 두는 것

- **`blueprint` 청사진.** 3D 칸 바탕을 짙은 청으로 바꾸고, 벽·가구 모서리 선(`model-edges.ts` 가 이미 뽑아 둔 선)을 흰 선으로 그린다.
  면은 거의 투명, 바닥 격자는 제도 격자, 설비는 옅은 흰 면이다. 설비 모서리는 뽑지 않는다. 성수 설비가 정점 1천만 개라 `model-edges` 도 설비에는 긋지 않는다.
  다크·라이트 어느 쪽에서 켜도 같은 청사진이다.
- **`title` 방 이름 자막.** 비행 모드(`G`)에서 방 경계를 넘어 들어서면 화면 아래 3분의 1 자리에 `3F · 회의실 301` 과 그 아래 `42.3㎡ · 설비 7대` 가
  0.4초에 떠서 2초 머물고 사라진다. 게임에서 새 지역에 들어설 때 뜨는 지역 이름 오마주다. 눈 자리의 층·물리존은 점-다각형 판정으로 초당 5번 보고,
  면적은 계산 값, 설비 수는 `hasLocation` 수다. 같은 방에 10초 안에 다시 들어가면 띄우지 않는다.
  손짓은 비행 중 `Q`·`E` 를 0.12초 안에 같이 누르는 것이다. 지금 둘을 같이 누르면 오르내림이 상쇄돼 아무 일도 없다.
- **`heat` 풍량 밀도.** 물리존 바닥을 "그 방을 담당하는 말단의 정격 풍량 합 ÷ 면적(CMH/㎡)" 으로 칠한다. 값이 없는 방은 0 으로 칠하지 않고
  빗금 회색에 "값 없음" 이다. 범례에 구간 값과 방 수를 적는다. 정격 풍량은 `capacity.ts` 가 읽는 값만, 담당은 담당 공간 표(`served.ts`)가 낸 것만 쓰고,
  출처(BIM · 계산)를 범례에 붙인다.
- **`tour` 계통을 따라가는 대기 화면.** 켜 둔 동안 10초 아무 입력이 없으면 넓게 보기(`Ctrl+\`)로 UI 를 접고 위아래 검은 띠(2.39:1)를 내린다.
  그다음 `feeds` 가 가장 많은 계통을 원천(공조기)에서 말단까지 카메라가 천천히 따라간다(경로 위 3m, CatmullRom 곡선). 지나가는 설비 이름이 한 줄씩 뜬다.
  아무 입력이 오면 바로 원래 시점과 화면으로 돌아간다. 발표 전 쉬는 시간에 두 판이 나란히 켜져 있을 때를 위한 화면이다.
- **`ticker` 읽는 중인 IFC 클래스.** 파일을 읽는 동안 진행 막대 아래에 `IfcDuctSegment 3,421 · IfcAirTerminal 812 · …` 가 고정폭 글자로 오른다.
  임포터 worker 가 진행 메시지에 클래스별 수를 실어야 하므로 임포터를 건드린다. `npm run check:sample` 결과가 그대로인지 본다.
  파일을 열기 전에 켜져 있어야 해서 URL 로만 켠다.
- **`banner` 콘솔 배너.** 파일을 열면 개발자 도구 콘솔에 한 번 찍는다. 층 수만큼 줄을 쌓은 글자 건물, 그 옆에 수(설비 · 물리존 · TTL `feeds`),
  마지막 줄 `~ 를 눌러 보세요`. 기본으로 켜진 유일한 egg 다(G2 예외). DOM·3D 를 건드리지 않고, e2e 모드(`import.meta.env.MODE === 'e2e'`)에서는 찍지 않는다.
- **`cube` 방향 큐브 튕기기.** 방향 큐브를 세게 끌다 놓으면 관성으로 돌다가 가장 가까운 면에 스프링처럼 멈춘다. 지금 끌기는 그대로 두고,
  놓는 순간의 속도가 클 때만 갈린다.
- **`fold` 3D 가 접혀 평면도가 되기.** 켠 동안 `Shift+V` 가 바로 바뀌지 않고 0.6초 연출을 한다. 카메라가 위로 오르며 시야각을 줄이고 그만큼
  물러나(돌리 줌) 원근이 사라지고, 평면도(SVG)와 정확히 겹치는 순간 교차해 넘어간다. 돌아올 때는 거꾸로다.
  어려운 곳은 평면도 viewBox 와 카메라 투영을 맞추는 것이다. 기본 경로(`Shift+V`)에 분기를 넣으므로 맨 마지막에 한다.

## 5. 발표 동선

| 순간 | 꺼내는 것 |
|---|---|
| 발표 전 쉬는 시간 | `tour` |
| 첫 화면 | 이미 있는 인트로(`#intro`) — 구운 건물이 조립된다 |

| "우리 3D 는 데이터다" | `xray` — `Space` 꾹 |
| 계통 확정 `C` | `alive` — 그 계통부터 흐르기 시작 |
| 대지와 해 | `sun` — 시각 막대를 끈다 |
| 마지막 위반 고치기 | `pass` |

링크 모양: `http://<55>:8084/?open=<성수 파일들>&egg=rise,alive,pass`. 나머지는 무대에서 `~` 로 꺼낸다.
55 는 http 라 `isSecureContext` 가 거짓이다. 쓰는 API(View Transitions, WebGL)가 그 상태에서 도는지 리허설 때 본다.
