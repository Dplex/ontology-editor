## 고친 것

| ADR | 어긋남 | 고친 것 |

| 0016 ↔ 0023 | 0023 이 0016 의 "온톨로지로는 아직 내보내지 않는다" 를 바꿨다고 두 본문에 적혀 있는데 머리(`supersedes`·`superseded_by`)에는 없었습니다. 0004 ↔ 0012(별명 한 줄만)처럼 일부 대체입니다 | 0016 `superseded_by: "ADR-0023 (내보내기 한 줄만)"`, 0023 `supersedes: ["ADR-0016 (내보내기 한 줄만)"]` |
| 0034 | 제목이 "편집 파일은 이동량·지움만" 인데, OE-ML-07 층별 고치기 PR 에서 본문에 조각 모양(`parts`)을 더했습니다 | 제목·README 목록을 본문에 맞췄습니다 |

내용이 서로 엇갈리는 결정(같은 것을 다르게 정한 것)은 찾지 못했습니다. 비슷해 보여 대 본 짝: 0010 ↔ 0022(흐름 없는 기기를 빼는 것 — 형상 연결 추정과 연결 후보로 쓰임이 다름) · 0029 ↔ 0031(사람이 그린 배관도 0029 의 구간·이음쇠 사슬) · 0014 ↔ 0034(층 없는 편집은 건물 조각 — 0034 가 그 규칙을 따름) · 0032 ↔ 0034(다중층 작업 하나 = 이력 하나, 같은 말).
