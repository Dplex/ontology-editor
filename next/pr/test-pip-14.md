## 요약

OE-PIP-14(BIM 배관 가져오기)의 수용 기준을 지금 동작에 대 보았습니다. 다섯 가지 중 넷은 이미 들어간 기능으로 충족되어, 빠져 있던 "재임포트" 와 "출처 구분" 검증을 실제 BIM 시험으로 더했습니다. 코드는 바꾸지 않았습니다.
Flow Type 에 따른 표시는 BIM 배관에 Flow Type 을 붙일지에 대한 PM 확인(수동 배관 PR #192 의 `needs-pm`)을 기다립니다. 그래서 #195 는 닫지 않습니다.

## 구현한 것

`scripts/check-sample.test.ts` 에 "BIM 배관 다시 열기 (OE-PIP-14)" 두 시험을 더했습니다.

- **Duplex HVAC 를 다시 열기**
  - 편집: 엘보 #582938 을 0.3m 옮기고(양쪽 구간 둘이 늘어남), 배수관 #582951 – 샤워 #582917 의 포트 연결을 해제 보정합니다
  - 같은 파일을 새로 열어 편집 파일을 얹으면
    - 설비·배관 수가 새로 연 것과 같습니다(중복 없음)
    - 연결은 해제 보정한 하나만 빠지고, 해제 보정 목록에 그 연결이 남습니다(자동으로 되살아나지 않음)
    - 늘인 두 구간의 경로가 편집한 쪽과 같습니다
- **Duplex MEP · MEP-2(다시 낸 판본)**: 포트가 없는 파일이라 연결이 모두 형상으로 이은 것입니다. 출처가 모두 `geometry` 이고 방향이 없습니다(MEP 783개 · MEP-2 504개).
